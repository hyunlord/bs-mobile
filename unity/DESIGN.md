# Sow & Siege — First Playable 디자인 시스템

## 현재 방향: 휴경의 왕국 황금 1분 (#197)

wave-1a의 새봄의 터에서는 아래 역사 계절 지형색 대신 `FallowAsh #797B79` 회색 왕국을 사용한다. `WorldFallow`는 실제 작업 상태를 128² 월드 마스크로 투영한다. 파종/싹의 세이지, 익음의 황금, 건물의 온기를 RGB에 두고 A는 복원 범위다. 0.1초 간격으로 갱신하며 실제 수확만 1.4초 확산한다. 반경 0.42→0.95, 건물 1.3은 시각 단위이고 게임 판정에 전달하지 않는다. 셰이더 종이 얼룩은 월드에 고정되어 카메라 이동에 따라 흐르지 않는다. 적·영주·아군·공격·경험치는 복원 셰이더 밖에 둔다.

독립 고랑·길·물길·다리·죽은 나무·물레방아·석표 자산은 배경 레이어다. 실제 작물·건물만 성장 상태에 따라 바뀐다. 새 아트 역할은 wave-1a manifest에만 연결하고 기존 프로필은 보존한다. 각 그림은 원본 alpha와 종횡비·발/기초 pivot을 유지한다. 영주의 코발트 외곽과 적 붉은 표식을 전면 흑백 효과로 지우지 않는다.

세로900×1600 기준 HUD 상단104, 하단156, 슬롯76. 위치 이름은 좌상단, 실제 체력·레벨은 가운데, 시간·일시정지는 우측이다. 하단 무기5·도구4의 표현 칸은 슬롯 상한 변경이 아니며 빈칸은 소유한 것으로 꾸미지 않는다. 타이틀 배경·한국어 로고는 별도 자산, 시작/설정/출정 준비는 실제 버튼이다. OS 글꼴 제목 fallback은88이며 일반 본문 토큰은 유지한다. 한국어만 표시한다.

최종 확인은 실제 Mac Release 첫 1분과 A-battle/A-title 나란히 비교다. 별도 성능 측정은 하지 않고 #98을 보류한다. 아래 이전 기록은 역사 동작의 설명이며 위 범위의 시각 방향이 우선한다.

## 1. 분위기와 정체성

잉크 윤곽 위에 과슈 색을 얹은 판타지 변경의 살아 있는 영지. 황금 수확과 푸른 일꾼이 자라는 동안 붉은 약탈자가 밀려온다. 같은 장면 후보3개 중 사용자 지정1안을 채택했다. 목업은 방향 참고이며 실행 화면 증거가 아니다. 실제 화면의 배경 꽃·풀 밀도와 건물 크기는 목업보다 줄여 적과 공격이 먼저 읽히게 한다. Core의 역할·상태를 그림으로 연결하며 그림은 규칙을 소유하지 않는다.

## 4. 간격과 배치

간격 토큰4/8/12/16/24/32/48, 최소 터치 높이88(Canvas 기준). 세로900×1600 기준, 안전 영역 내 여백24. 펼친 비율에서도 HUD와 카드가 안전 영역을 지키며 월드 카메라 시야를 유지한다. 상시 거대 패널은 없다. 상단 체력/XP/계절·시간, 그 아래 작은 장비 행, 하단 이동 엄지 영역만 항상 보인다. 카드·설정·결산은 해당 상태일 때만 나타난다.

탑다운3/4 그림을 정사영 월드에 배치한다. 900px 너비의 기준 시야 목표 크기: 영주64–76px, 일반 적40–60px, 정예76–96px, 보스120–148px, 백성40–52px, 작물36–52px, 건물76–110px. 실제 카메라 줌에 따른 변화는 정상이며 최종 Editor/폰 캡처에서 판독성을 확인한다. 큰 건물은 적을 가리는 상부 면을 줄인다. 그림 pivot은 발/기초, 공격 중심은 Core 원점과 일치한다. 좌표·이동·공격 사거리를 그림 크기로 바꾸지 않는다.

카메라는 전체 화면을 유지하며 영주를 HUD·하단 조작 영역·노치를 제외한 사용 가능 영역의 중심으로 부드럽게 추적한다. 지도 경계 밖 기본 여백은1 Unity 단위이며, 각 방향에서 UI가 제외한 픽셀만 현재 줌의 월드 단위로 환산해 추가하여 발 pivot의 큰 그림을 보존한다. 세로1600px를 기준으로 낮은 화면 높이에서는 최대 줌아웃을 줄여 정사각 화면의 실루엣 축소를 막는다. 안전 영역·HUD와 영주가 겹치지 않는지는 실제 UI 통합 화면에서 별도로 검증한다.

## 5. 재사용 구성 요소

- 월드 그림: 역할 ID→atlas/rect/pivot/시각 크기/애니메이션 계약. 동일511개 인스턴스 묶음으로 그리며 적마다 GameObject를 만들지 않는다. 없는 역할은 검증 실패, 도형 대체물로 숨기지 않는다.
- HUD는 높이160 이내의 작은 정보 배경·바·아이콘 행과88 높이 설정 버튼으로 구성하며 전체 폭을 덮는 큰 종이 패널을 쓰지 않는다. 결산 재시작/나가기는 빌드 아이콘 목록보다 먼저 표시한다.
- 장비 아이콘: 과슈 그림과 동일 잉크 가장자리, HUD 작은 슬롯과 카드 큰 슬롯이 같은 소스를 사용한다.
- 종이 패널/카드: 역할 Sprite의 원본 rect/texture에서 경계 비율20%의 실제 border를 가진 UI 전용 Sprite를 캐시해9-slice로 그린다. UI pixels-per-unit multiplier2로 경계의 화면 두께를 고정하고 패널48/카드36 내부 여백을 둔다. PNG/atlas 좌표를 바꾸지 않는다. Common/Uncommon/Rare 등 실제 희귀도에 맞는 일관된 테두리와 텍스트. 고정·금지·선택 상태는 명시적 배지.
- 버튼/토글/슬라이더/엄지 조작: 파란 주 버튼에는 밝은 Attack색 글자, 밝은 보조 토글에는 Ink색 글자를 둔다. 그린 종이·가죽 표면, normal/pressed/disabled 및 실제 입력 상태. 내부 uGUI 이벤트 컴포넌트 사용은 허용하되 기본 스프라이트 외형은 사용하지 않는다.
- 알림: 실제 계절 전환과 보스 출현에 1.8초 종이 배너를 표시한다. 영주가 상단에 있으면 아래, 그 외에는 위의 안전 영역에 배치한다. 보스 경고를 우선하고 겹친 계절 알림은 뒤에 표시한다. 정예를 보스로 알리지 않는다. 한 번만 표시하는 안내는 M3에서 연결한다.

구현 중 생기는 반복 패턴은 이 절을 갱신한다. 아직 미구현인 구성 요소를 완료됐다고 보고하지 않는다.

## 6. 움직임과 상호작용

Press100ms, Panel220ms, Emphasis450ms, SeasonBlend1800ms. actor walk bob/lean 주기300–450ms, 피격 번쩍임90ms, 처치 파편320ms, 수확 금빛480ms, 경험치 흡수420ms. 2–4프레임 또는 의도적인 트윈을 역할 메타데이터에 명시한다. Core 공격의 위치·나이·수명·넉백을 표현하며 Unity에서 두 번째 공격 시뮬레이션을 만들지 않는다.

실제 이벤트 ID로 중복 연출을 방지한다. 레벨/계절은 실제 프레임 전환으로 판별한다. 화면 흔들림·피해 숫자·진동·음량은 사용자 설정을 따른다. 카메라 흔들림은 작은 시각 오프셋이며 월드 입력 좌표·충돌에 영향을 주지 않는다. 실제 전달되지 않은 피해 귀속이나 보스 출현을 추정해서 표시하지 않는다.

피해 숫자는 실제 양을 바꾸지 않고 타격점 주변의 겹치지 않는 위치에 띄운다. 주변이 가득 찬 경우 추가 숫자를 겹쳐 잘못된 큰 수처럼 보이게 하지 않는다. 게임 피해와 이벤트 기록은 그대로 유지한다.

## 7. 깊이와 표면

전략은 그린 잉크 윤곽과 국소적인 과슈 명암이다. 웹식 떠 있는 카드 그림자·유리 효과·발광 테두리를 혼합하지 않는다. 지형은 저대비, 밭/건물은 낮은 레이어, 아군/공격/적/영주는 명시적 순서로 구분한다. 큰 시각 효과의 alpha와 지속시간을 제한하되 게임 플레이 객체나 필수 연출을 성능 점수를 위해 숨기지 않는다. PNG 실제 alpha를 보존하고 검은 배경·프린지·이웃 atlas 셀 번짐을 실제 GPU 캡처로 확인한다.

지형 질감의 기본 alpha는0.45, 지속 장판0.10, 넓은 공격0.26, 이동 투사체0.72다. 공격 개수에 따라 전체 효과를 지우지 않고 각 실제 공격을 계속 그린다. 지형의 투명 장식 테두리는 런타임 UV 안쪽16%를 사용해 제외하며 원본 PNG 픽셀은 수정하지 않는다. 간격 없이 배치한 인접 타일의 UV를 가로·세로로 번갈아 반전해 맞닿는 색과 무늬를 연결한다. 셀 안쪽 반 texel 보정은 반전 부호를 따라 이웃 atlas 영역의 번짐을 막는다.

성공 조건은 계약 검사와 실제 Editor 세로/펼침 비율, 실제 Fold7 화면이다. 목업·정적 파일 수·CI만으로 시각 관문을 통과시키지 않는다.

## 판 밖 성장 화면

변경 지도·장원·가신·도전은 기존 종이 패널 안의 세로 스크롤로 구성한다. 카드 표면은 `ui.card.common`, 내부 여백은 CardInset36, 간격 Gap16, 제목 Heading30, 본문 Body26, 보조 Small22, 버튼 TouchHeight88을 공유한다. 데이터의 아트 역할을64 단위 초상으로 표시하고 이름·효과·재료·현재/상한·잠김 이유는 실제 상태 텍스트로 그린다. 변경마다 새 페이지를 만들지 않고10개 데이터를 같은 구성 요소로 그린다. 장원은 수동 건설 버튼 대신 우선 깃발 하나만 제공한다. 가신의 동행 슬롯·강화 비용과 상한·조각 승급 조건을 함께 보여준다. 결산은 획득·상한 초과·자동 성장·도전 해금을 구분한다.

챕터 지형은 데이터의 정규화된 영역과 실제 지형 그림을 월드 지형 레이어에 타일링한다. 도구 아이콘은 강·숲·언덕 지형의 대체물이 될 수 없다. 지형은 TerrainOpacity0.45를 유지해 적과 밭의 가독성을 보존한다. 새 화면의 클릭·스크롤·세로/펼침 비율과 한글은 실제 Unity 캡처 관문에서 검증해야 한다.

장원의 실제 자동 성장 결과만 초상에 강조한다. `GrowthStartScale0.82`에서1로 `EmphasisSeconds0.45` 동안 부드럽게 확대하며 성장 완료 문구를 함께 표시한다. 애니메이션은 Transform 배율만 바꾸고 레이아웃이나 Core 상태를 변경하지 않는다.

## wave-1a의 작업과 무리 표현

`Wave1aArt`는 기존 아트 역할을 재사용하면서 물받이·목공 작업소·방패 파편·발효 말벌·상아왕의 실제 상태를 별도 그림으로 표현한다. 새 wave atlas(actors·growth·fx·icons·arcs)의 패딩은 생성 원본의 미세한 alpha를 보존하며 최대16/255까지만 허용한다. 실제 바깥 패딩 전체 검사에서 최대9/255를 확인했다. 기존 atlas의 완전 투명 패딩 규칙은 유지한다. 이 수치 검사는 GPU에서 테두리·번짐이 없다는 시각 확인을 대신하지 않는다.

훈련된 무리는 Core 엔티티 하나에 대표 스프라이트 둘을 사용한다. `GroupRepresentativeOffset=0.22`는 저작된 스프라이트 너비에 대한 표현 간격이다. 실제 `FrontRank`와 `Formation`이 전열·엄호 자세를 바꾸며, 이 표현 간격을 충돌·공격 반경에 사용하지 않는다. 성장·출고·관개·귀환 경험치는 각각 실제 Core 사건에서 표현하고, 완료 전 금빛 수확을 미리 그리지 않는다.

가공 목재 꾸러미는 실제 출고 후보 수량을 바탕으로 표시하며 `StockBundleScale=0.28`의 표현 배율을 쓴다. 원목 더미는 Core의 원래 위치와 남은 재고를 표시한다. 판매 가격이나 장원 지급량을 추정하지 않는다.

wave-1a 시각 보정은 역사 프로필에 적용하지 않는다. `WaveTerrainOpacity=0.18`로 바닥 대비를 낮춘다. 작물은 실제 농장 간격의 `WaveCropSpacingFraction=0.8` 이내 너비로 저작 비율을 유지하며 축소하고 `WaveCropOpacity=0.8`을 쓴다. 경계에 걸친 그림만 지도 안쪽으로 맞추며 Core 위치는 바꾸지 않는다. 카메라는 전체 뷰포트를 지도 안에 제한하고 울타리는 변 길이를 균등 분할해 배치한다(`WaveFenceOpacity=0.65`). 적의 깊이는 실제 Y좌표로 50~69 레이어를 사용하며, 영주는 79 레이어의 잉크 실루엣 네 방향 `WaveHeroOutline=0.045`과 기존 80 레이어로 구별한다. 모든 실제 개체를 그대로 그리며 개체 수나 판정 반경은 바꾸지 않는다.

새싹 길은 실제 `PathSpacing`의 `WavePathSpacingFraction=0.8` 안에 저작 종횡비를 유지한다. 지도 가장자리에서는 영주 그림 최대 변의 `WaveEdgeActorMargin=0.8`만큼 카메라 여백을 허용하고 그 부분까지 같은 지형을 연속해서 그린다. 울타리는 실제 이동 경계에 남아 비플레이 영역과 구분한다. 영주가 경계에 도달해도 그림을 자르거나 Core 위치를 옮기지 않는다.

wave 검·낫 90도 공격 아트는 그림의 피벗을 실제 공격 원점에 놓고, 피벗에서 유효 alpha 픽셀까지의 최대 반지름이 월드1단위가 되도록 manifest `worldSize`를 정규화한다. 렌더러는 이 저작 크기에 Core 사건의 반지름만 곱한다. 정사각형을 2R로 늘리거나 가운데 피벗으로 돌리지 않으며, 회전은 실제 사건의 원점→목표 방향을 따른다.

원목 더미는 `WaveTimberSourceScale=0.42`로 저작 크기를 줄여 영주보다 큰 장애물처럼 보이지 않게 한다. 남은 원목 비율의 제곱근 배율과 실제 원점은 유지한다. 목표 재료 타이틀은 초기 미선택 상태를 명시하고 선택한 버튼에 `선택됨`을 표시하며, 선택마다 같은 화면을 갱신한다.

wave 영상의 밀집 장면에서는 방패 파편을 `WaveFragmentScale=0.32` 이하이면서 실제 파편 충돌 지름 안에 그린다. 중심·궤도·생존 시간은 Core 그대로다. 작업소와 연결 지붕은 `WaveWorkshopScale=0.48`, 물받이는 `WavePoolScale=0.48`·`WavePoolOpacity=0.65`, 출고 꾸러미는 기존0.28배다. 젖음·정지 표시는 `WaveStatusScale=0.36`·`WaveWetOpacity=0.38`로 낮은 성장 레이어에 두고, 젖음의 높이만 `WaveWetHeight=0.55`로 눌러 지면 표시로 읽히게 한다. 영주 잉크 윤곽은 `WaveHeroOutline=0.045`이다. 실제 진화 사건의 기존0.45초 강조만 78 레이어로 올려 성장물에 가리지 않게 하며 지속 공격을 새로 만들지 않는다.

## 1a 혼잡 판독 보정 (#168)

영주 발밑 표식은 실제 보간 위치의 얇은 이중 타원이다. `WaveLordRingRadius=0.34`, 세로 비율0.55, 외곽 Ink·안쪽 Attack, 안쪽 반지름0.82, 밝은 안쪽 띠의 배율0.94·안쪽 반지름0.9를 사용한다. 실루엣 잉크 폭은0.045다. 영주 탐색 표식은 공격 반경을 뜻하지 않는다. 적은 실제 발 피벗을 유지하고 일반 적 그림의 긴 변만 `WaveEnemyMaxSize=0.64` 이내로 제한한다. 말벌 그림에는 추가0.82배 표현 배율을 적용한다. 보스는 크기 제한에서 제외한다. 인접 적을 밀거나 지우지 않는다.

공격의 넓은 과슈 면은40 레이어를 유지한다. 실제 공격 alpha 안쪽 가장자리만70 레이어에 최대0.72 불투명도로 덧그린다. 적 예고·활성 위험은72 레이어이므로 내 공격 윤곽보다 먼저 읽힌다. 윤곽은 atlas 내부2 texel 또는 화면1.25px 중 큰 간격의 이웃 검사로 만들며 원래 공격 alpha 밖에 새 판정처럼 번지지 않는다. 파종 검무는 금빛 검 윤곽과 실제 새싹 발생점의 묘목 강조를 함께 사용한다. 새싹 발생점을 가상의 연속 궤적으로 채우지 않는다.

익은 밭은 기존 크기 안에서 실제 익음 상태에만 짧은 밝은 가장자리를 유지한다(`WaveRipeEdgeOpacity=0.55`). 떨어진 경험치는 크기0.18·불투명도0.55이며 성장 레이어에 두고 상시 반짝이지 않는다. 실제 `reward-collected`만0.42초 동안 원래 경험치 위치에서 영주 쪽으로 작은 금빛 흡수 흔적을 그린다. 수확과 익음을 섞지 않는다.

성장 카드는 본문·제목·아이콘을 포함한 종이 면 전체가 선택 버튼이다. 금지·고정은 선택 면 밖의 형제 보조 행에 둔다. 비활성 보조 동작을 눌러도 선택으로 전달되지 않는다. 레벨업 설명은 변경된 성장표를 비교해 '더 넓게 공격', '더 자주 공격' 등 실제 체감 방향만 표현하고 월드 단위 범위·속도를 노출하지 않는다. 카드 출현 빈도나 실제 수치는 바꾸지 않는다. 세로·정사각 UI와 일반 속도 혼잡 녹화의 관문은 별도 실행 검증이며 코드만으로 통과하지 않는다.

공격 윤곽은 같은 alpha 안쪽을 사용한다. 검무는 바깥 윤곽과 그 안의0.78배 잉크 곡선을 짝지어 일반 검의 단일 곡선과 구분한다. 영주 몸통과 겹치는 일반 적 상부만 불투명도0.55로 낮추며 발·피격·예고 자세는 보존한다. 일반 적 몸통 크기를 줄여도 실제 적 수·좌표·피격 범위는 그대로다.

### 혼잡 일반 녹화의 공격 대비 보정 (#168)

### 혼잡한 수확 인과와 번개 (wave-1a 보정)

일반 A03/B02에서 익은 밭·실제 수확·경험치 흡수가 적/차양에 묻히고, 번개는 본체가 적 아래에 가려지는 실패를 보존한다. 번개의 같은 경로·끝점·수명에 화면 기준1.25px 밑선과 본체를70/71층으로 그린다. 두 인스턴스만 사용하고 적 예고72와 영주보다 아래에 둔다.

가까운1.2월드 단위 안의 살아 있는 익은 밭 한 곳에 작은 이삭을 표시한다. 최초에는 거리·ID 순으로 선택하고, 여전히 익어 있고 범위 안이면 같은 밭을 유지해 깜빡임을 줄인다. 수확·파괴·상태 변경·범위 이탈·프로필 초기화 때 즉시 제거한다. 링·조준 표시나 실제 상호작용 범위를 만들지 않는다. 실제 `harvest-complete`만 짧은 상승 이삭(동시에 최대3개), 양수 `reward-collected`만 최근 획득 하나의 흡수 효과를 표시한다. 경험치 수치는 Core 그대로이며 바닥 방울의 작은 크기·낮은 대비는 유지한다. 수리 대상의 방패 표식도 실제 영주 밖 미완성 건물에만 붙인다. 해당 모양과 판독성은 새 일반 녹화로 검증하며 진단 재생만으로 통과하지 않는다.

### wave-1a 성장 사건의 문구

근처의 실제 익은 밭 한 곳에는 `익음`, 실제 양의 경험치 수집에는 `수확 +N XP`(작물) 또는 `완료 +N XP`, 현재 수리 중인 실제 건물에는 `수리 중`을 표시한다. 최대 세 문구와 각 잉크 그림자만 풀링한다. 경험치 문구는 실제 수집 사건의 양을0.9초 동안 영주 위에 표시하며 HUD 증가나 남아 있는 드롭을 경험치 지급으로 추정하지 않는다. 새 카탈로그·null 스냅샷·해당 상태 종료에서 문구를 없앤다. 이 표현은 적/영주/공격 예고보다 낮은 월드 그리기 순서를 유지한다. 골드 드롭 전체를 확대하거나 성장·보상 수치를 바꾸지 않는다.

### A02 실제 화면 비교 후 보정

바닥만 별도 FallowGroundSprite로 대비를 줄이고 타일2.6으로 바위 크기를 낮춘다. 소품은 원본 픽셀 종횡비를 보존하고 시작 영지 주변에 배치한다. 실제 작물 각각의 파종/싹/익음 표시 최소 너비는0.28/0.34/0.40, 집·작업장과 진화 지붕은 표시 배율1이다. 개수·좌표·성장 시간·충돌을 바꾸지 않는다. 복원 바닥의 세이지·금빛을58% 섞어 회색과 구별한다. 타이틀 보조 버튼/일시정지는 차콜 #2E3235 종이, 체력은 상아색이며 반복 빈칸 글자는 표시하지 않는다. 프레임 배율5는 장식 두께만 줄인다.

### 작은 화면 UI 판독 보정 (#204)

Fallow 시작 버튼은 기존 `ui.button.secondary`의 상아 종이·금속 모서리 장식을 실제 버튼 배경으로 사용한다. 부제는 Heading30과 88% 종이 바탕으로 구름과 분리한다. 출정 준비에는 목표 재료 선택 동작, 선택한 실제 도구 아이콘·재료명·변경 동작을 표시한다. 진화 단서는 FallowEvolution32로 표시하며 진화 이름/상태, 필요 장비, 지도 조건을 각각 줄로 나눈다. 규칙과 요구 장비는 원래 실행 데이터다.

조이스틱 입력 반경120은 유지한다. 기존 atlas에서 base alpha bounds174×174, thumb153×153을 중심 pivot으로 잘라 표시하고 각각 지름240·80으로 그린다. 손잡이 표시 이동은 입력 최대 반경을80으로 사상해 손잡이 전체가 바탕 안에 남는다. 화면 pixel→Canvas 변환과 PlayerInput 정규화는 변경하지 않는다. 새 텍스처·의존성은 없다.
