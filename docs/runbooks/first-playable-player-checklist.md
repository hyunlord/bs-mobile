# 첫 플레이 가능판에서 해 볼 것

전달 준비용 목록이다. [M4 실기 관문 #98](https://github.com/hyunlord/bs-mobile/issues/98)이 끝난 뒤 검증한 APK와 함께 전달한다. 현재 폴드7 설치·실기 시험은 보류 중이다.

처음에는 아래 표를 읽기 전에 게임 안의 안내만 보고 시작해 본다. 최대15분 동안 봄부터 겨울까지 버티는 판이며, 체력이 다하면 결산으로 넘어간다. 설명을 더 찾아야 했던 순간도 중요한 피드백이다.

## 한 판에서 확인할 것

| 해 볼 것 | 알려 줄 내용 |
|---|---|
| 타이틀에서 **시작**, 첫 안내에서 **개척 시작**을 누르고 빈 화면을 끌어 이동 | 처음 무엇을 해야 하는지 알겠는가? 한 손으로 이동하기 편한가? |
| 처음 나온 성장 카드를 읽고 선택 | 아이콘·효과·현재→다음 변화가 이해되는가? 더 강해진 점이 화면에서도 보이는가? |
| 무기와 도구를 함께 고르고 영지를 지나며 익은 밭과 백성을 관찰 | 도구가 공격과 성장에 무엇을 했는지 보이는가? 수확·징집 안내가 도움이 되는가? |
| 카드의 진화 단서를 읽고 필요한 조합이 나오면 시도 | 필요한 조건을 알 수 있는가? 실제 진화가 일어났다면 변화를 알아챘는가? |
| 계절이 바뀌고 적이 몰릴 때 영주·적·아군·공격을 구별 | 놓친 위험이나 가려진 대상이 있는가? 손맛과 소리가 상황을 알려 주는가? |
| 겨울 끝까지 생존했다면 보스를 만나고, 종료 후 결산 확인 | 보스의 등장이 분명한가? 이번 판의 성장과 피해·수확 결과가 이해되는가? 한 판 더 하고 싶은가? |

원하는 카드나 진화가 나오지 않아도 괜찮다. 나온 선택지 안에서 해 보고, 보지 못한 것은 보지 못했다고 남긴다. 사망했다면 그때까지의 경험을 적고 **다시 하기**를 사용하면 된다.

## 필요할 때 비교할 설정

**설정**에서 이동 방향 조준과 가까운 적 자동 조준을 비교한다. 화면 흔들림·피해 숫자·진동을 끄거나 소리를 조절해 편한 상태를 찾아본다. 판이나 카드 화면으로 돌아왔을 때 진행과 선택지가 자연스럽게 이어지는지도 확인한다. 물리적으로 접고 펼치는 시험은 별도 일정으로 남겨 둔다.

## 짧게 남길 피드백

- 가장 재미있었던 순간과 가장 답답했던 순간.
- 설명이 더 필요했던 화면이나 읽기 어려웠던 글자·대상.
- 문제를 봤다면 당시 계절·대략 남은 시간·직전 조작, 가능할 때 화면 한 장.

개발 메뉴나 기록 파일을 직접 찾을 필요는 없다. 자체 실기 검증과 원자료 수집은 담당 에이전트가 수행하며, 이 목록은 사용자의 첫 판정에 쓰인다.
