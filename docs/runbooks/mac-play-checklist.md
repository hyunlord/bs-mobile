Gatekeeper 경고가 나오면 `.app`을 우클릭 → **열기**로 실행합니다. 그래도 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에서 이 앱을 확인합니다.

# 맥에서 Sow & Siege 해 보기

`phase2a-mac-play-01`은 메타 없는 첫 플레이 가능판이며, P4 재배포 `phase2a-mac-play-02`는 챕터·장원·가신·도전을 포함하는 Apple Silicon 맥용 실행판입니다. 앱은 [Release phase2a-mac-play-02](https://github.com/hyunlord/bs-mobile/releases/tag/phase2a-mac-play-02)에서 받을 수 있습니다. 정상 한 판 자동 실행을 검증했고 화면4장과 초반·후반 각180초 Editor 영상 표본을 제공합니다. Release의 배포 ZIP을 풀고 `Sow and Siege.app`을 실행합니다. Unity 에디터 설치는 필요하지 않습니다. 공증된 App Store 배포판은 아니며, 위 절차는 [Apple의 앱 열기 안내](https://support.apple.com/en-us/102445)를 따릅니다(확인: 2026-10-09).

## 조작

| 할 일 | 조작 |
|---|---|
| 영주 이동 | WASD 또는 화면의 빈 곳을 누른 채 끌기 |
| 성장 카드 선택 | 원하는 카드 클릭 |

비율 전환은 현재 디스플레이에 맞춰 창을 줄입니다. 실제 폴더블 기기의 접기 검증을 대신하지 않습니다. 마우스를 끌고 있는 동안에는 마우스 방향이 우선합니다. 카드·설정에서 돌아온 뒤에는 WASD를 한 번 놓았다가 다시 누릅니다.

## 첫 판에서 해 볼 것

1. 타이틀에서 시작하고, 게임 안의 첫 안내만 보며 이동해 봅니다.
2. 무기와 도구를 함께 선택합니다. 수확과 징집이 전투에 어떻게 이어지는지 관찰합니다.
3. 설정에서 이동 방향 조준과 가까운 적 자동 조준을 비교합니다.
4. 봄부터 겨울까지 최대15분을 버팁니다. 사망하면 그 지점에서 결산합니다.
5. 결산 내용을 읽고 **다시 하기**를 눌러 다음 판을 시작합니다.

## 판 밖 성장도 해 볼 것

1. 챕터 선택에서 열린 챕터와 잠긴 챕터를 구분하고 첫 챕터를 시작합니다.
2. 결산에서 자재 환산과 실제 지갑 변화, 자동 장원 성장을 비교합니다.
3. 장원 우선 깃발을 바꾸고 가신 강화·출전 슬롯·도전 해금 조건을 확인합니다.
4. 종료 후 다시 실행하여 챕터·장원·가신·도전 진행이 유지되는지 확인합니다.

경제 수치는 조정 중입니다. 수정 전 21일 관측에서 보통 챕터6·10 도달이 목표보다 빨랐으며 [#126](https://github.com/hyunlord/bs-mobile/issues/126)의 기준·보정안 결정은 대기입니다. 수정 후420판·483행도 직전 정본과 바이트까지 같았습니다. 보통의 챕터3/6/10 첫 시도2/3/12일·첫 클리어2/3/15일과 지갑 상한/장부 통과·페이싱 실패를 유지합니다. 보정 후보는 미적용입니다.

재미있었던 순간, 답답했던 순간, 설명이 더 필요했던 화면을 짧게 알려 주세요. 오류가 보이면 계절·남은 시간·직전 조작과 화면 한 장이 도움이 됩니다.

## 검증 범위

맥 에디터 영상의 자동 입력 여부와 실제 맥 Release 실행 결과는 각 Release 설명에 별도로 적습니다. 사용자 결정으로 깨끗한 OS 계정·외부 입력 관문은 [앱 내부 자동 실행 관문 #129](https://github.com/hyunlord/bs-mobile/issues/129)으로 대체했습니다. 과거 [#114](https://github.com/hyunlord/bs-mobile/issues/114)의 미검증 기록은 통과로 바꾸지 않습니다. 사람이 클릭하고 조작하는 확인은 사용자가 맡습니다. 폴드7 실기 [M4 #98](https://github.com/hyunlord/bs-mobile/issues/98)은 계속 보류 중입니다.

## 앱 자체 자동 실행 증거

다음 옵션은 게임 자신의 입력과 렌더 화면만 사용하며 macOS 화면 기록·손쉬운 사용 권한을 요구하지 않습니다. 일반 실행에는 자동 조작이 없습니다.

```sh
"Sow and Siege.app/Contents/MacOS/Sow and Siege" --autoplay-capture --capture-output "$PWD/new-capture"
```

출력 폴더는 새 경로 또는 빈 폴더여야 합니다. 독립 저장으로 타이틀→정상 속도 한 판→결산→재시작을 실행하고 화면 네 장과 실행 결과를 저장합니다. 성공 종료 코드 0은 생존·겨울 보스 격파·결산·재시작과 리플레이 검사가 모두 끝났다는 뜻입니다. 실패 기록을 성공으로 대체하지 않습니다. 이 옵션에서는 포커스가 없어도 진행하며, 사람 조작이나 폴드7 성능을 검증하지 않습니다.

## 현재 알려진 범위

공개 앱의 정상 한 판 생존·보스 처치·결산·재시작과 입력 재생 일치를 확인했습니다. 전체 Recorder 실행도 별도로 검증했습니다. 초반 영상은 이후 실패 경계를 명시한 기존 실행의 유효 표본이며, 후반 영상은 정상 완주한 별도 실행의 표본입니다. 밀집 장면과 일부 대비에는 작은 한계가 있습니다. 장원 화면의 대장간 이름이 중복되어 구분이 다소 모호한 점은 남아 있습니다. 공개 파일과 준비 상태는 [Release](https://github.com/hyunlord/bs-mobile/releases/tag/phase2a-mac-play-02), 기술 검증 기록은 [설계 문서의 전달 관문](../design/02_BM_경제_골격_v0.2.md#현재-전달-관문과-증거)을 확인합니다. 사람이 클릭하고 조작하는 확인은 사용자가 맡습니다. 경제 페이싱 실패와 폴드7 보류는 유지합니다.

## wave-1a 캡처의 선택적 회피 입력

`--autoplay-capture --capture-movement evasive` 또는 Recorder의 `P1_CAPTURE_MOVEMENT=evasive`는 영상 표본용 일반 이동 입력만 바꾼다. 기본값은 기존 이동이다. 현재 영주 주변1800단위의 살아 있는 적과 이미 표시된 돌진·물길 예고만 읽고, 성장 목표 방향과 최대450단위의8방향 후보를 비교한다. 적과 예고 선분에서200단위 여유를 두려 하며 안전한 성장 방향은 유지한다. 이 값은 입력 보조의 관찰·이동 거리이며 Core 공격·피해·충돌·시간 설정을 바꾸지 않는다. 순간이동·HP/자원 지급·적 제거·가속은 없고, 선택된 목표는 기존 포인터 이동 경로에만 전달한다. 표본 기록에 옵션을 명시하며 이 입력의 생존을 정책 우세나 생존율 관문으로 판정하지 않는다.

Recorder에만 `P1_CAPTURE_MOVEMENT=evasive P1_CAPTURE_EVASION_AFTER_TICK=9000`을 함께 지정하면9000틱 전에는 기존 성장 목표 이동, 이후에는 위 회피 입력을 사용한다. 생략 시 임계값0으로 기존 선택 모드가 즉시 적용되며 음수·비정수는 거부한다. 값은 시작 때 한 번 읽고 정확한 계획과 전환 틱을 Recorder ledger에 남긴다. 이는 초반 성장과 후반 보스 장면을 한 표본에 담기 위한 편집기 캡처 입력이며 앱 옵션·Core·HP·시간·적 생성은 바꾸지 않는다.
