# ADR 0014: 결과를 보기 전에 리그 판정 규칙을 고정한다

- 상태: 채택, R2 / #56 / #58
- 사전 선언: [S4b-protocol](../league/S4b-protocol.md)

## 결정과 근거

기존 S4는 전원 생존, 정책별 이동 차이, mixed와 random의 동일 원장으로 설계 차이를 분리하지 못했다. 기존 결과와 FAIL은 보존한다. 새 실험은 별도 프로필과 산출물 이름을 사용하고, 기존 S2·S4 실행의 해시와 RNG 경로를 유지한다.

A는 여섯 카드 정책의 실제 이동을 같은 영지 기준 결정 함수로 통제한다. B는 random 카드 정책에서 세 이동만 비교하며 관문을 대신하지 않는다. mixed는 기존 네 정책 범주 중 가장 적게 소유한 범주를 우선한다. 소스 종류 세 개를 네 정책 범주로 오인하지 않는다.

전역 위협과 비선형 XP는 별도 data JSON에 둔다. seed1000–1031의 기준 봇으로 최대 여섯 완전한 후보를 평가한다. 생존율과 생존자 레벨 목표를 함께 충족한 첫 후보를 고정하며, 없으면 여섯 번째 후보의 실패를 보존한다. 평가 seed42–73은 고정 이후에만 실행한다. 이 seed는 기존 S4와 같으므로 완전히 새로운 맹검 표본이라고 주장하지 않는다.

## 판정과 증거

순위는 생존·도달 틱·레벨·실제 귀속 피해만 사용한다. 식량·자재 보유량은 점수가 아니다. 네 특화 정책을 세 사람 규칙 묶음에서 모두 1위로 요구하는 관문(c)는 정확한 공동 1위가 있어야 통과한다. 해석의 제약은 #57에 남기되 임의 오차나 사후 순위 변경으로 통과시키지 않는다.

결정론 반복은 독립 표본이 아니다. 실제 사망 이후 좌표를 채우지 않으며, 미수확 밭의 관측 종료는 우측 검열로 별도 집계한다. 유효성 검증 실패 시 통계 결론을 보류한다. 밸런스 관문 실패는 원인 가설과 후속 실험을 남긴 정상적인 결과다.

전체 원자료는 ADR0012에 따라 Release에 보관하고 요약·해시·재현 명령만 저장소에 둔다. R3은 동결한 R2 수치와 프로토콜을 재사용해 선택된 A안의 최소 고리 영향을 별도로 측정한다. Unity 구현은 범위 밖이다.

## 기각한 대안

- 평가 결과를 보고 특정 정책 강화: 과적합과 목표 맞추기로 해석을 손상한다.
- 기존 S4를 덮어쓰기: 실패 원인과 개선 효과를 비교할 증거를 잃는다.
- 체류율 하나만 유지: 포화된 지표 대신 실제 거리와 익은 밭 대기를 측정한다.

## 구현 경계와 검증 (#60)

Core의 선택적 experiment 설정·상태·결과는 비활성 시 null 직렬화를 생략한다. 기존 S2/S4의 RNG 경로와 골든 해시를 유지하며 새 프로필만 결정론적 이동·비선형 XP·mixed 규칙을 사용한다. Sim은 매 틱 실제 좌표를 little-endian int32 XY로 내보내고, 실행기는 15개 정책 쌍 각각의 생존 공통 구간을 비교한다. 요약 거리 표본과 전수 이동 동일성 증명을 구분한다.

실험 wrapper가 기본 tuning을 대체하므로 추가 경계를 둔다. 기본 `data/tuning.json`과 의미적으로 같은지 비교하고 `world.map.lordHealth`와 `world.threat.*` 외 차이는 Node·Sim 모두 거부한다. 적 수치 오버라이드는 명시적으로 선택된 적 집합과 일치해야 한다. 정책 가중·경제·계절·슬롯 변경을 위협 보정으로 숨길 수 없다. 후보 간 이동·mixed 순서는 동결하고 실제 수치 diff·파일 해시를 외부 실행 증거로 남긴다.

명시적인 null 실험 설정과 외부 심볼릭 링크 참조는 기존 실행으로 우회하지 않고 오류로 종료한다. smoke는 별도 seed9000–9002와 900틱으로만 실행하며 720초 생존율을 보고하지 않는다. CI는 매번 새 무시 경로를 만들어 증거를 덮어쓰지 않는다. 통계 보고는 열 개 CSV를 사용하고 raw가 있는 경우 원본 해시를 추가 검사한다. CSV-only 재생성은 원본을 다시 검증했다는 주장이 아니다.
