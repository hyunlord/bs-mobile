# ADR 0002 — 순수 C# 코어와 실행 어댑터 분리

- 상태: 승인됨(의뢰서 확정 경계 기록)
- 날짜: 2026-10-08
- 근거: 의뢰서 S0·S2; 설계 01 §14

## 맥락
Unity 없이 동일 seed·정책·설정 결과를 재현하고 봇 리그를 수행해야 한다. 플랫폼의 시간·난수·객체 수명은 결정론을 깨뜨릴 수 있다.

## 결정
`core/src/SowSiege.Core`는 .NET 8 순수 C# 규칙, `SowSiege.Sim`은 JSON·CLI·실행 I/O, Tests는 xUnit, Bench는 BenchmarkDotNet으로 구분한다. Core는 엔진 참조를 가지지 않고 seed RNG와 입력·설정을 주입받는다. 실제 30Hz 이동·충돌·계절·성장은 S2 범위다.

## 결과와 대안
동일 규칙을 헤드리스·Unity 어댑터에서 소비한다. Unity MonoBehaviour 안에 규칙을 배치하는 안은 헤드리스 검사와 경계에 맞지 않아 채택하지 않는다. 부동소수점·런타임 간 결정론 범위는 실행 환경과 함께 검증하며 단일 환경의 동일 해시로 모든 플랫폼을 보증하지 않는다.

## 검증
엔진 참조 적합성 검사, 동일 seed 3회 해시, 빌드·테스트·분석기. S0 작은 연기 시뮬레이션은 S2 플레이 구현 검증이 아니다.
