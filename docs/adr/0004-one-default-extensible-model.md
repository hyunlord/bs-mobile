# ADR 0004 — 기본 영웅·영지 각 하나, 모델은 복수 전제

- 상태: 승인됨(사용자 확정 사항 기록)
- 날짜: 2026-10-08
- 근거: 설계 01 P8·§12·§15; 설계 02 §2.1; 의뢰서 공통 규칙

## 맥락
초기 제작량을 줄이면서 나중에 영웅과 영지 층을 독립적으로 확장해야 한다. 기본 하나라는 제품 범위와 단일 ID에 묶인 코드 구조는 다른 문제다.

## 결정
기본 영웅 1·기본 영지 전통 1로 게임을 완성한다. 양쪽은 각각 JSON 레코드이며 Core에 ID나 전용 규칙을 넣지 않는다. `data/test/`에 시작 도구와 규칙 값이 다른 더미 영웅·영지를 두고 같은 경로로 실행한다. 더미는 출시 후보나 수집 상품이 아니다. 최종 정체는 S3 세 후보 및 needs-decision 이슈에서 선택한다.

## 결과와 대안
초기 영웅·영지 판매 축은 없으며 추가 영웅·영지의 데이터·그림 제작을 지금 시작하지 않는다. 기본 하나를 enum/singleton 전용 분기로 고정하는 안은 P8 위반으로 채택하지 않는다. S0 기본 레코드의 임시 이름은 최종 아트·콘셉트 승인으로 해석하지 않는다.

## 검증
Core의 영웅·영지 ID 문자열 적합성 검사, 기본 및 더미 조합 실행, 더미가 기본 콘텐츠에 자동 포함되지 않는 로딩 경계.
