# ADR 0016: 전달 비용을 줄이고 변경한 관문을 별도 판정한다

- 상태: 채택, 사용자 2026-10-08 승인 / #66·#57
- 대체 범위: ADR0012의 향후 단계 ZIP·전량 원자료 전달 절차. 크기 예산·도구 언어·역사 보존 규칙은 유지한다.

## 결정

신규 ZIP·CRC·전달 영수증을 만들지 않는다. 보고는 커밋 해시·PR·CI 링크로 충분하며, 필요한 원자료는 Release 태그로 연결한다. 업로드 대상은 실패 사례와 선정 기준을 명시한 표본뿐이다. CSV에서 재생성 가능한 보고·그래프·집계는 업로드하지 않는다. 작은 정본 CSV와 재생성 코드·실행 조건은 저장소에 남긴다. 전량 실행 파일은 분석용 무시 경로에서만 사용한다. 일반 CI도 전체 artifacts 트리를 올리지 않고 테스트 실행 결과와 커밋별 지정 지표 표본만 보관한다. 지표 추세의 기존 JSON·HTML 운영은 유지하되 새 metrics-history ZIP은 생성하지 않는다. 역사적 패키징 테스트는 파일을 유지하고 현행 기본 검사에서 제외한다. 과거 ZIP·Release와 기록은 삭제·재작성하지 않는다.

#57의 옛 관문(c)는 특화 정책4개가 사람 규칙3묶음에서 각1위가 되어야 하므로 공동1위 없이는 통과할 수 없었다. 새(c′)는 **weapon·land·building·people 각각의 생존율이 같은 사람 규칙 묶음의 random 생존율의 0.6~1.5배(양끝 포함)**인지 검사한다. 4×3=12셀 모두 만족해야 한다. (b)의 전조건 우세 부재는 유지한다. 부동소수 오차 없이 표본 수를 포함한 정수 교차곱으로 판정한다. random 생존0인 묶음은 비율을 정의할 수 없어 평가불가이며 자동통과시키지 않는다.

R2·R3 원본 판정·보고는 그대로 보존하고, 동일한 기존 CSV에 새 기준을 적용한 후향 재판정을 별도 표로 추가한다. 이는 새 실험이나 사전 선언 결과가 아니다. 생존 비율은 관측 추정치이며 작은 표본의 불확실성을 없애지 않는다. 이번 결정은 정책·위협·무기 수치 보정을 승인하지 않는다.

## 기각과 검증

- 과거 FAIL을 PASS로 덮어쓰기: 당시 계약과 추적성을 훼손한다.
- 임의의 동률 허용 오차 확대: 승인한 생존율 비율 기준과 다르다.
- 모든 JSON/재생성 산출물 재업로드: 사용자가 명시적으로 중단했다.

새 재판정 도구는 경계0.6·1.5, 경계 밖, random0, 누락/중복 셀, 기존(b)와의 일치 및 반복 재생성 동일성을 검사한다. 실제R2/R3 CSV와 원본 파일 불변을 확인한다. 기기·UnityCI 선택 및 Unity 설치는 이 결정의 범위가 아니다.
