# ADR 0009: 데이터로 주입하는 월드와 통제된 헤드리스 실험

상태: 채택(기술 계약). 날짜: 2026-10-08. 연결 이슈: #33. 제품 선택은 [#32](https://github.com/hyunlord/bs-mobile/issues/32)의 미정 상태를 유지한다.

## 맥락

S0의 산술 연기 시험은 CI·로딩·결정론 기반만 검증했다. S2는 이동·충돌·농지·건물·사람의 실제 상태 전이를 요구한다. S1 검토는 간접 성장 산출을 피해에 합산하는 오류와 메타·광고의 비교 혼입을 지적했다. 코어의 데이터 경계 및 숫자·ID 검사는 그대로 유지해야 한다.

## 결정

- 기존 `Simulation(catalog, options)`, `Tick`, `IsComplete`, `Result` 호출 형태를 유지하면서 내부를 공간 월드로 교체한다. 순수 Core에는 파일·시계·엔진 의존성을 넣지 않는다.
- 월드 크기·이동·공격·성장·징집·계절·출현·희귀도·카드 정책 수치는 JSON으로 주입한다. 30Hz와 네 계절을 데이터 계약에서 검사한다. 기본과 더미 조합을 동일 경로로 실행한다.
- S0의 정책별 피해·성장 배율은 게임 정책의 우열을 만들기 위해 사용하지 않는다. 정책은 카드 선택과 관찰 가능한 이동 결정을 통해 결과에 영향을 준다.
- 결정론 상태 해시는 결과 총합만이 아니라 미래에 영향을 주는 월드 상태와 난수 seed·소비 횟수를 포함한다. 엔티티 순서와 동점 처리 순서는 안정적으로 유지한다. 동일 .NET 런타임의 재현성을 우선 검증하고 다른 런타임·플랫폼까지 검증했다고 확대하지 않는다.
- 발동 피해, 직접 성장 피해, 성장 산출 및 경험치 출처를 별도로 기록한다. 수확 경험치로 구입한 무기 강화의 피해를 도구 피해에 다시 더하지 않는다.
- 정상 실험은 같은 중립 메타·광고 없음으로 통제한다. 이번 범위에는 판 밖 자재 환산·장원·상품을 구현하지 않는다. 식량 잔고는 점수가 아니다.

## 임시 실험 설정과 비용

정상 한 판은 계절별 180초, 합계 720초(21,600틱)를 초기 가설로 둔다. 이는 사용자 최종 밸런스 결정이 아니다. 짧은 CI 실행은 같은 규칙의 앞부분만 실행하고 `shortened`임을 기록한다. 이를 네 계절 완주 증거로 사용하지 않는다. 전체 한 판 증거는 별도로 실행한다.

부하 시나리오는 실제 월드 시스템을 실행하면서 적 1,000·농지 300·건물 20·사람 60을 유지하는 시험 장치다. 틱 전후 개수를 검사하고 부족분의 보충 비용을 측정에 포함한다. 준비·워밍업은 별도로 구분한다. 이 측정은 보충 비용까지 포함한 보수적인 헤드리스 틱 비용이며 자연 발생한 게임 상태나 모바일 렌더러 성능을 뜻하지 않는다. 5ms 목표 실패는 수치를 숨기거나 엔티티를 줄여 해결하지 않고 병목과 함께 보고한다.

## 거절한 대안

- S0 카운터에 성장 이름만 붙이기: 상태·공간·손실·복구를 검증할 수 없어 거절.
- 정책별 직접 피해 배율로 승률 맞추기: 카드 선택의 효과를 검증하는 실험을 오염시키므로 거절.
- 기본 영웅·영지 분기와 코어 수치 상수: 데이터 교체 및 확장 감시 계약을 깨므로 거절.
- 초기 부하 개수만 기록하기: 도중 사망·수확으로 측정 부하가 줄어도 숨겨지므로 거절.
- 짧은 시험에서 계절만 압축하고 전체 판으로 부르기: 성장·위협의 시간 비율이 바뀌므로 거절.

## 검증

검증 계약: 실제 상태 전이 테스트, 동일 seed·정책·설정 세 번의 전체 상태 해시, 기본/더미 전체 실행, 도구 세 종류의 피해와 성장 산출, 부하 틱 전후 개수와 p95, clean-clone 검사 및 필수 CI. 실행 결과는 S2 보고서와 원자료에 기록한다. 이 ADR 작성 시점은 구현 전이며 위 검사가 완료됐다는 뜻이 아니다.

실행 결과: 소스 커밋f0a111e에서 기본·더미 × A/B/C 각3회 전체21,600틱 완주·동일 해시, 부하2,700표본 p95 1.40675ms를 확인했다. [S2 보고](../review/S2-report.md)와 원자료를 따른다. 사람60은 실제 시뮬레이션 entity 수이며 부대 구성원60~116명은 별도 기록한다. 수동 카드 제어 상태·기본 아군 피해도 해시와 원장에 포함한다.
