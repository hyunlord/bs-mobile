# ADR 0001 — 모바일 Unity·F2P를 제품 경계로 고정

- 상태: 승인됨(사용자 확정 사항 기록)
- 날짜: 2026-10-08
- 근거: `docs/design/01_게임플레이_베이스_v0.1.md` §0; `02_BM_경제_골격_v0.1.md` §1~2

## 맥락
모바일 한 손 액션의 게임플레이와 수익 구조를 함께 설계한다. 광고·과금·유저 획득을 나중에 억지로 붙이지 않되 미검증 가격·확률을 확정하지 않는다.

## 결정
제품 엔진은 Unity, 플랫폼은 모바일, 비즈니스 모델은 F2P다. S0~S5에서는 Unity 프로젝트·운영 SDK를 만들지 않는다. 에디터 버전·CLI·라이선스·CI 지원 사실은 S0 조사 및 별도 운영 ADR로 기록한다.

## 결과와 대안
엔진 독립 코어를 .NET 8에서 검사할 수 있다. Unity 대신 다른 엔진을 선택하는 안은 사용자 확정 결정과 충돌하므로 채택하지 않는다. 광고·IAP 실제 동작과 모바일 화면 검증은 이 결정 기록으로 증명되지 않는다.

## 검증
Core 엔진 독립성 CI, `unity/README.md` 범위, 후속 Unity 단계의 라이선스·빌드·디바이스 관문.
