# ADR0050: 기본 규칙을 보존하는 이동·피격 실험

- 상태: 승인된 사용자 의뢰 구현, A/B 외형 선택은 사용자 관문 대기
- 날짜: 2026-10-11
- 추적: [#207](https://github.com/hyunlord/bs-mobile/issues/207)

## 결정

공통 보행의 그림 전체 튀기기·기울이기·찌그러뜨리기와 방향 전환 중 폭 축소를 제거한다. 영주 A는 고정 자세, 적은 종류별 작은 움직임·그림자·먼지로 표현한다. B는 머리·몸통·망토·팔·다리·검을 관절 계층으로 저작하고 걷기8·서기·공격·피격을 atlas로 굽는다. 실행에는 기존 SpriteBatch만 사용하고 새 패키지나 실시간 뼈대는 추가하지 않는다. B는 선택 가능한 시안이며 기본값 A를 교체하지 않는다.

설정의 이동·접촉·체력·피격 표현 실험은 모두 기본 OFF이고 다음 출정에서 고정한다. 기존 PlayerPrefs 저장/복구 목록에 포함한다. 게임 규칙 세 개만 immutable `InteractiveOptions.Feel`로 전달하고, 피격 표현과 B 선택은 화면에만 둔다.

- 이동은 물품 효과 적용 후13/10배, 정수 좌표의 축별 나머지를 누적한다. 정지·방향 반전·지도 경계에서 잔여값을 초기화한다. 화면은 Core의 읽기 전용 실제 보행 속도를 쓰고 정수31/32 교대나 밀려남을 새 보행 속도로 학습하지 않는다.
- 일반 적 접촉은 기존 일반 원형의 명시적 허용 목록으로 한정하며 돌진·정예·보스·알 수 없는 분류를 제외한다. 적 몸 너비와 실험 영주 몸 너비300의 반지름 합을 사용한다. 말벌의 사격 사거리를 접촉 범위로 쓰지 않는다. 정상 성공 피해 후15틱 무적과 기본 보행3틱 거리의 영주 밀려남을 적용한다. 방향이 같으면 영주 방향을 기준으로 결정하며 지도 안으로 제한한다. 무적 동안 모든 영주 피해를 막되 특수 적의 예고/공격 진행은 유지한다.
- 체력 실험은 최대/현재100, 원래 피해를5~15로 제한한다. 새 난수나 콘텐츠 수치를 추가하지 않는다. 실제 감소량을 피격 사건에 기록한다.
- 피격 표현은 흰 HP 잔상·0.2초 붉은 번쩍임·붉은 화면 가장자리·영주 피해 숫자와 기존 피격음을 사용한다. 전역 카메라 흔들림은 추가하지 않는다.

## 호환성

세 규칙 모두 OFF는 null로 정규화하고 기존 replay format1/2와 상태 해시 바이트를 유지한다. ON만 format3에 nullable 목표 재료, 실험 version1, flags를 기록한다. 알 수 없는 버전/비트를 거부하고 실험 가변 상태를 조건부 해시에 포함한다. 전역 역사 codec 버전은 바꾸지 않는다. 리플레이의 규칙은 헤더가 정본이며 저장된 UI 설정을 덮어 씌우지 않는다.

## 검증과 한계

집중 회귀는 OFF 헤더 바이트·기존 상태 직렬화 필드, ON 왕복·피해·무적·분수 이동·예외 적을 검사한다. 기존27000틱과 실제 두 Core 대상 비교는 CI 안전망으로 유지한다. A/B는 같은 seed와 고정 걷기 방향, OFF/ON은 같은 seed와 성장·회피 반응 정책을 각각 실제1배속으로 실행한다. 규칙 변경 때문에 카드·상태·사망이 달라질 수 있고 동일한 전체 입력/장면이라고 주장하지 않는다. 카드 정지 시간, 사망, 누락 프레임은 숨기지 않는다. 사용자 영상·직접 플레이 선택이 최종 손맛 관문이다.

#126 일반 수치·경제, #98 Fold7, C05 측정과1b는 보류를 유지한다.
