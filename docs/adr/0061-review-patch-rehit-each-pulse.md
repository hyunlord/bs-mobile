# ADR0061: 검토 합성 장판이 펄스마다 같은 적을 다시 칠 수 있게 하는 선택 옵션

- 상태: 제안 — 사용자 결정 대기. 구현하지 않았다.
- 날짜: 2026-10-16
- 연결: [#266](https://github.com/hyunlord/bs-mobile/issues/266), `docs/review/m1-266-weapon-feel.md` "포자 부채 설계 전환", `core/src/SowSiege.Core/WaveReviewImpacts.cs`
- 번호: 이 브랜치 기준 다음 번호다. main의 ADR 번호와 겹치면 병합 때 다시 매긴다.

## 맥락

검토 장면의 포자 부채는 설계(`08_system-design-v1` ground-zone, `data/weapons/spore_fan.json` "고정된 포자 장판이 일정 간격으로 지나가는 적을 타격")대로 영웅이 지나간 자리의 장판이 되었다. 새 Core 코드 없이 기존 검토 합성(`forward-line`, `spacing 0`)으로 만들었다. 장판 하나가 `count`회 펄스한다.

기존 합성은 활성화(시전) 하나에서 같은 적을 한 번만 친다. `TickReviewImpacts`의 `state.Activations[impact.ActivationId].HitTargets.Add(enemy.Id)` 때문이다. 화살·장창·투석끈처럼 착탄 지점이 서로 다른 합성에서는 이것이 맞다. 같은 자리에서 여러 번 펄스하는 장판에서는 "위에 있는 적을 주기적으로 타격"이 되지 않는다. 장판 위에 머문 적은 첫 펄스에만 맞는다.

## 결정(제안)

`WaveAttackComposition`에 선택 필드를 하나 더한다.

- 이름: `rehitEachImpact`(bool)
- 기본값: 꺼짐. 꺼져 있으면 직렬화에서 빠진다(`OmitWhenNull`과 같은 방식). 그래서 기존 카탈로그·검토 사례·재생 해시가 바이트 단위로 그대로다.
- 켜면 착탄(펄스)마다 중복 판정을 새로 한다. 같은 활성화 안에서도 펄스마다 장판 위의 적을 다시 친다. 한 펄스 안에서 같은 적은 한 번만 친다.
- 쓰는 곳: 검토 카탈로그 포자 부채 3사례만 켠다. 다른 무기와 wave-1a·첫 플레이 데이터는 이 필드를 쓰지 않는다.
- 검사: Core 테스트에 (1) 필드가 없을 때 기존 21사례 해시가 같다, (2) 켰을 때 장판 위에 서 있는 적이 펄스 수만큼 맞는다, (3) 한 펄스 안 중복이 없다를 더한다.

## 결과·비용

- 포자 부채 검토 사례 3개의 replay·종료 해시가 다시 바뀐다(검토 장면 해시만, wave-1a 프로필 해시는 그대로).
- 피해량이 늘어난다(장판 위에 머문 적이 펄스마다 맞음). 수치(피해·주기·횟수)는 정본 성장표 그대로지만 결과 DPS가 달라지므로 #126(밸런스 보류)과 함께 본다.
- 대안 1: 펄스마다 별도 활성화로 예약한다. 활성화 수가 늘어나 활성화 기반 진단·View 묶음이 바뀌므로 택하지 않는다.
- 대안 2: 그대로 둔다(한 장판은 같은 적을 한 번, 겹친 다른 장판에는 다시 맞음). 지금 상태다.
