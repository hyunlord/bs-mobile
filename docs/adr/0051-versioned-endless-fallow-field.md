# ADR0051: 이전 재생을 보존하는 끝없는 휴경 들판

- 상태: 승인된 사용자 결정 구현, 네이티브 관문 검증 중
- 날짜: 2026-10-11
- 이슈: [#210](https://github.com/hyunlord/bs-mobile/issues/210)
- 번호 확인: origin/main 최대0046, 선행 가지0047~0050 보존. 병합 직전 다시 확인한다.

## 맥락

12000×12000 경계가 짧은 이동 뒤 영주와 카메라를 막고 적을 한자리에 모았다. 사용자는 영주 B와 기존 맵 성능 작업 뒤, 적 애니메이션보다 먼저 사방으로 이어지는 들판을 승인했다. #126 수치·경제, #98 Fold7, 1b 보류는 유지한다.

## 결정

새 wave 출정은 nullable `FieldOptions(Version=1)`을 명시한다. null은 역사적 직사각형이다. Core는 음수 좌표를 포함한 정수 위치와 결정론 격자를 사용하며 일반 이동·작업·밀침에서 사각형 클램프를 하지 않는다. 집과 기존 작업은 원래 좌표에 남는다.

생성량과 시점은 유지한다. 새 적은 영주 중심 반경16200의 정수 방향 고리에서 생성한다. 반경32400 밖의 일반 적은 ID·체력·재사용 상태를 보존해 진행 방향 쪽으로 재배치한다. 죽음·경험치·새 생성으로 세지 않는다. 살아 있는 작물을 실제 공격 반경에서 노리는 적은 보호하지만 먼 추격만으로 무한히 남지 않는다. 보스는 재배치하지 않는다. 보스 등장 위치의 반경6000 원형 경기장만 임시 이동 경계가 되며 처치 때 해제한다.

이 반경은 스폰량 조정이 아닌 지도 기하 계약이다. Core는 해상도를 읽지 않는다. 화면은 기존 줌·보간을 유지하고 최대 반높이6000·가로비16:9 이내를 보장한다. 더 넓은 창은 게임 카메라를 레터박스 처리한다. 새 규칙의 적 표식과 돌진 예고 의미는 유지한다.

View는 `(seed, signed sectorX, sectorY, slot)` 해시로 낮은 대비 소품을 생성하고 보이는 구역만 재사용한다. 개울의 공유 끝점은 구역 방문 순서와 무관하다. 복원 마스크는 고정256² 카메라 주변 창이며 원점·배율로 세계 좌표를 매핑한다. 창 밖은 복원색0, 돌아온 작업은 현재 상태에서 다시 칠한다. 화면 캐시가 Core 작업을 삭제하거나 다시 생성하지 않는다. 재배치 사건은 보간을 건너뛰어 적이 화면을 가로질러 날아오지 않게 한다.

## 재생과 해시

형식1~3의 헤더·옵션·상태 바이트는 그대로 둔다. 형식4만 target material, feel schema/flags, field schema/version을 명시한다. 알려지지 않은 버전·비트·불완전한 헤더는 거부한다. 기존 글로벌 codec 상수를 올려 역사 해시를 바꾸지 않고, field 옵션이 있을 때만 tagged 상태를 덧붙인다. 재생은 헤더를 따르며 앱의 새 출정 기본값으로 덮어쓰지 않는다.

들판의 마지막 이동 방향과 보스 경기장은 이후 상태에 영향을 주므로 해시에 포함한다. seed와 실제 입력이 같으면 Core 결과와 장식 구역이 재현된다. 별도 실제 입력 봇의 old/field 비교는 동일 seed·정책이며, 상태가 달라진 뒤 입력까지 같다고 주장하지 않는다.

## 비용과 거절한 대안

- 거대한 직사각형으로 크기만 확대: 결국 벽과 마스크 해상도 문제가 남아 거절.
- 기존 재생 헤더를 새 규칙으로 해석: 역사 해시와 실패 사례를 훼손하므로 거절.
- 먼 적을 죽이고 새 체력으로 보충: 경험치·상태·생성량이 달라지므로 거절.
- 방문한 모든 구역의 그림을 보존: 캐시가 무한히 자라므로 거절. 작업 상태와 화면 캐시를 분리한다.

현재 유한 판의 최대 이동·밀침 범위는 정수 표현 안에 검증한다. 화면의 끝없음이 임의 시간 동안 무한 정밀 좌표를 지원한다는 뜻은 아니다. 좌표 차이는 long으로 확장한 뒤 계산한다.

## 검증

필수: 역사 재생·형식4의 두 Core 대상 해시, 음수 격자와 이동, 적 상태 보존 재배치, 보스 울타리 수명, seed/구역 방문 순서, 카메라·마스크 회귀. 네이티브에서는 같은 seed6분 old/field의 경계막힘·카메라클램프·화면 안 적 중심 수·캡처 없는 프레임 비용을 비교하고, 한 방향60초 및 먼 곳에서 집으로 돌아오는 실제 입력 영상을 남긴다. 사망·포커스 이탈·녹화 누락은 보존한다. 빌드·단위 검사만으로 이 화면 관문을 통과 처리하지 않는다.
