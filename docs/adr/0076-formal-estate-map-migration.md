# ADR0076: 정식 r8 지도 영지와 기존 장원 저장의 전환

- 상태: 2026-10-30 사용자 최종 승인 — 수치 가설·구현 관문 유지, 06:00 이후 병합
- 날짜: 2026-10-30
- 연결: [#546](https://github.com/hyunlord/bs-mobile/issues/546), [GDD14](../design/gdd/14-estate-map-release-proposal.md)

## 맥락

사용자는 정식 영지를 r8 지도로 바꾸고 첫 건설 시안 07~09를 기준으로 정했다. 현재 Release는 자동 장원이며 지도는 저장하지 않는 개발 사본이다. Core에는 선택 Estate와 v6 codec·Migrate가 있으나 호스트 변환 트랜잭션은 없다.

## 결정 제안

GDD14를 전환 계약의 정본으로 제안한다. 신규는 r8 v6, Estate 없는 기존 계정은 구형 정산 복구 후 일회 변환한다. 지갑·가신·장부·원본 ManorLevels를 보존하며 신규 시제품 지갑으로 덮어쓰지 않는다. 기존 v6 r2~r7는 원래 설정으로 유지한다. v6 schema는 그대로 두며 메모리 사본에 그리던 명령만으로 저장 연결이 완성됐다고 주장하지 않는다.

[ADR0071](0071-account-estate-state-and-save-version-six.md)의 v6/과거바이트/시계/이관 불변량을 계승한다. 그 ADR에서 아직 미정이었던 구형 방치와 영지 생산 병행은 마지막 구형 구간을 정산한 뒤 지도 생산으로 단일화하는 방안을 제안한다. 이 전환 설계는 사용자 승인됐으며 아직 구현되지 않았다. 구형 미수령 장부와 나머지는 보존하고 새 생산에 합쳐 재지급하지 않는다. 기존 v6 r8/r2~r7도 정식 경로에서 legacy 방치 적립을 중단하되 미관측 구간을 추가 정산하거나 지도 시계를 초기화하지 않는 보수적 정책을 권고한다. 미관측 구간의 일회 추가 지급이 필요하면 지속 표식·겹침 검증과 저장 형식을 별도 승인받기 전 출시를 막는다.

[Codex 저장 검토](https://github.com/hyunlord/bs-mobile/pull/547#issuecomment-6505712165)를 반영해 첫 startup Publish(terminal 복구 포함) 전 정확한 설정 의미 검증, 미지원 설정 fallback 금지, 계정 경로 단일 writer, progress/terminal의 존재·hash·완료 상태를 묶는 불변 복구 세대, 실제 primary 재읽기와 커밋 불명확 시 쓰기 중단을 필수로 한다. 같은 시간 입력의 결정성과 시간이 지난 재접속의 중복 구간 방지는 따로 검사한다. 호스트 복구 manifest만으로 Core 저장 버전을 올리지는 않는다.

## 결과·비용

표시만 바꾸는 변경이 아니므로 호스트 단일 writer·불변 복구 사본·단계별 장애 복구·효과 호환 관문이 필요하다. 효과는 GDD14 r2의 L1/L2/L3→E3/E6/E10 [가설] 표와 기존 ManorLevels 단조 장부로 연결한다. 최초 이관 표시는 old0→L0, old1~5→L1, old6~9→L2, old10→L3으로 제안하되 원래 효과값은 그대로 보존한다. 이후 실제 완료 상태 전이에서만 max로 갱신하며 읽기/로드/이관에서 지도 단계의 효과를 재지급하지 않는다. 건물 완료와 장부는 같은 저장 후보로 커밋한다. 이미 낮은 장부/L3인 기존 v6는 암묵 강등·무료 상한 지급 없이 보존하고 별도 승인 전환 정책이 나올 때까지 정식 효과 연결의 출시 차단 예외로 남긴다. 대응표의 숫자는 [가설]이며 문서 승인만으로 정식 전환을 출시하지 않는다. v6에 필요한 상태를 표현할 수 없으면 새 버전 ADR을 먼저 검토한다.

롤백은 최신 v6 상태를 보존하는 호환 UI 패치가 기본이다. 이미 진행한 계정을 낡은 v5 사본으로 자동 복원하거나 v6을 v5로 내리지 않는다. 이전 바이너리가 v6을 지원하지 않으면 쓰기를 막고 전진 수정한다.

## 거절한 대안

- 별도 활성 장원과 지도 양쪽 쓰기: 같은 지갑의 중복 지출·생산과 두 진행 경로를 만든다.
- 모든 기존 계정 NewPrototype: 초기 자원으로 덮어쓰고 실제 진행을 버린다.
- 저장 버전 번호만 상승: v6가 이미 필요한 구조를 담으며 과거 저장을 바꿀 이유가 없다.
- 지도 L3를 기존 효과 L3로 강제: 기존 상한·슬롯을 잃거나 이미 얻은 효과를 재지급한다.
- 표시 롤백 때 v5 사본 자동 복원: 이관 후 얻은 재화·건설·해금이 사라진다.

## 검증

이번은 현행 코드·문서 정적 조사 및 문서 검사뿐이다. GDD14의 저장행렬·장애 주입·생산 단일화·효과·롤백·실제 정식 화면 관문은 구현 후 실행한다. Unity·빌드·기기·게임 코드·데이터 변경 없음.
