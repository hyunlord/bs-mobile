# 0031 — 첫 플레이 UI 상태와 로컬 표현 설정

- 상태: 승인 — 1단계 B 의뢰서 M3 구현 범위
- 날짜: 2026-10-09
- 연결: [#97](https://github.com/hyunlord/bs-mobile/issues/97)
- 관련: ADR0024 정본 연결, ADR0029 첫 플레이 프로필, ADR0030 그림 계약

## 맥락

카드 선택 중 설정을 열거나 결산에서 돌아올 때 동일 판·제시 카드·종료 기록을 보존해야 한다. 기본 스타일 화면을 그림 계약으로 대체하며, 소리·진동·화면 설정과 일회성 안내는 규칙 상태와 분리한다.

## 결정

1. Coordinator가 타이틀·안내·판·카드·설정·결산·기록 검증 화면을 명시적으로 소유한다. 설정은 진입 화면으로 돌아가며 결산 재표시는 기록을 다시 종료하지 않는다.
2. PlayerPrefs의 `sowsiege.fp.v1.`에 표현 설정과 실제 표시한 안내만 저장한다. 잘못된 음량·조준 값은 정규화한다. 메타 성장이나 분석 SDK는 추가하지 않는다.
3. 시작 조준은 리플레이 헤더에, 판 중 조준 변경은 기존 `SetAimMode` 입력으로 기록한다. 음량·진동·흔들림·피해 숫자는 Core를 변경하지 않는다.
4. UI는 역할 ID의 원본 그림과 900폭 디자인 토큰을 사용한다. uGUI 이벤트 컴포넌트만 재사용하고 기본 외형은 쓰지 않는다. 패널 역할의 원본 rect에서 정규화된 테두리를 가진 Sprite를 캐시하고 실제 Sliced 이미지로 표시한다. 원본 PNG와 atlas 좌표는 변경하지 않는다.
5. 카메라는 화면을 자르거나 Core 좌표를 바꾸지 않고 실제 HUD·안전 영역·엄지 영역을 월드 단위 여백으로 환산한다. 기존 전체 화면 API의 기본 경계는 보존한다.
6. 각 승인된 Core 프레임의 실제 이벤트를 7개 독립 효과 채널에 전달하고 원본 음악1개를 반복한다. ID 중복·보스 등급을 확인하며 음악은 메뉴에서 계속되고 앱 배경에서 일시정지한다. 합성 소스·사용 근거를 보관한다.

7. 카드 안내는 카드 스크롤 본문에 배치한다. 월드 공지는 메뉴에서 숨기고 남은 표시 시간을 보존한다. 개발 오버레이는 기본 화면에 버튼을 두지 않고 Editor/개발 빌드의 F12 또는 QA API로만 연다.

## 결과와 검증 범위

로컬 설정은 계정/서버 동기화를 하지 않는다. 정적 음원 파형 검사와 AudioSource 상태 검사는 실제 청취·폰 진동을 대체하지 않는다. 화면 흐름·한글·조작·실제 렌더·음원 재생은 Editor에서, 정상 완주·실측 성능·녹화·진동은 M4 기기에서 검증한다. 결과는 PR의 실제 테스트와 표본에 연결한다.

## 거절한 대안

- 카드/설정 화면을 매 프레임 무조건 다시 생성: 설정을 덮어쓰고 제시 상태를 잃는다.
- 조준을 표현 설정만으로 변경: 기록을 재생할 때 입력이 달라진다.
- HUD 때문에 월드 viewport를 축소: 동일 폴드 화면의 기존 카메라 시야와 렌더 경로를 바꾼다.
- 효과마다 새 GameObject 또는 외부 음원 패키지: 할당과 새 의존성을 늘린다.
