# ADR 0005 — 판타지 표현과 일관된 인과

- 상태: 승인됨(사용자 확정 사항 기록)
- 날짜: 2026-10-08
- 근거: 설계 01 §0·P7·§12

## 맥락
기이한 작물·건물·백성은 화면의 차별점을 만들지만 이유 없는 효과는 도구의 발동·성장 관계를 흐린다.

## 결정
중세풍 판타지이며 현실 고증에 묶이지 않는다. 영지 전통은 인과가 닫힌 고유 순환 고리 하나를 표현한다. 최종 기본 영지의 고리는 S3 사용자 선택 전까지 잠정 후보로 다룬다. 기존 IP 고유 명칭·디자인을 쓰지 않는다.

## 결과와 대안
현실 역사 재현을 제품 제약으로 삼지 않는다. 무관한 효과를 보너스 목록에 쌓는 안 대신 성장물이 힘으로 돌아오는 주 경로를 설명한다. 스킨은 표현만 바꾸며 고리의 성능을 바꾸지 않는다.

## 검증
콘텐츠 리뷰에서 발동→성장→환원의 근거를 확인한다. S3 도구 필드·참조 검사는 일부 구조만 검사하며 인과의 설득력과 화면 가독성은 사람 평가가 필요하다.
