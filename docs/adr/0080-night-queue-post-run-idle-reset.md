# ADR0080 · 야간 측정 대기열의 게임 종료 직후 유휴 타이머 리셋

상태: 승인 — 사용자 승인 2026-11-01(#614). 날짜: 2026-11-01. 연결: [#613](https://github.com/hyunlord/bs-mobile/issues/613).
번호: 작성 시 main의 최대 번호는 0078이다. 0079는 열린 #607이 쓰고 있어 0080을 쓴다. 병합 전 다시 확인한다.

## 맥락

[공유 Mac 런북](../runbooks/shared-mac.md) 6절에서 C05·FP01 측정과 녹화는 사용자 입력이 20분 없을 때만 시작한다.
야간 대기열은 마지막 입력 시각을 시스템 유휴 타이머(`HIDIdleTime`)로 계산한다.

측정 앱(`Sow and Siege`, Unity)은 실행 중에 이 타이머를 스스로 리셋한다. 그래서 앱이 끝난 직후에는 "20~30초 전 입력"으로 보이고,
측정마다 20분을 헛되이 기다렸다.

2026-10-31/11-01 야간에 게임 종료 직후 샘플(`class=game-exit`) 6건을 기록했다.
- 6건 모두 실행 중 외부 HID 입력이 0건이었다.
- 리셋 시각은 앱이 마지막으로 떠 있던 시각보다 9~20초 앞서 있었다. 앱 종료 순간과 정확히 같지는 않다.
- 같은 밤 사람 입력(내장 키보드·트랙패드) 310건 중 이 조건과 겹친 것은 없었다.

이 변경은 공유 Mac 운영 계약(입력 대기 규칙)을 바꾸므로 AGENTS.md에 따라 ADR로 남긴다.

## 결정

종료 후 첫 샘플에서 다음 세 조건을 **모두** 만족할 때만, 그 리셋을 사용자 입력으로 보지 않고 20분 대기를 생략한다.

1. 그 실행 동안 외부 HID 입력이 0건이다. 측정 앱이 아닌 WindowServer `queue.tickle ... service:<장치>`를 센다.
2. 리셋 시각(`샘플 시각 − HIDIdleTime`)이 실행 시작 이후이고, 앱이 마지막으로 확인된 시각 이전이다.
3. 종료 뒤 샘플에 새 HID 입력이 없다.

- **기록:** 건너뛸 때마다 night 로그에 세 조건의 실제 값을 남긴다(`GAMEEXIT skip:`). 건너뛰지 않은 경우도 값과 함께 남긴다(`GAMEEXIT not skipped:`).
- **되돌리기:** 건너뛴 직후의 측정이 입력 사유로 무효가 되면, 한 번만 생겨도 규칙을 끄고(`gameexit-rule-off`) 사용자에게 보고한다.
- **바뀌지 않는 것:** 사람 입력에 대한 20분 대기, 측정 중 무효 조건, 다른 프로세스 대기 규칙은 그대로다.
- **소유자:** 야간 측정 담당 스크립트(`idle-sampler2.sh`, `c05-lib.sh`)만 이 규칙을 쓴다. 규칙은 `$MV/gameexit-rule-on`이 있을 때만 켜지고, 이 PR 병합 후에 만든다.

## 결과·비용

- 측정 사이 빈 대기가 줄어 하룻밤에 끝나는 실행 수가 늘어날 것으로 예상한다. 실제 효과는 적용 후 night 로그로 확인한다.
- 위험: 실행 중 외부 입력 감지가 놓친 사람 입력을 앱의 리셋으로 잘못 볼 수 있다.
  - 완화: 조건 3과 되돌리기 규칙.
  - 측정 중 입력은 기존처럼 그 실행을 무효로 만든다.
- 근거가 6건이고 같은 Mac·같은 앱에서 나온 것이다. 다른 앱이나 다른 기기로 일반화하지 않는다.

## 거절한 대안

- **유휴 타이머 대신 HID 이벤트만 센다:** 측정 앱이 실행 중인 동안에는 이미 이 방식이다. 앱이 꺼진 뒤 다른 앱이 보낸 합성 입력을 놓칠 수 있어 유휴 타이머 기준을 유지한다.
- **20분 대기를 짧게 줄인다:** 사람 입력과 앱 리셋을 구별하지 않으므로 기존 사용자 규칙을 약하게 만든다.

## 검증

- `node tools/check-docs.mjs`가 통과했다.
- 근거 표는 #614 본문에 있다. 원자료는 `$MV/c05/input-source.log`의 `class=game-exit` 줄과 `night.log`의 실행 시각이다.
- 적용 뒤 효과와 되돌림 여부는 아침 보고와 night 로그로 확인한다. 이 ADR만으로 측정 관문을 통과했다고 보고하지 않는다.
