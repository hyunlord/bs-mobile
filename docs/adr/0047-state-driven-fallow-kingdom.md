# ADR 0047: 돌본 땅의 색은 게임 규칙이 아닌 성장 상태의 표현으로 둔다

- 상태: 승인된 사용자 방향의 구현
- 날짜: 2026-10-10
- 연결: [#194 선택](https://github.com/hyunlord/bs-mobile/issues/194), [#197 구현](https://github.com/hyunlord/bs-mobile/issues/197)

## 맥락

사용자는 A 휴경의 왕국과 A-battle/A-title를 선택했다. 기존 wave-1a 첫 1분의 보이는 품질이 범위이며, 콘텐츠·수치·규칙은 그대로여야 한다. 회색 세계에서 영지가 자라며 색이 스며드는 장치가 게임의 얼굴이다.

## 결정

Unity가 기존 WaveWorkView의 위치·진행·완료·생존 상태를 읽어 월드 마스크를 만든다. 수확 확산은 실제 harvest-complete 사건에서만 시작한다. 셰이더는 지형과 성장물에만 회색/세이지/황금/온기를 적용하고 피아·공격 예고를 지우지 않는다. Core에 색·마스크·새 상태를 추가하지 않는다. 기존 실행 데이터와 다른 프로필의 아트는 유지한다.

지형 소품은 별도 그림과 월드 좌표로 구성하고, 실제 성장물·배우·HUD를 목표 그림에 구워 넣지 않는다. 타이틀도 배경·로고·실제 버튼을 분리한다. 표현 슬롯 수는 장비 상한이 아니며 실제 소유만 표시한다.

Mac의 OS 캡처 권한을 요구하지 않는 기존 자동 입력 경로에 명시적 `--golden-minute`를 추가한다. 게임이 실제 프레임버퍼와 AudioListener 출력을 기록한다. 60게임초까지 정상 입력·속도를 유지하고 카드 정지 시간도 영상에 남긴다. 게임 상태나 카드 제시를 주입하지 않는다. 일반 실행에는 이 캡처를 켜지 않는다.

## 결과와 비용

마스크·그림은 Unity만 소유하며 게임 해시를 바꾸지 않는다. 마스크 해상도와 표현 반경은 시각 품질 선택이다. 캡처의 동기 GPU 읽기·파일 기록 비용은 성능 증거로 사용할 수 없다. 원자료 전체 프레임을 Release에 중복 업로드하지 않는다.

## 거절한 대안

- 전체 화면 흑백 후처리: 적 표식과 영주를 지운다.
- 기준 전투 이미지를 배경으로 사용: 실제 성장·전투를 증명하지 못한다.
- 첫 1분용 자원·성장 가속: 수치 불변 조건을 어긴다.
- 별도 성능·해시 측정 프로젝트: 사용자 범위 밖이며 CI 안전망으로 유지한다.

## 검증 경계

실제 Mac 빌드의 같은 구도 캡처와 정상 속도 영상으로 비교한다. 사용자만 시각 관문을 판정한다. 코드·아트 계약 검사와 필수 CI는 안전망이며 #126·#98은 보류한다. 실행 결과는 PR의 Verification과 캡처 런북에 연결한다.
