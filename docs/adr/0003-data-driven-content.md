# ADR 0003 — 콘텐츠와 조정 수치를 데이터로 분리

- 상태: 승인됨(사용자 확정 사항 기록)
- 날짜: 2026-10-08
- 근거: 설계 01 P6·P8·§14; 의뢰서 S0·S2·S3

## 맥락
에이전트가 새 도구·영웅·영지를 추가할 때 Core의 특정 ID 분기나 복제된 수치가 늘면 콘텐츠마다 다른 실행 경로가 생긴다.

## 결정
JSON 레코드와 JSON Schema를 계약으로 쓴다. ID는 `namespace:name`. 콘텐츠 ID·밸런스 숫자는 데이터에, 일반 알고리즘은 Core에 둔다. 필드 추가·참조 변경은 스키마·로더·검사를 함께 갱신한다. 스킨에는 성능 필드를 허용하지 않는다. S0 스키마는 연기 시험용 최소 계약이며 S3의 전체 콘텐츠 스키마·수량 완료를 의미하지 않는다.

## 결과와 대안
콘텐츠만 바꾸는 PR은 Core 수정 없이 검증된다. 모든 숫자 문자를 금지하는 안은 인덱스·알고리즘 상수까지 막으므로 적합성 정책은 게임 수치와 구조 상수를 구별한다. 특정 영웅 ID switch나 도구별 하드코딩 대신 데이터 입력의 공통 경로를 사용한다.

## 검증
스키마·중복/참조 ID 검사, Core 하드코딩 검사, 더미 데이터 실행, 도구 발동·성장 필수 필드 검사. 스키마 통과가 재미나 수치 적정성을 증명하지 않는다.
