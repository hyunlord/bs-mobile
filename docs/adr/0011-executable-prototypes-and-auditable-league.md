# ADR 0011: 실행 가능한 후보 효과와 재생 가능한 리그 원자료

- 상태: 채택, S4 실행 계약
- 연결: #38, 기본 영웅·영지 선택은 needs-decision #32

## 문제

후보 문장의 태그만 읽거나 효과명을 결과에 출력하는 것으로는 S3 콘텐츠를 실행했다고 볼 수 없다. 반대로 새 효과를 기존 기준 프로필에 자동 적용하면 S2의 결정론 회귀 증거가 깨진다. 반복 실행을 독립 표본으로 세거나 식량 축적을 점수로 쓰면 리그 비교도 왜곡된다.

## 결정

S4는 별도 명시 프로필로 무기 4·도구 4·특허장 4·물품 12·진화 2·적 6을 고른다. 기본 영웅·영지는 한 쌍이다. 코어는 콘텐츠 ID 분기 대신 유한한 조건·효과 연산을 실행하고, 수치·범위·기간·비용·칸 수는 데이터로 받는다. 각 선택 레코드에는 실제 실행되는 범위와 아직 구현되지 않은 후보 설명을 함께 기록한다. 혼합 도구는 두 성장 대상의 상태를 실제로 바꿔야 하며, 효과 집계는 조건 확인 횟수가 아니라 실제 변화만 센다.

레벨업 카드는 무기·도구·특허장만 공유한다. S4의 칸 수는 각각 5·4·4다. 물품은 위치·태그·비용 조건이 있는 자동 수집 전리품이며 소지 칸이나 누적 스택 상한을 두지 않는다. 땅에 남는 전리품 엔티티 수는 계산량을 제한하기 위해 데이터로 제한한다. 생성·획득·효과 발동을 구분한다. 진화는 입력 장비를 모두 소유한 뒤 실행되며 원래 피해나 성장 산출에 중복 가산하지 않는다.

추가 카탈로그와 월드 상태는 선택적인 런타임 확장에 둔다. 확장이 없는 S2에서는 해당 속성을 직렬화하지 않고 RNG 호출과 타임라인도 유지한다. 기존 기준 프로필과 여섯 전체 기간 해시를 보존한다. 확장이 있는 S4에서는 모든 추가 상태를 결정론 해시에 포함하고 실제 초기 0틱과 종료 시점 표본을 남긴다.

리그는 정책 6종 × 사람 규칙 A/B/C × seed 42~73의 독립 사례를 실행한다. 같은 입력의 세 반복은 결정론 검사용이며 첫 반복만 통계에 쓴다. 전체 기간은 원본 데이터의 21600틱을 유지한다. 짧은 CI 실행은 900틱의 앞부분이며 계절이나 게임 시간을 압축하지 않는다. 제한된 병렬 프로세스로 실행하고 누락된 사례나 불일치가 있으면 완성된 원자료로 발표하지 않는다.

보고서의 숫자는 원본 CSV만으로 다시 계산한다. CSV에는 실행·시간 표본·카드·효과·전리품·반복 해시·출처 메타데이터를 나눠 담고, JSON 원본의 해시도 보존한다. 피해는 무기·도구 발동·도구 성장·별도 아군을 구분하며 경험치나 식량을 피해로 환산하지 않는다. 사망 이후 값을 채우거나 보간하지 않고 곡선의 관측 수와 생존 수를 표시한다.

순위는 생존 여부, 도달 틱, 레벨, 실제 귀속된 전투 피해의 사전식 비교다. 식량·자재 보유량과 영지 체류 시간은 순위에 쓰지 않는다. 모든 사람 규칙×seed 조건에서 공동 1위를 포함해 항상 1위인 정책이 있으면 관문을 실패로 표시하고 원인 가설 세 개를 남긴다. 전부 동률이어도 이 규칙을 적용한다. 실패 결과를 감추려고 측정 후 데이터를 조정하지 않는다. 보편적인 1위가 없다는 결과 역시 게임 전체의 균형이나 재미를 증명하지 않는다.

## 검증과 한계

효과별 참·거짓 조건, 실제 상태 변화·비용·귀속, 혼합 성장, 무제한 물품 스택, 진화 획득, S2 호환성을 검사한다. CSV 파싱·누락 행·반복 해시·종료 표본·교차 시점·공동 순위의 경계를 테스트한다. 별도 디렉터리에서 CSV만으로 보고서·파생 표·그래프를 재생성하고 바이트를 비교한다. 그래프는 로컬에 설치된 Matplotlib를 사용하고, CI의 계산·문서 검사는 그래프 의존성 없이 실행한다.

헤드리스 리그는 화면 가독성, 휴대전화 조작, 첫 도구 이해, 사람의 재미, Unity 성능을 검증하지 않는다. 실제 렌더링이나 모바일 플레이를 했다고 보고하지 않는다.

## 기각한 대안

- 물품을 레벨업 카드에 포함: 원본의 무제한 전리품 구조와 다르다.
- 태그만 혼합인 도구 또는 이름만 있는 진화: 실제 두 성장 대상이나 조건부 작동을 검증할 수 없다.
- 후보 전체를 자동 실행: 프로필 경계를 무너뜨리고 기존 회귀를 오염시킨다.
- 사망 후 값 채우기: 살아남은 시간의 실제 관측과 가정된 값이 섞인다.
- 유일한 1위만 지배로 판정: 모든 조건에서 공동 1위인 정책을 관문에서 빠뜨린다.
