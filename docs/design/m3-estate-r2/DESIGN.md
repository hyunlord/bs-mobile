# M3 r2 영지 화면 시안 · 디자인 계약

## 1. 분위기와 정체성

휴경의 왕국에서 집을 중심으로 회색 땅이 생활의 색을 되찾는다. 기존 portrait-v0의 과슈 건물, 목재 자원 바, 금속 테두리, 명조 제목을 그대로 사용한다. 영지는 버튼 네 개가 아니라 주민이 오가고 생산·원정 동네가 갈라지는 지도다. 세 화면은 **정적 설계 시안**이며 게임 화면이나 7일 실측 결과가 아니다.

## 3. 글자

제목은 portrait-v0와 같은 Gowun Batang(없으면 AppleMyungjo/Batang), 본문은 Noto Sans KR(없으면 Apple SD Gothic Neo/Malgun Gothic). Google Fonts는 기존 portrait-v0와 같은 글꼴 제공원이며 실패해도 본문을 숨기지 않는다. 기본 13px, 보조 11px, 건물/작업 제목 15px, 화면 제목 19px, 주 버튼 24px. 선 높이는 1.35–1.45. 390×844에서 1 CSS px = 설계 1pt.

## 4. 공간과 지도

고정 보드 390×844. 상단 안전 영역 44px, 하단 34px. 바깥 여백 10px(원본 Home 유지), 내부 기본 간격 4/8/12/16px. 자원 바 44px, 챕터 줄 52px, 목표 줄 52px, 지도 408px. 누르는 요소는 44×44px 이상. 그림의 지리 좌표·건물 크기는 개별 보드에서 지정하는 아트 배치 값이다. 세 보드는 한 크기로 렌더하며 데스크톱에서는 가운데 놓인다.

## 5. 구성 요소

- 목재 자원 바: 기존 `ui-bar-wood.png`, 좌우 slice 44 / 표시 18px.
- 파랑 챕터 배너: `ui-btn-blue.png`, slice 52 / 표시 26px. 정보 영역이며 추가 주 버튼이 아니다.
- 크림 패널·보조 버튼: `ui-panel.png` 사방44/16px, `ui-btn-cream.png` 좌우46/16px. 진한 갈색 글자.
- 빨강 주 버튼: `ui-btn-red.png`, 좌우52/30px. 영지에서는 출정, 분기 창에서는 선택 확정 한 개만.
- 지도: 어둠/개간/복원 영역, 흙길·물길, 건물, 실제 기존 아틀라스의 주민과 작물. 생산→운반→창고 관계를 공간상으로 연결한다.
- 건물 이름표: 크림 9-slice를 재사용. 주민 말풍선은 작업의 목적을 한 줄로 표시한다.
- 하단 탭: 원본 Home의 문장·가신·깃발·상자 그림 사용. 빨간 점은 받을 보상에만.
- 전문화 선택: 세로로 두 선택지, 선택한 카드에 금색 경계. 효과·기회비용·적용 시점을 함께 표시.

## 6. 움직임과 상태

이 납품은 정적 시안이다. 주민의 이동 방향·짐·작업 말풍선으로 살아 있는 영지의 구현 의도를 보인다. 지도 드래그·시간 진행·경제 계산·저장 기능은 구현하지 않는다. 건물 선택 보드는 전문화 선택 미리보기이며 선택 버튼은 정적 문서상의 조작 대상이다.

## 7. 검증과 출처

기존 `../portrait-v0/source/Home.html`, `../portrait-v0/README.md`의 구성·9-slice를 계승. 건물은 `portrait-v0/source/a`, 작물·짐꾼은 `unity/Assets/Art/crops-people.png`, 집/공사 현장은 `fallow-growth.png`, 지형의 구역·길·물길은 공유 팔레트의 인라인 SVG로 그린다. 복제·수정한 게임 에셋 없음. 브라우저 390×844 실렌더에서 글자 잘림, 안전 영역, 상대 이미지 경로를 확인한다. 7일차 상태와 숫자는 M3 r2의 **시제품 가설 저장 상태**이며 무과금 7일 도달 보장이 아니다.

### r2 가설 수치와 화면 시점

첫 접속 보드는 최초 지급 곡물120·목재180·철재60에서 곡창 L1 복구비 목재30을 지불한 뒤 36초가 흐른 상태다. 자원 바는120/150/60, 공사 남은24초이며 생산 터는 아직 복구하지 않았다. 곡창 이후 경작지·벌목장을 각각 복구해야 생산한다. 대장간 첫 공사는120초. 건물 선택 보드는 L3 검술 공방이 무기+2 선택을 해금하지만 현재 준비에서는+1(2점)을 선택한 예시다. 보급 공방은 영지 철재 생산+20%p, 판 기여는 L1 한도로 제한한다. 7일차 준비6점은 무기+1(2점)·병사1(2점)·다시뽑기1(1점)·식량20(1점)이다.

첫 생산 경로(곡창·대장간·세 생산 터)의 최초 비용30/100/25를 지갑 안에 보호 예약한다. 첫 화면은 곡창 목재30을 이미 지불한 시점이라 남은 예약30/70/25를 표시한다. 별도 통화나 추가 지급이 아니다.
