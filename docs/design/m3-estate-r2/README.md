7일차 화면은 도달 시간을 실측한 것이 아니라 **시제품 가설 저장 상태**다. 숫자·시간은 [M3 r2](../m3-account-estate.md)의 가설값이며 #126 확정 경제가 아니다. UI 구현 전 의도 검토용으로, 사용자가 문서를 승인해도 게임 구현·재미 관문이 자동으로 통과하지 않는다.

브라우저로 HTML을 열면 390×844 CSS px 보드가 표시된다. 2배 캡처는 780×1688이다. 상단 44px / 하단 34px를 안전 영역으로 비우며 본문은 13px, 보조는 11px 이상이다. 그림·레이블의 배치는 [DESIGN.md](DESIGN.md), 공통 스타일은 [estate.css](estate.css)에 있다. 외부 글꼴 요청을 차단하면 시스템 한국어 폰트로 대체된다.

새 게임 아트·Core/data/Unity 파일은 수정하지 않는다. 근거 에셋과 9-slice 값은 [portrait-v0 README](../portrait-v0/README.md)에 있다.

첫 접속 시안은 곡창 복구 착수36초 뒤다(최초120/180/60에서 목재30 지불 →120/150/60, 남은24초). 회색 생산 터는 미복구 상태다. 첫 생산 경로 보호 예약은 곡창 착공비를 뺀 곡물30/목재70/철재25다. 자세한 가설값·화면 시점은 DESIGN.md의 마지막 절을 따른다.

## 검증 · 2026-10-24

- Chrome headless/CDP의 device metrics를 **390×844, DPR2**로 설정해 세 장을 실제 렌더했다. 각 캡처 780×1688. OS 화면 기록·손쉬운 사용 권한은 사용하지 않았다.
- 로컬 이미지 누락 0, 주요 텍스트/패널 DOM overflow 0. 독립 시각 검토 2회에서 발견한 곡창 시간·공방 이름표·패널 뒤 안내문 겹침을 수정한 뒤, 두 검토자가 최종 캡처를 다시 확인했다.
- 상단44px/하단34px 안전 영역(상단의 시안 설명은 제품 조작 요소 아님), 본문13px/보조11px, 주요 버튼 최소44px를 확인했다. 실제 기기·게임 입력·생산 실행·사용자 재미 검증은 아니다.
- 문서의 첫 생산 경로 비용은 곡물30/목재100/철재25, 공사270초, 잔여90/80/35. 선택 예시 준비 예산은 세 조합 모두6점. 초기 생산비 보호 예약으로 비생산 시설 선행 시 자원 고갈 경로를 막는 산술을 확인했다.
- 새로운 게임 그림이나 실행 파일은 없다. HTML과 CSS가 정본이며 브라우저 캡처는 로컬 검토용이다. 사용자 지시로 push/CI 재실행 없이 같은 PR 브랜치에 보존한다.
