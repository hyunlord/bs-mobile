# Sow & Siege 시스템 설계 v1.1

관문: 설계 수정 승인 — 런타임 구현·플레이 판정은 아직 별도 관문이다.
씨앗뿐 아니라 건물의 완성·출고와 사람의 임무 귀환에서도 경험치를 수확한다.
기본 무기는 내 밭과 식량을 깎지 않으며, 위험한 영지 거래는 선택한 진화·특허장에서 읽는다.
모든 무기·도구에 진화와 연결 물품이 있어 어느 빌드도 조합의 막다른 길이 되지 않는다.
짧은 조건→효과 카드와 눈에 보이는 상태로 다음 행동을 이해한다.
작업 반경 안에서는 움직이며 싸워도 공사가 이어지고, 아군 무리는 한 개체로 다룬다.
목표 재료의 도구 제안과 챕터 기본 지급으로 카드 운 때문에 장원이 멈추지 않게 한다.
먼저 wave-1a의 수확·진화·적 예고·보스 국면을 실제 Mac 플레이와 영상으로 보여 준다.
수치·밸런스·경제 #126과 Fold7 #98은 계속 보류한다.

## 설계의 공통 규칙

- 모든 도구는 공격→지도 흔적→실제 성장 완료→경험치 수확으로 닫힌다. 밭 성장 주기·출고·임무 식별자를 완료 원장에 기록해 재시도·복구·저장 로드·보상 재수거로 중복 지급하지 않는다.
- 무기·도구마다 진화 하나 이상, 연결 물품 1~4개다. 물품은 연결형36개와 범용6개다. 범용6개는 회수 반경·이동 속도·재사용 대기·범위·체력·밀침의 수치 전용 기본기이며 6/42=14.3%로 20% 이하 상한을 지킨다. 수치 자체는 확정하지 않는다.
- 모든 콘텐츠의 `cardText`는 한국어 40자 이하, 화살표 하나의 조건→효과다. 무기·도구는 기본 동작 하나와 눈에 보이는 조건부 변형 최대 하나다. 카드 길이 통과가 실제 3초 판독을 입증하지는 않는다.
- 자동 무기의 대가는 사각·지연·설치 위치 같은 형태의 빈틈이다. 물품의 `effect.cost`는 본래 동작에 붙은 제약이 없으면 null이다. 모든 물품에 대가를 강제하던 규칙을 철회한다.
- 목수 망치·지붕 아래 파종·무장 수확권은 반경 안에서 이동·전투하며 진행한다. 머무름이나 정지가 조건이 아니다.
- 사람 도구·가신·아군 진화는 공유 동시 개체 예산을 따른다. 무리 하나는 Core 한 개체이고 대표 스프라이트로 표현한다. 상한 도달 시 기존 무리를 재사용하거나 소집하지 않는다. 개체 상한과 스프라이트 수는 성능 측정 전 null이다.
- 모든 레코드의 `primitives`·`params`·`bespoke`는 유한 문법으로 분해한다. `operationSupport`의 문법·처리기·프로필 선택·관측·고유 의미 일치는 서로 다른 사실이다. 구현할 수 없는 잔여 의미는 bespoke로 공개한다.

## 재료 운과 원장

출정 전 목표 재료를 고르면 해당 도구를 첫 장비 제안에 포함한다. 프로필에 그 도구가 있어야 목표를 선택할 수 있다. wave-1a에는 곡물(씨앗 자루)·목재(목수 망치)·특허 기록(뿔나팔)이 열리고 가마 풀무가 없는 철재 목표는 열리지 않는다. 철재 출처를 목수 망치로 바꾸지 않는다.

챕터 클리어 시 목표 선택·관련 카드 미선택과 무관하게 네 재료의 기본분을 모두 지급한다. 따라서 철재 목표가 닫힌 1a에도 기본 철재가 있다. 실패한 챕터에는 클리어 기본분이 없고, 첫 제안을 거절하면 재제안까지 보장하지 않는다. 기본분과 실제 출처 행동으로 번 추가분은 별도 원장에 한 번만 기록한다. 지급량·환산 상한·경제 조정은 #126 보류다.
