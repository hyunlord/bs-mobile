# 09 BM·라이브

버전: v1.1 · 날짜: 2026-10-24 · 바뀐 점: 도전 받기 금빛 강조를 #248 구현으로 고치고 v1.0의 "적용되지 않았다"를 당시 docs-only 변경의 기록으로 남겼다([#357](https://github.com/hyunlord/bs-mobile/issues/357) G02). 이전 v1.0(2026-10-12): 승인된 BM 자리와 실제 제공 범위·미정 수치를 분리했다.
상태: 정본(가벼운 무료형 정책); 실제 구매·광고·라이브 운영은 미도입, 수치·가격은 [미정].

## 힘을 팔지 않는다

판매 대상으로 승인한 것은 영주 외형, 영지 테마, 고정 보상의 시즌 패스, 외형/패스에만 쓰는 보석 묶음, 1회 구매 광고 제거다. **가신·가신 조각·자재·판 안 능력·확률형 뽑기·출정 에너지**는 팔지 않는다. 상점과 시즌 패스는 보기 전용이며 미정 가격·보상은 `[n]`으로 표시한다. 시즌 패스에는 “판 안 힘은 없음”을 명시한다. 실제 판매 가격·결제/상점 SDK·운영 서버·분석 SDK는 이 문서 범위가 아니다.

## 선택 광고 자리와 노출

| 자리 | 성공 한도 | 현재 경계 |
|---|---|---|
| 결산 2배 | 판당 1회, 지갑 상한까지 | 추가 배율/별도 상한 #126 미정; production 설정 없으면 숨김 |
| 부활 | 판당 1회 | 체력·무적 등 #224 미정; production 규칙 없으면 숨김 |
| 방치 생산 2배 | 하루 3회 **[가설]** | 기본 받기가 주 동작; 기존 지갑 상한 보존 |
| 레벨업 다시 뽑기 +1 | 판당 2회, 기존 잔여 0일 때 | 카드 선택 중에만 제안; 명령으로 기록 |

강제 광고·배너·카운트다운은 없다. 첫 판과 첫날에는 광고 제안을 숨긴다. 받을 것이 없거나 한도·문맥·제공 가능 조건이 맞지 않아도 숨긴다. 실패·취소가 자원·성공 횟수를 소비하지 않으며 창 닫기는 손해 없는 선택이어야 한다. 광고 없는 주 동작을 유지하고 광고 버튼은 같은 크기 이하의 크림 보조 버튼, “광고” 문구를 숨기지 않는다. 광고를 본 직후에는 새 광고를 연달아 제안하지 않는다.

광고 제거 권한은 같은 노출 조건을 지킨 뒤 광고 없이 동일 보상을 주며 “바로 2배”로 표시한다. 현재 권한 fixture는 실제 구매 경로가 아니다. 첫 판/첫날 숨김은 이 권한에도 적용한다.

## 현재 구현 사실

확인 기준 `9387b7669bdc3d01790246509ad8d66f212af0ad`. [ADR0054](../../adr/0054-opt-in-host-rewards-and-local-bm-slots.md), [정책](../../../unity/Assets/Game/App/RewardedAdsPolicy.cs), [제공자 계약](../../../unity/Assets/Game/App/RewardedAdsContracts.cs), [원장](../../../unity/Assets/Game/App/RewardedAdsLedger.cs)이 근거다.

- Editor/Development는 즉시 성공/실패의 가짜 제공자로 흐름을 검증한다. Release는 사용 불가 제공자이며 실제 광고를 재생하지 않는다. 슬롯 그림과 테스트 fixture가 있다는 사실을 서비스 연동으로 보고하지 않는다.
- 정책은 첫 판·첫날·날짜 역행·일/판 한도·제공 가능·미지급 완료·저장 대기를 검사한다. 연속 제안 차단은 새 출정/레벨 등 의미 있는 플레이 사건으로 해제하며 화면만 열고 닫아 해제하지 않는다.
- 계정 보상은 안정적인 완료 ID와 지급 영수증으로 중복 지급을 막는다. 지급 저장과 host 원장 확인은 별도 저장이므로 단일 트랜잭션이라고 부르지 않는다. 저장 실패 때 지급을 진행하지 않고 재시도한다.
- 부활과 다시 뽑기는 host reward opt-in 재생 v5의 명령이다. 기존 v1–v4는 그대로 보존한다. 화면이 직접 체력·다시 뽑기·지갑을 수정하지 않는다. 부활한 판도 클리어로 인정하고 결산/기록에 부활 표시를 남긴다.
- 테스트용 부활 수치와 보너스 정책은 제품 기본값이 아니다. #126·#224를 확정하지 않고도 슬롯·실패·복귀·중복 방지 흐름을 검사한다.

## 라이브 운영·확인 경계

계정 서버·결제 복구·광고 네트워크·분석 이벤트·시즌 일정·운영 가격은 [미정/미도입]이다. 로컬 달력 키를 서버 시간이라고 부르지 않는다. 광고 없이도 클리어할 수 있어야 한다는 정책은 유지하되 #126 밸런스 보류 상태에서 이미 입증했다고 주장하지 않는다.

화면 기준은 [portrait-v0](../portrait-v0/README.md), 흐름·경제는 같은 GDD의 해당 장과 함께 관리한다. 도전 “받기”는 활성 상태에서 잠긴 칸과 구별되는 금빛 강조가 필요하다는 M1-1 후속 요청이 있었다. v1.0(2026-10-12)의 "**아직 이 문서 변경으로 적용되지 않았다**"는 당시 docs-only 변경의 기록이다. 지금은 #248(main `792d510`, 2026-10-21)로 구현됐다([05](05-screen-ux.md)). 시각 승인과 실기 확인은 별도다. 도전 정상 보상은 광고 상품이 아니다. #223 멈춤, #98 실기, 1b 확장은 BM 자리 구현으로 해소되지 않는다.

## [승인 대기 제안] BM 그림 승인과 전투력 경계 · 2026-10-29

BM r2 그림 흐름은 승인됐지만 가격·시간은 fixture다. 시간당 보석 공통 기준과 성장가속권 소폭 할인 방향은 실제 판매정책 확정과 별개다. 자원/시간→가신 레벨·대장간 상한·병영칸·연구의 우회 전투력 경로와 provenance 없는 지갑의 한계를 [가신 전투 제안의 BM 대안](13-vassal-combat-proposal.md#5-bm-직접-판매와-우회-경로-미정승인-필요)에 기록했다. 기존 금지 범위를 해제하지 않으며 대안은 사용자 승인 필요다.
