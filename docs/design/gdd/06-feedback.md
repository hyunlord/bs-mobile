# 06 손맛·연출

버전: v1.1 · 날짜: 2026-10-17 · 바뀐 점: 영웅 시트의 그림자·카메라 여백 몸 크기를 각 role의 매니페스트 셀 크기·발 기준선에서 계산한다(#295). 이전 v1.0(2026-10-12)은 실행 중인 피드백과 M1-1 기준표를 분리했다.
상태: 정본(현재 상태·사용자 승인 방향); M1-1 수치는 [가설], 적용·영상 판정은 미완료.

## 목적과 판정

2026-10-12 승인 기둥은 타격감, 캐릭터·무기별 몸동작, 시도하고 싶은 무기·진화 규모다. 영지가 힘이 된다는 재미는 아직 가설이며 M1 실험으로 판정한다. 손맛을 먼저 갖춰 영지 도구 A/B/C 실험을 공정하게 한다. 이 문서는 구현 완료 보고가 아니다.

관문 질문은 **“소리를 끄고 봐도 맞았다는 게 느껴지나”**다. 같은 seed의 현재/적용 후 30초 영상 두 개를 앱 내부 캡처로 만든다. OS 화면 녹화 권한을 요구하지 않는다. 효과를 켠 C05 800+의 25ms 초과 비율이 기준보다 나빠지지 않아야 한다. #223 야간 원인 측정은 별도로 유지한다.

## 타격감 기준표 v1

아래는 사용자 승인된 구현 방향이고 시간·픽셀·개수는 모두 **[가설]**이다. 화면만 바꾸고 Core 규칙·입력·역사 리플레이 해시를 바꾸지 않는다.

| 등급 | 화면 | 소리·진동 | 금지/경계 |
|---|---|---|---|
| 일반 타격 | 맞은 적만 흰 번쩍임 60ms, 그림만 뒤로 2–3px/80ms, 작은 파편 3–5개 | 음높이 ±5% 변주 | 실제 위치/판정 반경은 그대로 |
| 치명타·처치 | 치명타 숫자는 크게 다른 색; 처치 조각·먼지와 경험치 보석 튀어나옴 | 처치음 별도 | 치명타 규칙을 새로 만들지 않고 실제 사건만 표현 |
| 큰 기술·진화 | 0.05초 이하 흔들림과 큰 이펙트 | 짧은 진동, 최소 간격 보존 | 소리·진동·흔들림 끄기를 존중 |
| 보스 타격·처치 | 보스 타격만 전체 히트스톱 40–80ms; 처치 슬로 0.3초 | 보스 판독 우선 | Core 시각이나 명령을 바꾸지 않는 표시 연출. 처리 방식은 구현 검토 필요 |

일반 적 처치에는 전체 히트스톱을 쓰지 않는다. 같은 적의 짧은 시간 피해는 합산하고 동시 숫자 수를 제한한다. 합산 창·파편 풀 상한·큰 기술 분류·픽셀 기준 해상도는 [미정]이며 구현 때 명시한다. 모두 풀에서 꺼내 쓰며 매 프레임 임시 할당을 추가하지 않는다. 실제 밀려남은 무기 데이터 속성으로 별도 결정한다. 새 손맛 표현의 기본값은 ON이고 소리·진동·흔들림·피해 숫자 끄기는 유지한다.

## 모순·역사와 현재 기본값

[ADR0050](../../adr/0050-opt-in-movement-and-hit-feel.md)의 “모두 기본 OFF·B는 기본 A를 교체하지 않음”은 초기 실험 기록이다. 현재 [RunPreferences](../../../unity/Assets/Game/App/RunPreferences.cs)는 설정 버전1 최초 적용 때 빠른 걸음과 영주 피격 표현을 ON, 접촉/체력 실험은 OFF로 저장하며 B 기본 선택은 ON이다. 기존 사용자가 이후 끈 값은 버전이 같으면 보존한다. M1 의뢰의 “ADR0050 기본 OFF”를 현재 코드 사실로 반복하지 않는다.

“적을 때릴 때의 반응 없음”도 문자 그대로의 구현 부재와 다르다. 90ms flash와 hit 효과는 있지만 사용자에게 충분히 읽히지 않았으며 새 기준표는 그 부족을 해결한다. 설정의 흔들림 ON과 실제 흔들림 0 역시 구분한다. 현재 기본값을 이 문서 작업에서 변경하지 않는다.

[부드러움·표시 계약 ADR0048](../../adr/0048-continuous-presentation-and-live-capture.md), [아트·캐릭터](07-art-character.md), [소리](08-audio.md)를 함께 갱신한다. #126·#98·1b·#224는 계속 보류한다.

## 영웅 전신 스프라이트 시트 (구현, 2026-10-17)

기사 영웅을 Astra의 이미지 생성 전신 시트로 바꿨다. 컷아웃 리그가 아니다. View 전용이며 Core 판정·피해·타이밍·재생 해시는 그대로다. 공격 동작 설계("공격 동작": 이동 중 핵심 자세 / 정지 중 전체 동작)는 #266 스택의 같은 문서에 있고, 아래는 그 설계를 main에 구현한 값이다.

**그림과 등록**

지금 등록된 값이다. 실행 중에는 칸 수와 프레임당 시간을 코드에 고정하지 않고 아트 매니페스트 role(`frames`, `frameMs`)에서 읽는다(`HeroSheetTimings`).

| 클립 | 프레임 | 프레임당(60Hz 틱) | 출처 |
|---|---|---|---|
| 걷기 | 8 | 10 | 승인 r3 |
| 베기 | 8 | 9 | 승인 r3 |
| 겨누기·시전·불기·던지기 | 각 6 | 10 | 승인 r3 |
| 이동 핵심 자세 | 5(베기·겨누기·시전·불기·던지기) | 7 | 승인 r3 |
| 대기 | 6 | 12 | r4 추가분, 승인 2026-10-17 |
| 피격 | 2 | 7, 8 | r5, 승인 2026-10-17(r4 피격은 반려) |

- 53칸을 `hero-knight.png` 한 장에 재표본 없이 옮겼다(`tools/art-authoring/knight-sheets/pack.mjs`). 전달된 픽셀 해시 53/53을 다시 확인했다.
- first-playable·wave-1a 두 아트 매니페스트에 같은 role을 등록했다(`hero.core.frontier_knight.{idle,walk,hit,death,action.*,key.*}`). 그래서 어느 프로필에도 없는 영웅 role을 찾지 않는다(#268). 사망은 피격 마지막 칸을 임시로 쓴다.
- 새 그림은 같은 role 이름으로 다시 포장하면 코드 변경 없이 교체된다. 칸 수나 frameMs가 달라도 된다(예정: Astra의 새 걷기, 2026-10-17). 한 클립의 칸은 같은 프레임당 시간을 쓴다. 피격 마지막 칸만 예외로, 피격이 끝날 때까지 유지한다.
- 컷아웃 B 리그(설정의 "걷기 B · 부위별 애니메이션")는 시트로 대체했다. 설정 토글은 지웠다. B 리그는 시트 role이 없는 영웅이거나, 비교 캡처의 B 요청 또는 군중 벤치마크 `--crowd-hero-b`처럼 명시적으로 요청할 때만 그린다.
- 크기: 시트의 115px 몸 기준을 기존 기사 그림의 몸 높이에 맞췄다. 그림자·카메라 가장자리 여백은 셀 전체가 아니라 기존 기사와 같은 몸 크기를 쓴다. 그 몸 크기의 셀 대비 비율은 각 role의 매니페스트 셀 크기(프레임 너비·높이)와 발 기준선(pivot y)에서 계산한다(#295). 그래서 다른 셀 크기로 다시 그린 클립(예: 새 걷기)도 같은 세계 크기의 그림자·여백을 쓴다. 몸이 발 기준선 위 셀에 들어가지 않는 클립은 시트를 불러올 때 오류를 낸다.

**재생 규칙(`HeroActionSelector`)**

- 걷기는 등록된 칸(지금 8칸)을 반복하되, 재생은 실제 이동 거리에 따른다(기본 속도에서 칸 수 × 프레임당 시간에 한 주기, 지금 80/60초). 멈추면 대기를 반복한다.
- 좌우 이동은 좌우 반전, 위아래 이동은 같은 3/4 시트로 그린다.
- 이동 중 공격: 그 동작의 핵심 자세 1장을 그 role의 프레임당 시간(지금 7/60초 ≈ 0.117초) 동안 보이고 걷기로 돌아간다.
- 정지 중 공격: 전체 동작을 재생한다. 그동안 움직이기 시작하면 바로 걷기로 바꾼다(사용자 승인 2026-10-17).
- 같은 틱이면 진화 > 피해량 > 무기 id 순서로 고른다. 동작 중 더 높은 우선순위가 오면 교체하고, 같거나 낮으면 버린다. 같은 동작은 0.4초 안에 다시 시작하지 않는다(쌓지 않음).
- 피격이 오면 피격이 공격 동작을 덮고, 끝난 뒤 공격 동작을 잇지 않는다. 피격 중 온 공격도 버린다.
- 피격 표현(사용자 결정 2026-10-17): 전신 붉은 칠은 쓰지 않는다. r5 젖힘 자세를 쓰고, 처음 2프레임만 밝게 한다. 피격 표현 설정이 켜져 있으면 붉은 외곽선(적 외곽선과 같은 방식, 테두리 2텍셀)을 겹친다.
- 무기 매핑:
  - 철날 검·고랑 장창: 베기
  - 수로 활·곡창 투석끈: 겨누기(쏘기)
  - 빗물 쇠스랑: 시전
  - 뿔나팔: 불기
  - 수호 고리: 진화 단계의 적중에서만 던지기
  - 포자 부채와 그 밖의 장비: 동작 없음
- 사건: main의 wave 런타임 `attack`(진화 공격은 첫 입력 무기로 보고 진화로 침), 검토 합성의 시전 예고 `review-impact-tell`(같은 틱 착탄 지점에서 떠나는 튕김 비행은 제외), 사슬 `chain-link`, 수호 고리는 `hit`. 무기·틱마다 한 번만 넘긴다. first-playable 무기 전투는 아직 동작을 내지 않고 걷기·대기·피격만 쓴다.
