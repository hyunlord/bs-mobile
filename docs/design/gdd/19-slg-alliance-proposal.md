상태: **사용자 승인 — 2026-10-30**. 2026-10-30, 추적 [#560](https://github.com/hyunlord/bs-mobile/issues/560). [승인된 월드 GDD18 #559](https://github.com/hyunlord/bs-mobile/pull/559)의 연맹 계약을 구체화한다. [SLG 로드맵 #554](https://github.com/hyunlord/bs-mobile/pull/554)의 ④ 서버 운영·연맹에 해당하며 ⑤ 월드맵과 연결한다. **모든 신규 인원·글자·시간·횟수·상한 수치는 [가설]**이고 UI 예시도 확정 가격·밸런스가 아니다. 게임 코드·데이터·서버·SDK는 변경하지 않는다. 사용자 승인에 따라 최신 main과 최종 CI를 확인한 뒤 squash 병합한다.

## 1. 목적과 첫 출시 경계

연맹은 같은 월드의 회원들이 채팅하고 서로의 영지 건설·병력 훈련·연구·치료를 조금 앞당기는 모임이다. 서바이버 직접 참전으로 되찾은 땅의 공사와 전투 후 회복을 도우며, 전투 보상·땅·병력을 공유 계정에 복사하지 않는다.

첫 출시에는 무료 생성, 공개 가입/신청 승인, 탈퇴·추방·권한 위임·해산, 연맹 채팅, 작업 도움, 신고·차단·운영 처리를 포함한다. **연맹 영토·서버전·시즌·집결전·지원군·공동 창고·자원 거래·연맹 연구·상점·기여도 보상은 포함하지 않는다.** 월드 전체 채팅·개인 메시지도 제외한다. 회원 수·결제·기여도에 따른 전투 보너스나 VIP 권한을 추가하지 않는다.

현재 구현 완료를 주장하지 않는다. 서버 인증·저장·동시성·운영 권한의 기술 선택은 Codex의 C# 서버 ADR에서 정하고, 여기서는 제품 상태와 권한 불변량만 정한다. 기존 Core·리플레이 format7/8·골든과 [가신 계약](13-vassal-combat-proposal.md)은 변경하지 않는다.

## 2. 생성·검색·가입 [가설]

| 항목 | 계약 |
|---|---|
| 기본 | 같은 논리 월드 안에서 계정 소속 최대1개, 정원20명. 생성 무료. 정식 서버 계정만 참여하며 개발 장원 저장을 가져오지 않음 |
| 생성 | 미가입이고 재가입 제한이 끝난 계정만 가능. 이름·가입 모드 확인 뒤 연맹과 생성자의 연맹장 소속을 함께 확정. 재전송은 같은 연맹을 반환하며 빈 연맹을 중복 생성하지 않음 |
| 이름·소개 | 이름2~12자, 소개80자, 공지120자. 서버의 동일한 유니코드 정규화·표시 문자 계산을 입력 검증과 카운터에 사용. 제어문자·마크업 삽입 차단, 공백만 있는 이름 거절. 이름 변경은 무료이며 연맹장 확인과 운영 이름 정책을 따른다. 이름은 표시용이며 관계는 불변 allianceId를 사용. 중복 이름 검색 결과에는 연맹 ID를 함께 표시 |
| 검색 | 이름/연맹 ID로 검색. 연맹명·회원 수·가입 모드·소개·연맹장 표시. 회원 전원의 접속시각·도시 자원·병력은 검색 결과에서 공개하지 않음 |
| 공개 가입 | 별도 승인 없이 서버가 현재 미가입·제한 종료·정원·가입 모드를 검사하여 소속 확정. 화면의 빈자리 수는 예약 보장이 아님 |
| 신청 승인 | 계정당 대기 신청1개, 대기24시간 뒤 만료. 신청은 자리/소속을 예약하지 않음. 신청 취소 후 다른 연맹에 신청 가능. 승인 때 신청·현재 모드·정원·미가입·제한을 다시 검사 |
| 경합 | 마지막 자리 경쟁은 서버 확정 순서의 한 명만 성공. 같은 계정의 생성/가입/승인 경합도 하나만 소속을 얻고 나머지는 변화 없이 거절. 성공한 가입은 기존 대기 신청을 닫음 |
| 모드 변경 | 연맹장만 변경. 신청 승인→공개로 바꾸면 대기 신청을 만료시키고 안내하며 자동 가입시키지 않음. 공개→신청 변경 전에 확정된 회원은 유지 |

신청자 목록은 연맹장·간부만 읽는다. 거절은 자원 차감 없이 신청을 닫으며 개인 제재·가입 제한을 추가하지 않는다. 탈퇴/추방 제한을 이름 변경·연맹 새 생성으로 우회할 수 없다. 가입 실패/정원 초과는 버튼을 다시 누르면 성공한 것처럼 보여 주지 않고 서버 사유를 표시한다.

## 3. 역할·권한과 탈퇴 [가설]

연맹에는 항상 연맹장1명이 있다. 새 회원의 기본 역할은 회원이다. 권한은 요청 때의 서버 역할로 검사하며 화면에 오래 남은 버튼으로 이전 권한을 행사하지 못한다.

| 기능 | 회원 | 간부 | 연맹장 |
|---|---|---|---|
| 채팅·작업 도움·회원 목록·신고/개인 차단 | 가능 | 가능 | 가능 |
| 가입 신청 승인/거절 | 불가 | 가능 | 가능 |
| 소개·공지 편집 | 불가 | 가능 | 가능 |
| 이름·가입 모드 변경 | 불가 | 불가 | 가능 |
| 회원 추방 | 불가 | 일반 회원만 | 간부·일반 회원 |
| 간부 임명/해임 | 불가 | 불가 | 가능 |
| 연맹장 위임·해산 | 불가 | 불가 | 아래 조건에서 가능 |
| 타인 메시지 숨김 | 불가 | 일반 회원 메시지만 | 간부·회원 메시지 |
| 운영 신고 원문 열람·계정 채팅 제재 | 불가 | 불가 | 불가; 별도 운영 권한 |

자신을 추방하거나 간부가 다른 간부·연맹장을 추방/강등/메시지 숨김하는 것은 불가하다. 간부도 자신이 보낸 메시지는 삭제할 수 있고 자신의 신고/차단을 관리할 수 있다. 모든 역할은 본인 탈퇴 가능하되 연맹장은 아래 위임 또는 마지막 회원 해산을 먼저 한다. 역할 변경·추방·이름 변경·해산은 대상과 결과를 보여 주는 확인을 거친다.

- **위임:** 현재 회원 중 후임을 지정하고 확인하면 한 사건으로 후임을 연맹장, 기존 연맹장을 일반 회원으로 바꾼다. 탈퇴는 별도 확인이다. 대상이 먼저 탈퇴했거나 다른 위임이 먼저 확정되면 실패하며 연맹장0명/2명 상태를 만들지 않는다. 장기 미접속만으로 자동 탈취하는 제도는 첫 출시에서 제외한다. 연맹장이 사라져도 다른 회원은 탈퇴 가능하다.
- **탈퇴/추방:** 소속 해제, 채팅/신청/회원 전용 접근 철회, 해당 회원이 요청한 남은 도움 닫기를 함께 확정한다. 계정별12시간 재가입/재생성 제한을 기록하며 첫 가입에는 적용하지 않는다. 제한 중에도 개인 영지·전투·월드 채집은 계속 가능하다.
- **재가입:** 같은 연맹에도 제한을 적용한다. 과거 역할을 복원하지 않고 일반 회원으로 시작한다. 과거 jobId의 도움 횟수와 닫힘 상태를 복구하지 않는다. 추방은 영구 가입 금지가 아니므로 재발 괴롭힘은 신고/운영 처리 대상이다.
- **해산:** 유일한 회원인 연맹장만 가능하다. 채팅 접근·신청·도움 요청을 닫고 allianceId를 종료 상태로 보존한다. 이름이 같아도 새 생성은 새 ID다. 해산한 계정에도12시간 제한을 적용한다. 회원이 있는 상태에서 일괄 추방과 해산을 하나의 버튼으로 수행하지 않는다.

연맹 변경은 귀환 중 병력·자재·연구·영지 구역을 회수하지 않는다. GDD18의 도시 공격은 발령/도착 때 현재 소속을 각각 검사하며, 이동 중 같은 연맹이 되면 회군한다. 이미 전투가 확정된 뒤 가입하여 손실을 취소할 수 없다. 개인 차단·채팅 제재가 이 전투 관계 검사를 대신하지 않는다.

## 4. 채팅·삭제·개인 차단 [가설]

연맹 채팅은 서버가 현재 소속을 검사한 회원만 읽고 쓴다. 가입 뒤에는 현재 보존 범위의 이전 채팅을 볼 수 있다. 탈퇴 뒤에는 새 메시지뿐 아니라 과거 메시지 조회/재접속 구독도 차단하며 기기의 연맹 대화 캐시를 숨긴다. 이미 읽은 정보까지 회수했다고 주장하지 않는다. 권한이 사라진 실시간 구독도 서버에서 끊는다.

메시지는 일반 텍스트200자 이하·계정당5초에1회다. 빈 글·제어문자·마크업·첨부파일을 거절하고 링크 자동 열기/미리보기는 제공하지 않는다. 내용·길이·권한·제한을 서버에서 검사한다. 메시지 ID를 재전송하면 중복 발송하지 않으며 전송 중/실패/확정 상태를 구분한다. 실패한 메시지를 임의로 새 ID로 반복 전송하지 않는다.

본문 수정 기능은 첫 출시에서 제외한다. 작성자는 본인 메시지를 삭제할 수 있고 표의 관리자는 허용된 대상 메시지를 숨길 수 있다. 화면은 삭제/숨김 표식으로 바꾸되 신고·감사 증거는 서버 정책 범위에서 별도로 보존한다. 관리자 숨김은 계정 채팅 정지와 다르다. 관리자는 신고 원문·신고자 목록·차단 목록에 접근하지 않는다.

개인 차단은 서버 계정에 저장한 상대 계정 ID 기준의 **내 채팅 화면 숨김**이다. 차단/해제 메뉴는 본인에게만 보이며 상대에게 통지하지 않는다. 차단해도 상대의 연맹 소속, 역할, 도움 자격, 월드 정찰/공격 자격은 바뀌지 않는다. 필요한 시스템 공지·회원 조치 결과·도움 결과는 계속 보이고 개인 메시지 차단으로 중요한 상태를 지우지 않는다. 숨긴 메시지를 신고할 필요가 있으면 차단 관리에서 해당 증거 선택 경로를 제공하되 무조건 차단을 풀도록 강요하지 않는다.

## 5. 신고·운영 처리

신고 대상은 채팅 메시지·연맹 이름/소개/공지·회원이다. 이유(괴롭힘/혐오·위협/도배·광고/부적절한 이름/기타)와 짧은 설명을 받아 서버가 요청자가 볼 권한이 있었던 대상인지 확인한다. 채팅 신고에는 원본 messageId·allianceId·작성자·서버 시각·내용 버전, 신고자·접수 시각을 증거로 보존한다. 클라이언트가 보낸 인용문만으로 제재하지 않는다. 탈퇴 후 신규 대화 조회는 금지하지만 이미 본 메시지 ID의 신고는 서버의 열람 권한 기록과 보존된 원문으로 검증할 수 있다.

신고 접수와 개인 차단은 별도 동작이다. “신고 후 차단” 선택은 각각의 성공/실패를 표시한다. 중복은 같은 신고자·대상·사유·같은 사건/내용 버전으로 한정하고 기존 접수 ID를 반환한다. 채팅은 원본 messageId, 연맹 이름/소개/공지는 서버에 보존한 내용 버전/스냅샷, 회원은 서버가 검증한 관련 증거의 사건 ID로 식별한다. 사건/내용 버전은 서버 정본이며 클라이언트가 임의로 바꾼 값으로 새 접수를 만들지 않는다. 이전 접수가 종결되었어도 변경된 내용 버전이나 별개 사건은 신규 신고로 받아 일일 신규 신고 한도에 포함한다. 신고 횟수 투표로 자동 제재하지 않는다. 거짓 신고 의심만으로 회원 역할·도움 권한을 자동 박탈하지 않으며, 신고 악용 판단도 별도 운영 검토와 통지를 거친다. [가설] 신고 본문200자, 계정당 신규 신고 일일20건이며 중복 접수 조회는 제한에 포함하지 않는다. 서버가 한도를 알려 주고 기존 접수 상태는 계속 조회 가능하게 한다.

| 상태 | 사용자에게 보이는 것 / 운영 권한 |
|---|---|
| 접수 | 접수 번호·대상·처리 대기. 신고자와 운영자만 열람하며 상대/연맹장에게 신고자 공개 없음 |
| 검토 | 운영자가 원문·관련 조치 기록을 확인. 조작된 인용·중복·삭제/탈퇴로 증거가 사라졌는지 구분 |
| 조치/종결 | 내용 숨김, 부적절한 이름/소개 수정 요구, 일시 채팅 제한 또는 조치 없음. 사용자에게 처리 여부만 알리고 다른 계정 개인정보·제재 세부 사유는 공개하지 않음 |
| 제재 통지/이의 | 대상 계정에 적용 범위·종료 시각·사유 분류·문의/이의 경로 표시. 이의 접수만으로 제재를 자동 해제하거나 강화하지 않음 |

일시 채팅 제한은 서버 종료 시각까지 쓰기만 막고 읽기·개인 차단·신고·도움·전투를 막지 않는다. 제재는 운영 권한의 사유·담당·시각·전후 값과 함께 감사 기록에 남긴다. 연맹장/간부는 이 운영 권한을 갖지 않는다. 계정 전체 이용 제한은 이 GDD에서 임의 도입하지 않고 인증/운영 정책으로 넘긴다.

**출시 전 확정 항목:** 채팅/신고/제재 로그의 보존·삭제 기간, 신고 처리 인력·응답 목표, 미성년자/개인정보 처리, 계정 삭제와 증거 보존 충돌, 운영 권한 감사·이의 절차. 이는 구현/운영 출시 관문이며 지금 법규나 스토어 정책을 충족한다고 주장하지 않는다. 실제 서비스를 열기 전에 해당 정책과 운영 수단을 확인해야 한다.

## 6. 작업 도움: GDD18 계약 유지 [가설]

도움 대상은 활성 건설·훈련·연구·치료뿐이다. 대기/완료/취소 작업과 행군·채집·전투에는 적용하지 않는다. jobId와 **작업 시작 때의 연맹 ID**를 고정한다. 미가입 때 시작한 작업은 나중에 가입해도 도움 대상으로 바꾸지 않는다. 요청 버튼은 이 조건을 충족할 때만 활성화하고 이유를 표시한다.

도움 확정 때 요청자·제공자 모두 현재 같은 작업 시작 연맹 소속이고, 요청이 열려 있고, 제공자가 본인이 아니며, 작업이 아직 활성인지 검사한다. 제공자별 `(jobId, giverAccountId)` 평생1회, 작업 전체 최대5회다. 제공자 탈퇴/재가입은 기존 횟수를 초기화하지 않는다. 요청자 탈퇴/추방/연맹 해산 때 요청을 영구 종료하고 같은 작업을 새 연맹에 요청하지 않는다. 기존 단축은 유지한다. 가입 제한이 끝났다는 이유로 닫힌 작업을 다시 열지 않는다.

속도 보너스가 반영된 최초 지속시간 D0, 현재 남은 시간 R, 누적 도움 H를 사용한다. 실제 단축은 `min(30초, floor(D0×2%), R, floor(D0×10%)−H)`다. 음수 여유는0으로 처리한다. 결과0이면 횟수·재화·제공 기록을 소비하지 않는다. 양수일 때만 시간 차감·H 증가·중복 방지 기록·횟수를 함께 확정한다. 도움은 자원/보석/기여도 보상을 주지 않는다.

D0=200초면1회4초·최대5회20초다. 훈련/건설 속도30% cap에 도움을 다시 속도 배율로 더하지 않는다. 도움·유료 가속·자연 완료가 경합하면 매 사건에서 남은 시간을 다시 검사한다.0초 도달은 해당 작업 완료와 다음 작업 시작을 한 번 처리하고 남는 차감은 다음 job으로 넘기지 않는다. 화면의 예상 단축과 확정 단축이 다르면 확정 값을 결과로 보여 준다.

도움 요청 공개/제공은 회원 목록/채팅과 별개의 권한이다. 상대를 개인 차단했어도 작업 요청은 보이며 도움 가능하다. 채팅 제재도 도움을 막지 않는다. 역할 승격으로 도움 횟수나 단축량이 커지지 않는다.

## 7. 서바이버 판과 영지·월드 연결

| 실제 판 결과 | 연맹이 돕는 후속 작업 | 유지할 경계 |
|---|---|---|
| 검증된 밭/숲/폐허 임무에서 지정 r8 구역 개방 자격 획득 | 기존 인접·비용 조건으로 구역을 연 뒤 시작한 건설 작업에 도움 | 연맹 가입만으로 구역을 열거나 타 회원에게 개방 자격을 복제하지 않음 |
| 월드 직접 PvE 후 병력 귀환·입원과 자재 수령 확정 | 해당 회원의 치료/재훈련에 도움 | 부상률·병상·N=S+A+L 정산은 병력 GDD 유지. 전투 중 병력을 즉시 보충하지 않음 |
| 기록 회수·광석길 탐사로 연구 조건 달성 | 조건/비용을 충족해 시작한 연구에 도움 | 도움은 탐사 증명이나 연구 비용을 대신하지 않음 |

가입하지 않아도 개인 무료 기초 개척전·영지 성장·연구·월드 참전이 가능하다. 연맹 가입을 무료 복구 경로의 필수 조건으로 만들지 않는다. 공유 거점 격파는 해당 targetId/세대만 바꾸며 연맹 영토·공동 수익으로 전환하지 않는다.

## 8. 화면 계약과 확인 관문

390×844, 승인된 양피지 본문·어두운 바·파란 주 버튼·광택 아이콘을 따른다. 조작 영역은48×48 이상이고 역할·남은 제한시간·서버 결과를 글자로도 표시한다. 장문의 설명창 대신 다음 화면 상태를 구분한다.

| 화면 상태 | 핵심 내용 / 행동 |
|---|---|
| 미가입 | 검색·연맹 목록(회원 수/정원·모드), 무료 생성, 바로 가입 또는 가입 신청.12시간 제한 중이면 남은 시간과 비활성 이유 |
| 신청 대기 | 대상 연맹·만료 시각·취소. 확정 소속/채팅 화면으로 먼저 넘어가지 않음 |
| 가입 홈 | 이름·회원 수·내 역할, 도움/회원/채팅. 도움 목록에는 작업명·남은 시간·횟수(예2/5)·예상 실제 단축(예4초) |
| 회원·관리 | 역할별 실제 가능한 메뉴만 제공. 탈퇴는 남은 도움 종료·12시간 제한 안내, 연맹장에는 위임/마지막 회원 해산 |
| 채팅·신고 | 전송 상태·글자 수·제한시간, 메시지별48px 메뉴에서 신고/차단. 신고 접수 번호와 결과, 차단 관리 진입 |
| 도움 결과 | 확정 단축초·새 남은 시간, 완료/이미 도움/소속 변경/정산 대기 등 구체 사유 |

후속 구현의 종료 관문은 다음과 같다.

1. 생성/공개 가입/승인의 동시 요청에서 소속1개·정원·연맹장1명 보존. 가입 모드 변경·신청 만료·취소 경합의 단일 결과.
2. 권한 변경 직후 오래된 버튼/실시간 연결 거절. 간부의 동급/상급 조치 거부, 위임/탈퇴/해산 경합에 고아 연맹 없음.
3. 탈퇴자가 메시지/회원/신청을 다시 조회하지 못하고, 적법한 과거 메시지 신고는 증거로 접수. 개인 차단이 도움/전투 권한을 바꾸지 않음.
4. 도움 재시도·탈퇴/재가입·연맹 해산·완료/가속 경합에서 최대5회·D0의10%·제공자1회·0초 경계와 다음 작업 차감 금지.
5. 삭제된 메시지 신고·중복 신고·잘못된 인용·신고자 비공개·운영 역할 분리·채팅 제재 만료/이의 경로 확인. 서버 재시작 뒤에도 제한·중복 방지 기록 유지.
6. 실제 휴대폰의 두 계정에서 직접 PvE→영지 구역/치료 작업→도움→변경된 완료 시각을 확인. 가입하지 않은 계정의 동일 성장/복구 경로도 확인.

문서·계약 검토만 수행한다. 서버 동시성·부정행위·운영 대응·실제 휴대폰·경제 밸런스는 **NOT_RUN**이며 문서 CI로 대체하지 않는다. 사용자 검토 후보는 신청/정원/재가입 제한, 권한·관리자 메시지 숨김 범위, 신규 회원의 보존 대화 열람, 신고 제한, 도움 수치다.
