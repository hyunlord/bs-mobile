## 1a 무기·도구의 첫인상

다음은 역할·판독 목표다. M1에서 효과를 과장하더라도 피해·범위 수치를 조정하지 않는다.

| 장비·ID | 기본 동작과 읽어야 할 차이 |
| --- | --- |
| 철날 검 `core:iron_blade` | 바라보는 앞쪽의 짧은 호. 몸의 휘두름과 칼날 호가 같은 방향 |
| 수호 고리 `core:ward_orbit` | 영주 주위를 도는 조각. 고리 안·조각 사이 빈틈이 보임 |
| 빗물 쇠스랑 `core:storm_fork` | 적 사이를 잇는 연쇄. 지속 직선 경고와 구별되는 번개 리듬 |
| 잔불 지팡이 `core:ember_wand` | 적에게 굽어 가는 불씨. 발사·비행·적중이 분리됨 |
| 이삭 낫 `core:harvest_scythe` | 넓은 베기와 익은 밭의 수확 반응. 일반 검과 길이·호·잔상이 다름 |
| 씨앗 자루 `core:seed_bag` | 뿌리기 → 파종 흔적 → 성장 → 경험치 수확 |
| 빗물 바가지 `core:rain_ladle` | 물의 발동·흔적과 땅 성장의 연결 |
| 목수 망치 `core:carpenter_hammer` | 타격·작업 → 반경 안 건설·완성. 움직여도 진행 |
| 뿔나팔 `core:muster_horn` | 소집 → 아군 임무·귀환 → 사람 경로 완료 |

1a 진화는 파종 검무·호위 성가퀴·지붕 아래 파종이다. 입력 장비가 이미1a에 있어야 하며 단순 색갈이 대신 궤적·흔적·범위의 시각적 변신을 읽는다. 전체 입력·조건·ID는 [08의 wave 표](../08_system-design-v1.md)와 runtime을 정본으로 삼아 이 문서에 별도 수치를 복제하지 않는다.

일반 적6종은 씨앗 진드기·작물 포식자·약탈병·방패 약탈병·돌진 주자·발효 말벌이다. 보스 둑깨는 상아왕과 구별하며, 서로 다른 실루엣·예고·행동 원형으로 읽는다. 평소 돌진 주자를 항상 빨강으로 칠하지 않고 위험 중에만 붉게 강조한다.

## 추가·수정 콘텐츠의 설계 검사

- 모든 도구는 경험치 반환 경로, 모든 무기·도구는 진화 하나 이상을 가진다.
- 장비별 연결 물품1~4개, 범용6~8개, 수치 전용 물품 비율20% 이하. 범용을 연결 수에 중복 집계하지 않는다.
- 무기·도구는 기본 동작 하나 + 화면 상태로 읽히는 조건부 변형 최대 하나다. `cardText`는 한국어40자 이내 조건→효과다.
- 기본 자동 무기의 대가는 사각·지연·설치 위치다. 내 밭·식량 손실은 선택하는 진화·특허장에 둔다. 모든 물품에 대가를 강제하지 않는다.
- `primitives`·`params`·`bespoke`로 조립한다. 전용 동작을 늘리기 전에 승인된 bespoke 경계를 확인한다. [지원 JSON](../runtime-primitive-support.json)은 지원 상태를 읽는 자료이지1b 착수 승인서가 아니다.
- 성장·출고·임무 완료의 출처를 지워 같은 숫자 보너스로 만들지 않는다. 작게 읽히지 않는 복잡성은 카드 글자를 줄이는 것만으로 해결하지 않는다.

## M1 범위와 보류

새 기본 영웅 후보3안은 같은 영웅의 외형 방향이다. 사용자 선택 뒤 나머지는 스킨 후보로 보존하고 성능을 추가하지 않는다. 철날 검 시제품의 동작 방식은 사용자 선택 대상으로 [07](07-art-character.md)에 기록한다. 무기·진화의 스케일을 키우고 싶은 기둥은 콘텐츠 수 확대나1b 해제 승인이 아니다.
