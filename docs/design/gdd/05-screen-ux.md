## 가신 효과 표시 (#539)

[확정] 가신 전투가 켜진 wave 출정은 부모 #528에서 계산한 스냅샷을 표시한다. 목록의 여섯 행에 보유 능력과 편성 적용값·판 안 상한을 구분하고, 상한에 닿으면 추가 강화로 전투 효과가 늘지 않는다고 알린다. 편성 변경은 다음 출정부터 적용한다. OFF 안내는 보존하며 ON 빈 편성의 적용값 0과 구분한다. 화면이 능력 수치를 따로 계산하거나 저장 규칙을 바꾸지 않는다.

출정 확인창은 뒤쪽 준비 화면의 글자가 비치지 않는 양피지 위에 고정될 편성·능력과 미편성 0값을 표시한다. 편성 변경과 출정 버튼을 제공하며, 확인 전에는 판을 시작하지 않는다. 전투 HUD는 고정 스냅샷의 편성 수를 표시하고 무기 2개·도구 2개와 나머지 `+N`으로 접는다. 예약 높이는 390×844 기준 84px 이내, 일시정지 터치는 48×48 이상이다. 승인 입력은 `vassal-effects-ui-531-20261029`의 목록·출정 r1과 HUD r2이며, 실제 계정 값과 시안 값의 차이는 별도로 기록한다.

구현·검증 상태는 [#539 기록](../../review/vassal-effects-ui-539-20261030.md)을 따른다. 정적 검사나 화면 비율 모사는 기기 검증·사용자 화면 승인을 대신하지 않는다.

## 영지 작업 루프 (#466)

[확정] 승인 Release `m3-estate-work-loops-444-20261027`의 농사 r2·망치질 r1·자루 r1을 쓴다. 완공 밭 가장자리의 농사는 8×200ms, 공사 부지 가장자리의 망치질은 8×150ms이며 기존 정지 작업자를 대체한다. 운반 주민이 곡창으로 돌아왔을 때 자루 8×300ms를 한 번 재생하고 걷기를 잇는다. 공사 부지 도착 때 자루를 재생하지 않는다.

건물 ID 순서로 일감을 고르고 농사·건설·운반을 합쳐 최대 6명을 표시한다. Core·자원·저장·공사 시간에는 영향을 주지 않는다. 기존 unscaled View 시간을 유지하여 페이지를 다시 그리거나 열 때 현재 위상을 표시하고 도착 동작을 처음부터 재생하지 않는다. 숨긴 페이지에는 표시 객체가 없으며, 게임 규칙의 일시정지와 새로 연결하지 않는다.

그림은 농사 96×96(발 기준점 30,83), 망치질 64×76(22,66), 자루 66×66(31.453125,59.5546875)의 원본 크기·발 기준점을 유지한다. 기존 운반 그림은 256셀을 66px로 표시한다. 각 그림의 발 기준점을 같은 지도 좌표에 맞춰 교체한다. 농사 r2의 합성 먼지는 중복해서 그리지 않는다.

30초 고정 60fps 검토 영상은 실제 영지 UI의 명시적 Editor 저장 상태 표본이다. 정상 native 성장·실시간 성능 증거와 구분한다. 화면 검증 후에만 구현 완료를 기록한다.

## 화면을 만드는 기준

[portrait-v0 README](../portrait-v0/README.md)·[보드](../portrait-v0/boards/)·[HTML](../portrait-v0/source/)이 기준이다. 서면과 다르면 그림을 따르며 HTML의390×844pt 좌표·크기·색·폰트와9-slice를 읽는다. Mac은 세로 화면을 가운데 놓고 양옆을 비우며 긴 화면도 safe area 안에 HUD와 버튼을 둔다. 레거시 [screen-flow-v0](../screen-flow-v0.md)의 키 큰 카드 가로3열 설명은 새 그림의 긴 카드 세로3단으로 대체됐다.

본문13pt 이상·보조11pt 이상, 상호작용 영역44pt 이상을 지킨다. 아이콘 자체26pt여도 누르는 영역까지26pt로 줄이지 않는다. 자주 누르는 주 동작은 아래1/3에 둔다. 누름은 다음 프레임에 읽히고 전환 목표는0.2초 이하다. 상시 패널로 전장을 덮거나 전환마다 로딩 스피너를 덧대지 않는다.

## 판 배율과 가장자리 위험 표시 · 2026-10-12 결정

사용자는 [현재/1.4배/1.8배 비교](../../review/m1-2-camera-scale.md) 뒤 **1.4배를 기본 카메라 배율**로 선택했다. 영웅·적·이펙트가 함께 커지는 표시 변경이며 Core 위치·크기·공격 거리·피해·스폰 수치를 바꾸지 않는다. `7bc241f`의 기존 B 그림·역사 경계 지도 비교는 과거 선택 증거로 보존한다. 선택 승인을 새 A 기사 구현 완료나 현재 끝없는 들판의 검증 완료로 쓰지 않는다.

좁아진 시야를 보완하는 **화면 가장자리 위험 화살표 최대 [가설: 6개]**, **돌진 예고 [가설: 0.5초]**는 사용자가 제시한 표시 가설이다. 위험 방향을 알리되 HUD·영주를 가리지 않고 붉은색은 위험에만 쓴다. 이 값은 적 공격 준비 시간·발동 규칙을 조정하는 승인이 아니다. 실제 그림·혼잡 상황 검증 전 구현 완료로 기록하지 않는다.

화면 밖 접근 위험은 실제 피해 사건을 안정 공격자 개체 ID에 귀속해 확인해야 한다. 기존 공격 거리 진입 대리 지표는 실제 피격이 아니다. 같은 입력 재생에서 경고 그림만 켜거나 꺼도 Core 피해는 같아야 하므로, 표시 ON/OFF만으로 피해가 줄었다는 인과를 주장하지 않는다. 경고에 반응한 새 플레이 입력이 있어야 회피 효과를 별도로 판단할 수 있다. 상세 계측 경계는 [06 손맛·연출](06-feedback.md)을 따른다.

  - 위아래 막대와 열린 선택 창은 지도를 가리는 여백으로 계산한다. 끌기 한계가 그 여백을 빼고 정해져, 어느 줄이든 보이는 곳까지 끌 수 있다.
- **등각 격자(M3a-3):**
  - 논리 셀 (u,v)는 화면에서 마름모 64×32다(원본 128×64). 좌표는 x=(u−v)×32, y=(u+v)×16이다.
  - 건물 footprint는 2×2다. 그리는 순서는 footprint 앞 꼭짓점의 화면 y, 같으면 인스턴스 순서다.
  - Core가 저장하는 좌표는 (u,v) 그대로다. 투영은 View에만 있다.
- **넓은 지도와 어둠(#374):**
  - 60×60 격자에 중심 20×20과 안쪽 고리 4구역을 둔다. 1.8(#375)에서 세로 배치 `m3a-prototype-r4`를 도입했고, 1.10(#386)의 새 영지 기본값은 `m3a-prototype-r6`다. r6은 중심 열린 땅을 (26,26)의 8×8로 줄이고 네 둘레 구역으로 이전 중심 영역을 보존한다. 열 채의 부지·경제값은 r5와 같고, r3~r5 파일·저장은 원래 설정으로 연다(자동 이관 없음). 키 아트 A·C처럼 위는 북동 숲·서쪽 언덕(채석장)·풍차, 가운데는 중심 마을, 아래는 밭·마을 확장·휴경·폐허·강가다. 강은 오른쪽 가장자리를 따라 위에서 아래로 흐른다. 영지는 1280×2048(약 1:1.6)이다.
  - 처음 화면은 1.9(#379)부터 "영지" 배율이다. 열린 구역에 둘레 0.75셀을 더한 범위가 보이는 곳에 맞는다(1.10, 기존 2.5셀에서 축소)(키 아트 C 구도) [가설]. 다음 접속부터는 마지막 배율·위치로 연다(개발 설정에 저장, 끌기를 마치거나 배율을 바꿀 때만 기록).
  - 어둠(1.9, #379)은 구역별 덮개가 아니라 열린 땅에서의 거리로 정하는 하나의 연속 어둠이다 [가설]. 복원 빛은 각 열린 구역 중심의 둥근 거리장(정사각 구역은 원형)으로 지면과 어둠에 함께 적용한다(1.10, View만 변경; 논리 열린 칸은 그대로). 빛의 내부는 밝고, 둥근 경계에서 0.5로 시작해 바깥 2.5셀에서 0.75가 된다(사용자 판정 2026-10-25, 0.88과 비교 후)(열린 땅 안쪽 0.5셀은 0에서 0.5로 부드럽게). 색은 키 아트 C의 밤 청회색(#363D49)이다. 지도 전체에 깐 하나의 텍스처(셀당 4텍셀, 쌍선형)라 닫힌 구역 사이에 직선 경계가 생기지 않는다. 구역 둘레 10셀까지 땅을 그리고, 어둠은 그보다 6셀 더 넓게 깔려 마지막 3셀에서 불투명한 밤으로 닫힌다. 그래서 지도 밖도 같은 밤으로 이어진다. 1.8의 구역별 덮개·금빛 경계선·Astra 어둠 경계 마스크는 뺐다.
  - 등불(1.9) [가설]: 열린 땅의 지은 건물(공사 중 포함)마다 M2 RIM 금빛(#E5C97F)의 부드러운 빛을 깐다. 중심 불투명도 0.24에서 가장자리 0으로 사라지고, 반경은 집 3.2셀·그 밖 2.2셀이다. 가산이 아닌 일반 합성이다.
  - 격자선과 생활 장식은 열린 땅에만 그린다. 닫힌 땅의 강·강둑·폐허·다리 등 큰 지형지물은 어둠 위에 밝기 0.4 [가설]의 청회색 실루엣으로 한 번 더 그린다(1.10). 강물은 어두운 청색 띠이고 원색 강둑을 노출하지 않는다. 작은 소품은 어둠 아래에 둔다.
  - 지도에는 구역 라벨이 없다(1.9). 닫힌 구역을 누르면 창에 이름(중심 마을·마을 확장·북동 숲·서쪽 언덕·풍차 언덕·밭·휴경지·폐허·강가 [가설])과 조건이 나온다. 탐사 구역은 "탐사로 열 땅"과 함께 [개방]을 막는다. 전체 보기에서는 다음에 열 수 있는 구역 하나(열린 땅과 맞닿고 조건이 이 설정에서 닿는 구역)에만 작은 금빛 마름모 표식을 둔다.
- **조작:**
  - 한 손 끌기로 둘러본다. 두 손 벌리기·오므리기(손가락 간격 1.35배마다 한 단계), 마우스 휠, +/− 단추로 확대 단계를 바꾼다.
  - 누르면 그 점을 담은 마름모 칸으로 판정한다. 건물은 그 칸을 덮는 footprint로 고른다. 그림 사각형이 아니다.
  - 끌기는 선택하지 않는다. 빈 땅을 누르면 선택이 닫힌다.
- **확대 4단계 [가설]:** 영지 전체(구역 전체를 보이는 곳에 맞춤), "영지"(1.10: 열린 땅 + 둘레 0.75셀에 맞춤, 첫 화면), 동네(셀 64×32), 건물(셀 128×64, 원본 크기). 맞춤 두 단계는 배율 순으로 놓인다(창·바를 뺀 전체 화면 기준). r4처럼 중심 구역이 영지 폭과 같으면 "영지"가 더 먼 쪽이 된다. r5(#379)의 14×14·첫 화면 약 0.32는 역사 설정이다. 현재 r6은 8×8이며 불빛 폭 약 60%, 건물 높이 45~55px를 첫 화면의 시각 목표로 둔다 [가설]. 실제 맞춤 배율은 화면과 열린 선택 창의 크기로 계산하므로 고정값이나 화면 검증 완료 수치가 아니다. 지도의 범위는 구역들의 투영 범위다(1.8, #375). 격자의 빈 모서리는 빼므로, 전체 보기에서 세로 영지가 화면 폭(1280 → 390)에 맞고 높이 약 624(844의 74%)를 쓴다. 끌기도 그 범위에서 멈춘다.
- **선택 창과 이동:**
  - 건물 이름은 선택 창 제목으로만 표시해 그림을 가리지 않는다(1.10). 공사 중 표지는 별도로 남긴다. 선택한 부지 중심을 하단 창 위 보이는 영역의 가운데로 이동한다. 이동 모드에서는 카메라를 강제로 옮기지 않는다. 창이 열리면 +/−·배율·장식 단추는 숨긴다.
  - 선택 창에는 이름, 레벨/최대, 상태, [이동] [닫기]가 있다.
  - [이동] 뒤 칸을 누르면 footprint 마름모 미리보기가 녹색(놓을 수 있음)이나 빨간색으로 보이고, 이유(다른 건물과 겹침, 열린 구역 밖, 공사 중)가 함께 나온다.
  - [확정]은 사본에만 옮기고, [취소]는 마지막 확정 자리로 돌아간다.
- **흐름(M3a-4):**
  - 탭 위에 공사 줄이 있다: 진행 공사와 남은 시간, 예약 수, 재고가 있으면 [받기 n], 개발용 [+1분] [+10분]. 공사 줄을 누르면 대기열 창(진행 1, 예약 2와 취소, 자동 착공 켬/끔, 예약 시작)이 열린다.
  - 건물 선택 창은 다음 레벨 비용과 시간을 보이고, [짓기]/[올리기], 예약 중이면 [예약 취소], 최고 레벨이면 [전문화]를 준다.
  - 전문화 창은 r2 시안 03처럼 두 카드에서 하나를 고르고(금빛 테두리) "…으로 정하기"로 확정한다. 영지 효과는 설정 값으로 보이고, 판 효과는 [가설] 설명이다.
  - 닫힌 구역을 누르면 개방 조건(생산 터 수·비용·준비 시간)과 [개방]이 나온다. 달성한 목표는 목표 줄에 [받기]가 붙는다.
  - 남은 시간과 재고 글자는 1초마다 갱신된다. 완공처럼 화면이 바뀌는 일은 다시 그리되, 끌기 중이면 손을 뗀 뒤에 그린다.
- **자동 장식(#372, 틀):**
  - 규칙은 View 전용 표 `EstateDecorRules.json`이다(Resources, `data/` 밖이라 Core·저장·리플레이 해시와 무관). 결정적 해시(FNV-1a, seed)로 배치한다.
  - 마당: 건물 footprint 둘레 칸에 종류별 개수만큼 놓는다. 고르는 순서를 건물 기준으로 두어, 건물을 옮기면 마당도 따라간다.
  - 길: 집 문 칸에서 각 건물 문 칸까지 격자 L자 길을 낸다. 1.9부터는 모래색 마름모 대신 Astra 마당 바닥(흙)을 칸마다 1.4칸 폭 타원으로 겹쳐 칠한다. 길가 소품은 일정 칸마다 놓는다.
  - 빈 땅 군집: 남은 칸에 군집 수와 크기 범위대로 놓는다. 건물이 움직이거나 구역이 열리면 다시 계산한다.
  - 납작한 소품(고랑)은 바닥층, 선 소품(돌·죽은 나무)은 건물과 함께 발 위치 화면 y 순으로 그린다.
  - 임시 그림은 판 소품(fallow.prop.*)이다. 개수·종류는 Astra 규칙이 오면 표만 바꾼다. 개발용 [장식 켬/끔]으로 그리기 묶음 수를 비교한다.
- **Astra 그림(M3a-5, #375):**
  - **지면:** 두꺼운 상자 칸을 없애고 칠한 지면으로 바꿨다. 열린 땅에 큰 지면 패치(휴경·세이지·복원)를 5칸 간격으로 1.6배씩 겹쳐 깐다 [가설]. 길은 흙 마당 바닥(1.9), 격자선은 이동 중에만 보인다. 아직 짓지 않은 터(레벨 0)는 흙 마당 바닥 위에 선다(1.9). 터 표시(말뚝·줄) 그림은 Astra에 요청했다.
  - **건물:** 10종 × 3단계 그림이 footprint 가운데에 앵커(128, 280)로 서고, 별도 그림자가 아래에 깔린다. Core 레벨이 단계를 고른다: 3단계 건물은 0·1→1단계, 2→2단계, 3→3단계, 1단계 터(경작지·벌목장)는 폐허→3단계.
    - Lv0는 Astra 시작 단계가 가진 무너진 모습을 그대로 쓰고 추가 회색 폐허 틴트를 입히지 않는다(1.10). 열린 빛 안 건물은 원색이며 시작 집은 완성·불 켜짐 상태다. 공사 중 일반 건물은 목표 단계를 흐리게 보이되, 경작지는 빈 고랑(0단계)과 공사 표지를 쓴다. #390의 납작한 Lv0 부지 전환은 별도 후속이다.
    - 철공소는 대장간 그림을 함께 쓴다. 설계상 대장간의 내부 생산 부속이다.
  - **배치:** 마당·길가·빈 땅 군집은 Astra assembly.js 규칙과 seed(20261024, art-v1)를 그대로 옮긴 코드가 놓는다. Astra의 B 조립을 같은 입력으로 돌리면 59개가 모두 같은 자리에 나온다(EditMode 검사). 게임 지도에서는 격자 길과 열린 땅이 그 입력이 된다.
  - **생활 키트:** 나무 군집 2종(복원·세이지 땅의 빈 땅 후보 일부를 바꿈), 밭 울타리 모서리, 양 목장, 강·다리(앞 난간은 주민보다 위), 주민 작업 자세 3종(표시 전용, 생산과 무관)을 쓴다.
  - **닫힌 땅 [가설]:** 큰 지면 패치(휴경, seed로 30%는 세이지), 오른쪽 가장자리를 따라 내려가는 강 패치(닫힌 땅 6장, 중심 1장과 다리), 4칸마다 seed로 흔든 후보 하나(55%)를 그린다. 후보는 북동 숲 구역에서는 75%가 나무 군집, 그 밖은 35%가 죽은 나무, 나머지는 frontier 흔적 6종 중 하나다. 그 위를 어둠이 덮는다. Astra의 어둠 경계 마스크는 어둠이 오른쪽 위로 그려진 그림이라, 닫힌 땅이 열린 땅의 오른쪽 위(−v)에 있는 경계에만 닫힌 쪽에 깐다. 다른 경계는 덮개의 부드러운 변과 RIM 선이 맡는다. 나무 군집·흔적은 받침 섬을 뺀 r2 파일이다.
  - **복원 색 [가설]:** 소품·나무·흔적은 놓인 칸의 상태로 칠한다. 지은 건물과 길에서 2칸 안은 복원(원색), 5칸 안은 세이지(채도 0.7), 그 밖은 휴경(채도 0.35·밝기 0.86), 닫힌 땅은 1.9부터 채도 0.25·밝기 0.95에 M2 어둠 공식 0.25를 섞어 푸르게 칠한다(낮의 황토색이 어둠 사이로 비치지 않게). 어둠은 연속 어둠이 맡는다. 판의 "돌본 곳에만 색"과 같은 방향이다.
  - 수치는 모두 `EstateDecorRules.json` 한 곳에 있다. 그림 교체는 `tools/estate-art.mjs`로 한다.
- Back은 이동 취소 → 선택 닫기 → 종료 확인 순서다.
- **그림은 임시다:** 대장간·기록소·곡물창고·병영은 기존 장원 그림이 footprint 앞 꼭짓점에 선다. 나머지는 올린 단색 블록, 짓지 않은 터는 회색이다. Astra 영지 그림은 승인 뒤에 들어간다.

## 입력·상태·복귀

[Logic HTML](../portrait-v0/source/Logic.html)과 [보드](../portrait-v0/boards/16-Logic.png)를 확인할 수 있다. 앱 백그라운드와 완전 종료/재실행은 다르다.

- 판의 이동은 한 손뿐이며 조이스틱은 손가락 위치에만 나타난다. 메뉴 진입 때 이동 입력을 정리한다.
- 판 안 화면 전환은 Core를 멈춘 상태에서만 한다. 카드 진입 후0.3초 입력 보호, 진입 전 누름의 전달 금지. 같은 제안 재그리기로 보호 시간을 다시 시작하지 않는다.
- Back은 판→일시정지, 다른 화면→이전 화면, 영지→종료 확인이다. Cards→Pause→계속은 같은 카드 제안으로 돌아온다.
- 전화·백그라운드 전환은 자동 일시정지하며 전경 복귀가 자동 전투 재개를 뜻하지 않는다. 설정은 진입한 화면으로 돌아간다.
- 되돌릴 수 없는 포기·큰 자재 지출은 확인 한 번을 받는다. 취소는 부모 상태로 돌아가며 보상을 소모하지 않는다.
- 완전 재실행: 영지는 영지, 준비는 영지로 복귀하고 선택 챕터는 기억한다. 판/카드/일시정지는 정산 기록이 있으면 결산 복원, 없으면 보상 없는 포기로 정리한다. 판 중 이어하기를 새로 가정하지 않는다.
- 결산 중복 지급은 금지, 가신 지출·도전 받기는 즉시 저장한다. 저장 계약은 [04](04-economy.md), 구현 근거는 [ADR0053](../../adr/0053-explicit-meta-claims-and-wave-accounting.md)이다.

## 첫10분의 경험 · 사건 기반 설계

다음은 신규 타이머나 확정 발생 시각이 아니라 안내 순서다. 카드 빈도·경험치·생존 수치를 변경하지 않는다.
