## 플레이어가 하는 일

한 손으로 이동하며 자동 공격·도구 발동·수확의 위치를 바꾸고, 레벨업 때 카드를 선택한다. 전투 중 수동 건물 배치·노동자 배분은 넣지 않는다. 기본 영웅 하나·영지 전통 하나로 먼저 완성하되 Core에 그 ID를 박지 않는다.

판의 순환은 **이동 → 자동 무기·도구 발동 → 적 처치와 지도 흔적 → 성장 완료·경험치 회수 → 카드·진화 → 다음 위협**이다. 판 밖은 **결산 → 상한 있는 자재·해금 → 장원·편성 → 출정**이다. 영지가 실제로 다시 하고 싶은 판을 만드는지는 아직 가설이다.

## 유지하는 경계 P1~P8

| 기준 | 설계·검토 계약 |

## 지도·작업·재생 계약

새 wave 출정은 [ADR0051](../../adr/0051-versioned-endless-fallow-field.md)의 끝없는 휴경 들판이다. 집·작업장은 시작점, 밭·작업물은 만들어진 자리에 남는다. 동일 seed/구역의 소품은 같고 화면 캐시 재생성이 작업을 없애지 않는다. 적은 영주 주변 고리에서 나오며 먼 일반 적은 죽음·경험치 지급 없이 상태를 유지해 재배치한다. 보스 동안만 임시 원형 울타리가 있다. 형식1~3 역사 재생에는 기존 사각 경계를 유지한다.

모든 도구의 설계는 완료 때 경험치 수확으로 닫힌다. 땅은 익은 작물, 건물은 완성·출고, 사람은 임무 완료·귀환이다. 완료 식별 원장이 중복 지급을 막는다. 목수 망치 등은 작업 반경 안에서 이동·전투해도 진행하며 정지를 요구하지 않는다. 아군 ‘무리’는 Core 한 개체·대표 그림으로 표현한다. 성능을 확인하지 않은 동시 상한은 임의 확정하지 않는다.

회색→복원색은 성장 상태의 표현이다. 그 자체에 공격 보너스나 점령 규칙을 추가하지 않는다. 영주 코발트와 적 위험 빨강은 회색 지역에도 유지한다.

> **[결정] 밝힘 구역 한정 예외(1.2, 2026-10-17 사용자 승인):** 위 문장은 돌봄 복원색에 대해 그대로 둔다. `EstateLight`가 있는 선택 프로필에서만 깨운 건물의 **영구 밝힘 구역**이 Core 상태가 되고 어둠 위협 규칙과 이어진다. 그 프로필이 구현되기 전에는 어떤 실행 프로필에도 적용되지 않는다. [ADR0064](../../adr/0064-dark-estate-awakening-buildings.md)를 따른다.

## 프로필과 종료의 경계

역사 [01 v0.2](../01_게임플레이_베이스_v0.2.md)의 first-playable은 30Hz·27000틱·15분과 생존+보스 처치 클리어 규칙을 설명한다. 새 기능을 이 역사 프로필에 소급 적용하지 않는다. 현재 wave 선택은 [프로필](../../../data/profiles/wave-1a.json)과 [runtime](../../../data/runtime/wave-1a.json)을 함께 확인한다. 계정 화면이 보인다고 역사 메타 배율을 wave에 주입하지 않는다([ADR0053](../../adr/0053-explicit-meta-claims-and-wave-accounting.md)).

Core는 실제 피해·이동·결과·재생 해시를 소유한다. M1-1의 적 그림 반동·번쩍임·히트스톱 등은 View 표현이며 실제 적 밀침은 별도 무기 데이터 결정이다. 표현 변경만으로 Core 시간을 건너뛰거나 명령 순서를 바꾸지 않는다.

### 지금 있는 것 (조사, `046fbea` 정적 읽기)

- 색은 View가 현재 작업물(밭·건물·물)과 수확 사건으로 0.1초마다 다시 칠한다. Core에는 색 상태가 없다. 영웅은 색의 원천이 아니다. 땅 칸의 기억이 없어 수확한 밭은 다시 회색이 된다.
- 판 시작에 Core 건물은 없다. 시작점의 집은 장식 그림이다. 밭·건물·웅덩이는 씨앗 자루·목수 망치·빗물 바가지 발동으로만 생긴다. 건물은 영주가 작업 반경 안에 있을 때만 지어지고, 완성되면 목재를 써서 출고 경험치를 준다.

### 판의 순환에 더하는 것

**이동 → 잠든 건물 발견(가장자리 표시) → 켜기(버티기 또는 소비) → 영구 밝힘 → 그 판의 도움 → 어둠 위협 감소**. 기존 순환(무기·도구·성장·카드)은 그대로다. 건물은 고정점이나 전역 효과이고 무기는 영주에 붙어 있다. 그래서 건물은 "어디서 싸울지", 무기는 "어떻게 싸울지"를 바꾼다.

| 시스템 | 입력 → 플레이어에게 읽히는 결과 | 기존/새 |
| --- | --- | --- |
| 잠든 건물 | 판 시작 배치(M2는 데이터 고정 목록, 이후 계정 영지 결과) → 어둠 속 흐린 건물과 가장자리 아이콘 | 새로 만듦 |
| 켜기 | 원 안 머무름·곡물/목재 → 진행 고리, 지불 표시 | 새로 만듦(건물 진행 판정·목재 예약 재사용) |
| 영구 밝힘 | 활성 건물 → 줄지 않는 복원색 원 | 새로 만듦(마스크·셰이더 확장) |
| 어둠 위협 | 밝힘 밖의 적 → 강화 표식, 더 아픈 공격 | 새로 만듦 |
| 건물 효과 | 활성 건물 → 사격·회복·수비·자석·강화·벽·공개 | 일부 재사용(완성 건물 공격·무리·회수) |
| 무시 보너스 | 잠든 채 남긴 건물 수·클리어 → 결산 가산 | 새로 만듦(수치 #126) |

### P1~P8 검토

| 기준 | 결정의 처리 |
| --- | --- |
| P1 | 건물은 도구가 아니므로 도구의 발동·성장 면을 대신하지 않는다. 막사는 뿔나팔의 귀환 경험치를 하지 않는다 |
| P2 | 건물 밝힘과 효과가 지도 위 자리의 힘이 된다. 재미는 M2 실험으로 판정한다 |
| P3 | M2에서 깨운 건물은 공격받지 않는다 [결정]. P3 연결(공격·기능 정지·수리, 빛 유지 권고)은 후속이다 |
| P4 | 버튼 없이 들어가고 머무는 이동만으로 켠다. 소비는 0.5초 머문 뒤 자동 지불한다 [가설] |
| P5 | 어둠은 지형·성장물 셰이더에만 적용한다. 적·공격·아군은 원래 색이다 |
| P6 | 판매는 건물 외형만, 그림 참조만 가진다 |
| P7 | 빛이 있는 곳은 깨어난 영지이고 어둠은 위협이다. 인과가 닫힌다 |
| P8 | 건물 ID·효과를 데이터에서 주입하고 검사용 더미 건물을 같은 경로로 검사한다 |

### 원칙

- 건물은 버팀목이고 주인공은 무기다. 건물의 피해 몫과 전역 강화에 상한을 둔다 [가설].
- 깨울수록 쉬워지되 이득은 체감한다. 건물 없이도 강한 빌드는 완주할 수 있어야 한다.
- 잠든 채 남긴 건물은 클리어 결산의 보너스가 된다. 강한 플레이어에게 다른 목표를 준다.
- 영지 성장은 시간과 플레이로만 한다. 건물 레벨·자재·켜기 감면은 팔지 않는다. 방치 2배 광고는 영지 자재에 적용하지 않는다 [결정].

손맛이 준비된 다음 영지 도구 A(도구도 무기처럼) / B(영지가 전투 유닛) / C(영지는 판 밖만)를 비교한다. 실험 프로토콜·채택안은 [미정]이며 이번 GDD 통합은 어느 안의 구현 승인도 아니다. #126의 정책 우세·생존율·경제 조정과1b는 보류다.

[1.2] "어둠 속 영지"는 B와 C의 결합이다. 판 밖 영지가 판 안 건물을 정하고(방향 결정, M2 이후 구현), 판 안 건물이 전투를 돕는다. 이 실험이 A/B/C 비교 전체를 대신하는지는 [미정]이다. 사용자 결정은 [M2 설계 8절](../m2-dark-estate-buildings.md)에 있다.
