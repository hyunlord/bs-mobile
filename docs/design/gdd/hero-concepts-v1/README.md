- 상태: [초안] 외형 미선택. 능력·영웅 ID·기본 실행 외형은 바꾸지 않는다.
- 원화: imagegen 생성, 잉크·과슈. 투명 PNG 원본을 보존한다. 별도 IP나 외부 캐릭터 참조 없음.
- A-knight.png: 정통 개척 기사. 긴 코발트 망토·상아 누비옷·긴 실루엣.
- B-scout.png: 경쾌한 성인 개척자. 짧은 망토·바지·땋은 머리·가벼운 자세.
- C-warden.png: 거한 장원 수호자. 넓은 어깨·작업 앞치마·짧은 망토·무거운 자세.

- 선택하지 않은 두 안은 외형 후보로 보존한다. 스킨 능력치를 만들지 않는다.
- 실제 판 390pt 비교는 동일 리플레이·틱·화면 크기에서 원화 정면을 View에만 교체해 캡처한다. 생성 이미지로 판 화면을 합성해 실제 캡처라 부르지 않는다.
- 현재 원화는 모션 제작 방식 비교에 쓰지 않는다. b/c 비교는 승인된 기존 B 부위만 공유한다.

## 생성 입력 요약

공통: 성·밭·공성의 휴경 왕국, 잉크 선과 불투명 과슈, 코발트/상아/강철/갈색/밀 금빛, 아군 빨강 금지, 60px에서도 읽히는 큰 형태, 투명 배경, 별도 장면/문구 없음. 각 방향의 체격·복식·표정·검 자세를 위와 같이 지정했다.

원본 시트 1536×1024. 실제 View 검토는 원본 픽셀 정면 범위 A(0,15,532,925), B(0,0,495,995), C(0,25,470,940)를 사용한다. 동일 발 기준·기존 영주 높이로 배치하며 그림 자체를 영웅 선택의 확정으로 취급하지 않는다.

### 실제 판 크기 정규화

기존 B의 `fallow-hero-b-layers.png` idle 12번 셀에서 네 층의 알파 합집합을 검사했다. 알파 ≥8/255 기준 세로 범위는 y=44–210, 실제 그림 높이 167px이다. 런타임은 256px 셀을 252px 역할 크기에 맞춰 그리므로 기준 높이는 `hero.preview-b.idle.worldSize.y × HeroRigHeightScale × 167/252`이다. 빈 여백까지 포함한 quad 높이로 후보를 맞추면 후보 A가 약 1.45배 커지는 오류가 있었다.

같은 기준으로 후보 crop의 실제 그림 높이/아래쪽 픽셀은 A 888/900px, B 968/985px, C 892/917px이다. 후보 quad 높이는 `기준 실제 높이 × crop 높이 / 후보 실제 그림 높이`로 정규화하고, 실제 그림의 아래쪽 픽셀 중심을 발 기준점에 놓는다. 원화 비율·폭은 유지하며 Core 크기나 판정은 바꾸지 않는다. 8/255 문턱은 거의 투명한 가장자리 잡음을 제외하는 공통 측정 기준이다. 변경 뒤 네이티브 재캡처로 화면 비교를 갱신해야 한다.
