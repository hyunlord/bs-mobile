## 1. 범위와 현재 구현 경계

첫 출시는 공유 타일맵, 자원지 채집 행군, PvE 몬스터·거점과 직접 서바이버 참전, 정찰·공격·보호막, 연맹 생성·채팅·도움 가속을 포함한다. **연맹 영토, 서버전, 시즌은 출시 후**다. 집결전·지원군 파견·도시 이전·자원 거래·실시간 PvP 직접 조작도 이번 최소안에 넣지 않는다. PvP는 아래 자동 판정안으로 검토하며, 직접 조작은 PvE에 제공한다.

현재 [r8 설정](../../../data/opt-in/account-estate/m3a-prototype-r8.json)은 개인 계정의 영지 배치다. [WaveEstateContract](../../../core/src/SowSiege.Core/WaveEstateContract.cs)는 판 안 영지 효과의 계약이지 공유 서버 월드가 아니다. 이번 월드·연맹·행군은 신규 설계이며 존재하는 변수 이름이나 그림을 구현 증거로 세지 않는다. [가신 snapshot](13-vassal-combat-proposal.md)과 역사 리플레이는 보존한다. C# 서버의 실행·검증·인증·저장 구조는 Codex 별도 ADR이 정한다.

## 2. 타일과 주소 [가설]

| 항목 | 첫 안 |
|---|---|
| 월드 | 논리 서버 하나, 128×128 정사각 타일. 주소는 `(worldId, x, y)`, 정수 x/y 범위 0~127, 가장자리 순환 없음 |
| 계정 영지 | 월드에는 계정의 마을 표식 1타일만 둔다. 내부의 r8 13구역·1,664칸·2×2 건물 격자는 별도 `(accountId, zoneId, u, v)` 공간이다. 축척·소유권을 혼합하지 않음 |
| 타일 종류 | 평지/숲 통과 가능, 산·물은 통과 불가, 고정 다리는 통과 가능. 도시·자원지·몬스터·거점 표식은 목적지이며 타인의 통과를 막는 영토가 아님 |
| 배치 | 계정 생성 시 서버가 연결된 시작권역의 빈 마을 자리를 배정. 도달 불가능한 섬·봉쇄 타일 배정 금지. 수용량을 넘으면 임의 두 도시 중첩/새 서버 생성 대신 운영 수용 정책을 적용 |
| 경로 | 상하좌우 인접 이동. 통과 가능한 최단 경로의 간선 수 d를 거리로 사용. 동률은 고정된 좌표 순서로 결정. 지형은 첫 출시 중 플레이어가 변경하지 않음 |
| 공개 정보 | 지형·도시 위치/계정명·연맹명·자원지 종류·몬스터/거점 등급은 보임. 도시 자원량·수비 병력·진행 작업은 정찰 성공 정보로 분리 |

한 타일에는 동시에 하나의 상호작용 대상만 둔다. 대상의 재생성은 같은 좌표라도 `targetId + generation`이 다른 사건이다. 개인 도시 표식은 계정 소유지만 주변 타일 소유권·통행세·연맹 경계로 확장되지 않는다. PvE 거점은 격파/회복 상태가 바뀌는 공유 목표이며 영구 점령·영토 보너스는 없다.

## 3. 행군 상태·편성·시간 [가설]

계정 동시 행군 칸은 2개, 행군별 지휘 영웅은 1명이다. 영웅 하나는 귀환 확정까지 다른 행군·직접 전투·수비에 복제하지 않는다. 기본 기사만 보유하면 동시에 지휘할 행군도 하나뿐이며 무료 영웅 획득 경로를 유지한다. 영웅 수집을 행군 칸 무제한 구매로 바꾸지 않는다. 직접 조작 전투는 계정당 동시에 1판이다.

병영 L1/L2/L3의 단일 행군 인원20/40/60, 계정 총60/120/200, 병상20/40/80은 병력 GDD의 후보를 유지한다. 병종별 준비 R에서 D로 잠그고, 편성 영웅·가신·연구·효과 상한·규칙/콘텐츠 버전·목적지 세대를 발령 때 고정한다. 새로운 연구·강화는 이미 출발한 왕복 여정에 소급하지 않는다. 가신+영웅+연구 동종 전투 보너스의 공통 cap도 영웅 GDD대로다.

| 상태 | 전이와 자원/잠금 |
|---|---|
| 확인/발령 | 서버가 목적지·경로·슬롯·인원·영웅·공격 자격을 검사. 성공한 같은 명령에서 R→D, 영웅/행군 칸 잠금, 시작 시각 기록. 거절은 변화 없음 |
| 이동 중 | 서버 시간으로 도착. 출발 전 취소는 잠금 없음. 출발 후 취소는 현재 경로상의 이동 지점에서 회군하며 즉시 R 복원하지 않음 |
| 도착 | 목표 ID/세대·보호막·동맹 관계·경합을 다시 검사. 없거나 사용할 수 없으면 손실/보상 없는 회군. 자동으로 다른 목표를 공격하지 않음 |
| 채집 / PvE 대기 / 전투 | 타일 사용권 또는 전투 계약에 잠김. 전투 시작 후 단순 취소로 원상 복귀하지 않음. 정산이 불명확하면 잠금 유지 |
| 귀환 | 운반물·결과 자격을 보유한 채 원래 도시로 이동. 첫 출시에는 귀환 행군을 공격하지 않음 |
| 귀환 확정 | 병력 수량·부상/전사·지갑/수령 대기·영웅과 슬롯 해제를 한 번 확정. 중복 요청은 기존 결과만 반환 |

기본 이동은 간선당10초다. `travelSeconds = ceil(10 × d / (1 + min(10%, 월드 행군속도 합)))`. 연구 A3 최대6%와 모든 원천 합산10% 상한을 따른다. 판 안 이동 보너스를 여기에 더하지 않는다. 왕복은 각각 실제 경로 길이에 같은 출발 snapshot 속도를 적용한다. 중도 회군은 서버가 계산한 지나온 간선/현재 간선 진행분의 거리로 산정하며, 앱의 좌표/시계로 줄이지 않는다. 좌표 같음은 거리0이고 도착 처리를 한 번만 한다. 첫 출시에는 유료 순간이동·행군 가속 상품을 추가하지 않는다.

접속 종료는 이동/채집 시간을 멈추지 않는다. 요청 재전송은 같은 marchId를 조회한다. 연결 실패를 취소 완료로 간주하거나 새 병력으로 재발령하지 않는다. 서버가 확정한 취소만 잠금을 해제한다.

## 4. 자원지와 운반 보존 [가설]

곡물·목재·철재 자원지를 둔다. 초기 노드 재고는 종류별600개, 채집속도는 병사당 분당1개, 적재량은 병사당10개다. 병종 차이·연구 채집 보너스는 첫 안에 넣지 않는다. 자원지 채집에는 영웅과 준비 병력1명 이상이 필요하며, 병력0의 무료 개인 기초 개척전은 별도 경로다.

자원지는 도착 확정 순서에서 한 행군만 채집권을 얻는다. 출발 화면의 “비어 있음”은 예약 보장이 아니다. 다른 행군이 먼저 얻으면 자동 공격하지 않고 회군한다. 첫 출시에는 채집 중인 타인 부대를 공격하지 않는다. 서버는 재고·채집량·적재량을 같은 진행 사건으로 갱신하고, 가득 참/재고 고갈/사용자 회군 확정 때 채집권을 해제한다. 채집권을 잃은 과거 요청은 같은 세대에 다시 자원을 가져올 수 없다.

자원지 고갈 후10분에 새 세대를 생성한다. 첫 세대의 잔량을 새 세대 보상으로 넘기지 않는다. 서버가 생성한 유한 원천량을 기준으로 `생성 재고 = 남은 재고 + 누적 채집 확정량`을 유지한다. 누적 채집 확정량은 현재 운반 중인 양과 이미 귀환하여 지갑/수령 대기로 옮긴 양을 모두 포함하는 원천 원장이며, 지급 후에도 차감하지 않는다. 완료된 세대의 재전송은 새 세대 재고를 차감하지 않는다.

채집/전투에서 확정된 운반물은 귀환 시 지급한다. 지갑 여유만큼 지급하고 나머지는 해당 귀환 ID의 **수령 대기 운반물**로 보관해 버리지 않는다. 수령 대기는 거래·재출정 적재·생산 보너스의 대상이 아니고 소유자만 한 번씩 지갑 여유만큼 받는다. 최초 발령 때 수령 대기가 남아 있으면 새 자원 획득 행군을 막아 무제한 외부 창고로 쓰지 못하게 한다. 전투 중 이미 확정된 귀환까지 버리지는 않는다. 지원 가능한 최대 대기량은 행군 상한·적재 상한에서 유도해 서버 ADR에서 검증하며, 범용 무한 우편함으로 확장하지 않는다.

## 5. PvE 몬스터·거점과 직접 참전

몬스터는 단발 전투, 거점은 표식/길목 수비 등 목적이 있는 전투다. 각 목표는 콘텐츠 버전별 병력 권장치·조건·보상 후보를 공개하며, 강도 수치와 승률은 전투 밸런스 표 없이 확정하지 않는다. 보상 원천은 해당 targetId/세대의 유한 목록이다. 물질 보상 후보 합계는 출정 N×10 이하로 발령 전에 표시하고, 승리 후 실제 자재는 생존 S×10 적재 한도와 보상 후보 중 작은 양으로 확정한다. 곡물→목재→철재 순으로 배분하며 한도를 넘은 후보는 획득되지 않고 우편/수령 대기로 우회 지급하지 않는다. S=0이면 물질 운반물은0이다. 탐사 자격·영웅 일지 등 비물질 보상은 별도 유한 중복 방지 원장을 사용하며 운반량에 넣지 않는다. 거점 승리가 연맹 영토나 자동 수익 구역을 만들지 않는다.

[가설] 도착 때 첫 행군이 목표를 잠그고 **직접 참전 / 자동 전투 / 회군**을 선택한다. 직접 참전이 불가능한 바쁜 계정은 자동/회군만 선택한다. 선택 대기60초를 넘기면 손실 없는 회군으로 종료하고 목표를 해제한다. 직접과 자동은 하나의 encounterId에 둘 다 실행할 수 없다. 자동 전투는 서버 규칙으로 판정하며 높은 보상을 보장하지 않는다. 직접 조작은 같은 목표의 전술적 달성을 플레이로 바꾸는 선택이지 클라이언트가 보상값을 정하는 권한이 아니다.

서버는 대상 세대·성공 조건·제한시간·병력 N·영웅/가신/연구 snapshot·규칙/콘텐츠·보상 정책을 묶은 run 계약을 발급한다. 직접 참전의 Core 결과를 서버 실행/검증 중 어떤 방식으로 신뢰할지는 Codex ADR이 확정한다. 클라이언트의 승리·시간·피해·K 숫자만 받아 정산하는 안은 허용하지 않는다. 제한시간은 목표 콘텐츠에 명시하고 무기한 목표 잠금을 허용하지 않는다.

연결 끊김은 같은 runId로 재개한다. 입력 부재 구간은 계약의 안전한 무입력으로 진행하며, 제한시간 도달은 실패/퇴각 결과로 확정한다. 서버 장애로 결과를 판단할 수 없으면 별도 복구 대기 상태를 표시하고 기존 결과 조회/복구를 한다. 목표가 잠겨 있는 동안 같은 세대를 재생성·재지급하지 않는다. 운영 취소가 필요하면 명시적인 서버 취소 사건으로만 무보상 복귀시키며, 이미 확정된 성공을 취소해 재보상하지 않는다.

**전투 종료 커밋**은 목표 격파/회복 상태, 병종별 N/K, 보상 자격, 개인 탐사/개방 자격, 회군을 함께 확정한다. 이때 병력은 D에 잠겨 있으며 최종 입원 A/전사 L은 아직 아니다. **귀환 커밋**에서 병력 GDD의 `S=N−K`, `A=min(floor(K×부상률), 남은 병상)`, `L=K−A`, `N=S+A+L`을 적용하고 운반물 지급/수령 대기와 잠금 해제를 확정한다. PvE 부상률80%, PvP60% 후보는 유지한다. 입원은 동시 귀환의 서버 확정 순서를 따르며 미리 병상을 보장한 것처럼 표시하지 않는다.

[가설] 격파된 몬스터는10분, 회복된 거점은30분 뒤 새 세대로 다시 위협을 만든다. 실패는 같은 목표 세대를 다시 도전할 수 있지만 이미 발급한 같은 runId의 보상을 다시 받지 않는다. 목표의 새 세대가 개인의 기존 구역·연구 해금 자격을 되돌리지 않는다.

## 6. 정찰·공격·보호막 [가설]

정찰은 영웅과 병사1명, 행군 칸을 사용하며 전투를 하지 않는다. 대상 도시 도착 시 해당 시점의 수비 병종/인원, 보호막 상태, 약탈 가능한 자원 범위를 보고한다. 정확한 생산/연구 큐·미수령 보상·보석·가신/영웅 전체 보유 목록은 공개하지 않는다. 보고에는 관측시각이 붙고 실시간 보장 정보가 아니다. 첫 안에서 정찰병 손실은 없으며 귀환까지 잠긴다. 타인의 보호막이 있으면 보고 없이 회군한다.

공격은 자기 계정·동일 연맹을 대상으로 할 수 없다. 발령/도착 모두 이 관계와 보호막을 검사한다. 행군 중 같은 연맹이 되거나 보호막이 생기면 무손실·무보상 회군한다. 취소한 공격의 출발 시 보호막 해제/공격 제한시간은 되돌리지 않는다.

도시 PvP는 서버의 자동 전투다. 공격측은 발령 snapshot을 사용한다. 수비측은 도착 판정 직전에 남아 있는 준비 R에서 단일 행군 상한까지 병종 순서/명시된 수비 편성 우선순위로 선택하고, 미리 지정한 수비 영웅이 사용 가능하면 그 영웅과 지원 효과를 고정한다. 지정 영웅이 행군/판에 잠겼거나 없으면 영웅 기여0으로 R 수비를 계속하며 임의의 다른 영웅을 대체 소환하지 않는다. 가신·연구는 수비 시작 시점 snapshot과 같은 합산 상한을 적용한다. 다른 행군의 영웅·D·W·Q는 수비에 복제하지 않는다. 수비에 선택한 인원 B는 **R 내부의 잠긴 부분집합**이므로 `O=R+D+W+Q`에 B를 다시 더하지 않는다. B의 출정/훈련 취소·다른 수비 동시 사용을 막고 대상 도시의 전투를 확정 순서로 직렬 처리한다.

수비는 고유 defenseId의 즉시 귀환으로 간주하며 귀환 이동 없이 전투 확정 때 `R에서 N 차감 → S 복원, W에 A 추가, L 소멸`을 한 번 적용하고 B 잠금을 푼다. 공격측 N/K는 회군까지 D에 남고 귀환 때 S/A/L로 정산한다. 방어자 병상도 같은 확정 순서로 배정한다. 수비 병력0이면 건물을 파괴하지 않고 아래 보호량을 넘는 자원만 약탈 가능하다. 영웅·가신 삭제, 건물 레벨/연구 강등, 열린 r8 구역 회수는 없다.

약탈 대상은 곡물·목재·철재 **현재 지갑**뿐이다. 보석·인장·영웅/가신 조각·미수령 보상·운반물·예약 비용·생산 시설 재고는 제외한다. 자원별 보호량100, 해당 자원 약탈한도 `floor(max(0, wallet−100)×10%)`를 후보로 둔다. 전체 적재는 살아 돌아갈 공격측 S명×10개 이하이며 곡물→목재→철재 순으로 한도를 배분한다. 승리 때만 `방어 지갑 감소 = 공격 회군 운반물 증가`를 같은 거래로 확정한다. 귀환은 지갑/수령 대기로 옮길 뿐 원천을 다시 만들지 않는다. 보상을 잃었어도 개인 무료 기초 개척전의 진입은 유지한다.

| 보호 규칙 | 후보 계약 |
|---|---|
| 신규 보호 | 계정 생성부터24시간 무료 보호막. 첫 앱 실행/기기 변경으로 다시 지급하지 않음 |
| 평상시 보호 | 계정별24시간마다 무료 보호막4시간 사용 가능. 생성 시점부터 서버 시각으로 다음 사용 가능 시각을 기록하며, 반복 재접속·연맹 변경으로 초기화하지 않음 |
| 효력 | 도시 정찰·공격만 막음. PvE/채집 가능하며 진행 중 생산·연구를 멈추지 않음. 신규/평상시를 포함해 보호막 활성 중에는 새 보호막을 켜거나 시간을 겹쳐 더하지 않음 |

방어자는 공격이 이동 중이어도 사용 가능한 무료 보호막을 켤 수 있다. 자원 소비·병력 손실 전에 “보호로 회군” 결과를 공격자에게 보여 준다. 유료 보호막 판매·무한 연장·보호막 강제 파괴 상품은 이번 제안에 넣지 않는다. 반복 표적화 방지를 위해 같은 공격자→방어자 공격은 귀환 뒤30분 간격을 두는 후보를 함께 검토한다. 여러 계정의 괴롭힘·보호막 빈틈 악용은 운영 신고/제재와 별도 밸런스 실험의 대상이다.

## 7. 연맹 생성·채팅·도움 [가설]

연맹 생성은 무료, 계정당 소속1개, 정원20명이다. 유료 VIP·영토 보유·서버간 동맹은 없다. 가입은 공개 가입 또는 신청 승인 모드 중 연맹장이 선택한다. 역할은 연맹장/간부/회원이며 간부는 가입 승인·회원 추방을 할 수 있으나 연맹장 교체·해산은 못 한다. 연맹장은 후임을 지정한 뒤 탈퇴하고, 마지막 회원만 해산할 수 있다. 해산·이름 변경·추방은 권한과 확인 절차를 거친다. 탈퇴/추방 이후 가입 제한12시간은 재가입 도움 악용 방지 후보이며 첫 가입에는 적용하지 않는다.

연맹 채팅은 해당 연맹 현 회원만 쓰고 읽는다. 탈퇴자는 새 메시지 접근이 끊기며, 운영 신고 대상 메시지의 증거는 서버 운영 정책에 따라 보존한다. 첫 안은 메시지200자·5초당1회, 차단/신고/운영 삭제·일시 채팅 제한을 포함한다. 사용자 차단은 개인 화면 숨김이고 서버의 멤버 권한 검사를 대체하지 않는다. 보존 기간·개인정보/미성년자·운영 권한은 출시 전 운영 정책에서 확정하며 이 수치가 법규 충족을 보증하지 않는다. 월드 전체 채팅·개인 거래 메시지는 이번 범위 밖이다.

도움은 현재 활성 건설·훈련·연구·치료 작업에 요청한다. 대기/완료/취소 작업, 행군/채집/전투에는 적용하지 않는다. 도움 요청은 고유 jobId와 시작 때의 연맹 ID에 묶고, 요청자 자신은 줄 수 없다. 매 도움 확정 때 제공자와 요청자의 현재 연맹이 모두 job 시작 연맹 ID와 같은지 검사하여 탈퇴 제공자·타 연맹의 요청을 거절한다. 제공자별 `(jobId, giverAccountId)`는 평생1회, 작업 전체 최대5회다. 제공자·요청자가 연맹을 나갔다 들어와도 횟수를 초기화하지 않는다. 요청자가 탈퇴/추방되면 남은 도움 요청은 닫고 새 연맹에 같은 작업을 다시 요청하지 않는다. 이미 확정된 단축은 유지한다.

작업의 속도 보너스를 반영한 최초 지속시간을 D0, 현재 남은 시간을 R로 놓는다. **1회 단축 `min(30초, floor(D0×2%), R)`**, 누적 도움 상한 `floor(D0×10%)`를 후보로 둔다. 소수 초는 버리고 결과0이면 횟수나 재화를 소비하지 않는다. 남은 시간 최저0초이며 도움으로 완료될 수 있다. 유료 가속은 별도의 남은 시간 차감이지만 완료된 작업에 소비되지 않는다. 도움과 가속·완료가 경합하면 서버가 한 순서로 처리하고 매번 남은 시간을 다시 검사한다. 작업 완료·다음 작업 시작을 같은 확정 명령에 포함하되 남는 도움량을 다음 작업으로 넘기지 않는다.

예: 속도 반영 뒤 D0=200초 작업은 1회4초, 최대5회20초 단축이다. 훈련 속도30%·건설 속도30% 상한을 추가 속도 배율로 다시 곱하지 않는다. 연구의 기본 시간과 진행 작업 snapshot도 그대로다. 도움 제공에 자원/보석/병력 보상을 붙이지 않아 다계정 보상 농장을 만들지 않는다.

## 8. 서바이버 판이 실제로 바꾸는 것

| 검증된 판의 목표 | 개인 r8/연구 변화 | 공유 월드 변화 |
|---|---|---|
| 밭·숲 작업대·광석길 확보 | 지정 `zone:inner-fields`, `zone:inner-northeast-wood`, `zone:inner-west-hill` 중 계약된 구역의 개방 자격, 대응 경제 연구 탐사 증명 | 잠긴 자원지의 방해자 제거/채집 가능 상태. 실제 자재는 채집과 귀환으로 얻음 |
| 폐허 표식·거점 회복 | `zone:inner-ruins` 개방 자격 또는 기록 회수 연구 조건 | 해당 targetId/세대의 거점이 회복 상태로 바뀌고 다른 행군은 같은 세대를 다시 격파하지 못함 |
| 강가 통로 수비 | `zone:inner-riverside` 개방 자격 또는 행군 측량 조건 | 지정 목표/채집대의 위협 제거. 고정 다리 지형을 즉석에서 새로 만들지는 않음 |

각 계약은 이 중 실제 해당하는 대상과 자격만 포함하며 한 판 성공으로 모든 구역을 열지 않는다. 개방 자격은 계정·구역별 한 번이고 실제 개방은 기존 r8 인접·비용·조건을 만족해야 한다. r8의 13구역 배치·크기를 이 문서에서 바꾸지 않는다. 이미 열린 구역의 반복 PvE는 명시된 자재/영웅 일지 보상만 주며 땅을 추가 복제하지 않는다. PvP 승리는 개인 영지·연구 증명의 원천이 아니다.

기초 개인 개척전은 월드 병력/적재량·연구·수집 영웅이 없어도 기본 기사로 무료 참가한다. 특정 월드 목표의 경쟁 때문에 신규 계정이 영구 잠기지 않도록 동일 탐사 목적의 개인 임무 대체 경로를 둔다는 연구 제안을 따른다. 개인 임무는 다른 계정의 공유 거점을 격파한 것으로 기록하지 않는다. 이 대체 경로도 실제 전투·서버 검증과 중복 방지 규칙을 거친다. [가설] 병력0 예외의 개인 판 물질 보상은 합계60개 이하, 계정당 미수령 개인 보상도60개 이하로 별도 제한한다. 판 시작 때 남은 수령 여유를 계약에 예약하고 그 안에서만 보상 후보를 표시한다. 수령 대기가 가득 차도 무료 판·탐사 자격 획득은 계속 가능하지만 추가 물질 보상은0으로 사전 표시한다. 개인 보상은 시작 전에 곡물/목재/철재 중 필요한 종류를 선택한다. 불필요한 개인 수령 대기는 자원 종류·수량·복구 불가를 보여 주는 명시적 포기 확인으로 폐기할 수 있다. 폐기는 대기량 감소와 폐기 원장 증가를 함께 확정하며 재발급·보상 환산을 하지 않는다. 따라서 다른 자원으로 가득 찬 대기를 정리한 뒤 필요한 자원의 무료 판을 다시 할 수 있고, 모든 물질 복구 경로가 막히거나 무한 대기 창고가 생기지 않는다. 월드 수령 대기의 최대치는 동시 행군 상한×행군 병력 상한×병사 적재량, 개인 대기는 별도60개로 검증한다.

## 9. 서버 책임·검증·화면

서버는 계정/대상 세대/행군/작업의 명령 ID와 상태를 권위 있게 판정한다. 도착 동률·보호막·채집권·동시 공격·병상·도움의 확정 순서를 재현 가능하게 기록한다. 동시성·저장 원자성·복구 세대·장애 주입·배포 롤백·전투 검증 실행 위치는 Codex C# 서버 ADR에 넘긴다. DB·큐·프로토콜·프로세스 수는 여기서 채택하지 않는다. 개발 장원/시간 가속 저장을 정식 서버에 수입하지 않는다. 기존 format7/8와 골든을 덮어쓰지 않고 새 월드/전투 계약 버전을 따로 설계한다.

화면은 발령 전 예상 시간·편성·남는 수비대·적재·위험·보호막 해제를 보여 준다. 이동/대기/전투/회군/정산 대기를 구분하며, “전투 승리”와 “자원 도착”을 같은 완료로 숨기지 않는다. 전투 직후 N/K·예상 입원, 귀환 후 S/A/L·실제 지급/수령 대기를 표시한다. 연맹 도움에는 남은 횟수와 실제 단축 초를 표시한다. 승인된 390×844·48×48 터치 기준을 유지하며 이번에 새 그림/화면 시안을 만들지 않는다.

후속 구현 종료 관문:

1. 타일/경로 경계·도달 가능 배치·타일 세대·동시 채집에서 이중 점유/재고 음수/동일 세대 중복 보상 없음.
2. R/D/W/Q 보존과 수비 B의 R 내부 예약, 영웅 중복 배치 거절, 동시 공격/귀환 병상, 영지 건물·개방 구역 보존.
3. 발령·도착·보호막 활성/종료·연맹 변경 경합을 고정 사건 순서로 검사. 보호막 경계에서 피해/약탈이 두 번 적용되지 않음.
4. 공격측 운반 증가=방어측 지갑 감소, 채집 원천=잔량+누적 확정량(현재 운반+귀환 지급), PvE S=0·적재 초과·개인 무료 판 대기 상한, 귀환/수령 대기 중복 요청·지갑 가득 참·서버 재시작의 총량 보존.
5. 직접/자동 동시 시작 거절, 연결 끊김/입력 부재/시간 종료/검증 실패·결과 불명확을 구별. 실제 검증 전 클라이언트 결과로 세계를 변경하지 않음.
6. 연맹 권한·탈퇴 접근 차단·신고/차단·도움 중복/재가입/완료 경쟁. 속도와 시간 차감의 다른 단위,0초 작업과 차감0 경계를 확인.
7. 실제 휴대폰에서 개인 개척→훈련/연구→월드 직접 PvE→공유 대상 변화→귀환 자원/부상→영지 확장→연맹 도움을 관측. 다계정 정상/고밀도·장시간·서버 장애 검증은 별도 실측.

사용자 검토가 필요한 후보는 지도 크기·행군 칸, 채집 독점/채집 PvP 제외, 자동 도시 PvP, 약탈/보호막/반복 표적 제한, 부상 손실, 연맹 정원/도움, 개인 탐사 대체 경로다. 수치와 규칙은 초기안이며 법규·공정성·밸런스·재미가 검증됐다고 주장하지 않는다. 문서/산술 외 서버·게임·실기 관문은 **NOT_RUN**이다.
