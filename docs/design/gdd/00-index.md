## 기둥 v0 · 2026-10-12 사용자 승인

1. **타격감:** 소리를 꺼도 적을 맞혔다는 것을 읽는다. 일반 타격을 전체 화면 정지로 대신하지 않는다.
2. **캐릭터·무기별 몸동작:** 한눈에 끌리는 영웅과 무기 성격이 드러나는 동작을 만든다.
3. **다 해 보고 싶은 무기·진화 스케일:** 형태·크기·리듬이 다르고 진화에서 변화가 읽힌다.
4. **영지가 힘이 된다 [가설]:** 차별점 후보이지 재미가 입증된 사실이 아니다. M1 실험으로 판정한다.

기존 P1~P8 경계는 [01 시스템](01-system.md)에 보존한다. 영지의 재미가 미증명이라는 사용자 판정은 기존 기능을 삭제하거나 경제 수치를 바꾸라는 승인이 아니다.

## 결정·보류 장부

### 최신 결정 · M1-5 예산 0 경로 (2026-10-13 기록)

사용자 M1-4 판정은 **실패**다. AI 생성 2D 프레임 방식은 중단하고 결과를 실패 기록으로 보존하며 PR261은 초안으로 유지한다. 승인된 외형은 A 정통 개척 기사, 판 배율은 1.4배다. 이전 모션 선택은 새 제작 방식의 통과 근거가 아니다.

현재 순서는 무료 A(승인 원화→Microsoft TRELLIS.2→Mixamo) → 손·검·얼굴 메시 품질 실패 시 무료 B(Mixamo 기성 기사형) 비교다. **둘 다 실패한 뒤에만** US$100 이하 유료 후보 3개를 조사하며 구매는 사용자 선택·승인 후 사용자 직접 수행한다. 현재 유료 후보 조사는 중단한다. Hunyuan3D는 사용하지 않는다.

2026-10-13 후속: 사용자 DINOv3 약관 검토·게임 제작 동의는 완료됐고 HF 접근 승인만 대기한다. MIT BiRefNet과 허용 의존성을 먼저 준비한다. 오늘 안에 접근 승인이 오지 않으면 A 메시 실패 없이도 무료 B로 파이프라인을 시험할 수 있으나, 접근 대기를 품질 실패로 세거나 유료 조사 조건을 완화하지 않는다. A는 **메시 정면·측면·후면과 손·검·얼굴 확대를 사용자에게 승인받은 뒤 Mixamo**로 넘긴다. nvdiffrast·nvdiffrec §3.3과 CuMesh의 cubvh 비상업 제한 구성은 제작 경로에서 제외하며, MIT `_C`·xatlas 분리 준비를 설치 완료로 보고하지 않는다.

같은 날 최신 갱신: **DINO 접근 승인 완료**, 고정 가중치 1,212,559,808바이트 다운로드 성공, 설정 수집은 진행 중이다. 위의 승인 대기는 역사 상태다. 원본 A 정면(532×910 crop)의 BiRefNet 알파를 생성했으며 FlashAttention 준비 후 메시를 만든다. 별도 A-pose 미리보기는 사용자 승인 전이므로 해당 메시 생성은 대기한다. 두 경로 모두 알파 입력·메시 3방향·손/검/얼굴 확대를 제출하고 사용자 메시 승인 후 Mixamo로 간다. 검은 별도 손 본 소품, 망토는 보조 본 또는 단순화 계획을 함께 검토한다. [입력 provenance와 실행 상태](../../research/m1-5-free-trellis.md#현재-입력과-두-시제품-경로)를 따른다.

한 방향 걷기·베기·피격을 먼저 영상으로 승인받은 뒤 나머지 동작·8방향으로 확장한다. 설치·정지 그림·비율 검사만으로 통과하지 않는다. Mixamo 로그인·다운로드는 사용자 담당이고 원본 FBX는 Git/Release에 올리지 않는다.
