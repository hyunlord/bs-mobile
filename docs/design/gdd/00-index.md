## 기둥 v0 · 2026-10-12 사용자 승인

1. **타격감:** 소리를 꺼도 적을 맞혔다는 것을 읽는다. 일반 타격을 전체 화면 정지로 대신하지 않는다.
2. **캐릭터·무기별 몸동작:** 한눈에 끌리는 영웅과 무기 성격이 드러나는 동작을 만든다.
3. **다 해 보고 싶은 무기·진화 스케일:** 형태·크기·리듬이 다르고 진화에서 변화가 읽힌다.
4. **영지가 힘이 된다 [가설]:** 차별점 후보이지 재미가 입증된 사실이 아니다. M1 실험으로 판정한다.

기존 P1~P8 경계는 [01 시스템](01-system.md)에 보존한다. 영지의 재미가 미증명이라는 사용자 판정은 기존 기능을 삭제하거나 경제 수치를 바꾸라는 승인이 아니다.
