DGX Spark ARM64는 별도 환경·낮은 우선순위로 시도하고 막힌 지점을 기록한다. Microsoft 코드·본체 MIT와 DINOv3·배경 제거 모델의 조건은 별도다. 기본 RMBG-2.0은 상업 제한으로 제외한다. [공식 출처·무료 경로·Mixamo 인계](../../research/m1-5-free-trellis.md)를 따르며 설치 성공을 생성 품질로 간주하지 않는다.

nvdiffrast v0.4.0·nvdiffrec renderutils의 §3.3과 CuMesh의 cubvh에 포함된 비상업 제한 코드를 제작 경로에서 제외한다. MIT `_C`·xatlas만 남기는 분리 작업은 준비 단계이며 실행·내보내기 성공이 아니다. 과거 호환성 평가 검사는 제작 사용 승인으로 바꾸지 않는다.

**메시 먼저:** A의 정면·측면·후면과 손·검·얼굴 확대를 제출하고 사용자 메시 승인을 받은 뒤에만 Mixamo로 넘긴다. 원화 승인·자동 비율 검사·설치 성공은 이 관문을 대신하지 않는다. 메시 승인과 다음 동작 영상 승인은 별도 관문이다.

먼저 **한 방향 걷기·베기·피격**만 만든다. 원화색(코발트 망토·상아 옷·금발), 툰/셀 셰이딩과 외곽선, 실제 이동 속도에 맞는 보폭을 유지한다. 피격은 흰 번쩍임 2프레임과 0.2–0.3초 움찔이며 전신 색칠을 금지한다. 매 프레임 머리/전신 비율 흔들림 ±3% 이내 검사, 2배 영상과 0.05초 확대 시트를 함께 제출한다. **사용자 영상 승인 전에는 통과로 선언하지 않는다.** 승인 후에만 나머지 동작과 8방향 실제 렌더·동작당 12–16프레임으로 확장하고 일정 입력·원 그리기 입력을 확인한다. 회전·반전으로 방향을 대신하지 않는다.

Mixamo 로그인·다운로드는 사용자가 직접 한다. 업로드할 파일이 준비된 때 필요한 작업을 요청한다. 원본 FBX는 Git/Release에 올리지 않고 구운 스프라이트만 게임에 포함해 전달한다. 독립 atlas 공개 배포는 별도 라이선스 확인 전 허용하지 않는다. #126·#98·#224·1b 보류, SDK 미도입, Charter & Kin 변경 금지를 유지한다. 아래 내용은 각 확인 시점의 역사로 보존한다.

## 세계와 시각 우선순위

채택된 세계는 [A 휴경의 왕국](../world-directions/A-fallow-kingdom.md)이다. 계절이 멈춘 잿빛 들판에 개척 기사가 씨앗을 심어 색을 되돌린다. 성·밭·공성의 판타지 안에서 쓸쓸하지만 다정한 복구 동화를 지향한다. 새봄의 터는 사방으로 이어지고 출발점의 집·작업장은 귀환 장소로 남는다. 소품과 세계 별칭을 새 충돌·자원 규칙으로 바꾸지 않는다.

잉크·과슈, 3/4 탑다운, 낮은 대비의 회색 흙/돌길/죽은 나무/물길/폐허가 바탕이다. 파종→싹은 세이지, 익음은 황금, 건물 완성은 따뜻한 회벽과 창빛으로 번진다. 성장 상태와 실제 수확 사건이 색 복구를 이끈다. 영주의 코발트·상아와 적의 위험 표식은 회색에서도 남는다.

판독 우선순위는 적 > 내 공격 > 아군 > 익음/완성 > 나머지다. 평소 적 몸은 잿빛 갈색/숯빛, 돌진 예고·돌진만 붉게 강조한다. 빨강을 아군 이펙트에 쓰거나 수확 보석을 영주보다 두드러지게 하지 않는다. 색만 바꾼 적, 피폐 고어, 무지개 폭발, 시안 전체를 배경에 붙여 실행 화면처럼 보이는 방식은 금지한다.

## M1-1 영웅 3안 제출 계약

기본 영웅은 하나이며 외형 후보 세 가지를 비교한다. 아래 방향은 탐색 브리프이고 완성된 컨셉이나 사용자의 선택이 아니다.

| 방향 | 구분할 매력 | 필수 제출 |
|---|---|---|
| 정통 기사 | 멋짐·단정한 기사 비례, 검과 망토 | 전신 정면/3·4시점, 팔레트, 무기 자세, 검정 실루엣 |
| 경쾌한 소년·소녀형 | 민첩한 리듬과 명료한 몸짓 | 같은 구성, 성별/세부 복장은 시안에서 제시 |
| 거한 마초형 | 큰 체격·무게감·농기구와 공성 도구의 힘 | 같은 구성, 단순 확대가 아닌 별도 실루엣 |

이는 비교 틀이지 방식 확정·패키지 설치 승인이 아니다. 유료 라이선스 도구는 사용자 확인 뒤에만 사용하고 새 패키지도 승인 없이 추가하지 않는다. (b)는 현재 실행 기반이며 M1 최종 선택은 다시 사용자에게 받는다. 숫자로 된 제작 공수·메모리 예산은 실제 해상도·방향·프레임 수가 정해진 뒤 측정한다.

동작 초안: 서기, 걷기(방향 수 [미정]), 피격, 쓰러짐, 레벨업, 진화 포즈. 공격은 검·낫 휘두름, 창 찌르기, 망치 내려찍기, 지팡이·활 던지기/쏘기, 씨앗·물 뿌리기, 궤도형 손짓이다. 선택 방식으로 철날 검 하나의 실제 판 시제품 영상을 만든다. 선택 전 임의 방식의 시제품을 최종 승인으로 표현하지 않는다.
