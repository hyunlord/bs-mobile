## #223 완료 전에 필요한 증거

- [ ] 끊긴 프레임의 판 시간·개체 수·관리 힙/Unity 메모리·버퍼/목록 용량·직전 사건·Unity 마커와 Profiler 원자료를 연결한다.
- [ ] 버퍼 재할당, 목록 증가, 소리 로딩, 글꼴 이미지 추가, Present 대기 등의 원인을 증거로 구별한다. `GC=0`, `Core ticks=0`만으로 OS 지연이라고 단정하지 않는다.
- [ ] 원인에 맞는 수정 후 Release ABBA, A=8f446e5와 수정 B 각각3회. 411/C05전체/C05800+의 p95·p99·최대·25ms 초과 비율을 남긴다.
- [ ] 전경 유지 구간만 집계하되 잃은 구간과 전경 앱 이름을 삭제하지 않는다. 잃으면 중단/초기화하지 않고 유효 시간이 찰 때까지 이어 간다.
- [ ] 판 중 최대≤50ms를3회 모두 지킨다. 25ms 초과≤0.2%도 유지한다. Development Profiler 결과를 Release 관문 대신 쓰지 않는다.
- [ ] 실패나 원인 미확정이면 미달로 남긴다. UI #235 병합과 별개로 #223에서 완료한다.

## M1 손맛·영웅 관문

순서는 #236 문서 정리 후 M1-1이다. #223 야간 진단을 취소하거나 완료한 것으로 간주하지 않는다.

- [ ] 06 손맛 기준표에 현재 구현·부족한 반응·등급별 가설 수치·설정·풀링 범위를 기록한다.
- [ ] 같은 seed의30초 적용 전/후 영상을 앱 내부 캡처로 만든다. OS 녹화·손쉬운 사용 권한은 요청하지 않는다. 캡처 방식·음성 여부·출처 커밋을 명시한다.
- [ ] 사용자가 “소리를 끄고 봐도 맞았다는 게 느껴지나”를 판정한다. 코드·테스트 통과로 대신하지 않는다.
- [ ] 효과ON C05 800+에서25ms 초과 비율이 기준보다 나빠지지 않는다. 전후 조건·분모·각 반복을 함께 기록하며 #223 실패는 별도로 보존한다.
- [ ] 영웅3안의 정면·3/4·무기 자세·팔레트·검정 실루엣, 기존 A/B와 실제390pt 군중 화면 비교를 전달한다. 사용자1안 선택 전 기본 영웅 교체 확정 금지, 나머지는 스킨 후보로 보존한다.
- [ ] 프레임 그림/리그를 구운 atlas/실시간 뼈대의 표현·제작량·비용·하체 걷기+상체 공격 조합을 비교한다. 사용자 방식 선택 전 시제품을 최종 제작 계약으로 부르지 않는다.
- [ ] 선택한 방식의 철날 검 실제 판 영상. 새 유료 도구는 별도 사용자 확인, 새 패키지/SDK 무단 도입 없음.
- [ ] 도전 받기 활성 상태의 금빛 강조와 잠김 구분을 실제 화면에서 확인한다. #235의 버튼 존재 승인과 이 추가 요구를 구별한다.
