# 모듈형 캐릭터 저작 공장

[첫 시험과 출처](../../review/m1-5/modular-factory-1.md). 이 경로는 게임 실행 데이터가 아니라 오프라인 캐릭터 저작 레시피다. Core·게임 콘텐츠 ID·리플레이 규칙을 바꾸지 않는다.

## 조립 계약

- 기본 몸: 무료 Universal Base Characters 남성 몸의 기존 전문가 가중치를 유지한다.
- 체형: 같은 연속 변환으로 몸 정점과 기본 뼈 길이를 바꾸고 기존 가중치 값은 보존한다.
- 단단한 부품: 머리/얼굴·어깨·팔뚝·장갑·벨트·무릎·부츠·검은 각각 유효한 단일 본을 따른다. 장갑 내부 손가락 변형은 없다.
- 천: 앞/뒤 겉옷과 망토는 독립 메시·보조 본 사슬을 사용한다. 앞 트임을 유지한다. 물리 시뮬레이션은 금지한다.
- 색: 상아 옷·파랑 망토·갈색 부츠. 부품 출처와 원본 색/재질을 바꾼 범위를 기록한다.
- 동작: UAL 원본 걷기를 기본 몸의 rest 차이를 고려해 재생한다. 새 몸동작을 임의로 만들어 UAL이라고 표시하지 않는다.

## 저장소와 저작 도구 경계

`tools/repository-budget.mjs`의 RB003은 Python 추가·변경을 금지한다. Blender Python 저작 도구를 저장소에 넣거나 다른 확장자로 숨겨 검사를 우회하지 않는다. 실제 실행 소스는 외부 저작 산출물로 보존하고, 이곳에는 레시피와 버전별 재현 절차를 남긴다. 원본 패키지는 공식 무료 다운로드에서 취득한다. 파일 이름이 같다는 이유로 다른 모델/리그를 대신 사용하지 않는다.

모듈 공장 검증과 개별 캐릭터 품질 승인은 다르다. 같은 공장으로 조립돼도 전체 걷기 프레임에서 늘어남·찢김·관통을 검사하고 사용자 영상 승인을 받아야 한다. 첫 시도의 실패를 숨기고 반복 수정하지 않는다.

## 동결 소스 재현

[실패 후보 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m1-modular-factory-1)의 개별 저작 소스를 [source-manifest.csv](source-manifest.csv)의 경로로 복원한다. `factory--README.md`에 Blender4.5·외부 원본 경로·실행 명령을 기록했다. 레시피 두 개는 이 디렉터리 정본을 `recipes/`로 복사한다. 승인(b) GLB, UBC 무료 원본, UAL1 원본은 별도 입력이며 원본 모델을 Release에 재게시하지 않는다.

공장은 현재 고정 부품 라이브러리다. 모든 치수·offset을 자유롭게 바꾸는 범용 형상 생성기는 아니다. 미지원 고정값 변경은 오류로 거부한다. 체형5값·색·지원 부품/부착 본은 JSON으로 조립하며 체형 변형도 같은 경로로 실행했다. 금지 입력10건 거부 검사 통과. 새 시도를 승인받기 전에는 동결 실패 후보를 보정하지 않는다.
