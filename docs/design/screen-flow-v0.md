# 화면 흐름 v0: 13개 세로 화면의 구현 정본

상태: 사용자 승인 범위의 서면 대체 명세. 연결된 canvas와 Logic 표는 직접 확인하지 못했다. 이 문서는 사용자 서면 지시와 이슈 #225·#226·#227을 구현 가능한 화면 계약으로 정리하며, 확인하지 못한 canvas의 배치·복귀 동작을 확인 사실로 쓰지 않는다. 아래 `[잠정]`은 안전한 구현 기본안이며 미정 경제·부활 규칙을 확정하지 않는다. 화면 명세는 구현·실기·시각 관문 통과 증거가 아니다.

## 공통 표시·조작 계약

- 기준은 **390×844 세로 논리 좌표**다. 휴대폰 safe area를 적용하고 Mac 가로 창에서는 같은 세로 화면을 가운데 놓는다. 카메라·Canvas·포인터·조이스틱의 뷰포트가 일치해야 한다. 바깥 여백에서 이동·선택이 발생하지 않는다. Fold7 비율 확인은 시뮬레이션이며 #98 실기를 대신하지 않는다.
- 누를 수 있는 영역은 최소44×44pt, 일반 주요 동작 높이는48pt다. 카드 설명·진화 조건·보조 버튼을 잘라내거나 말줄임으로 숨기지 않는다. 필수 정보가 길면 전체 카드 영역을 함께 스크롤한다. 화면 전환 목표는200ms 이하다.
- 전투 HUD는 usable 세로 높이의10% 이하이며 **전장의90% 이상을 가리지 않는다**. 장비는 위쪽26pt 아이콘 줄로 모으고 아래 장비 막대는 새 모드에서 없앤다. 모든 장비5/4/4칸과 진화 정보는 일시정지에서 읽는다.26pt 아이콘이 상호작용한다면 터치 영역은44pt를 유지한다.
- 휴경의 왕국의 잉크·과슈, 회색 땅과 복원 색, 영주 코발트, 적 위험 빨강을 유지한다. 영지의 빨간 출정 버튼은 사용자 지정 UI 강조이며 적 위험 표식과 월드에서 혼용하지 않는다. 한국어와 실제 콘텐츠 이름·`cardText`를 사용한다.
- 메뉴·카드·일시정지·중단 상태에서는 Core 틱을 진행하지 않는다. 레벨업 화면 진입 후300ms 동안 선택을 받지 않고, 진입 전 pointer-down을 진입 후 선택으로 이어받지 않는다. 같은 제안을 다시 그리거나 창 크기가 바뀌었다고300ms를 다시 시작하지 않는다.
- 진동은 설정에서 켜고 끄며 기존 소리·표현 설정을 유지한다. SDK나 패키지를 새로 추가하지 않는다. 구형 프로필의 레이아웃·게임 규칙·재생은 새 portrait 표시 모드와 분리해 보존한다.

## 복귀·일시정지·저장

[확정] Back은 가장 위 모달부터 닫고 설정은 **정확한 진입 화면**으로 돌아간다. Run→Pause, Cards→Pause→Cards를 구별한다. 종료·포기·지출은 승인된 확인 동작을 거친다. 완료·포기 뒤에는 영지로 돌아가 타이틀을 반복하지 않는다. 백그라운드 전환 뒤 전경으로 돌아와도 한 판을 자동 재개하지 않는다. 이동 입력과 누적 시간을 정리하고 명시적 이어하기를 기다린다.

[잠정: canvas Logic 미확인] 비전투 화면은 현재 페이지·선택을 보존한다. 카드 중 중단은 동일 제안을 일시정지한 채 보존한다. 가짜 광고의 중단·실패·취소는 지급·횟수 소비 없이 원래 선택 상태로 돌아간다. 확인 창의 취소도 같은 부모 화면으로 돌아간다. 실제 운영 광고 상태 복원 규칙이라고 확정하지 않는다.

[잠정: 재시작] 기존 저장의 종료되지 않은 판은 기존 포기·결산 복구 계약을 지킨다. 체크포인트가 있다고 판 중간 이어하기가 구현됐다고 주장하지 않는다. 새 세션 재개가 필요하면 원자적 선택 상태와 재생 복원 계약을 별도로 정한다. 결산·받기 도중 종료는 지급 원장의 완료 여부로 복구해 중복 보상을 막고, 보존된 영수증이 없으면 영지에서 복구 결과를 알린다. 기존 저장을 초기화하지 않는다.

## #226 계정 화면 연결의 구체적 경계

명시적 받기는 schema4 `PendingClaims`의 sequence로 실행한다. 도전은 진행/받기/받음 세 상태를 구별하며, 구형 자동 지급으로 받은 도전을 다시 지급하지 않는다. 미수령 도전의 해금은 받기 성공 전에 완료라고 표시하지 않는다. 방치 상세·광고2배는 #227 범위다.

가신6명은 잠긴 가신을 포함해 모두 표시한다. 출정 자리는3칸이지만 현재 열린 자리와 가신 해금 상태는 기존 규칙으로 제한한다. wave 계정 화면의 출정은 `AccountOnlyWave`로 원본 전투 Catalog를 사용하며 메타 능력 보너스와 `.meta` sidecar를 추가하지 않는다. 실제 실행은 챕터1이고2–7은 미리보기이며1b 확장을 의미하지 않는다.

결산 조각은 실제 증가분만 표시한다. 현재 기존 규칙의 클리어 보상은 최소 보상 시간을 충족한 판의 동행 가신당2개·조각 상한 적용이며, 죽음/포기/최소 시간 미달은0이다. 따라서 무조건 `+2` 표시를 하지 않는다. 생존 사람 수는 집단 Health>0만 반영한다. 가격·보상 계수·능력 수치 변경은 #126 보류로 남긴다. 상세 결정은 [ADR0053](../adr/0053-explicit-meta-claims-and-wave-accounting.md)을 따른다.

## #227 선택 보상·BM 자리의 구현 계약

[구현 결정] 상점·시즌 패스는 보기 전용이고 미정 가격·보상은 `[n]`이다. 가신·조각·자재·전투 능력을 판매하지 않는다. 무료/유료 패스는 고정 보상 자리이며 `판 안 힘은 없음`을 표시한다. 광고·결제·분석 SDK는 없다. Editor/Development의 가짜 광고 성공/실패만 제공하고 일반 Release는 제공 불가로 광고 버튼을 숨긴다.

정책은 첫 판·첫날, 문맥 불일치, 사용 불가, 한도 소진, 아직 지급 확인 중인 보상에서 버튼을 숨긴다. 실패·취소에는 지급·성공 횟수 소비가 없다. 광고 제거 fixture도 첫 판·첫날 숨김과 한도를 지키고, 직접 받기를 선택해야 지급한다. 날짜는 주입 가능한 로컬 달력 키다. 연속 제안 차단은 새 출정·새 레벨의 플레이 사건으로 해제하며 단순 화면 이동으로 풀지 않는다. 이는 미확인 canvas Logic을 확인했다고 주장하는 것이 아닌 로컬 v0 선택이다.

방치2배는 실제 claim의 기본 지급과 추가1배를 기존 지갑 상한 안에서 한 번에 저장한다. 하루3회는 가설을 유지한다. 정상 받기 뒤 같은 claim에 보너스를 덧붙이지 않는다. 결산 보너스는 마지막 판에서 실제 받은 자재만 기준으로 삼고 조각은 제외한다. 결산 배율·상한 #126은 미정이므로 생산 제안은 숨긴다. 실제 부활 규칙 #224도 미정이며 테스트 fixture 외에는 숨긴다.

schema5 원장은 완료 ID와 보상 종류/원본 sequence로 중복 지급을 막는다. v1–v4 저장을 이전할 때 과거 보상이나 영수증을 새로 만들지 않는다. 부활·추가 다시 뽑기는 opt-in 재생 v5의 명령으로만 반영하며 기존 옵션 없는 재생은 기존 형식·해시 경로를 유지한다. 부활 가능한 판은 선택이 끝나기 전에 결산을 확정하지 않고 부활 표시를 남긴다. 가신·장원의 wave 능력 투영과1b 확장은 계속 보류한다.

화면·광고 정책·복귀·재생·새 HUD 끊김의 통합 관문은 아직 별도 검증 대상이다. 상세 경계는 [ADR0054](../adr/0054-opt-in-host-rewards-and-local-bm-slots.md), 실제 확인 상태는 [#227 검토 기록](../review/portrait-bm-227.md)에 남긴다.
