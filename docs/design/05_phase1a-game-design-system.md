# Sow & Siege — Phase1A 화면 기준

## 1. 분위기와 정체성

회색 도형으로도 위험과 성장이 구분되는 한 손 게임이다. 화면 중앙의 영주와 진한 적을 먼저 읽고, 공격·아군·성장물은 순서대로 읽는다. 그림·장식·소리·손맛 다듬기는 이번 범위가 아니다. 원본 의뢰서의 P5와 U3를 우선한다.

## 3. 글자

좁은 세로 화면 기준 논리 캔버스 폭360을 사용한다. 제목24, 카드 제목18, 본문16, 보조14, 작은 개발 지표12를 공통 토큰으로 둔다. 글꼴은 한국어를 실제로 표시할 수 있는 시스템/Unity 글꼴을 검증하여 사용하며, 네모 글리프·잘린 받침은 실패다. 운영체제 글꼴 파일을 허가 없이 복사·배포하지 않는다. 동적 콘텐츠 이름은 정본 JSON에서 생성한 표시 정보를 사용한다.

Unity6.6의 [설치 글꼴 이름 조회](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Font.GetOSInstalledFontNames.html)와 [OS 동적 글꼴 생성](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Font.CreateDynamicFontFromOSFont.html)을 우선한다. 대안은 [실제 OS 글꼴 경로 조회](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/Font.GetPathsToOSFonts.html) 결과를 사용하는 것이다. OS 이름이나 경로를 기기마다 같다고 가정하지 않는다. UI 문구와 정본 표시 이름의 한글 글리프를 검사하고 Editor·Android의 실제 화면에서 확인한다. API 존재는 기기 글리프 통과를 뜻하지 않는다.

## 4. 간격과 배치

기본 간격4, 작은 간격8, 패널 안쪽16, 큰 간격24, 기본 터치 영역48 논리 단위. 캔버스는 실제 안전 영역에 맞춰 배치하고, 길쭉한 화면과 정사각형에 가까운 화면에서 다시 계산한다. 카메라 줌의 최소·최대·여백은 `data/` 표현 설정에서 읽는다.

HUD에는 경험치·계절/남은 시간·체력만 상시 표시한다. 카드3장은 좁은 화면에서는 세로로 배치하고 모든 선택·리롤·금지·고정 영역이 안전 영역 안에 들어가야 한다. 부트 오류와 결산도 같은 패널/버튼을 사용한다. 조이스틱은 UI가 소비하지 않은 터치 위치에서 생기며 손을 떼면 사라진다.

화면 크기 변화는 기존 세션을 유지하며 카메라/HUD만 재배치한다. `Screen.safeArea`가 접힘부의 모든 정보를 보장한다고 가정하지 않는다. 물리 접힘부·카메라 구멍은 실기 관문에서 확인한다.

## 5. 재사용 요소

- 버튼: 공통 글자·패딩·최소48 터치 영역; 눌림은 밝기 변화, 비활성은 대비와 입력 차단으로 함께 표현한다.
- 패널: 카드·설정·결산·오류에서 같은 배경/텍스트/간격 토큰을 사용한다.
- HUD 막대: 같은 외곽과 비율 표시; 숫자/짧은 이름을 함께 제공한다.
- 도형 배치: 공통 인스턴스 버퍼와 재사용 메시/재질. 적마다 GameObject를 만들지 않는다.
- 개발 정보: 개발 빌드에서만 별도 접기 가능한 오버레이; 일반 HUD를 대신하지 않는다.

세계 도형의 표시 반지름은 Unity 단위로 영주0.13, 적0.11, 사람0.085, 밭0.16, 건물0.19다. 아군 내부 채움 비율은0.72다. 준비된 성장물의 맥동 진폭은0.045, 속도는 초당2라디안이다. 표시 효과의 수명은 공격0.18초, 경험치0.55초, 건물0.45초이며 풀 상한은2,048개다. 화면 밖 위협 표시는8방향으로 묶고 안전 영역 가장자리에서22픽셀 안쪽에 둔다. 모두 표현 토큰이며 Core의 충돌 반경·공격 지속 시간·위협 판정을 바꾸지 않는다.

## 6. 움직임과 입력

Core 고정 틱 사이 위치만 보간한다. 카메라는 영주를 따라가며 표현 설정의 속도로 줌을 완만히 바꾼다. 공격·투사체·경험치 효과는 Core가 이미 확정한 사건을 표시하며 새 피해·수집 규칙을 만들지 않는다. 효과의 위치·방향·범위는 Core 사건에서 읽는다.

익은 작물·완성 건물만 약하게 맥동한다. 나머지 성장물에 주의를 끄는 애니메이션을 넣지 않는다. 카드 선택 중 Core 시간은 정지한다. 버튼의 눌림 상태는 즉시 보인다. 장식용 진입 애니메이션은 추가하지 않는다.

## 7. 층과 표면

평면 도형·테두리 방식이다. 그림자·그라데이션·유리 효과를 쓰지 않는다. 바닥/성장물 → 아군 → 반투명 공격 → 적의 판독성을 유지한다. HUD·카드·개발 오버레이는 별도 안전 영역 레이어이며 세계 판정에 영향을 주지 않는다.

검증은 실제 Unity 화면과 기기 캡처로 한다. 긴 세로/정사각형 비율, 카드 정지/선택, 설정, 오류, 결산/재시작을 확인한다. 헤드리스·스크립트 검사만으로 판독성 통과를 주장하지 않는다.
