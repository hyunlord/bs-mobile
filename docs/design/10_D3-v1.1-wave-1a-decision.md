# D3 v1.1 수정 승인과 wave-1a 실행 결정

- 사용자 결정: [#143 수정 후 승인](https://github.com/hyunlord/bs-mobile/issues/143#issuecomment-6088571163)

- 상태: 수정 조건을 충족해 CI 병합한 뒤 사용자 재승인 없이 1a 구현. 이 문서는 런타임 완료 증거가 아니다.

## 승인된 방향

도구가 곧 무기이며 땅·건물·사람별 지도 흔적, 출처별 재료·장원, 챕터 장치·보스 국면과 시각 우선순위를 유지한다. 시스템13·직접 영향41, 별도 파일·공유 ID·designRef의 designed-v1 카탈로그 구조, 무기 형태16·역할 분포는 승인됐다. 원본01·02·03과 v1의 역사 기록은 보존한다.

## v1.1에서 충족할 수정 조건

1. 도구15개 모두 실제 성장 완료 때 경험치 수확을 둔다. 땅은 성장한 작물, 건물은 완성·출고, 사람은 임무 완수·귀환이며 모든 returns에 xp가 있다.
2. 무기·도구마다 진화 하나 이상. 고랑 장창·씨받이 쇠살·경계돌 망치·잔불 지팡이·맷돌 원반·망루 쇠뇌의 무기×도구 진화를 추가한다.
3. 모든 무기·도구의 연결 물품은 1~4개. 범용 물품6~8개와 수치 전용20% 이하 상한을 검사한다. 이번 카탈로그는 범용6개, 수치 전용6/42개다.
4. 자동 무기의 대가는 형태의 빈틈으로 제한한다. 이삭 낫·숯불 도리깨·씨받이 쇠살·곡창 투석끈·뿌리 작살의 영지 손실은 선택하는 진화로 옮긴다. 물품은 조건→효과를 기본으로 하며 본래 동작의 제약 외에 대가를 강제하지 않는다.
5. 모든 무기·도구는 기본 동작 하나와 화면에 보이는 조건부 변형 최대 하나. 모든 콘텐츠에 한국어40자 이내 조건→효과 cardText를 둔다. 문구 축약으로 복잡한 실제 동작을 숨기지 않는다.
6. 목수 망치·지붕 아래 파종·무장 수확권은 반경 안에서 움직이며 싸워도 진행한다.
7. 사람 도구·가신·아군 진화는 동시 개체 상한 정책과 무리 하나=Core 한 개체·대표 스프라이트 규칙을 둔다. 수치는 성능 측정 때 정한다.
8. 출정 전 목표 재료에 관련 도구 첫 제안을 보장하고 챕터 클리어 기본 지급을 둔다. 수량은 보류다. 프로필에 보장 도구가 없는 목표는 선택할 수 없지만 클리어 기본분은 네 재료 모두에 독립 지급한다.
9. 가신8명 모두 화면에서 구별되는 대표 장면 하나를 가진다. 물류의 실제 출처·운반·소비를 보존하며 판타지 표현을 사용한다.
10. 모든 콘텐츠를 유한한 공통 동작 단위와 파라미터로 분해한다. mechanic-primitives.md 및 JSON primitives·params·bespoke, runtime-operations.md의 operationSupport를 연결한다. 기존 단위로 표현되지 않는 동작은 bespoke로 보고한다.
11. wave-1을1a·1b로 분할한다. 1a는 무기5·도구4·진화3·연결 물품6·범용2·서로 다른 일반 적6·새싹 들판·둑깨는 상아왕이다. 정확한 ID는 [설계서](08_system-design-v1.md)의 1a 표가 명시한다. 후속 웨이브 순서는 유지한다.

## 완료 경계

v1.1 PR은 설계·카탈로그·스키마·검사만 변경한다. 기존 프로필·런타임 데이터·Core diff는 없어야 한다. 자동 검사와 Lattice 렌즈의 동일 규칙 값은 대조하되 Lattice의 존재나 지원을 가정하지 않는다. CI 통과 후 병합하고 #143에 결정·v1.1 링크를 남긴 뒤 닫는다.

그 다음 1a는 새 프로필에서 구현하고 기존 실행을 보존한다. 각 PR에 designRef·동작 증거를 붙이며 범위 안 아트·이펙트·소리까지 완성한다. 봇은 결정론·무충돌 검사만 한다. 플레이 가능한 Mac 빌드와 무기 형태·도구 수확·진화·적 예고·보스 국면이 보이는 영상이 다음 사용자 관문이다.

[#126](https://github.com/hyunlord/bs-mobile/issues/126)의 수치·밸런스·경제와 [#98](https://github.com/hyunlord/bs-mobile/issues/98) Fold7은 계속 보류한다. 보고 첫10줄은 개수보다 판의 변화부터 설명하고 커밋·PR·CI 링크를 남긴다. 일반 증거 ZIP·CRC·영수증 금지는 유지하고 승인된 Mac .app 배포 ZIP 예외만 따른다.
