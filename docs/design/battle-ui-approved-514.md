# 전투 UI 승인 시안 적용 초안

- 버전: v0.2 / 2026-10-30
- 상태: Unity 두 프로필 검증 완료, 실제 화면 사용자 판정 대기. 기존 런타임 스킨과 승인 시안의 화풍 차이 남음.
- 변경 요약: #514의 승인 HUD r2·레벨업 카드 r2·일시정지 r1을 기존 uGUI 스킨으로 구성한다.
- 기준: [battle-ui-499-20261028](https://github.com/hyunlord/bs-mobile/releases/tag/battle-ui-499-20261028)의 LAYOUT-r2.json과 세 PNG. DESIGN-r1.md의 과거 HUD 102px 대신 승인 r2의 84px를 따른다.

## 화면 계약

HUD는 기존 76px 높이 + 안전 영역 안쪽 8px 계약을 유지한다. 크림 종이 바탕 위에 잉크색 시간·계절과 28px 장비 13칸, 13px 레벨을 둔다. 일시정지 48×48 터치 영역도 기존 값을 유지한다. 신규 PlayMode 검사는 실제 생성된 RectTransform을 390×844와 390×932에서 읽어 HUD 총 점유 ≤10%, 터치 영역 ≥48×48, 장비 열의 바탕 내부 배치를 확인한다. 기존 아이콘 풀 재사용 검사는 보존한다.

레벨업 카드는 46px 아이콘, 20px 제목, 15px 설명, 14px 진화 조건을 쓴다. 진화 조건과 설명은 선호 높이로 늘리고 세 카드는 스크롤한다. 다시 뽑기·금지·고정은 기존 활성 조건과 명령을 보존하며 58px 높이, 16px 두 줄 글자로 표시한다. 광고 흐름은 기존 선택적 기능을 유지한다.

일시정지는 장비 줄을 압축하고 진화 조건을 14px로 확대한다. 조건의 실제 글 높이만큼 패널을 늘리고 스크롤하여 긴 진화 조건이 잘리지 않게 한다. 소리·진동·화면 흔들림·피해 숫자 설정, 상세 설정, 포기 확인, 계속하기 동작을 유지한다. Core·데이터·리플레이는 수정하지 않는다.

## 검증 상태와 후속

두 프로필 EditMode/PlayMode와 보충 fixture 2건을 실행해 실패 0을 확인했다. [낮 검증 보고](../review/battle-ui-543-20261030.md)에 실제 390×844 비교와 최초 실패·수정 근거를 남겼다. 기존 금색 장식 스킨·서체는 승인 시안과 다르며, 텍스트 영역 검사 통과를 장식 테두리 가림 없음이나 사용자 승인으로 확대하지 않는다.

진행 중인 가신 UI는 PortraitHud/UiHud를 수정하므로 통합 때 충돌 검토와 점유율 재검증이 필요하다. 이 PR에는 미승인 가신 브랜치를 가져오지 않았다. 전체 시안 PNG를 게임 화면에 붙이지 않고 기존 아트 역할·실제 장비 아이콘·동적 텍스트를 사용한다.
