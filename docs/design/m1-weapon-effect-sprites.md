# M1 무기 효과 스프라이트 명세 (핵심 그림 + 셰이더·코드 애니메이션)

상태: **제작 경로 결정됨 — Astra 아트 파이프라인. 철날 검 4장으로 먼저 시험**, 통과하면 나머지를 진행한다. 2026-10-15 검수에서 c656471·c5b0116의 4종이 불통과했다. 원인은 코드로 그린 평면 도형이 주 형태였다는 점이다. 주 형태는 원화와 맞는 칠한 그림으로 하고, 프레임별 그림은 최소화한다. 움직임·변형·드러남·사라짐·개수는 셰이더와 코드가 맡는다. 장창·투석끈은 보류. [#266](https://github.com/hyunlord/bs-mobile/issues/266)

**2026-10-20 갱신:** 사용자가 승인한 Astra 게임용 스프라이트 6종(Release `weapon-game-assets-20261019`: 철날 검 띠, 수로 활 화살·꼬리·물튐, 수호 고리 방패·꼬리, 포자 장판 얼룩, 고랑 장창 창·찌름, 투석끈 자루)을 `wave1a-weapon-fx` 아틀라스에 리샘플 없이 넣었다(#335, `tools/art-authoring/weapon-fx`). 아래 무기별 절의 "임시 그림" 표기는 이 갱신 전의 역사 기록이다.

**2026-10-20 사용자 결정(View만, Core 반경·시간·#126 불변):**
- 곡창 투석끈의 점선 향 고리를 Astra의 곡식 향 그림(`fx.granary_sling.aroma`)으로 바꾼다. 그림 띠를 착지점 둘레에 5토막 곡면으로 감고, 바깥 경계를 Core 반경(927, 진화 1390)에 맞춘다(그림 위 여백 때문에 약 1.6% 안쪽, 허용 ±5%). 진화형의 폭발 직전 0.3초 범위 표시도 같은 그림이다.
- 날아가는 자루는 1.5배로 키우고 바닥 그림자를 단다. 그림자는 영웅 발밑에서 착지점으로 이동하며, 자루가 높을수록 작고 옅고, 착지 순간 자루와 겹친다. 궤적 선은 없다.
- 포자 장판은 그림 배율 2.1(보이는 얼룩 = 피해 범위)을 유지하고, 투명도를 0.87 → 0.55로 낮춘다. 새 장판이 깔리면 이전 장판은 0.3초 안에 사라지고, 겹친 곳의 진하기는 장판 하나의 1.3배를 넘지 않는다. 장판은 적·영웅보다 아래 층(AttackLayer)이다.

## 공통 작성 지시 (Astra)

모든 항목에 적용한다. 항목별 지시는 아래 표의 "작성 지시"가 덧붙인다.

- 형식: 배경 없는 투명 PNG(RGBA, 미리 곱하지 않은 알파), 항목의 원본 크기 그대로. 여백은 사방 8px 이상 비우고 그림이 캔버스 밖으로 잘리지 않게.
- 화풍: [아트 바이블](07_first-playable-art-bible.md)의 잉크·과슈. 광원은 좌상단 고정, 과슈 명암 2~3단계(밝은 면·중간·그늘). 사진 질감·3D 렌더·그라데이션 메시 금지.
- 외곽선: 캐릭터와 같은 charcoal 잉크 `#292822`, 원본에서 3~4px(최종 화면 1~2px). 반투명 기운(번짐·연기·물빛)에는 외곽선을 넣지 않고 가장자리만 한 단계 짙게.
- 피벗: 항목에 적은 위치에 그림의 기준점이 오게 그린다(예: 칼끝, 바닥 가운데). 피벗 좌표는 왼쪽 아래 (0,0), 오른쪽 위 (1,1).
- 색: 무기 주색만. 적 색(빨강·적갈색)·순검정 면 금지. 흰색은 칼날·물방울 같은 가장 밝은 심에만.
- 금지: 글자·기호·워터마크, 배경 바닥이나 그림자 바닥판, 움직임 흔적(잔상·속도선)을 그림에 그려 넣기(코드가 만든다), 여러 프레임을 한 장에 나열하기(명시한 변형만 예외).
- 전달: 항목 id 파일명(`fx.iron_blade.slash.png` 등), 같은 폴더에 작성 메모(사용한 색 3~4개 HEX). 코드는 같은 id의 role을 찾고, 없으면 임시 그림을 쓴다(`WorldBladeArc.cs` `EffectArt`).

크기 기준: 검토 캡처(1080px 높이, 카메라 1.4배)에서 보이는 기사 키 H = 115px, 기사 리그 원본에서 약 320px. 원본은 최종 화면 크기의 약 2.5배. 런타임은 기존 role 형식(`unity/Assets/Art/wave1a-manifest.json`: 픽셀 사각형, 정규화 피벗, worldSize)으로 등록하고, 코드가 Core 판정 크기에 맞춰 늘리거나 줄인다. 그림이 들어오기 전에는 지금의 임시 그림으로 같은 자리를 그리며, role이 아틀라스에 등록되면 코드 변경 없이 교체된다.

## 무기 8종 동작 축 비교 (2026-10-16 갱신, ADR0062·0063 반영)

검토 장면의 Core 판정(`data/review/m1-weapon-combat-cases.json`)과 지금 View 연출, 사용자 설계 정합성 결정(2026-10-16)을 기준으로 정리했다. "결정"은 사용자가 정했지만 Core 변경이 필요해 아직 반영하지 못한 방향이다. **굵게** 표시한 칸은 다른 무기와 같은 축이 겹친다.

겹치는 축:

1. 수호 고리 ↔ 포자 부채: 포자 부채를 장판으로 바꿔 해소했다.
2. 수로 활 ↔ 곡창 투석끈: 해소했다. 수로 활은 직선 튕김(ADR0062), 투석끈은 모음 후 폭격(ADR0063)이다.
3. 진화의 하늘 축: 결정대로 바꾸면 하늘은 쇠스랑, 낙하는 거대 검만 남는다. 활(물길)·투석끈(자루 흡입)·장창(창책)은 땅 축이다.
4. **땅 축이 세 무기에 겹친다**: 장창 창책(직선 고랑에서 솟음), 활 물길(꺾이며 파임), 투석끈 자루(한 점으로 빨아들임). 모양은 직선 / 꺾인 선 / 한 점으로 서로 다르지만, "땅에 자국을 남긴다"는 진화 축은 같다. 셋을 동시에 장비했을 때 구분되는지는 결합 장면에서 다시 본다.
5. 철날 검 ↔ 고랑 장창: 둘 다 영웅 앞 가장 가까운 적 방향이지만 모양(호 vs 직선)과 리듬(즉시 vs 단계)이 달라 겹침으로 보지 않는다.

## 포자 부채 (3번째, 진행 중)

철날 검·수로 활과 같은 방식이다. 핵심 그림 몇 장에 코드 애니메이션을 더한다. 그림이 오기 전에는 같은 피벗·비율의 임시 그림으로 같은 자리를 그린다(View만, Core 판정·피해·궤도·주기는 그대로). 결정된 안 A는 다음과 같다.

- 일반(Lv1·최대): 궤도체마다 작은 부채꼴 포자 구름이 바깥(영웅 → 궤도체 방향)으로 퍼진다.
- 진화: 포자 줄기 3갈래 소용돌이다. 이전 판의 토막 난 1.4바퀴 나선은 점선 동심원처럼 읽혔다. 그래서 줄기마다 이어진 띠 한 줄로, 0.6바퀴만 감아 갈래끼리 겹쳐 고리가 되지 않게 한다. 지면 퍼짐 고리도 진화에서는 그리지 않는다.

공통 작성 지시(위)를 따르되, 포자 부채는 아래 예외를 둔다.

- **어두운 화소 금지.** 외곽선·잉크·그늘 검정을 넣지 않는다. 알파 0.1 이상인 모든 화소의 밝기(Rec.709)가 140 이상이어야 한다. 검토 캡처의 잔디 밝기 중앙값이 약 141이라, 포자가 잔디보다 어둡게 보이는 화소가 없어야 한다. 과슈 명암 2~3단계는 밝은 색끼리만 쓴다.
- **색은 황록·청록 두 가지 계열만.** 예: 황록 밝은 면 `#D8EC7A`·중간 `#B6D85A`, 청록 밝은 면 `#8FF0DC`·중간 `#5CD6C2`. 흰색은 알갱이·줄기의 가장 밝은 심에만 쓴다.
- 연기·줄기는 반투명 기운이다. 가장자리는 한 단계 짙게가 아니라 **한 단계 옅게**(알파로) 사라지게 한다.

- 일반(Lv1·최대): 궤도마다 방패가 영웅 둘레를 돌고, 뒤로 금색 잔상이 궤도를 따라 남는다.
  - 크기는 Core 충돌 반지름과 관계없이 영웅 키 0.35배(Lv1) → 0.45배(진화)로 고정한다.

## 고랑 장창 (5번째, 진행 중)

같은 방식이다. 핵심 그림 4장에 코드 애니메이션을 더하고, 첫 플레이 HUD 아이콘 1장을 둔다. 그림이 오기 전에는 같은 피벗·비율의 임시 그림으로 그린다(View만, Core 판정·피해·타이밍은 그대로). 공통 작성 지시(위)를 따른다.

Core는 시전 때 영웅 앞(가장 가까운 적 방향)으로 일직선의 착탄을 예고하고, 15틱(0.5초) 뒤 안에서 바깥으로 2틱 간격으로 착탄시킨다. 착탄 수는 검토 Lv1 3, 최대 6, 진화 10이다.

- 고랑 자국: 시전 순간 영웅에서 마지막 착탄점까지 땅에 고랑이 6프레임에 걸쳐 열린다.
  - 폭은 영웅 키 0.35배(Lv1) → 0.5배(최대) → 0.7배(진화)다.
  - 찌르기가 끝나면 0.6초에 걸쳐 사라진다.
  - 적 아래 바닥 층에 그리므로 가림에 들지 않는다.
- 찌르기: 첫 착탄 4프레임 전에 창끝이 영웅을 떠난다. 착탄마다 그 Core 틱에 창끝이 그 착탄점에 닿고, 고랑을 따라 바깥으로 나아간다.
  - 창 그림은 영웅 키 1.3배 길이로 고정이다.
  - 영웅에서 창끝까지 찌르기 궤적(띠)이 이어진다.
  - 마지막 착탄에서 3프레임 멈춘 뒤 6프레임에 걸쳐 거둬들인다.
- 창끝 섬광: 착탄마다 4프레임, 영웅 키 0.5배 크기다.
- 맞은 적은 2프레임 멈추고 찌르기 방향(고랑 방향)으로 밀린다. View 자세만 바뀐다.
- 진화: 착탄마다 고랑에서 창 3자루가 위로 솟는다(창책). 가운데는 수직, 양옆은 ±25°다. 창 그림을 0.6배 길이로 다시 쓴다.
  - 4프레임에 솟고 10프레임 서 있다가 6프레임에 가라앉는다.
  - 화면 상한은 30자루다.
- 넓은 면은 찌르기 궤적과 창끝 섬광(적 위 상한 0.5)이다. 창은 가는 물체라 상한 예외(층 78)다.
- 예전 판의 초록 동심원(소집 나팔 그림 재사용)과, 땅에서 수직으로 솟던 HUD 아이콘 창은 없앴다. 그 아이콘 사용이 Core↔View 검사(`tools/view-coverage.mjs`, #275)에서 첫 플레이의 `icon|core:ditch_pike|default` 누락으로 잡혔다. 이제 장창 연출은 아래 효과 role만 쓰므로 그 결합이 필요 없다. HUD 아이콘은 첫 플레이 장비 아이콘으로 따로 그린다(표 마지막 줄).

## P5 가림 예산

- 내 공격 이펙트가 적 그림 화소를 가리는 비율: 프레임 p95 ≤ 25%. 검토 캡처에서 렌더러가 적 그림 마스크와 이펙트 마스크를 따로 그려 잰다.
- 적 위 알파 상한: 넓은 면 요소(채움·번짐·연기·띠·면 모양)는 적 그림 화소 위에서 알파 0.5를 넘지 않는다. 적 그림이 스텐실에 표시를 남기고, 넓은 면 이펙트는 표시 없는 곳은 그대로, 표시된 곳은 0.5 상한으로 그린다. 가는 심·선·테두리(번개 흰 심, 선·외곽선 조각)는 태그(`wide = false`)로 예외 처리해 적 위에서도 제 세기로 그린다. 가림 비율은 넓은 면에 상한을 적용하고 가는 요소는 그대로 센 값이며, 상한 전 값도 함께 기록한다.
- 화면 전체 색조(폭풍 하늘, 화면 섬광)는 가림 예산에서 빼고 따로 검사한다: 적-바닥 밝기 대비가 색조 없을 때의 70% 이상, 알파 0.25 이하. 번개 진화는 측정값만 기록하고 6종 결합 장면에서 다시 본다.
