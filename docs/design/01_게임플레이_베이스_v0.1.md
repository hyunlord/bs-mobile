## 0. 한 문장과 전제

**뱀파이어 서바이벌 / 탕탕 특공대류 모바일 액션에서, 무기뿐 아니라 영지·건물·부하를 키우는 "도구"를 함께 고르고, 그 도구들이 무기처럼 화면에서 발동하며 세상에 무언가를 남겨, 빌드의 절반이 지도 위에 심어지는 게임.**

- [확정] 플랫폼: 모바일, Unity, F2P(광고 + 과금 + 유저 획득).
- [확정] 세계: **판타지**. 중세풍이지만 현실 고증에 묶이지 않는다. 기이한 작물·건물·백성 환영.
- [확정] 두 모드 분리가 아니라 **플레이 자체의 특색**으로 차별화한다.
- [확정] 영웅과 영지는 별개 층으로 두고, 과금도 따로 받을 수 있는 구조.
- [확정] BM은 게임플레이 설계와 **같이** 들어간다(구조는 지금, 숫자는 데이터로).
- [확정] **기본 영웅 1 + 기본 영지 전통 1로 게임 전체를 먼저 완성**한다. 추가 영웅·영지는 기본 게임이 어느 정도 완성된 뒤에 만든다. 판의 다양성은 무기·도구·특허장·물품·진화에서 나온다.

## 1. 대전제

| ID | 원칙 | 위반 예 |
|---|---|---|
| P1 | **도구가 곧 무기.** 모든 도구는 쿨타임마다 화면에서 발동하는 *발동 면*과, 세상에 남는 *성장 면*을 둘 다 가진다 | "작물 성장 +10%" 같은 수치 카드만 있는 도구 |
| P2 | **빌드의 절반은 지도 위.** 판의 힘은 영주 몸과 지도(땅·건물·사람)에 나뉘어 있다 | 성장물이 장식이고 영주 혼자 다 해결 |
| P3 | **번영이 위협을 부른다.** 영지가 부유할수록 그것을 노리는 적이 는다(음의 되먹임) | 식량 무한 누적이 곧 승리(지난 모바일 탐사 실패 원인) |
| P4 | **한 손 조작.** 배치 화면·탭 배치·수동 배분 없음. 선택은 레벨업 카드로만 | 전투 중 백성 배분 슬라이더 |
| P5 | **화면이 먼저 읽힌다.** 적 > 내 공격 > 아군 사람 > 익은 것·완성된 것 > 나머지 성장물 순으로 눈에 띈다 | 판 막바지에 적과 내 것이 구분 안 됨 |
| P6 | **외형과 성능 분리.** 스킨은 수치를 바꾸지 못한다 | 스킨에 능력치 |
| P7 | **판타지는 자유, 규칙은 일관.** 영지마다 "죽음→거름→해골 백성"처럼 인과가 닫힌 순환 고리 하나 | 이유 없는 효과 |
| P8 | **하나만 만들어도 여럿을 전제로.** 영웅·영지 전통은 처음부터 데이터 레코드이고, 코어 코드에 기본 영웅·영지의 ID나 규칙을 박지 않는다. 검사용 더미 레코드로 상시 확인 | `if (hero == knight)` |

## 2. 한 판의 모양

- [권고] 한 판 = **1년 = 12~15분**, 4계절.

| 계절 | 시간 [가설] | 리듬 | 도구 압력 |
|---|---|---|---|
| 봄 | ~3분 | 심기, 적 약함 | 씨앗·도구 카드 가중 |
| 여름 | ~3분 | 자람, 첫 약탈 | 지키기 시작 |
| 가을 | ~3분 | 추수 폭발, 추수 약탈 대습격 | 징집하면 수확 손실 큼 |
| 겨울 | ~3~4분 | 성장 정지, 저장 소모, 보스 | 징집 비용 거의 없음 |

- 계절 경계 = **끊는 지점**(부활·보상·결산이 걸릴 자리, 02 참조).
- [미정] 보스 뒤 연장(무한 저주 단계) 여부.

## 3. 조작·카메라·지도

- 한 손 이동, 공격·발동은 자동. [확정 방향]
- [권고] **경계가 있는 지도**(무한 지도 아님). 고정 성장물이 화면 밖으로 사라지지 않게.
- [권고] 영지가 커질수록 카메라가 천천히 줌아웃. 화면 밖 사건은 가장자리 표식으로만.
- 지도에는 강·숲·언덕·**터(건물 자리)**가 배치. 챕터마다 지형이 빌드 선택을 바꾼다.

## 4. 판 안 구성 요소 [권고]

| 칸 | 수 | 내용 |
|---|---|---|
| 무기 | 5 | 직접 공격 |
| 도구 | 4 | 땅·건물·사람을 키우는 것. 발동 면 + 성장 면 |
| 특허장 | 4 | 무기와 영지 **양쪽**에 걸리는 전역 수치(예: 근면 = 공격 속도 + 성장 속도) |
| 물품 | 무제한 | 상자·수레·장터에서 얻어 겹쳐 쌓음, 태그 조건 효과 |

- 레벨업 카드 풀은 무기·도구·특허장이 **하나의 풀**(슬롯만 분리).

## 5. 도구

### 5.1 규칙
- 발동 면의 화력 **바닥값**: 같은 레벨 무기의 60~70% [가설]. 집는 순간 손해가 아니게.
- 성장 면이 쌓여 무기를 넘어서는 **교차 시점**: 판의 중반(15분 판 기준 6~8분) [가설].
- 도구마다 성장물이 힘으로 돌아오는 **주 경로 하나**를 정한다: 경험치 / 직접 전투 / 판 안 금화 / 버프.

### 5.2 배치 [권고]
| 성장 대상 | 배치 방식 |
|---|---|
| 땅 | 이동 경로를 따라 남김 |
| 건물 | 지도의 정해진 **터**에만 |
| 사람 | 소집(영주 곁 또는 영지) |

### 5.3 예시
| 도구 | 발동 면 | 성장 면 | 대상 |
|---|---|---|---|
| 씨앗 자루 | 씨앗 부채꼴 투척, 작은 피해 | 떨어진 자리에 싹 → 곡식단(경험치) | 땅 |
| 쟁기 | 일직선 돌진, 범위 피해·감속 | 고랑 = 비옥한 땅, 성장 가속 | 땅 |
| 만드라고라 구근 | 구근 투척 | 익은 만드라고라는 수확 시 비명 → 주변 적 기절 | 땅 |
| 횃불 | 화염 장판 | 숲을 태워 개간(내 밭도 탈 수 있음) | 땅 |
| 목수 망치 | 내려찍기 충격파 | 터에 건물 짓기·수리·증축, 빈 땅이면 목책 | 건물 |
| 골렘 인장 | 돌 파편 | 골렘 공방 → 골렘 일꾼, 습격 때 벽 | 건물 |
| 뿔나팔 | 음파 넉백 | 백성 징집(일정 시간 영주 뒤로) | 사람 |
| 예배당 종 | 동심원 파동 | 징집병 귀환 + 작업 버프, 건물 내구 회복 | 사람·건물 |
| 징세 장부 | 처치 시 동전 연쇄 | 금화 → 건물 자동 증축 | 건물 |

## 6. 성장물

| 대상 | 모양 | 움직임 | 상한 [권고] | 손실과 복구 |
|---|---|---|---|---|
| 땅 | 면 | 고정 | 지력·땅 크기 | 먹힘 → 다시 심음 |
| 건물 | 점 | 고정 | 터 수 | 파괴 → 폐허 → 망치로 재건 |
| 사람 | 무리 | 따라옴/머묾 | 식량 | 죽음 → 뿔나팔로 재소집 |

- 손실은 "복구할 거리"로 남긴다(통째 상실 금지).

## 7. 사람 세 층 [권고, 시제품 판정]

| 층 | 수 | 위치 | 성장 |
|---|---|---|---|
| 가신 | 1~3 | 항상 영주 곁 | 판 안 카드 + 판 밖 메타 |
| 징집병 | 수십 | 일시적으로 영주 곁 | 뿔나팔 계열 |
| 백성 | 식량 한도까지 | 영지 | 땅·건물·식량 |

- 경제 고리: **땅 → 식량 → 백성 → (일: 더 자람) / (싸움: 화력·안전)**.
- 징집에 최소 지속 시간, 귀환에 이동 시간 → 결정이 일정 시간 유지됨.
- 영지에 남은 백성은 습격 때 자동으로 민병(훈련장 있을 때 강함).
- **부대 단위**: 징집병은 부대 하나 = 개체 하나. 화면 표시 수 상한, 초과분은 깃발 숫자(×3).
- 개인 화력은 낮게, 힘은 **진형 효과**(창벽 차단, 궁수 일제 사격)로.
- 시제품은 규칙을 설정으로 둔다: **A 군대형 / B 일꾼형 / C 징집·귀농형**.

## 8. 경험치와 레벨업

- 경험치 바 **하나**. 출처: 처치, 수확, 세금 걷기(장원 통과).
- 카드 풀 가중 = 최근 경험치 출처 비율(사냥 대 수확·세금).
- 카드 3장(행운 높으면 4장), 강화마다 **희귀도**(일반~전설) 굴림.
- **레벨 무제한**. 슬롯이 차면 강화만, 그 뒤 남는 레벨은 영지 확장 또는 금화로 전환.
- 리롤·금지(banish)·고정(lock) 처음부터.

## 9. 태그와 진화

- 태그 v0 [권고]: 날붙이, 투사체, 불, 서리, 독, 신성, 망령, 곡물, 숲, 돌, 짐승, 금화, 물.
- 물품 효과는 태그 조건으로 쓴다(예: "곡물 태그 구조물이 수확될 때 회전 칼날").

| 진화 층 | 예 |
|---|---|
| 무기 × 도구 | 낫 + 씨앗 자루 → 추수의 낫(벨 때 익은 작물도 거둠) |
| 도구 × 도구 | 씨앗 자루 + 쟁기 → 개방경지(고랑 위 대규모 띠밭) |
| 도구 × 성장 상태 | 뿔나팔 + 건물 5채 이상 → 민병이 망루에 배치 |

- **반시너지**를 일부러: 횃불↔밭, 양떼↔밭, 저주 늪↔내 백성 이동.

## 12. 영웅 · 영지 전통 · 스킨

- [확정] 출시 기본: **영웅 1, 영지 전통 1**. 아래 층 구조와 궁합은 **데이터 구조로만** 지금 만들어 둔다.
- [권고] 기본 영지 선택 기준: ① 땅·건물·사람 세 성장 대상을 모두 쓴다 ② **처치와 성장이 한 고리로 이어지는** 순환 고리를 가진다(이 게임의 논지) ③ 광고 첫 3초에 보이는 판타지 장면이 있다 ④ 다크·귀여움 어느 쪽으로도 넓은 층이 받아들인다.
- [권고] 기본안 방향: 인간 변경 개척 영지 + "쓰러진 적이 거름이 되어 기이한 작물(만드라고라 등)을 키운다" 고리. 묘지 영지는 논지가 가장 선명하지만 첫 인상이 좁을 수 있어 확장 후보로. 최종 후보 3안은 Astra S3에서.
- [권고] 기본 영웅: 기본 영지와 궁합인 범용 영웅 1명(예: 개척 기사). 가신 1~3명은 기본 영웅 아래에서 여럿 만든다(초기 수집·과금 축 후보).

### 층 구조

| 층 | 바뀌는 것 | 성격 |
|---|---|---|
| 영웅 | 시작 무기, 고유 능력, 기본 가신 | 플레이 |
| 영지 전통 | 시작 지형, 작물·건물 계열, 백성 종류, **고유 순환 고리** | 플레이 |
| 스킨 | 영웅 외형 / 영지 테마(건물·작물·백성 그림 세트) | 외형만 |

- 자유 조합 + 맞는 조합엔 **궁합 보너스**.
- **확장 후보(설계 자료로만 보관, 지금 데이터·그림 만들지 않음)** — 영지 전통 예: 곡창 왕국(밀·방앗간, 백성 많음) / 묘지 영지(죽은 적 → 거름 → 해골 백성) / 요정 숲(걷는 고목 파수꾼, 버섯) / 광산 요새(채석·골렘, 터 포탑 강함) / 늪 마녀(독초·저주 장판) / 용의 둥지(알 부화, 금화가 쌓일수록 용이 강해짐).
- 영웅 예: 기사 영주, 드루이드, 강령술사, 대장장이 군주, 늪 마녀, 순례 사제, 용기사, 상인 왕자.
- 이름·디자인은 기존 IP(톨킨·워해머·WoW 등) 고유 명칭을 피한다.

## 13. 판 밖으로 나가는 것

- 판이 끝나면 그 판의 영지 구성이 **판 밖 자재**로 환산(곡물·목재·석재·마력 등). 판 안 선택이 판 밖 장원의 성격을 바꾼다. 상세는 02.

## 14. 지금 비워 둘 자리 (BM 대비)

1. 영웅·영지 전통·가신·도구·스킨은 **각각 독립 데이터 레코드**.
2. 그림은 "역할 ID → 테마별 그림" 계약. 스킨은 수치를 못 바꿈.
3. 판 밖 성장의 **주입 지점**: 시작 레벨, 시작 도구, 가신 레벨, 수치 배율(무엇을 얼마나는 미정).
4. 판 길이와 **끊는 지점**(계절 경계).
5. **결정론 코어**: 같은 seed·입력 → 같은 결과(서버 검증·순위표 대비).

## 15. 1단계 시제품 범위 [권고]

영웅 1, 영지 전통 1(+ 검사용 더미 영웅·영지 각 1, 그림 없음), 무기 4, 도구 4(땅 1·건물 1·사람 1·혼합 1), 특허장 4, 물품 12, 교차 진화 2, 적 6, 계절 4, 챕터 1, 사람 규칙 A/B/C 설정 전환. 그래픽은 도형.

판정 질문:
1. 도구 위주 빌드가 무기 위주 빌드만큼 이기고 재미있는가(봇 승률 + 직접 플레이)
2. 교차 시점이 판 중반에 오는가
3. 판 막바지 폰 화면에서 적과 내 것이 구분되는가
4. 처음 집은 도구가 뭘 했는지 플레이어가 말할 수 있는가
5. 사람 규칙 A/B/C 중 빌드 분포가 고르게 나오는 것은
6. 플레이어가 시키지 않아도 영지로 돌아가는가(영지 반경 체류 비율)
