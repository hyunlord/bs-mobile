# 확장 콘셉트 보관표

확장 영웅 8·영지 6의 이름과 한 줄 콘셉트만 보관한다. 승인된 제작 목록이 아니며 추가 데이터 레코드·그림은 만들지 않는다. 기본 영웅·영지 각 1개로 게임을 먼저 완성한다.

## 영웅 8

| 이름 | 한 줄 콘셉트 |
|---|---|
| 이슬 견습자 | 응결수를 모아 마른 성장물을 되살리는 유랑 재배사. |
| 돌잠 장인 | 폐허의 돌을 깨워 임시 방벽으로 움직이는 석공. |
| 잿빛 목자 | 화재 뒤 초지와 가축을 돌보는 재생의 수호자. |
| 밤등 순례자 | 버려진 등불을 이어 백성의 귀환길을 만드는 길잡이. |
| 풍차 결투가 | 회전 바람으로 적을 몰아 제분 작업을 지키는 호위자. |
| 벌무늬 사냥꾼 | 적을 꽃밭 쪽으로 유인해 벌떼와 함께 싸우는 추적자. |
| 소금 외투 상인 | 위험한 방어띠와 교환소 사이의 운송을 지키는 행상. |
| 늪실 재봉사 | 살아 있는 섬유로 일꾼의 보호복과 덫을 짜는 장인. |
