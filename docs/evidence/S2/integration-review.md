# S2 통합 검토 기록

검토일 2026-10-08. 아래는 구현 중 발견사항이며 최종 수정·검증 여부는 S2 보고서와 테스트 원자료를 따른다.

- 부대 표현: 백성 하나의 role만 militia로 바꾸는 초기 구현은 01 §7의 부대 하나=개체 하나 계약을 표현하지 못했다. 부대의 Members와 실제 시뮬레이션 entity 수를 분리하고, 귀환 후 백성으로 복귀하는 상태 전이를 추가하도록 수정 요청.
- 사람 손실: Health 필드만 있고 피해 경로가 없으면 죽음·재소집이 장식이 된다. 실제 접촉 피해, 사망 제거, 식량 제한 내 재소집을 구현하도록 수정 요청.
- 피해 귀속: 도구 Source가 없는 초기 가신·백성의 공격을 WeaponDamage에 더하면 무기/도구 교차 곡선이 왜곡된다. AllyDamage로 독립 집계하도록 수정 요청. 도구가 만든 성장물의 피해만 해당 도구 GrowthDamage에 귀속한다.
- 지표 추세: config 안의 commit/소스 해시는 매 커밋을 별도 시계열로 나누었다. 실행 의미를 가진 설정과 provenance를 분리하고 commit 등은 sourceMetadata에 보존하도록 수정했다.
- 기존 S0 인위적 정책별 배율은 실제 정책 비교에 사용하지 않는다. 카드 선택의 결과로만 빌드 차이를 측정한다.
- 원문 §8의 리롤·금지·고정은 UI 없이 결정론 선택 상태와 예산으로 검사할 수 있도록 요청했다. 보상형 광고나 운영 SDK를 추가하는 요구는 아니다.

검증 전 로컬 실행은 dirty tree로 표시하고 데이터·소스·로드된 어셈블리 해시를 함께 기록한다. 중간 실행의 평균을 최종 p95로 부르지 않는다.

추가 부대 검증에서 C 귀환 후 시험 entity 수가 64개로 증가하는 오류와 부상 부대가 체력을 생성하는 오류가 재현됐다. 수정 후 독립 재현에서 entity 60 유지, 총체력 보존, 사망 제거·새 ID 재소집, 부대 5명=개체 1개, 아군 피해 별도 원장을 확인했다. 수동 카드 3장·고정 유지·리롤·금지·선택 후 재개 및 잠금 상태의 해시 반영도 독립 실행으로 확인했다. 자세한 출력은 같은 폴더 independent-review.md에 있다.
