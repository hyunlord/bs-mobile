# 제외한 최초 전체 리그

소스 `e0b5b9b317e39996c14ca3b8b01718e3dc748d57`에서 시작한 최초 전체 행렬은 PR #39 리뷰 후 중단했다. 완료된 174사례를 최종 리그의 독립 표본이나 반복 횟수에 합산하지 않는다.

- P1: 시간제 효과의 `appliedTotal`이 과거 종료 시각부터 현재까지의 경과 시간을 포함할 수 있었다. 실제 현재 시각 또는 아직 유효한 종료 시각을 기준으로 늘어난 시간만 세도록 수정한다.
- P2: 여러 `requiredTags`를 하나만 만족해도 물품이 획득 후보가 됐다. 모든 요구 태그를 만족해야 하는 조건으로 명확히 하고 단일 태그 음성 사례를 검사한다.

원본은 `e0b5b9b-raw.tar.gz`, 완료 결과 파일별 해시·반복은 `e0b5b9b-manifest.json`에 있다. 중단 당시 아직 완료되지 않은 작업의 일부 파일도 아카이브에 남을 수 있으며, 공식 CSV나 통계를 만드는 입력으로 사용하지 않는다. 후속 완전 행렬은 수정 소스를 새로 커밋·빌드한 뒤 별도로 실행한다. 수치를 좋게 만들기 위한 조정이 아니라 리뷰로 확인한 계측·선행 조건 결함 수정이다.
