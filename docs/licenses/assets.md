# First Playable 오디오 원자료와 사용 기록

제작일: 2026-10-09. 이 프로젝트 의뢰에 따라 Codex가 작성한 결정론적 합성 코드와 새 음표 배열로 만든 **프로젝트 원본 합성음**이다. 외부 음원, 녹음 샘플, 사운드폰트, 다운로드한 CC0 파일 또는 기존 곡의 악보를 사용하지 않았다. 사람이 연주하거나 녹음한 음원으로 표시하지 않는다. 별도 외부 음원 라이선스나 저작자 표시 조건은 도입하지 않았으며, 이 기록은 CC0 선언이나 권리 독점성 보증이 아니다. 생성 도구 사용 근거는 [프로젝트 생성물 출처 기록](first-playable-art.md#사용-근거)을 따른다.

저작 소스: [first-playable-audio.mjs](../../tools/first-playable-audio.mjs). WAV는 22,050Hz·모노·16bit PCM이며 Unity importer는 PCM, normalize 끔, preload를 명시한다. 런타임 음원 경로는 `unity/Assets/Resources/Audio/`이다. 파일 생성·동일성 검증에는 네트워크나 외부 패키지가 필요 없다.

|---|---:|---|
| hit.wav | 0.12초 | 짧은 하강 주파수·결정론적 노이즈 타격 |

WAV 총합 911,458바이트(헤더 포함). 음악과 효과음은 각각 독립 볼륨 설정을 받는다. 효과음 최대 샘플 절댓값0.14, 음악0.16;7전용 효과 채널×0.7 gain+1음악 채널×0.3 gain의 보수적 동일위상 합은0.734이다(16bit 양자화 오차 포함해도0.8미만). 이는 프로젝트 음원8개와 이 컴포넌트의 소스만 계산한 수학적 상한이며, 운영체제 출력·추가 소스·후처리의 청취 품질 보증이 아니다. 히트 폭주가 레벨·진화·보스 전용 채널을 차지하지 않는다. 일반 히트/킬/수확/피격은 간격 제한, 진동은1초 간격 제한을 적용한다.

## 재생성과 정적 검증

```sh
node tools/first-playable-audio.mjs
node tools/first-playable-audio.mjs --check
node --test tools/test-first-playable-audio.mjs
```

정적 검사3개 통과: 같은 소스의 바이트 재생성,8개 서로 다른 WAV, PCM 헤더/길이/유한값/peak,16초 루프 양끝0과 경계 기울기,최대 동시 믹스 headroom. `--check`는 저장된 WAV와 importer 설정이 저작 소스와 동일한지 검사한다. CSV·분석 JSON·ZIP·전달 영수증은 만들지 않았다.

## 실제 재생 QA — Editor 출력 검증 완료, 기기 청취 대기

M3 전체 Editor 검사44 EditMode/19 PlayMode가 통과했다. 합성 Core 이벤트를 실제 AudioSource와 AudioListener에 전달해7cue 양성 출력, 각 mute의0 RMS, 최대 동시 믹스 표본 peak0.2565 미만을 확인했다.16초 음악의 실제 재생 위치가2회 되돌아오고 양쪽 경계 표본에 출력이 있음을 확인했다. 이는 연속 녹음·사람의 청취·실기 진동 판정이 아니다. 기기에서 아래 항목을 추가 검증한다.

1. Unity/폴드7에서 음악을 최소2주기 들어 경계 클릭·뚝 끊김·반복 피로·배경음 대비를 확인한다. 외부 스피커/이어폰 출력 경로를 기록한다.
2. 실제 적 타격/사망/수확/레벨/진화/영주피격/겨울보스로7cue를 각각 발생시킨다. Elite는 boss cue를 내지 않고, 같은 event ID를 다시 전달해도 소리가 재시작하지 않아야 한다.
3. 히트 폭주 중 레벨·진화·보스 신호를 들어 별도 채널 유지, 찢어짐/과도한 크기/중요 신호 누락을 확인한다. 최대 volume1에서도 실제 믹스 캡처를 점검한다.
4. 음악/효과 volume0과 중간값, 진동 끔, 앱 백그라운드/복귀, 재시작을 확인한다. 카드 화면에서는 음악·레벨 신호가 계속되고, background만 audio pause한다. 진동은 선택한 토글과1초 제한을 지킨다.
5. 실제 출력 녹음·청취 결과와 실패 사례를 root가 기록한다. 현재 기록에는 이를 수행했다는 주장이 없다.
