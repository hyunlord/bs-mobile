# 리그 증거

관문: 원본 S4 우세 정책 검정 **FAIL**을 보존한다.
변경: 사례별 원자료·도표는 고정 Release로 이전하고 집계 CSV·보고서는 유지했다.
사용자 결정 필요: 없음. 후속 실험은 원본 결과를 덮어쓰지 않는다.

[S4-report.md](S4-report.md)는 원본 커밋과 바이트가 동일하다. 보고서의 기존 상대 링크와 전체 도표를 함께 열려면 [원본 Release](https://github.com/hyunlord/bs-mobile/releases/tag/phase0-evidence-original-20261008)를 빈 디렉터리에 추출한다. 다운로드·검증 방법과 파일별 해시는 [증거 보관 안내](../evidence/README.md)에 있다.

`raw/`, `case-metrics.csv`, `case-timeline.csv`, `final-builds.csv`, `S4-curves.png`, `S4-curves.svg`는 Release 안의 원래 `docs/league/` 경로에 보존했다. [커밋 고정 원본 파일](https://github.com/hyunlord/bs-mobile/tree/b3f4830bb8c441343f61362e2b39e474f5709290/docs/league)에서도 확인할 수 있다. 현재 `source-manifest.csv`는 원본 보고서의 입력 해시 목록이며 현재 트리에 원자료가 있다는 뜻은 아니다.

S0 합성 리그는 게임 밸런스 근거가 아니다. S4 수치 결과 또한 모바일 조작·재미·첫 도구 이해도를 검증하지 않는다.
