# S4b 전역 수치 변경 기록

사전 선언: [프로토콜](S4b-protocol.md), PR #59, 기준 main `aa8419c`. 보정은 random/C seed1000–1031만 사용한다. 평가 seed42–73 실행 후 재튜닝하지 않는다. 이전 S4 보고와 FAIL은 불변이다.

## 후보 1: 접촉 가능한 위협과 비선형 XP

구현 프로필 `s4b-01`, 전체 수치 `data/tuning-s4b-01.json`. 아직 측정하지 않았다.

| 항목 | 기존 S4 | 후보 1 | 근거 |
| --- | ---: | ---: | --- |
| 영주 속도 | 24 | 24 | 이동 속도 자체의 정책 차이를 추가하지 않음 |
| 영주 체력 | 3000 | 900 | 기존 생존 포화를 줄이는 전역 압력 |
| 기본 출현 수 | 2 | 3 | 접촉 빈도 증가 |
| 시간 증가 간격 | 2700틱 | 1800틱 | 후반 위협 증가 |
| raider 속도/피해/공격 주기 | 10/5/45틱 | 30/12/30틱 | 선택된 추적 적이 영주 속도를 넘음 |
| shield_raider 속도/피해/공격 주기 | 5/7/65틱 | 26/14/45틱 | 두 번째 추적 적도 접촉 가능 |
| seed_mite 속도/피해 | 7/4 | 14/8 | 비추적 적은 속도·피해를 2배로 통일 |
| crop_grazer 속도/피해 | 6/6 | 12/12 | 같은 원칙 |
| stone_breaker 속도/피해 | 8/8 | 16/16 | 같은 원칙 |
| siege_cart 속도/피해 | 3/18 | 6/36 | 같은 원칙 |
| XP Base/Linear/Quadratic | 선형 30/15/0 | 30/15/3 | 초반 선택을 유지하며 후반 비용 증가 |

원본 적 값은 선택된 6종의 실제 JSON과 대조했다. 적 체력·XP 보상·개별 카드 효과·정책 가중은 바꾸지 않는다. `ram_runner`는 기존 선택된 6종에 없으므로 의뢰서 예시의 적을 새로 섞지 않는다.

모든 A 정책은 영지 상대 `(-3000,-3000) → (3000,-3000) → (3000,3000) → (-3000,3000)` 순환을 사용한다. 이 경로·B 이동 상수는 data JSON에 들어가며 후보마다 이동을 바꾸지 않는다. 후보 변경은 전역 위협·XP에 한정한다.

## 측정 기록

구현 검증과 소스 커밋 후 후보별 데이터 해시·소스 SHA·생존 n/32·사망 시각·생존자 레벨·중단/후속 이유를 여기에 추가한다. 아직 보정 또는 평가 결과를 주장하지 않는다.
