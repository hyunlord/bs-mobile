# S4b 전역 수치 변경 기록

사전 선언: [프로토콜](S4b-protocol.md), PR #59, 기준 main `aa8419c`. 보정은 random/C seed1000–1031만 사용한다. 평가 seed42–73 실행 후 재튜닝하지 않는다. 이전 S4 보고와 FAIL은 불변이다.

원본 적 값은 선택된 6종의 실제 JSON과 대조했다. 적 체력·XP 보상·개별 카드 효과·정책 가중은 바꾸지 않는다. `ram_runner`는 기존 선택된 6종에 없으므로 의뢰서 예시의 적을 새로 섞지 않는다.

모든 A 정책은 영지 상대 `(-3000,-3000) → (3000,-3000) → (3000,3000) → (-3000,3000)` 순환을 사용한다. 이 경로·B 이동 상수는 data JSON에 들어가며 후보마다 이동을 바꾸지 않는다. 후보 변경은 전역 위협·XP에 한정한다.

## 후보 2: 생존 여유 증가와 후반 레벨 비용 증가

`tuning-s4b-02.json`은 후보 01에서 영주 체력 900→1800, XP Quadratic 3→5만 바꾼 완전한 전역 묶음이다. 낮은 생존율 때문에 체력 여유를 늘리고, 생존자 중앙값 47 때문에 공유 XP 비용을 높인다. 두 변경은 상호작용할 수 있으므로 같은 보정 seed32개에서 생존·XP를 함께 다시 측정한다. 수치의 효과를 사전에 보장하지 않는다. 이동·mixed 순서·개별 카드·정책 가중은 유지한다.
