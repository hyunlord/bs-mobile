# 첫 모집 영웅 초상화·등장 콘티 r1

상태: 사용자 그림/연출 검토 대기. 추적 [#564](https://github.com/hyunlord/bs-mobile/issues/564). 게임 코드·데이터·SDK·기존 atlas는 변경하지 않는다. 승인된 GDD16의 농로 길잡이(일반), 강가 수호자(희귀), 폐허 탐구자(서사)를 대상으로 한다. 가신은 별도 집합이며 기존 가신 인물을 이름만 바꿔 영웅으로 사용하지 않는다.

## 초상화

승인된 가신 초상화의 무광 잉크·과슈, 허리 위 구도, 좌상단 광원, 투명 배경을 기준으로 제작한다. 초상화의 품질은 등급에 따라 낮추지 않고 직업·소품·색과 얼굴로 구별한다. 문장이 있는 경우 씨앗 하나·휜 줄기·높이가 다른 잎 두 장의 새싹을 사용하며 백합·사자·왕가 보석 장식을 넣지 않는다.

새 영웅의 원본 atlas crop은 아직 없으므로 내보내기 크기는 신규 제안 계약이다. 기존 가신의 인물별 다른 crop 크기를 이 세 영웅의 역사 계약처럼 표시하지 않는다. 큰 생성 원본과 UI용 PNG, 작은 목록과 상세의 판독 비교를 보존한다.

## 모집 연출

서버가 모집 결과를 확정한 뒤에만 시작하는 짧은 등장 콘티다. 등급은 일반 초록·희귀 파랑·서사 보라로 구분하고 승인된 양피지·어두운 바·파랑 주 버튼·광택 아이콘을 사용한다. 표시 시간은 [가설]이며 실제 구현·체감 측정이 아니다.

서버가 결정한 같은 영웅만 드러낸다. 다른 등급·영웅으로 바뀔 것처럼 보이는 가짜 추첨, 아슬아슬한 실패, 재추첨·확률 변경을 연출에 넣지 않는다. 건너뛰기는 같은 결과를 즉시 보여 주며, 동작 줄이기에서는 정적 결과로 바로 간다. 응답이 불명확하면 기존 요청의 결과 확인 화면을 유지한다. 앱 종료나 확인 버튼은 결과를 다시 지급하거나 모집 카운트를 추가 변경하지 않는다.

실제 서버/RNG/결제/게임 애니메이션/휴대폰 검증은 NOT_RUN이다. 문서와 오프라인 콘티 검토는 사용자 최종 그림 승인을 대신하지 않는다.
