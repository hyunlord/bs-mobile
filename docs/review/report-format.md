관문: 통과 — 신규 보고는 커밋·PR·CI 3종으로 연결하고 첫머리 요약을 10줄 이내로 작성한다.
변경: 관문·변경점·결정·한계를 본문보다 먼저 읽을 수 있게 통일한다.
결정: 보관된 원본 보고서와 증거의 바이트는 형식 정리를 이유로 변경하지 않는다.

# 보고서 형식과 보관 원본

신규 단계·실험 보고서는 첫 줄에 관문 결과(PASS·FAIL·PARTIAL·미검증 등)를 쓴다. 이어 변경점, 필요한 결정 또는 결정 없음, 검증 범위·남은 한계를 적는다. 첫 본문 제목 전의 요약은 빈 줄을 포함해 10줄 이내로 유지한다. 결정이 미승인이라면 해당 needs-decision 이슈를 연결하고 승인처럼 표현하지 않는다. 실행 검증 통과와 밸런스·제품 관문 실패를 합쳐 전체 PASS로 쓰지 않는다.

기존 인계 보고서에는 당시 시점을 명시한 짧은 요약과 보관 링크만 추가할 수 있다. 수치·결과를 최신 실험 값으로 덮어쓰지 않는다. 원본 설계 문서, Release에 보관한 원본 보고서·ZIP·해시, CSV에서 생성한 역사적 [S4 원본 보고서](../league/S4-report.md)는 형식 적용 대상에서 제외하고 바이트를 보존한다. 원본의 오래된 실행 명령은 고치지 않고 [현재 리그 런북](../runbooks/run-league.md)과 [보관 안내](../league/README.md)를 함께 제공한다.

후속 결과는 새 보고서에 기록하고 원본을 연결한다. 제거된 원자료의 링크는 브랜치 최신 주소 대신 고정 커밋 또는 검증한 Release 자산을 사용한다.

## 2026-10-08 승인: 간결한 전달과 표본 보관

이 규칙은 [ADR 0016](../adr/0016-concise-evidence-and-retrospective-gates.md)에 따라 ADR0012의 신규 전달·전량 보관 절차를 대체한다. 신규 ZIP, CRC 검사, 전달 영수증은 만들지 않는다. 완료 보고의 증거 식별자는 **커밋 해시 + PR 링크 + CI 링크**다. 원자료가 필요하면 **Release 태그**만 덧붙인다.

원자료 공개는 실패 사례와 표본으로 제한한다. 실험 전에 표본 선정 기준과 상한을 명시하고, 실패 건수와 선택한 사례 식별자를 작은 CSV로 기록한다. CSV에서 재생성할 수 있는 보고서·그래프·집계 JSON·중복 CSV를 Release에 다시 올리지 않는다. 작은 정본 CSV, 분석/재생성 명령과 소스·설정·seed provenance는 저장소에 둔다. 실험 실행 중 생성한 전체 원자료는 무시된 로컬 경로에서 분석할 수 있지만 전량 업로드나 새 전달 묶음을 만들지 않는다.

CI의 실패 로그·테스트 결과와 지표 축적은 운영 증거다. 이를 별도 사용자 전달 ZIP·CRC·영수증으로 포장하지 않는다. 과거 자료·Release는 보존하며, 기존 패키징 도구는 역사적 재현용일 뿐 새 작업의 필수 검사나 전달 명령이 아니다.

관문을 변경한 경우 과거 보고와 판정은 그대로 두고, 별도 표에 새 기준·적용 시점·후향 재판정임을 표시한다. 새 기준으로 통과하더라도 과거 실험이 그 기준을 사전 선언했다고 쓰지 않는다.

## 2026-10-09 2단계 A 배포 예외

[2단계 A 의뢰서](../design/07_ASTRA_GOAL_bs-mobile_phase2a.md)는 `phase2a-mac-play-01`과 `phase2a-mac-play-02`의 **.app 배포용 ZIP 하나씩**을 명시적으로 허용한다. 이는 실행 파일 배포 예외이며 보고서·원자료 ZIP, CRC 또는 전달 영수증을 다시 요구하지 않는다. P1의 영상2개·해 볼 것 목록·선정된 관문 화면은 해당 Release에 제공한다. 단계별 첫 요약10줄·커밋/PR/CI 링크 형식은 유지하며, 맥 검증을 보류 중인 폴드7 M4 통과로 표현하지 않는다.

## 2026-10-09 Mac 자체 캡처 관문 변경

[ADR0035](../adr/0035-opt-in-native-mac-capture.md)의 사용자 결정으로 Mac 관문은 `--autoplay-capture`의 앱 자체 화면·정상 속도 자동 입력·완주·재시작 증거로 바뀌었다. 화면 기록/손쉬운 사용 권한이나 깨끗한 OS 계정 검증을 더 요구하지 않는다. 사람의 클릭 확인은 사용자가 맡으며 에이전트의 자동 입력 결과와 구분한다. Recorder 에디터 영상, 네이티브 앱 자체 캡처, 헤드리스/가속 회귀 검사를 섞어 표기하지 않는다. 빌드와 영상은 준비되는 대로 해당 Release에 제공하고 즉시 관문·커밋·PR·CI로 보고한다.
