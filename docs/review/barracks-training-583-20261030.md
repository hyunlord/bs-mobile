# 병영 서버·훈련 r2 연결 검토

날짜: 2026-10-30. 상태: 부분 검증, PR #590 초안. 공통 ADR0078 #586은 58c1e208로 병합됨.

## 서버

- 서버 PostgreSQL 66/66 통과, 실패/skip 0(b03ec5bc). 실제 HTTP 중복 명령·동시 요청·DB 원장·재시작과 양수 환불 대기 보존 포함.
- 훈련 수치는 opt-in 데이터. 서버가 인원별 총비용·기간·예정 완료 UTC·점유/상한·거부 사유를 quotes로 반환한다. 클라이언트가 비용/시간 공식을 복제하지 않는다.
- 환불은 지갑 상한 내 즉시 지급하고 초과액은 training 분야 상태에 자원별 합산한다. Q/대기 즉시 해제, 생산 수령 전 및 지출 후 자동 충당. 공통 계층은 환불을 해석하지 않는다.
- DB는 #586의 schema v2를 사용하며 이 PR의 추가 DDL/마이그레이션 번호 없음. Program.cs training 등록, Dockerfile 데이터 복사만 공통 파일 접점이다.

## Unity 실행 증거와 한계

9cf9a47b의 이전 UI 두 프로필:

| 프로필 | EditMode 통과/실패 | PlayMode 통과/실패 |
|---|---:|---:|
| first-playable | 956/0 | 55/0 |
| wave-1a | 966/0 | 96/0 |

두 공통 skip은 기존 생성 도구로 입력을 생성한 뒤 해당 테스트를 별도 실행하여 통과했다. 최종 skip 감사는 미설명 0, 기존 선택적 녹화 1이다. 예외 추가나 검사 완화 없음.

승인 training-r2 부품 적용(b23e6ada) 뒤 실제 서버를 연결한 390×844 화면 6장: 연결 → 훈련 확인 → 진행 → 대기 → 취소 확인 → 취소. 실제 버튼을 통한 서버 명령 흐름 PASS, 모든 캡처 cyanPixels=0, anythingCompiling 전/후 false. 완료 예정은 서버 UTC, 점유 O는 현재 점유이며 +N은 새 예약이다.

새 UI 전체 두 프로필 재실행은 **미실행**이다. 이전 기록을 새 UI 통과 증거로 전용하지 않는다. 22:30 공유 Mac 마감 뒤 Unity를 실행하지 않는다. 양수 환불 대기의 재시작 보존은 HTTP/DB 검사로 확인했으며 양수 잔액 UI 실제 캡처는 아직 없다.

## 자산

#589 Release slg-screen-assets-581-20261030의 승인 부품을 분리 요소로 사용한다. 원본 출처/해시는 tools/art-authoring/barracks-ui/와 training.json에 기록한다. 새 atlas 1024×828 예상 증가량 Mac 3.234MiB, 모바일 ASTC4 0.809MiB. 메모리 실측이 아니다.

Core 규칙·역사 리플레이·v6 저장 및 동결 영지 설정은 수정하지 않는다. Unity 연결은 명시적 로컬 개발 서버 경로이며 정식 인증·모집·연구는 이 PR 범위 밖이다.

승인 r2 병영 전용 EditMode 15/15, 실패/skip 0. 경계 검사 10 assemblies PASS. 독립 화면 검토 차단 이슈 없음; 빈 대기 수 중복 표시와 취소 안내의 의미 단위 줄바꿈은 경미한 잔여 개선이다.
