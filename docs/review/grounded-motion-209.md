관문: 부분 — 영주 B의 12자세·분리된 공격 자세와 검은 분신 제거에 이어 적 6종의 관절 애니메이션을 적용했다. 최종 544cc3d의 캡처 없는 구형 맵 혼잡 재생 p95는 16.249ms로 요청한 16.7ms 이하다. 보행의 사용자 판정과 최종 혼잡 영상은 미확인이며, 들판 귀환은 도착했지만 녹화 슬롯 누락 40개로 60fps 관문 실패다.

영주가 공격할 때 상체만 공격 자세로 바뀌고 다리는 이동 거리에 맞춰 걷는다. 발 디딤의 수학적 접촉 검사와 실제 GPU 영상은 구별하며, 실제 화면의 발 미끄러짐 0을 확정하지 않는다. 세로 이동은 더 짧은 투영 보폭을 사용하므로 종종걸음처럼 보이는지는 사용자 검토가 필요하다.

2배 확대 전후 비교의 로컬 표본은 `artifacts/grounded-motion/hero-b-before-after-2x.png`와 `hero-b-before-after-2x.mp4`다. 원본은 같은 seed 30001·오른쪽 일정 입력·1920×1080·실시간 5초의 `old-b-landscape-01`(019c5e3, 60.027fps)과 `new-b-landscape-03`(94676f3, 59.925fps)이며, 각각 301프레임·누락 슬롯 0이다. 확대 편집은 새 플레이 증거가 아니며 원본 녹화 시각을 유지한다.

Mac ARM64 Release/Metal, 1920×1080, 일반 실행의 120Hz vSync, 녹화·Development Profiler 끔, 실제 입력 기록을 10800틱까지 선행 재생하고 120프레임 예열 후 10800–11530틱을 1배속으로 측정했다. 이것은 새 실시간 입력 플레이가 아니라 역사 입력 재생이다. 프레임 표본 2344→2496→2394개, Core 표본은 각각 730틱이며 포커스 중단은 없다. 카드 선택 당시 사람의 대기 시간은 재생 형식에 들어 있지 않다.

화면 구성은 CPU 제출 비용이며 GPU 완료 시간이 아니다. 그리기 호출은 월드 배치만 세며 UI·렌더 파이프라인 전체 호출 수가 아니다. GC는 프로세스 전체 Gen0 횟수이고 할당 바이트 계측은 사용 불가였다. 배열 스냅샷의 LINQ 제거, 적 분리의 몸 너비·돌진 상태 캐시, 중복 영주 외곽선 제거를 적용했지만 세 변경의 기여를 각각 분리 측정한 것은 아니다. 평균 FPS나 캡처 켠 영상의 GC를 이 표와 혼합하지 않는다. 최종 표본의 화면 구성 p95는 1.799→1.483ms, 월드 배치 호출 p95는 67→39로 줄었지만 Core p95는 5.860→7.037ms로 늘었다. 서로 다른 시점의 단일 실행이며 비용 증가의 원인을 분리 측정하지 않았으므로 적 아트 때문이라고 단정하지 않는다.

실패 표본도 보존한다. `after-invisible-hero-failure`(3bc824b)는 빌드에서 영주 셰이더의 instancing variant가 제거되어 영주가 보이지 않았으므로 성능 개선 판정에서 제외했다. Resources의 instancing material을 유지한 94676f3의 영주가 보이는 실행만 위 이후 표에 썼다. 세로 위쪽 보행 `new-b-portrait-up-01`은 900×1600, 59.608fps, 누락 슬롯 **2개**로 60fps 관문 실패다. 이 자료의 일반 설명 문자열은 오른쪽 입력이라고 남아 있으나 실제 `movementProtocol`은 `tick-walk-up-v1`이므로 후자를 기준으로 읽는다.

[PR #211](https://github.com/hyunlord/bs-mobile/pull/211)의 GPU 검사에서 사용한 reflection이 Unity 경계 CI에 걸렸다. 수정 커밋 `d164b353be9aafb1ec4b2cf6078f22a91f837812`는 editor 전용 테스트 동작으로 대체하며, 고립 작업 트리에서 경계 검사 9개 assembly와 player 소스 무변경 비교를 통과했다. 해당 수정의 [CI](https://github.com/hyunlord/bs-mobile/actions/runs/38086632638)가 통과했고, 들판 후속 Unity 검사에서도 GPU 검사를 포함한 64개가 통과했다.

적 6종(씨앗 진드기·작물 포식자·약탈병·방패 약탈병·돌진 주자·발효 말벌)은 종별 걷기 8프레임·예고 2프레임·서기 1프레임을 atlas에 구워 기존 SpriteBatch의 몸체 한 quad로 재생한다. 역할·UV는 초기화 때 캐시하고 권위 상태의 예고·돌진 단계에 맞춰 자세를 고른다. 발밑 그림자는 유지하며 중복 외곽선과 말벌 날개 덧그림을 제거했다. 돌진 주자는 평소 어두운 몸이며 예고·돌진 때만 붉게 표시한다. 피격·사망 때도 붉은 몸으로 되돌아가지 않도록 어두운 서기 자세에 기존 번쩍임·소멸을 적용한다. 전용 사망 자세를 새로 만든 것은 아니며 다른 종의 피격·사망과 보스는 기존 경로를 유지한다.

Unity 집중 검사 75개와 아트 계약 검사 21개가 각각 전부 통과했다(로컬 `enemy-focused-01.xml`·`enemy-art-contract-01.xml`). 이는 자세 선택·위험 색·atlas 계약 등의 검사이며 실제 혼잡 화면의 판독성이나 재미 판정을 대신하지 않는다. 기본 규칙·실행 콘텐츠 수치와 기존 리플레이는 유지했다. 최종 커밋 [544cc3d](https://github.com/hyunlord/bs-mobile/commit/544cc3db453c1912bcdc3a1216312e1f01692624), [PR #214](https://github.com/hyunlord/bs-mobile/pull/214), [CI](https://github.com/hyunlord/bs-mobile/actions/runs/38089712996).
