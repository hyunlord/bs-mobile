# 전투 HUD·카드·일시정지 그림 감사 — #499

영지 밭r3는 사용자 승인, 강r3는 반려·보존 전용이며 적용 기준은 승인된 r2다. 영지 그림 추가 작업은 Codex 게임 적용까지 보류한다. 앞선 내부 QA 통과를 최종 사용자 승인으로 바꾸지 않는다. 영지 Release558파일은 그대로 보존하고 결정 설명만 추가했다.

이번 작업은 전투 UI 그림 감사와 시안이다. 게임 코드·데이터·atlas를 수정하지 않으며 승인된 광택 아이콘은 원본을 유지한다. 결과는 실제 구현 화면이 아닌 오프라인 전후 비교다.

## 현재 소스와 증거

현재 main `6b9bb50af9dc26ecd7124e64109c1b82cf5ad320`의 PortraitHud/PortraitRunPanels를 정본으로 삼았다. 과거390×844 Editor 캡처는 출처를 명시한 비교 배경으로 사용하며 최신 전투 원화가 적용된 실행 증거로 부르지 않는다.

| 요소 | 현재390기준 크기 | 판정·개선 우선순위 |
|---|---|---|
| 체력 |170×18, 숫자11 | 상태 글자13 이상 시안 |
| 경험치 |170×12, 레벨18 | 별도 터치 대상 아님 |

390×844와 safeArea전체라는 조건에서 논리1단위가 출력1px이다. 이를 물리기기의44pt나48dp와 동일시하지 않는다. [Apple44×44pt 권고](https://developer.apple.com/design/tips/)는 검토 기준이며 실제기기터치·DPI·레이캐스트는 NOT_RUN이다.

HUD 예약strip은 top8+root76=84px, 전체화면9.95%다. 실제 그림의 불투명 픽셀 점유율과 다르다. 카드·일시정지는 시뮬레이션이 멈추는 fullsafe-area modal이고 기존 scrim은220/255다. 모달 배경가림을 진행중 전투 HUD 가림으로 보고하지 않는다.

## 시안 제작 계약

우선순위3개는 HUD판독성, 카드표면·글자 hierarchy, 일시정지정보묶음이다. 잉크·과슈 패널만 새로 그리며 원본 광택 아이콘은 재생성하지 않는다. 390×844 화면에는 휴대전화 테두리를 넣지 않는다. 원본아이콘 크롭 픽셀과 화면축소 결과는 별도로 검증한다.

소스감사와 기존캡처에 없는 실제 대비·한글클리핑·기기상폰트·safeArea는 확인했다고 주장하지 않는다. 최종 시안과 새 battleUI Release 링크는 아래에 기록한다. 기존 영지 Release에 전투 UI 파일을 혼합하지 않는다.

23:00–07:00 Unity/게임빌드 실행 금지와 일회성 캡처 예외 종료를 지킨다. 이번 문서·이미지 작업에는 게임 실행 또는 광범위 fullcheck를 추가하지 않고 문서 정적검사·CI를 사용한다.

각 비교판의 좌우 화면은 실제390×844이며 휴대전화 프레임은 없다. 위40px 설명 띠만 별도다. 새 UI는 생성한 잉크·과슈 패널과 현재 승인 광택 아이콘을 기계적으로 조립한 오프라인 시안이다. 원본 atlas 크롭은 픽셀 검증하며 화면 리샘플링·숫자배지 덮임과 구분한다. 철날 검·씨앗 자루·수거 고리 원본은 과거/현재 동일하며 곡식 수호인만 승인된 새싹 문장의 현재 원본으로 대체한다.

후보 내부r5를 공개시안r1로 정리했다. HUD는 아이콘28·배지13, 카드 제목20·본문15·부가13, 일시정지 조건14px다. 원문 `창병`, `호위 성가퀴` 및 진화3종 조건·레벨·모든 행동을 유지했다. 경험치 막대는 원본처럼 비어 있다. 13칸 보조판은 승인 아이콘2개를 번갈아 반복한 합성 배치 시험이며 실제 가능한13개 장비 빌드를 재현한 것은 아니다. 안내문이 종료되는 기존 상태를 전제로 하며 본 시안에는 안내문을 보존했다.

과거 화면의 논리 사각형 합집합 추정은 `COVERAGE-r1.json`에 별도로 기록한다. 이를 픽셀 분할 결과로 부르지 않는다. 새 컨트롤의 논리 hit 최소는48×48이며 실제 터치 검증은 아니다. 상세설정은326×48, 계속210×60, 포기136×60, 카드 하단112×58이다.

기존 장식을 지우는 UI 전용 중립 바탕을 명시된 UI 영역 안에 깔고 새 패널을 합성했다. 이 영역 밖 실제 저장 이미지의 decoded RGBA 차이는3화면 모두0이다. 원본 세계를 새 게임 화면으로 재생성하지 않았다. 글자는 오프라인 AppleSDGothicNeo이며 Unity/기기 유효폰트를 검증한 것이 아니다.

## 검증 범위

실제390화면 독립 시각 검토와 저장 PNG·원본 크롭·좌표·폰트·hit proxy·영역 밖 픽셀 보존 검사를 수행한다. 게임 코드·데이터·기존 atlas는 수정하지 않는다. Unity 실행·실기 터치·게임 통합·야간 로컬 빌드/fullcheck는 NOT_RUN이다. 문서만 정적 검사와 원격 CI 대상으로 삼는다. 최종 그림 승인은 사용자 대기다.
