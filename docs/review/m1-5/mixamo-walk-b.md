## 별도 검·망토 준비

`rig-pilot-b/props/`에 긴 날·십자 손잡이의 검, 어깨~무릎 길이 파란 천 망토와 보조 본3개를 제작했다. 승인 몸체 정점/면수·SHA는 보존한다. 검과 망토를 정지 배치한 실제 렌더를 확인했고 어깨 장식이 망토를 뚫던 초기 후보를 보존한 뒤 망토 윗부분 간격을 조정했다. 최종 정지 표본은 `static-review-v3/`다.

이는 **소품 준비 완료, 실제 리그 부착 대기**다. `attachment-plan.json`은 실제 Mixamo RightHand/Spine2 계층을 받은 뒤 좌표를 확정하도록 표시한다. 인체 본이나 가짜 걷기를 만들어 제출하지 않는다. 정지 상태의 목 장식/망토 겹침과 손잡이 위치는 실제 리깅 후 포즈에서 다시 확인하며 걷기 관통 없음으로 판정하지 않는다.

## 사용자 Mixamo 단계

1. Mixamo 로그인 → Upload Character → 준비된 몸체 FBX.
2. 화면 지시대로 손목·팔꿈치·무릎·사타구니 등 마커를 배치해 자동 리깅한다. 실제 오류가 발생하면 문구를 보존한다.
3. Animations에서 `Walking`을 검색하고 걷기 하나만 고른다. [공식 애니메이션 안내](https://helpx.adobe.com/creative-cloud/help/animate-characters-mixamo.html).
4. 제공된다면 In Place 켬/Mirror 끔. 최초 속도·팔 간격 기본값을 유지하고 클립 이름과 설정을 기록한다.
5. 다운로드 권고: FBX Binary, With Skin,60fps,Keyframe Reduction None. 제공 옵션이 다르면 실제 옵션을 기록한다. 이 옵션명/60fps 제공 여부는 로그인 UI에서 아직 검증하지 않았다.
6. 다운로드 파일의 로컬 경로를 전달한다. 계정·비밀번호를 공유할 필요는 없다.

## 실제 걷기 검수 계약

받은 FBX와 클립/설정의 SHA·출처를 보존한다. 하체 이동 거리와 보폭을 맞추고 검을 오른손 본, 망토 보조 본을 몸통 기준에 연결한다. 제출: 2배 영상,0.05초 간격 시트, 팔·옆구리·겉옷 앞판·다리 사이 확대, 전신 약100px 미리보기. **늘어남·찢김·관통이 있으면 실패**로 남긴다. 망토·검과 몸의 관통도 포함한다. 사용자 걷기 영상 승인 전 베기·피격·8방향 확장은 하지 않는다.
