## 승인 범위

수작업 가중치 보정을 중단한다. 실제 UAL 기본 마네킹의 기존 가중치를 승인(b) 몸체에 정렬·표면 전사하고, 마네킹에 없는 영역은 주변 값으로 채운다. 손은 해당 손 본100%, 검 손은 주먹 자세다. 허리 아래 자락과 망토는 뼈 가중치 변형 대신 Blender Cloth로 시뮬레이션하고 허리/어깨 핀·몸/다리 충돌체를 사용한다. 검은 원화 십자 손잡이·긴 날, 망토는 파랑 천 텍스처·두께를 가지며 임시 막대·판자는 허용하지 않는다.

후보는 하나뿐이다. 동일 UAL `Walk_Loop` 한 방향의1×/2× 영상,0.05초 시트, 손·앞판·무릎·망토 확대,100px를 제출한다. 늘어남·찢김·관통이 남으면 원인 보고 후 중단한다. 외주 또는 짧은 튜닉 디자인 선택은 사용자 몫이다. 베기·피격·8방향 확장과 게임 통합은 이번 범위가 아니다.

## 입력과 방법 경계

UAL1 무료 Standard 원본의 실제 `Mannequin`은8,546정점·65 vertex groups와 Armature modifier를 가진다. 이전 UniRig/수작업 실패 가중치를 전사 출처로 삼지 않는다. [UAL 출처·라이선스·클립](ual-walk-b.md)을 보존한다. 승인(b) 몸체의4K/UV를 유지하며, 장갑 주먹 형상과 의복 분리 등 승인 범위의 변경량을 별도로 기록한다.

Blender의 [Data Transfer](https://docs.blender.org/manual/en/3.0/modeling/modifiers/modify/data_transfer.html)는 nearest-face interpolation을 제공하지만 영역 누락 보간이나 좌우 오매핑 방지를 자동 보증하지 않는다. 매핑 거리·미매핑 수·주변 보간 수·가중치 합을 실제 결과로 구분한다. 공통 bind 공간에서 표면을 맞추며 UAL의 rest/action 기준을 보존한다.

천은 핀 목표 변형 → Cloth → 외형 두께 순서로 구성하고, 몸 충돌체는 Armature 뒤 Collision을 적용한다. [Cloth modifier](https://docs.blender.org/manual/en/4.4/modeling/modifiers/physics/cloth.html)의 실제 point cache와 프리롤/걷기 프레임을 기록한다. 뼈로 흔든 천을 물리 계산으로 표현하지 않는다. 반복 입력이라도 천 루프가 저절로 이어지지는 않으므로 반복 영상의 이음새는 별도 한계다.

## 천 표면 준비와 한계

원본 색으로 자락 면을 단순 분리하면 무릎 혼입과 큰 누락이 있어, 원본 겉면에 투영한48열×30행의 연결된 천 proxy(1,488정점/1,402quad)를 구성했다. 실제 몸체는22,445→17,246삼각형으로5,199면을 제거했다. 참고 겉옷 면5,228개와 제거 면 수는 서로 다른 선택 기준이며 차이29개를 특정 해부학 영역으로 단정하지 않는다. 독립 좌표 검사에서 남은 몸체 삼각형은 원본의 부분집합이며 새로운 몸·다리 면 추가는0이다(1e-7 좌표 정밀도).

한 proxy 면에 원본 삼각형 UV를 외삽하는 첫 준비 방식은 정지 화면에서 심한 색 조각화를 보여 폐기했다. 원본4K 표면색을 별도 천용4K로 전사하는 준비 과정과 실제 걷기 후보 시험은 구분한다. 원본 이미지·몸체는 불변이며 캐시를 구운 뒤 추가 시각 보정 후보는 만들지 않는다.

단일 시뮬레이션 설정은60fps, quality12, mass0.3, tension/compression15, shear5, bend0.5, damping5, air3, object/self collision 활성, collision quality6, 거리4mm, Cloth 뒤 두께2mm이다. Dynamic Mesh는 꺼 두었다.1..120은 UAL 원본0 자세의 프리롤,121..200은 원본0..79 걷기이며 렌더는 프리롤을 제외한다. 캐시 결과와 실제 충돌 판정은 별도로 기록한다.

실제 `bake_all`은294.55초에 완료했다. 자락1,488정점·망토3,185정점 각각 `isBaked=true`, `200 frames on disk`를 확인했다. 프리롤 포함1..200을 저장했으며 제출 영상은121..200만 사용한다. 충돌·자체충돌 설정과 캐시 생성은 실제 관통0을 보증하지 않는다.

## 단일 실제 걷기 결과: 실패

위 수치는 실제 저장 캐시를 읽어 계산했다. Cloth 후단 Solidify를 검사 메모리에서만 제외하고 원정점수·순서를 확인했으며 모델 SHA는 불변이다. 팔·무릎 수치 영역은 좌표 구간이며 모든 정점을 해부학 라벨로 자동 확정한 것은 아니다. 표면 전사 자체의 계산 일치가 대상 메시의 의복·갑옷 경계까지 적절한 가중치를 보증하지 않음을 이 후보에서 확인했다.

천은 실제 물리 캐시에서 큰 변형이 확인됐지만, 충돌체의 열린/융합된 면·초기 접촉·고정 핀·강성 중 각 기여도를 분리한 추가 실험은 하지 않았다. 원인을 하나로 단정하지 않고, 사용자 계약에 따라 후보 실패 후 재설정·재베이크를 중단한다.

독립 검토에서 프리롤 scene1/60/120의 실제 몸체51,555정점 좌표 SHA와 pose matrices가 동일하고 최대 변위0m임을 확인했다. 정지 몸체의 프리롤 종료 시점에도 자락 표본 edge는16.57→171.43mm, 망토 표본은21.47→46.38mm였다. 따라서 걷기 입력만을 원인으로 볼 수 없다. 같은 캐시의 회색 재질 검사에서도 자락 형상 붕괴가 남았다. 최종 캐시 모델 SHA는 `4aa39e9269501bafad66e779de83efab12b2825ad92489ffb188bf71fe35103c`다.
