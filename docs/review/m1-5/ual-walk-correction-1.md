# M1-5 UAL 걷기 가중치 수정1회

2026-10-14 · [#262](https://github.com/hyunlord/bs-mobile/issues/262) · [이전 실패](ual-walk-b.md). 사용자는 비율 안정·실제 걷기를 확인하고 UniRig/UAL 방식은 유지했다. 아래 변경은 한 후보만 허용하며, 실패가 남으면 원인별로 보고하고 중단한다. 사용자 걷기 영상 승인 전 베기·피격·8방향은 금지한다.

## 사용자 수정 계약

- 손목 아래 장갑 전체는 해당 손 본100%, 손가락 영향0. 검 쥔 오른손은 주먹 자세로 고정한다.
- 허리 아래 치마는 골반약70%·허벅지약30%로 경계를 부드럽게 한다. 치마 안쪽 무릎을 안으로 이동한다. 필요할 때만 앞/뒤 치마 보조 본1개씩 허용한다.
- 망토는 몸과 간격을 두고 등/어깨 중심 가중치와 보조 본 각도 제한을 적용한다.
- 이전 실패 몸체·가중치·소품·영상은 불변 보존한다. 수정은 `ual-pilot/correction-1/` 파생 사본에만 적용하며 기존4K/UV/UAL 동작·FPS·재생 길이는 유지한다. 승인된 손·무릎 기하 보정은 변경량을 명시한다.

## 단일 후보 사전 선택

몸체는 단일 재질이므로 이름만으로 장갑/천/무릎 영역을 추정하지 않는다. 실제 rest 좌표·UV 색·연결성을 함께 확인하고 마스크와 변경 정점 수를 남긴다. 얼굴·상체·승인 범위 밖 영역을 임의로 수정하지 않는다.

망토는 정규화된1.8m 몸체 기준 뒤로0.07m 띄운다. 상단은 등80%·해당 어깨20%, 하단은 기존 보조 본3개를 따른다. 이번 후보의 보조 본 각도는0도로 제한해 별도 흔들림을 끈다. 실제 등/어깨 걷기 동작만 추종하며 동적 천 시뮬레이션 통과로 표현하지 않는다.

## 검증과 제출 계약

동일 UAL1 `Walk_Loop`의60fps80프레임을 재생한다. 전체 프레임의 손·앞판/무릎·망토 확대를 검사하고 후면/측면은 관통 확인용으로만 추가한다. 카메라를 바꾼 QA가8방향 동작 저작을 뜻하지 않는다.

제출물은1×/2× 영상,0.05초 간격 실제 프레임 시트, 손·앞판·무릎·망토 확대,100px 미리보기다. 통과 기준은 확대 프레임의 손 늘어남0, 앞판 찢김/무릎 관통0, 망토 관통0이다. 가중치 합·메시 무결성만으로 시각 관문을 통과시키지 않으며 가려진 면의 확인 한계를 구분한다.

### 원인 구분

- **손:** 장갑 내부 edge 길이 최대 차이는0.000254mm로 rigid 변형의 수치 오차 수준까지 줄었다. 그러나 손목 경계의 최대 길이 증가는29.80mm다. 오른손 실제0/64프레임은 검 손잡이를 감싼 주먹이 아니라 손과 손잡이 사이 틈이 보여, 주먹 고정의 시각 목표도 충족하지 못했다. 숫자상 rigid와 자연스러운 쥐기는 구별한다.
- **앞판·무릎:**66프레임 edge54766은43.51→340.26mm로 늘어났다. 무릎 정점27102는 기존 thigh_l8.003%/calf_l91.997%이고, 연결 정점27118은 치마 마스크로 분류돼 기존 calf_l100%에서 pelvis70%/thigh_l30%로 바뀌었다. 연결면 양쪽이 종아리와 골반을 다르게 따라가는 **이번 마스크·가중치 경계의 불연속**을 확인했다. 치마 마스크가 무릎 연결부까지 포함했을 가능성이 있으며 정확한 천/금속 경계는 미확인이다. UniRig 방식 전체가 불가능하다는 결론으로 일반화하지 않는다.
- **망토:** 독립 검토가 뒤/옆80프레임 전체에서 관통을 관찰하지 못했다. 가려진 면까지 충돌0을 보증하지 않는다. 상단이 어깨에서 떨어져 떠 보이며 판처럼 뻣뻣한 외형 결함이 남았다. 보조 본 각도0도 제한이므로 흔들림 품질은 시험하지 않았다.

실패 결과와 원본을 보존하고 사용자 지시대로 이 보정 시도를 종료한다. 베기·피격·8방향은 진행하지 않는다.

## 최종 독립 검토와 전달

4부위×4장(각20프레임)의 확대 시트로 전체80프레임을 독립 검토했다. **FAIL**. 장갑 내부 늘어남은 관찰되지 않지만 손목은 금속 덮개에 가려 시각적으로0을 증명하지 못했다. 오른손 주먹/검 쥐기, 앞판·무릎 변형은 명확한 실패다. 망토는 관찰 범위의 관통 미발견과 별개로 어깨에서 떠 있는 결함이 있다.

[선정 실패 표본 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m1-5-ual-walk-correction-1): 동일 UAL1 Walk_Loop80프레임(1.333초)을4회 반복한60fps·320프레임·5.333초1×/2× 영상,100px 영상,0.05초 시트, 부위별 실패 확대 시트. 무음 저작 렌더이며 게임 플레이·성능 증거가 아니다. 확대 표본은 최초 실패f0, 반대쪽 무릎f28, 손 쥐기f64, 최대 무릎 늘어남f66을 선정했다. 전체 원본과 실패 기록은 로컬 `ual-pilot/correction-1/`에 보존하고 원본 모델을 공개하지 않는다.

실행 데이터·Core·Unity 제품 코드는 무변경이다. 사용자 지시에 따라 추가 후보 수정과 베기·피격·8방향 확장을 중단했다. 방식 전체를 포기하는 결정은 내리지 않았다.
