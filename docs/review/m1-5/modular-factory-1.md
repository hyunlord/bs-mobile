## 최신 결정과 시험 경계

통짜 TRELLIS 메시의 영역 가중치·수작업 보정·표면 전사+천 시뮬레이션 경로는 종료한다. [이전 실패 기록](ual-transfer-cloth-1.md)과 원본은 보존한다. 새 방식은 기존 전문가 리그의 기본 몸에 독립 부품을 조립하는 공장이다. 기본 몸은 Quaternius Universal Base Characters 무료판, 동작은 실제 UAL `Walk_Loop`을 사용한다.

단단한 부품은 각자 뼈 하나에100% 부착하며 새 가중치 칠하기를 하지 않는다. 천은 앞판·뒷판·망토를 분리하고2~3본 사슬의 제한된 흔들림으로 표현한다. 앞판은 다리 사이를 가로지르지 않는 트임을 둔다. 물리 시뮬레이션은 사용하지 않는다. 기본 몸·체형의 뼈 길이/굵기·부품/부착 본·색을 JSON 레시피가 소유하며 조립과 굽기를 자동 실행한다.

A 기사 한 방향 걷기와 체형만 바꾼 두 번째 레시피의 걷기 정지3장이 범위다. 영상1×/2×,0.05초 시트, 손·앞판·무릎·망토 확대,100px를 실제 렌더한다. 늘어남·찢김·관통이 남으면 원인을 기록하고 중단한다. 수치 검사나 정지 그림은 사용자 영상 승인을 대신하지 않는다. 베기·피격·8방향·게임 통합은 포함하지 않는다.

[CC0 법문](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) 원문도 로컬에 보존했다. 확인2026-10-14.

## 조립과 구조 검증

기본 몸은 원본 전문가 가중치를 유지한다. 승인(b) 머리만 원본22,445면에서2,065삼각형으로 절취하여 원4K SHA `aacb4f27ef2c0f4cdc1606010285fe4b6b655f2a2974c757ef9bd44f5b552242`와 UV를 보존하고 `Head`100%로 부착했다. 머리 높이0.225m/몸 전체 약1.81m로 약8.04등신이다. 머리·손 대체 영역의 기본 몸 면을 제거하며 원본 정점 인덱스를 남겼다. 원본의 모든 면을 그대로 유지했다고 표현하지 않는다.

독립 저장본 검증에서 기사 몸체의 남은3,860정점 가중치는 원본 인덱스별로 정확히 같았다.35부품 중 천5개를 제외한30개는 단일 유효 본100%다. 앞/뒤 좌우 자락4개는 각각2본, 망토는3본이다. Cloth·Softbody·Fluid·rigidbodyworld는0이다. UAL81시점 회전 quaternion 오차는 최대8.65e-7로 실제 원본 동작을 재현했다. 이 수치는 관통 없는 부품 피팅을 증명하지 않는다.

원본 무료 glTF에 눈/눈썹 normal 이미지2개의 잘못된 파일명 참조가 있었다. 해당 기본 눈/눈썹 메시를 원본 머리 교체 때 제거하므로 최종 부품 재질에는 사용하지 않으며 취득 경고를 보존한다.

두 번째 레시피는 height/shoulder_width/torso_depth/arm_length/leg_length만 다르고 부품·색·동작은 같다. 실제 조립 후 남은 몸체3,864정점의 가중치도 원본과 같고 회전 오차 최대7.85e-7, 물리0이다. 기사와4정점 수 차이는 체형 변화 후 교체 영역 절단 결과이며 새로운 원본 몸체를 쓴 것이 아니다. 같은 공장의 두 조립 실행은 확인했지만 범용 캐릭터 품질 통과는 아니다.

후보 기사 저장본 SHA `ac8c5b85202f53f1d292e1537d1ff931bc4bc8ee4bd716bbfc2d86a4ff4cc681`. 이후 모델 변경 없이 관찰·렌더만 수행한다.
