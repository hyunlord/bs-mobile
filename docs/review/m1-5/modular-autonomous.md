# M1 모듈 공장 · 기계적 기준 자율 반복

2026-10-14 · [#262](https://github.com/hyunlord/bs-mobile/issues/262).

## 사용자 결정

[2차 실패](modular-factory-2.md)는 보존한다. 이후 반복은 새 사용자 승인에 따라 **최대10후보 또는6시간 중 먼저 도달하는 한도** 안에서 자율 실행한다. 이번 실행 시작은2026-10-14T14:44:50Z, 종료 시한은20:44:50Z다. 기존 동결본 측정은 기준선이며 새 후보 횟수에 넣지 않는다. 후보마다 수치 로그를 보존한다.

1단계는 UAL 걷기80프레임 전체에서 부품 간 관통 깊이≤2mm, 관절 틈≤3mm, 삼각형 늘어남±15%를 검사한다. 손과 검의 실제 파지 거리도 검사한다. 사용자가 파지 거리 한계를 별도로 지정하지 않았으므로 이번 시도에는 보수적으로≤3mm를 적용한다. 의도된 접합 겹침과 비접합부 관통은 구별하되, 넓은 부품 쌍 전체를 검사에서 제외하지 않는다. 열린 표면 때문에 판정할 수 없는 영역을0이나 통과로 기록하지 않는다.

허용된 변경은 조각·좁은 관절 띠 혼합, 겹침 확대·작은 관절 덮개, 허벅지를 따르는 앞·뒤판, 망토 뼈 사슬, 주먹 손 부품이다. 앞·뒤판 골반 고정과 광범위 가중치 칠하기는 금지한다. 기존 원본 메시·4K 텍스처와 실패 파일은 덮어쓰지 않는다.

기계적 관문을 전부 통과한 경우에만 툰/셀 셰이딩·잉크 외곽선·원화 색 보정 후 한 방향으로 굽는다. 제출은 실제 게임의1.4배 카메라·잔디·적을 포함한30초 걷기와2배 확대다. 기계적 통과는 외형 승인이나 사용자 영상 승인을 의미하지 않는다. 베기·피격·8방향 확장은 별도 영상 승인 이후다.

실패 한도에 도달하면 가장 좋은 회차·남은 수치·원인만 보고하고 멈춘다. 유료 전환, #126·#98·#224·1b 및 SDK 도입은 진행하지 않는다.

## 최종 상태

**실패,10회 상한에 도달하여 중단.** 2026-10-14T15:21:32Z에10후보×80프레임의 측정과 파일 해시를 확인했다. 시작 후36분42초이며6시간보다 후보 횟수 상한이 먼저 도달했다. 11번째 후보, 외형 처리, 게임 굽기·영상, 베기·피격·8방향은 시작하지 않았다.

사전에 정한 진단 순위에서 가장 낮은 점수는 **10회차47.8088**이다. 완전한 기계적 기준에 가장 가까움을 인증하는 순위는 아니다. 모든 후보는 실패이며 열린 표면의 고체 관통 깊이와 전체 경계 검사도 미완료다.

남은 큰 문제는 원본 외피를 강체 부품으로 나눴을 때 어깨 연결이 유지되지 않는 것과, 허벅지를 따라 움직이는 뒷자락이 손잡이를 침범하는 것이다. 10회차는 얇은 삼각형 때문에 어깨 면이 아래팔에도 잘못 복제되던 계산을 고쳐09회차 표본 거리156.4964mm를143.4265mm로 줄였으나 연결 자체를 해결하지 못했다. 열린 원본·절단 표면 때문에 관통 깊이를 완전하게 측정하지 못한 제한도 남긴다.

[회차별 정본 CSV](../../design/character-factory/autonomous/attempt-metrics.csv)와 [10회차80프레임 CSV](../../design/character-factory/autonomous/best-10-frames.csv)에 수치·누락·후보 SHA를 함께 보존한다. 02회차의 표본 거리0이나07회차의 원시 거리 감소를 틈 해결로 해석하지 않는다.

후보 비교는 각 지표의 기준 초과를 정규화한 최대값이 작은 순서로 한다. 동점에서는 표면 교차 수를 비교한다. 관통 깊이가 미확인인 경우 표면 교차량은 진단용 순위에만 사용하며, 순위가 높아도 합격으로 바꾸지 않는다.

## 측정의 의미와 한계

Blender4.5.14에서 실제 UAL `Walk_Loop`의0~79프레임을 평가한다. 모든 렌더 표시 메시와 modifier 결과를 포함하고, 숨긴 기본 몸·원본은 제외 목록에 남긴다. 후보 파일과 측정기 SHA를 기록하며 최종 비교에는 같은 `mechanical-v8` 측정기를 사용한다. 앞선 측정기 개발 결과는 역사 진단이며 최종 후보 비교와 섞지 않는다.

| 기록 | 실제로 측정하는 것 | 통과 주장에 필요한 추가 증거 |
| --- | --- | --- |
| 표면 교차량 | 서로 다른 부품의 삼각형 교차에서 계산한 교차 길이 | 닫히지 않은 몸 표면에서는 고체 관통 깊이가 아님. 포함 관계·고체 내부는 미확인 |
| 접합부 표본 거리 | 정해진 해부학적 부품 쌍의 원본 대응점에서 반대쪽 표면까지 거리 | 모든 노출 경계를 덮지 않으므로 실제 관절 틈의 완전한 최댓값이 아님 |
| 삼각형 변형 | REST 대비 두 주방향 길이 비율 | 퇴화면·계산 불능·토폴로지 변경은 통과로 처리하지 않음 |
| 손–검 접촉 | 고정한 원본 손바닥 위치523개로 접촉 구간을 정하고, 손잡이 표면48점의 손까지 최대 거리 | 3mm는 이번 시험의 보수적 가정. 접촉만으로 주먹이 손잡이를 감쌌다고 증명하지 않음 |

표면 교차가 없더라도 다른 닫힌 부품 내부에 완전히 들어갈 수 있다. 별도 고체 검사도 닫힌 대상의 정점·면 중심 표본만 검사하므로 열린 몸 전체를 인증하지 않는다. 의도한 관절 덮개 겹침 역시 부품 쌍 전체를 제외해서 숨기지 않는다.

진단 순위는 `max(교차량/2, 접합 표본 거리/3, 최대 변형 편차/0.15, 손잡이 접촉 거리/3)`다. 서로 다른 불완전한 진단을 비교하는 작업 순서일 뿐, 실제 관문까지의 거리를 나타내지 않는다. 누락된 경계·손바닥 표본과 고체 판정 불가는 별도로 공개한다.

분석 형상 검사는 강체 이동,20% 늘어남, 전단,4mm 틈,5mm 교차, 평면 겹침, 손잡이 접촉 실패 및 교차 없이 안에 포함된 닫힌 상자를 포함한다. 로컬 Blender에서 모두 통과했다. 이는 **측정기 사례 검사**이며 후보 캐릭터 통과가 아니다. Core·Unity·실행 데이터는 수정하지 않는다.

## 회차별 변경

| 회차 | 실제 변경과 확인된 제한 |
| --- | --- |
| 01 | 부품마다 다른 정렬 대신 원본의 한 rest 공간에 뼈대를 맞춤. 부품별 혼합 가중치와 잘못 배정된 긴 자락이 여전히 벌어짐 |
| 02 | 원본 위치가 같으면 같은 좁은 띠 가중치를 적용. 대응점 분리는 줄었지만 얇은 삼각형의 큰 변형이 남음 |
| 03 | 강체 부품, 허벅지를 따르는 좌우 앞·뒤판, 원본 장갑 굽힘. 검 방향과 얇은 면의 수치 불안정이 남음 |
| 04 | 검 방향 수정, 극소 면 정리, 작은 팔꿈치·손목·목 덮개. 변형은 약±2.1%지만 어깨·손 문제는 남음 |
| 05 | 국소 정점 병합·작은 구멍 봉합, 자락 회전 중심 변경. 대응점 손실과 새 극소 면 때문에 악화되어 보존 후 다음 후보에서 철회 |
| 06 | 허리·자락·좌우 경계에서 면을 실제 절단하고 원본 UV 계보 유지. 표본 접합 거리 감소, 어깨 문제 지속 |
| 07 | 원본에서2mm 이내인 작은 구멍만 봉합하고 병합 계보 별도 기록. 대응점을 복원하니 틈 개선은 사라졌고 극소 봉합면 변형도 악화 |
| 08 | 원본 열린 오른손을 보존·숨김 처리하고 별도 주먹과 손잡이 구멍을 제작. 별도 접촉 표본2.607mm, 외형 승인 없음 |
| 09 | 원본 어깨 갑옷 배정과 팔꿈치·손목 깊이 정렬 수정. 교차 진단은 감소했지만 접합 표본 거리는 악화 |
| 10 | 얇은 삼각형에서 폭주하던 절단 겹침 계산을 거리 함수의 상한으로 제한. 아래팔에 어깨 면이 잘못 복제되는 원인을 수정 |

07은 병합 이전 대응점을 별도 계보로 복원한 보충 측정을 함께 보존한다.08부터 새 주먹의 접촉 구간은 원본 손바닥 구간과 다르므로 직접 동등 비교라고 표현하지 않는다. 새 주먹은30mm 중앙 구간의3단면×64방향×80프레임을 별도로 검사한다. 기존 측정기의 원본 손바닥 계보 수에는 숨긴 손도 포함되는 제한이 있어, 정본 CSV에는 실제 표시 원본 손 사용 여부와 누락 수를 따로 기록한다.

## 보존·검증

10회차 Blender SHA는 `4aa0b422eccf811de948ce59c0988d7f5bf5f4babecf3f738dc5e886f5c02206`이다.10개 동결 파일의 실제 SHA, 각0~79프레임 총800행, 동일한 측정기 SHA를 독립적으로 다시 확인했다. 원본4K packed 텍스처 SHA `aacb4f27ef2c0f4cdc1606010285fe4b6b655f2a2974c757ef9bd44f5b552242`, UAL 입력 SHA `69591853d817488edaa8fd9bf8fc1d821eaeaf789f8627b3cd23b41c4ed67997`는 유지됐다. 정규화한 원본 전신 높이는1.8000000715m다.

09와10의80프레임 동작 채널 SHA는 `8dcc7da3971f091b06cffea00741b5dc8bdd43a2ea26546954ef847e754de7f1`로 같다.06·08과는09의 명시적 rest 관절 위치 조정 때문에 다르다. UAL 원본 동작 파일 자체를 바꾸거나 걷기를 정지시키지 않았다.

실패 원본·모든 후보·프레임별 원자료는 로컬에 보존한다. [재현 구조와 소스 목록](../../design/character-factory/autonomous/README.md)에 외부 저작 스크립트·측정기의 경로와 해시를 남긴다. 측정기 Python은 연구용 프로토타입이며 타입·린트 전체 검증은 수행하지 않았고, 구문·Blender 분석 형상 검사와 실제 후보 실행을 검증했다. 문서 CI는 모델·외형 통과를 증명하지 않는다. PR263은 초안을 유지한다.
