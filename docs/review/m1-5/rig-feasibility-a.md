# M1-5 (a) 리깅 준비 시험

2026-10-14 · [#262](https://github.com/hyunlord/bs-mobile/issues/262) · [사용자 승인 원본](https://github.com/hyunlord/bs-mobile/releases/tag/m1-5-mesh-a-seed42).

## 관문

**실패 — 이번 정리 파이프라인이 리깅 가능한 몸체를 보존하지 못했다.** 29,914삼각형으로 목표 면수는 맞췄지만 어깨/상완 공백, 등 안쪽 노출, 얼굴/갑옷 찢김이 남는다. 원본 자체의 모든 수작업 복구 가능성이 없다고 결론내리지 않는다. Mixamo에 업로드하거나 사용자 로그인을 요청하지 않았다. 자동 리깅/걷기 결과가 없는 **준비 단계 실패**이며, 걷기 중 변형 실패를 관측했다고 쓰지 않는다.

사용자 승인 범위: (a) 외형/비율 승인, 얼굴/손 세부는 게임 크기에서 허용. 2–3만 면 정리·검 분리·망토 엉덩이~무릎으로 단순화·보조 본2–3개·팔 접합 분리 후 걷기1동작/1방향 시험. 베기·피격·8방향 금지. (b)는 보류이고 자동 재생성하지 않는다.

## 실행과 직접 관찰

원본 PLY `8b6e32f2ddf57a3f9b92f9e39ea7bc3bd44a741f11476ada61c2a6af08faac93` 보존. Blender4.5.14 LTS 로컬 파생만 편집, 새 대체 몸체 생성 없음. 최대 연결 성분은3,275,506정점으로 몸·검·망토가 연결되어 있었다. 분리는 색·위치 마스크 기반 파생 시도이며 수작업 의미론 분리의 정확성을 보증하지 않는다.

| 단계 | 면수 | 실제 결과 |
| --- | ---: | --- |
| 승인 원본 | 6,645,292 | 겉모습 승인, 리깅 미검증 |
| 단순 Decimate | 708,815 | 목표 미달, vertex색 무늬 손실 |

부모와 렌더 담당자가 정면/측면/후면을 직접 확인했다. 등·팔 안쪽 관측은 원본 형상 부족과 분리 방식 손실이 섞일 수 있어 원본 내부의 완전한 해부학적 판정으로 일반화하지 않는다. 표면 소실은 열린 얇은 표면의 signed-volume 변환 가설을 지지하며 두께를 주면 소실은 완화됐다. 다만 이것이 리깅에 필요한 팔/몸 분리를 해결하지 않았다.

원본 정점색→UV 텍스처→FBX 포함 도구는 별도 검 조각 표본에서 실제 실행됐다. 15,176면 유지, 256px 텍스처 및 FBX 재임포트·PNG68,793바이트 포함 확인. 이것은 최종 몸체 색/실루엣 보존이나 리깅 검증이 아니다. 실패 몸체에 텍스처를 입혀 결함을 숨기지 않았다.
