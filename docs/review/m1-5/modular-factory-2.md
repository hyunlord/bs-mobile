# M1 모듈형 캐릭터 공장 · 원본 메시 부품 시험

2026-10-14 · [#262](https://github.com/hyunlord/bs-mobile/issues/262).

## 사용자 결정과 범위

사용자는 [1차](modular-factory-1.md)의 공장·레시피 구조와 체형 변형을 승인하고, 기본 도형 부품의 외형을 실패로 판정했다. 구조는 유지하되 원통·공·판자 갑옷을 새 후보에서 제외한다. 역사 후보·소스·실패 영상은 삭제하지 않는다.

승인된(b) A-pose 메시22,445삼각형·4K 텍스처를 UAL 뼈대에 정렬하여 가까운 뼈 기준으로 머리, 가슴·골반, 좌우 위팔·아래팔·손, 허벅지·정강이·발, 허리 아래 앞판·뒷판으로 분리한다. 기본 몸은 숨기고 뼈대와 실제 UAL 걷기만 사용한다. 새 부품은 원본 UV·텍스처를 유지하며 각 뼈에100% 부착한다. 관절 경계의 좁은 띠만 두 뼈 혼합을 허용하고2~3cm 겹침을 둔다. 넓은 영역 가중치 칠하기는 금지한다.

원본에 없는 망토는 두께 있는 파란 천과2~3본 사슬, 검은 십자 손잡이·긴 날과 오른손 부착이다. 물리 시뮬레이션은 사용하지 않는다. 부품 출처와 자르기 규칙은 레시피에 기록한다.

## 관문과 중단

한 방향 UAL 걷기1×/2× 영상,0.05초 간격 시트,100px, 손·앞판·무릎·망토와 팔꿈치·허리 확대를 제출한다. 늘어남·관통0,2배 영상에서 관절 틈이 눈에 띄지 않아야 한다. 구조 검증이나 정지 그림은 사용자 영상 승인을 대신하지 않는다.

첫 후보에서 결함이 남으면 원인을 기록하고 보정을 반복하지 않는다. 유료 기성 모듈 캐릭터로 전환할지는 사용자 결정이다. 베기·피격·8방향·게임 통합은 포함하지 않는다. #126·#98·#224·1b 및 SDK 미도입을 유지한다.

## 실행 기록

**실패, 후보 동결.** 첫 실제 걷기f20에서 무릎이 앞판을 뚫고 나오고 팔꿈치·목 경계가 벌어지며 검을 제대로 쥐지 못하는 것을 확인했다. 부품·가중치·레시피 수정은 중단하고 같은 후보의 증거만 보존한다. 원본은 로컬 `modular-factory-1`과 승인(b) 경로에 보존하며 새 출력만 `modular-factory-2`에 저장한다. Python 저장소 금지(RB003)를 우회하지 않으며 외부 저작 소스는 개별 파일과 manifest로 보존한다.

## 실제 구조·출처 확인

승인(b) GLB SHA `a8d65d591ae2da80829d409449b06eb33a065285a8268961b024e18c363a5cff`, 원본4K packed 이미지 SHA `aacb4f27ef2c0f4cdc1606010285fe4b6b655f2a2974c757ef9bd44f5b552242`를 사용했다. 저장본 SHA `bd9a2f93d6c2c35c463c2de5d521b2cf0fe10c9cc59ec9d39336b8f4f0cd3563`에서 실제 UV77,070곳을 원본 삼각형/barycentric 계보와 비교했고 최대 오차1.19e-7, 원본 텍스처 해시는 동일했다.

17개 원본 표면 조각을 만들었으며 새 기본 도형 갑옷·몸 부품은 생성하지 않았다. UBC 몸체는 렌더 숨김, 뼈와 실제 UAL 동작만 사용한다. 정렬용 과거 파일은 armature rest만 읽으며 기존 실패 모델의 가중치·action은 가져오지 않는다. 고정 원본 자락은 골반100%, 망토만 별도3본이다.

원본22,445삼각형 중22,348면이 분할 결과에 남았다. 제외97면은 모두 면적이 극히 작은 퇴화면(최대2.70e-13m²)으로 확인됐다. 이를 목·무릎의 큰 파손 원인으로 해석하지 않는다. 원본 전체 기하를 무손실 보존했다고도 표현하지 않는다.

## 검증과 제출물

전체80프레임과 손·앞판/무릎·망토·옆구리·팔꿈치/허리 확대20장을 독립 검토했다. 강체 부품 내부 모서리5,176,240회 비교의 최대 길이 변화0.000304mm는 부품 자체의 안정성만 증명한다. 부품 연결과 관통 관문은 실패다. 망토 바깥 찢김은 보이지 않았지만 등이 가린 접촉은 미확인이고 천이 뻣뻣하게 떠 보인다.

version2 레시피 파서는 현재 입력을 수락하고 금지 입력10건을 거부했다. 소스13개 구문 검사, 두 영상 CFR60·320프레임·5.333333초 및 전체 디코딩을 확인했다. 무음 Blender 저작 렌더이며 원래80프레임을4회 반복했다. 게임 실행·새 사용자 영상 승인이 아니다. Core·Unity·실행 데이터는 무변경이며 문서 검사만 수행한다.
