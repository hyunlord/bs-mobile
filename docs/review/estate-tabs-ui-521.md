# 가신·도전 첫 화면 시안

관문: 통과 — 현재 구현/GDD에 근거한 390×844 두 화면과 동일 배율 비교판을 검토했다. 실제 게임 적용·기기 조작은 NOT_RUN이며 사용자 그림 승인 대기다.

가신/도전은 빈 탭이 아니다. main `98b8dd33094494a97c8da224180a023ee78c38d5`에는 가신6명 선택·강화·승급·출전 기록과 도전20종 진행·연구조건·수령이 구현되어 있다. 이번 작업은 해당 기능의 첫 계정 상태를 승인 UI로 재배치한 오프라인 그림이다.

- 첫 계정 자원 곡물/목재/철재/인장은 모두0이다. 인장(`meta:charter`)과 BM 보석을 혼용하지 않았다.
- 고랑 방패수만 해금, 출전1/1, Lv1/현재상한5, 승급0/5·조각0/5다. 강화/승급은 비활성이며 현재 출정에 가신 보너스가 적용되지 않는 안내를 유지했다.
- 도전은 수령0/20, 첫3개 조건·연구·보상·실제 한국어 해금명과 전체20개 스크롤 제안이다. 출정·수확·처치는 1,800틱(30Hz 기준1분) 이상 진행한 종료 정산 때 집계한다.
- 계정가신6과 별도 GDD 설계가신8을 혼동하지 않는다. 새 배치/전투효과/유료·일일도전은 만들지 않았다.
- 원본 atlas 초상6·장비2를 정확히 크롭하여 축소했다. 일부 초상의 옛 문장은 그대로 보존했으며 새로운 새싹 초상이라고 주장하지 않는다.

비교판은 가신/도전을 나란히 둔 제안이며 런타임 전후 비교가 아니다. 공개r1은 내부후보r2를 선택했고, 내부실패r1은 국소 잔상과 추상적 조건문 문제를 포함하여 로컬에 보존했다. 새 본문14px 이상, hit48×48 논리px 이상이고 겹침/폭넘침이 없다. 실제 dp/pt·물리 터치 성능 증거는 아니다. 편집 마스크 밖 원본 rawRGBA 및 비교판의 native 두 패널은 그대로 보존했다.

BM r2 흐름은 사용자 승인됐다. 가격과 시간은 fixture로 남아 있다. 이후 시간당 보석 하나의 기준을 직접 가속/성장가속권에 공통 적용하고 권은 소폭 할인하는 방향만 기록하며 구체 환율·할인율은 확정하지 않는다. #122 보류, 광고·결제 SDK와 게임 코드·데이터 변경 없음.

검증: source/GDD 대조, native 시각 QA, 원본8crop·rawRGBA·서체·hit 검사, 문서 정적 검사와 필수 CI. 새로운 런타임 캡처·Unity·실기 검증은 수행하지 않았다.
