## 원인 분리

390×844 동일 첫 접속, 동일 카메라·Graphic 인스턴스를 유지하며 ①지면 ②어둠/빛 ③길 ④부지/장식 ⑤전체 순서로 표시했다. 지면 단계에도 기존 EstateTint 복원 색 셰이더는 적용된다. UI는 모든 단계에 동일하게 유지한다. 단계 구분·실제 메시 좌표·컬링 상태를 CSV로 남겼다. 원본을 픽셀 보정한 화면이 아니다.

| 현상 | 최초 층 | 확인한 원인 | 수정 |
|---|---|---|---|

## 실제 1배 픽셀 측정

ROIs는 수정 전 지정 후 고정했다. 좌상단 기준 dark-upper=(35,130)-(280,180), dark-lower=(35,530)-(280,590), lit=(90,320)-(170,380). 최종 화면의 lit에는 길·건물·소품도 포함된다. 이를 순수 잔디 색으로 표현하지 않는다. 지면만 분리한 lit RGB는 기존131.87/115.38/81.28 → 수정131.78/115.35/81.39로 사실상 유지되며, 그 자체는 제시된 R135 하한보다 낮다. 피벗이 바뀌어 고정 화면 ROI가 동일 월드 지점을 뜻하지는 않는다.

| 목표 | 수정 전 | 최종 수정 후 | 범위/판정 |
|---|---|---|---|
| 어두운 땅 RGB≤64/70/78 | 상단72.50/75.51/81.74, 하단73.64/76.48/82.19 | 상단61.98/67.15/76.58, 하단63.71/68.49/77.12 | 최종 고정 ROI 통과 |
| 밝은 영역 RGB135~155/115~125/75~85 | 141.07/117.98/77.75 | 146.63/121.28/81.12 | 최종 합성 ROI 통과; 순수 잔디 하한과 구별 |
| 큰길 가시 폭≥14px | 정량 원본 중심선 없음; UV 분석 예상4.22px는 측정값 아님 | 지정 단면3/4/5:15.75/18.00/14.00px | 기초 옆 두 곳 포함. 화면 전체 모든 단면 보증 아님 |
| 가지길 가시 폭≥9px | 정량 원본 중심선 없음 | 지정 단면14/20/23:11.00/10.50/11.50px | 교차부를 제외한 표본 |
| 화면 가장자리 삼각형0 | 지면 단계 우측 반복 노출, RGB77/83/86 평면8153px | 같은 y100~619 영역 평면0px, 직접 검토 삼각형0 | 실제 지면 캡처와 메시 경계 회귀 검사 |

길은 ②와③의 RGB 최대 채널 차이≥12, 중심에 이어진 구간을 .25px 간격 보간으로 측정한다. 교차부가 폭을 부풀리는 표본은 제외 표시하고 전체24단면 CSV를 보존한다. 반최대 대비(FWHM)도 별도 기록하며 메시 폭을 가시 폭으로 대체하지 않는다. 좁은 큰길 단면5의 FWHM은5.75px로 흙의 밝은 중심이 전체 가시 폭보다 좁다.

첫 수정은 큰길 단면3/5가13.25px로 미달했다. 두 번째 수정에서 UV의 실제 흙 중심만 사용하고 feather 기하 폭을 줄여15.75/14.00px로 통과했다. 세 번째 시각 수정은 하지 않았다. 독립 시각 검토에서 회색 띠·삼각형 제거, 무광 흙길로의 판독 개선을 확인했다. 사용자 미감 승인을 대신하지 않는다.

## 검증 기록

두 프로필 EditMode에서 같은 빛 경계 검사가 실패하여 중단했다. `R7NightMaskIsSmoothAcrossSubcellSamplesAndKeepsDeepInteriorClear`의 인접 texel 알파 차이는 **0.0823529363**, 기존 기준은 **0.08 미만**이다. 어두운 땅 목표를 위해 r7 어둠을 .75에서 .90으로 올린 변경이 경계 기울기도 늘렸다. 수치 목표 일부와 시각 개선은 전체 관문 통과가 아니다. 검사 기준을 완화하지 않았으며 추가 수정·재실행을 하지 않는다. 이미 실행 중인 마지막 PlayMode 결과만 보존한다.

곡창→경작지 native는 **0회 실행**: 동일 실패 두 번 중단 규칙 때문에 이번 승인된 1회 시도에 도달하지 않았다. 자원 지급·규칙 변경 없음. 새 native 성공을 주장하지 않는다.

 진단 하네스 개발 중 `GetMesh(mesh)` API 불일치 컴파일 실패1건, 화면 밖 culled 메시 null을 잘못 요구한 실패1건을 보존했다. `GetMesh()`의 렌더러 소유 메시를 읽고 화면 밖 null은 NA로 기록하도록 수정했다. 최종 층별 PlayMode 두 실행은 각1/1 통과했다.

남은 기존 한계: 반복 강굽이, 일부 넓고 각진 길 합류부, 밭 그림의 크림색 받침·공사 글씨. 작은 영역 픽셀 지표나 구조 검사로 전체 아트 승인을 주장하지 않는다.
