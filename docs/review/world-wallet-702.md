# 월드 서버 지갑 표시 (#702)

2026-11-04 · #691 공통 분리 `8abad792` 기반 독립 변경. 상태: 구현·정적 검사, Unity 및 실제 PNG 검증 대기.

월드 제목 아래에 병영·모집·연구에서 쓰는 `BarracksWallet` 네 칸(곡물·목재·철재·보석)을 재사용한다. 인장은 기존 콘텐츠 `meta:charter`의 승인 아트 역할 `icon.core.muster_roll.default`와 서버 수치로 별도 상단 행에 표시한다. 지갑은 스크롤 밖에 두고 제목·지갑·인장 아래에서 본문이 시작한다. 새 그림이나 수치 규칙은 추가하지 않는다.

값은 `BarracksServerClient.Latest.resources`만 사용한다. 응답 전체나 자원이 없으면 `—`이며 0을 만들어 표시하지 않는다. 기존 하단 전체 자원 문자열을 제거한다. 수령 대기(`held`)는 실제 응답 수량을 보존하고 인장·보석을 포함한 한글 이름으로 표시한다. 알 수 없는 자원은 ID 대신 `미확인 자원`으로 표시하며 새 자원명을 추측하지 않는다.

[GDD05](../design/gdd/05-screen-ux.md)의 상단 자원 표시 방향을 적용한 표현 수정이며 경제·계정·서버 계약에는 영향이 없다. `meta:charter`/`slg:gem`을 숨기면서 해당 보유량을 누락시키지 않는다.

## 검증

- 독립 EditMode 검사: 알려진/알 수 없는 수령 대기 이름, 숫자 보존, 누락 응답, 390×844·1080×2520 헤더 렌더 구조와 승인 아이콘.
- 위 테스트는 먼저 작성했으나 실행 슬롯 제한으로 red/green 실행은 아직 NOT_RUN이다.
- 실제 서버 PNG·두 프로필 전체4묶음·보충2건은 최종 소스에서 별도 실행한다. 합성 DTO 검사로 서버나 실기 증거를 대신하지 않는다.
- View C05 3:3 미통과 상태이며 병합하지 않는다.
