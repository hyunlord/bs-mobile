# 가신·주민·귀환 주민 걷기 #433

관문: 3종 제작·내부 전16장 검사 통과. 사용자 그림 승인과 게임 적용은 별도다.

[Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-people-walk-review-433-20261027) · [이슈 #433](https://github.com/hyunlord/bs-mobile/issues/433)

이전 [#428 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-bell-whistle-walk-review-428-20261027)의 종 도둑 r1·휘파람 사냥꾼 r1은 2026-10-27 사용자 승인이다. 사람형 적 걷기는 사용자 확인에 따라 완료로 기록했다. 이전 파일·당시 검사 기록은 보존했다.

## 납품

|role|걷기|atlas/셀|바닥 기준점(좌상단)|표시|
|---|---|---|---|---|
|person.vassal.move|16×40ms=.64초|4096×256/256×256|(125,225)|108px 셀, 전체 약85px|
|person.peasant.move|16×40ms=.64초|4096×256/256×256|(110,225)|111px 셀, 전체 약88px|
|person.returning.move|16×40ms=.64초|4096×256/256×256|(110,225)|111px 셀, 자루 포함 약95px|

각 세트는 개별 투명 PNG16장, 개별 전신 접사16장, 전체판, 전신/손–소품 검사표, 1배·3배 반복영상, 미설치 manifest 후보, 제작 원화·설정·C#을 포함한다. 모든 셀은 inset0이다. 게임에는 설치하지 않았다.

가신은 승인된 person-vassal-sprout-r1을 기준으로 씨앗 하나·휜 줄기·높이가 다른 잎 두 장을 유지했다. 창을 쥔 손과 창대는 전16장 직접 확인했다. 방패 뒤 손·팔은 가려졌으므로 확인 불가로 남긴다. 상체·창·방패는 한 연결 원화이며 다리는 실제 SpriteSkin으로 변형한다.

주민은 양손에 든 괭이, 귀환 주민은 어깨에 멘 곡식 자루와 받치는 손·자유 팔을 유지했다. 가신 완료 보고 후 주민을 전달·보고하고, 귀환 주민을 전달·보고했다. 공유 Mac 캡처 대기 중 귀환 상체 원화를 준비했으며 최종 검토와 납품 순서는 유지했다.

두 주민 상태는 하나의 Forge.People Scene/Gait/Config/Capture 구현, 같은 다리 원화·메시·뼈·보행을 사용한다. 설정 차이는 bodyRect와 bodyAnchor뿐이다. 실제 캡처의 다리 메시/텍스처 해시8개 및 motion.csv/material-points.csv/upper-body-anchors.csv가 바이트 동일했다. 같은111px 표시셀을 사용해 다리 표시크기도 같다. 자루·곡식 포함 귀환 높이는약95px로 원판 약88px보다 크며, 원판과 총높이가 같다고 표현하지 않는다.

## 검증과 한계

Unity6000.6.4f1/2DAnimation16.0.1 격리 output 프로젝트에서 실제 SpriteSkin의80위상+닫힘+정지 기준을 Camera.Render로 캡처하고0,5,...75를 추출한다. 공유 Mac 잠금·낮 시간대 실행 조건을 지켰다. 먼 다리 색 배율은(.42,.45,.58)이다.

- 가신: 독립 검토자가 개별 전신 접사00–15와 표시1배 판을 확인하고 root가 전체판을 검토했다. 전16장 새싹 구성과 창 파지 유지, 캔버스 잘림0, 고유 프레임16/16.
- 가신: 고정 뼈길이 변화 최대0.00003소스px, 같은 재질 지지점 이동 최대0.00010px, 지면Y오차0. 닫힘000↔080은7픽셀에서 채널 최대1/255 차이.
- 가신 영상2개: 각각160프레임/10주기/6.4초, ffprobe 확인·ffmpeg 전체 디코딩 종료0.

- 주민·귀환: 각16장 개별 접사/표시판 검토. 주민 양손–괭이 자루/날, 귀환 받치는 손–자루/자유 팔 연결 유지. 자루 어깨 접점은 가림. 각 고유16프레임, 가장자리 알파0.
- 공통 리그: 뼈길이 변화최대0.00003소스px, 동일 지지점 이동0(CSV정밀도), 지면Y오차0. 닫힘은 주민9·귀환6픽셀에서 채널 최대1/255차이.
- 주민·귀환 영상4개도 각각160프레임/6.4초, 전체 디코딩 종료0. 총48개 개별 전신 접사와6개 영상을 전달한다.

가려진 관절은 O, 관절은 가렸지만 이를 덮는 옷 경계는 연속인 경우는 O/P로 명시한다. 확인할 수 없는 손·입·관절을 직접 확인한 PASS로 세지 않는다. 상체와 소품이 연결된 원화를 유지하는 보행이며 개별 손가락·팔·소품의 새로운 물리/공격 동작을 구현한 것은 아니다.

이 검사는 실제 게임 이동속도 동기화, 전투 화면 판독성, 실기 성능, 사용자의 실시간 영상 재생 판정·최종 그림 승인을 대신하지 않는다. 반복 닫힘은 픽셀 완전동일로 표현하지 않는다.

## 보존과 출처

원본 atlas·게임 코드·데이터·기존 승인 파일은 보존했다. 이번 PR은 검토 문서만 추가한다. 결과는 `output/walk-people-20261027/`와 새 Release에 남긴다. SOURCE-PROVENANCE, 각 역할 provenance, ASSET-LIST, REPRODUCE 문서에 기준 커밋·원판 crop·생성 원본 SHA256·표시 배율·기준점·재현 명령을 기록한다.

귀환 주민의 main atlas는 LFS 파일이며 이전 로컬 atlas와 전체 SHA256은 다르다. 현재 main을 LFS로 읽어 해당 crop의 RGBA 및 추출 PNG가 이전 crop과 완전히 같은 것을 확인했다. 원판 상태 차이는 괭이를 든 주민과 곡식 자루를 멘 귀환 주민이다.
