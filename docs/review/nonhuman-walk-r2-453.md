# 비인간 걷기 r2 수정 #453

[이슈 #453](https://github.com/hyunlord/bs-mobile/issues/453), [그림 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-nonhuman-walk16-449-20261027). seed_mite r1은 2026-10-28 사용자 승인이다. crop_grazer와 wine_wasp만 r2로 추가하며 원본·r1·게임 코드·데이터는 보존한다.

## 사용자 판정과 수정

r1 내부 검수는 기존 8프레임과의 일치에 과도한 비중을 두어 다리 과신전과 노출된 부착 단면을 놓쳤다. 기존 PASS는 역사 기록으로 보존하며 사용자 수정 요청을 최신 판정으로 기록한다.

- crop_grazer: 보폭 진폭 20→8°, 앞다리 기본각 +6°. 뒤-앞 대각 쌍의 위상, 원본 부품·크기·전체 피벗, 640ms 주기를 유지했다. 00~07 뒷다리의 옆으로 뻗음과 11~14 앞발 돌출을 줄였다.
- wine_wasp: 오른쪽 원통은 leg5 원화의 속 빈 근위부였다. 기존 그리기 순서는 이미 몸통 뒤였으므로 순서만으로 가려지지 않았다. 첫 내부 수정은 근위부를 잘라 가렸으나 잘린 끝이 남아 REVISE로 보존했다. 최종 r2는 원본 부품 픽셀을 전부 복구하고 leg5 부착점만 author 좌표 (80,-3)→(68,7)로 옮겨 기존 몸통 뒤에 넣었다. 전체 피벗·크기·320ms 주기와 날갯짓·상하 움직임은 유지했다.

## 증거와 한계

실제 Unity SpriteSkin으로 각 16프레임과 닫힘 프레임을 캡처했다. 원본 256셀, 4px inset, 248 UV 및 역할 pivot/worldSize 계약을 유지한다. 1배는 기존 표시 계약의 오프라인 투영 영상이며 게임 실행·기기 성능 증거가 아니다. 3배는 최근접 확대, 비교 영상은 원본 8프레임과 새 16프레임이다.

멧돼지의 실제 변형된 발끝 64점을 원본 8프레임의 같은 원화 표식과 비교했다. 원본은 리그 식으로 계산하고 r2는 실제 SpriteSkin 변형 정점에서 읽었다. 계획 대비 최대 오차는 0.0000532 native px다. 3개 발은 엄밀한 원본 XY 범위 안이고 farRear Y는 0.001226 px 초과한다. 정수 픽셀 범위는 동일하지만 엄밀 포함을 통과했다고 표현하지 않는다. 주둥이 앞 전체 다리 그림의 돌출은 계산상 15.0197→0 px이며 새 전 프레임 육안 검사에서도 해소됐다. 고정 원본 위 4개 궤적과 같은 배율 상세 패널을 함께 제공한다. 숨겨진 발 접지나 물리적 미끄러짐을 측정했다고 주장하지 않는다.

말벌은 원본 14개 분리 부품 PNG 해시가 모두 동일하다. 350개 기록 중 leg5 부착점 25개만 이동했으며 나머지 325개 부품 변환과 100개 날개 기록은 r1과 정확히 같다. 00/08/12의 원래 부착점 합성·변경 부착점 단독·leg5 제외 대조가 원인을 확인한다. 최종 전 16프레임에서 원통과 잘린 끝의 노출을 검사한다.

두 종 모두 root 고정, 뒤집힘 0, 16개 고유 프레임, 시작/끝 픽셀 동일을 확인했다. 원본 5개 파일의 SHA-256도 보존됐다. 실패한 말벌 첫 내부 캡처는 삭제하지 않는다. 최종 사용자 승인은 별도다.

## 실행 경계

사용자는 이번 아트 캡처에 한해 야간 예외를 명시했다. 공유 잠금과 실행 중인 측정 앱 검사를 유지해 Unity를 직렬 실행했고 자기 잠금을 해제했다. 이 예외는 다른 측정·파일 삭제·브랜치 삭제를 허용하지 않는다.

원본 atlas의 왼쪽 영역을 보존하는 공용 후보는 승인 seed r1과 두 종 r2를 결합한다. 같은 텍스처 ID·머티리얼 경로를 위한 미적용 후보이며 실제 draw call은 게임 적용 후 검증 대상이다. 3072×3840 크기와 기존 폭에 따른 importer 주의사항은 #449의 계약을 유지한다.

## 최종 내부 관문

독립 검수는 멧돼지 91/100, 말벌 최종안 94/100이다. 각 16장 전신 접사와 1배 MP4에서 디코딩한 전 프레임을 확인했다. 첫 말벌 내부 수정안은 78/100 REVISE로 보존했다. 연속 재생을 직접 시청하거나 실제 게임 성능을 검증했다고 확대하지 않는다.

공용 atlas r2의 SHA-256은 `14fc2352fc73ea663303fa74eafb573576e7f07d312e4cbe8ca6034f2d3926c9`이다. 별도 Node PNG 디코더로 기존 2048×3840 영역 전체와 새 48셀을 비교해 RGBA 차이 0, 세 역할 pivot/worldSize 정확히 동일, 원본 다섯 파일 SHA-256 보존을 확인했다. Release에 두 종 r2와 공용 후보를 고유 이름으로 추가했으며 기존 파일을 덮어쓰지 않았다.
