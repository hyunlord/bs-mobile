`r7-construction-stages-r1.png`(1170×956)는390×844 화면3개와 설명 여백으로 구성한 하나의 조립판이다. 각 패널에 곡창(24,24)과 경작지(24,28)의 같은 공사 단계가 함께 표시된다. 승인 r4 바닥과 길, r7 집 및 나머지 부지를 유지한다. 길 점유14.7975%는 기존 r4 합성에서 유지됐다. 게임 캡처가 아닌 정적 아트 합성이다.

## 검증

- 36/36 PNG의 지정 크기·부분 알파·캔버스 잘림 없음 확인.
- 12개 밝음/어둠 쌍(6종×2배율)의 bbox 각 변 차이는1배 최대1px,2배 최대2px.
- 모든 원화, 단계1·2배 비교판, 소품/일꾼1·4배 비교판과 r7 조립판을 시각 검사했다.
- 첫 건물2·3단계는 사람 대비 기둥이 낮아 제외하고 높은 골조로 수정했다. 제외 원화와 검사 기록은 로컬 `output/m3-construction/rejected-height-r1/`에 보존했다.
- 색상 편집은 image_gen, 내보내기와 조립은 Swift/ImageIO/CoreGraphics. 새 의존성 없음.
- 게임 코드·데이터·원본 atlas·기존 승인 그림은 변경하지 않았다. 저장소 변경은 이 결과 문서뿐이다.

## 한계와 승인 경계

밝음/어둠의 생성 알파는 각각 보존하며 픽셀 동일하지 않다. 접지 정렬은 그림에서 확인한 바닥 범위와 앵커의 오프라인 정규화다. 실제 조명 전환·애니메이션·게임 실행 검증은 수행하지 않았다. 건물3단계는2단계보다 상부 높이가 약간 낮지만 벽체와 상부 보가 더 완성된 형태다. 최종 그림 판정은 사용자 담당이다.
