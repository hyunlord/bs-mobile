## 화면

[비교 Release](https://github.com/hyunlord/bs-mobile/releases/tag/battle-ui-543-review-20261030). 선택 기준은 사전 지정된 실제 HUD·레벨업 카드·일시정지 390×844 세 화면, 그리고 별도 최대 13칸 fixture다. 비교의 왼쪽은 승인 시안, 오른쪽은 실제 Unity 화면이다. 캡처는 에디터이며 모바일 실기 증거가 아니다.

- **알려진 시각 차이:** 기존 금색 장식 프레임·파란 계속 버튼·고운바탕 서체를 유지했다. 승인 시안의 얇은 잎 장식 종이·고딕 글자와 같지 않다. 초기 HUD 안내/장비 아이콘 위치도 제안과 다르다.
- 일시정지 진화 설명은 RectTransform 안에 들어오지만 왼쪽 장식 곡선에 가깝다. 텍스트 높이 통과는 프레임에 가리지 않음의 증거가 아니다. 픽셀/화풍 일치 통과를 선언하지 않는다.
- 카드 내용은 실제 제안 결과라 승인 그림의 예시 카드와 다르다. 긴 조건은 스크롤로 접근 가능하며 기존 기능 검사를 유지했다.
- 최대 HUD는 first-playable 실제 카탈로그의 5무기+4도구 Lv12+4특허장으로 만든 **render-only fixture**다. 배경은 진단용 세이지이고 정상 진행/실기 증거가 아니다. 원본 session 상태 해시는 전후 동일하다.
