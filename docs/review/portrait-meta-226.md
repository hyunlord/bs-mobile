## 계정 기록은 추가하고 전투 능력은 보존한다

schema4의 `PendingClaims`와 `NextClaimSequence`는 방치·도전의 아직 받지 않은 보상을 저장한다. `Claim(sequence)`가 성공해야 지갑과 도전 해금이 반영되며 같은 sequence를 재요청해도 중복 지급하지 않는다. 구형 자동 지급 모드와 이미 받은 도전은 보존한다. 화면을 열거나 다시 그리는 것만으로 지급하지 않는다.

`AccountOnlyWave`는 원본 전투 Catalog를 그대로 사용하고 메타 replay context 및 `.meta` sidecar를 만들지 않는다. 가신·장원 계정의 공격/체력/이동/성장/아군/경험치 보너스를 wave에 새로 적용하지 않는다. 결산의 생존 사람 수는 집단 Health>0만 반영한다. 패배 집단이 표시 기록에 남았다는 이유로 살아 돌아온 사람 수에 포함하지 않는다.

현재 조각 규칙은 유효한 클리어에서 동행 가신당2개를 조각 상한까지 지급한다. 죽음·포기·최소 보상 시간 미달은0이며 이미 상한이면 증가가 없을 수 있다. 결산 문구는 실제 증가분으로 만든다. `+2` 시안을 맞추려고 지급을 조작하지 않는다. 이 작업은 #126 수치·경제 조정이 아니다.
