# wave-1a 다듬기 전달

관문: 부분 — 일반 혼잡 판독·공통 단위 구현·Mac 실행 전달 완료. 후반400–800+ 성능은 미측정이며 낮은 밀도 p95도16.7ms 목표를 초과했다.

영주 링과 공격 윤곽으로 위치와 무기 형태를 찾기 쉽게 했고, 익은 밭·실제 수확 XP·수리 대상 건물을 짧은 표식으로 연결했다. 카드 본문·그림·제목을 눌러 선택하며 금지·고정은 보조 동작으로 분리했다. 사용자 플레이 소감의 빈 항목을 재미 승인으로 해석하지 않는다. [Mac 앱·일반 전후 영상·실패 성능 표본](https://github.com/hyunlord/bs-mobile/releases/tag/wave1a-polish-mac-01)을 전달한다.

## Mac 실행과 성능

앱의 정확한 source는 `25efe84282923ff52e71fcea142163556fce20f7`이다. Unity6000.6.4f1/ARM64/Mono/Metal, development=false, sourceDirty=false, sourceHash `9567432E85A63B80E9809F2F948860A179FF2A7C6EE4EC406E0AC8417A5F0A61`, dataHash `1B0214AEBC4023715DF31AA368BE4640C78D00DECE112809160128D1293C9C16`. C02와 unity/Assets·Core·data diff가 비어 있다. 병합 commit과 앱 commit은 구별한다.

[사전 등록](https://github.com/hyunlord/bs-mobile/issues/169#issuecomment-6094390423)한 seed30001/grain/evasive/기본 제안 카드 정책/깨끗한 프로필로 실제 Mac16,5(OS27.0.1)에서 Recorder·프로파일러 없이 실행했다. targetFPS60/vSync1/844×1828, process-scoped caffeinate 사용. 정상 앱 실행에는 자동 입력이 꺼져 있다. `--autoplay-capture`는 별도 저장 경로에서 타이틀→27000틱 생존·보스 미처치→결산→재시작120틱을 완료했다. 앱 자체 결산·재시작 그림도 확인했다. 인간 클릭·깨끗한 OS 계정 검증을 대신하지 않는다.

원본 입력을 .NET에서 재생한 종료 해시 `0EEDF34BADE2E07EDD20FB440D4CB198014E8C96A521DF706C76F32F6BAEB0F6`가 앱과 일치했다. 실제 run은 `d1a152a96b3347eb90154b3c55d8c7c1`, 재시작은 별도 seed30002/run `a5c58ed9f242483995080d656f7a609d`이며 두 번째 완주로 세지 않는다.

## 실패 보존과 남은 관문

A01 시계 차이 실패, A02 말벌 우선순위 실패, B01 공격 대비 실패, A03 수확 인과 실패, B02 연결 번개/수리 부분, B03 수확/수리 부분, B04 수리 대상 부분은 [판독 PR 기록](https://github.com/hyunlord/bs-mobile/pull/171)과 원자료에 보존했다. 후속 수정의 통과가 원판정을 덮어쓰지 않는다. C01은277.576초/t7102에서 시계 차이0.672>0.15초로 [실패 보존](https://github.com/hyunlord/bs-mobile/issues/168#issuecomment-6094804890)했고, C02는 같은 소스/입력의 단일 전면+caffeinate 재시도다. 근본 원인이 해결됐다고 단정하지 않는다. B04 게임 로딩 전 Unity 검색 인덱서 예외도 게임 예외와 구별해 남겼다.

첫 native 실행은 capture-output 안에 먼저 생성된 player.log 때문에 빈 폴더 보호 규칙으로 게임 전 거부됐다. 로그를 폴더 밖에 둔 새 출력으로 재실행했으며 앱 규칙은 바꾸지 않았다. [실행 기록](https://github.com/hyunlord/bs-mobile/issues/169#issuecomment-6095031455). Lattice 댓글403은 동일 SHA 재시도에서 회복했으나 [#175](https://github.com/hyunlord/bs-mobile/issues/175)의 정확한 외부 원인은 미확인이다.
