# 선택된 스토어 그림 r2 / 대표 C r3

관문: 부분 — A 아이콘과 C 대표 그림 후속 시안. 아이콘 A r2 사용자 승인·대표 C r2 불합격·대표 C r3 검토 대기이며 게임 적용·스토어 등록·기기 설치는 NOT_RUN이다.

이슈: https://github.com/hyunlord/bs-mobile/issues/536

Release: https://github.com/hyunlord/bs-mobile/releases/tag/store-art-534-20261029

아이콘은 새싹 방패를 중심으로 배경을 단순화했다. 실제1024·60·40 PNG를 내보내며 iOS 스타일 둥근사각형 기계 마스크 비교판을 제공한다. 이 마스크는 corner radius22.37%의 렌더 미리보기이며 정확한 OS 마스크 또는 설치 화면 검증이 아니다.

대표 그림은 실제 약탈병·방패병·충차 돌격병과 푸른 망토 영주 전신 참조를 사용해 전투를 추가했다. 제목과 하부 영지의 구도를 유지했지만 원본 픽셀 불변이라고 주장하지 않는다. 생성 raw를 보존하고 균등 축척·중앙 미세 크롭만으로1290×2796을 내보낸다. 기계 과정에서 새로운 내용을 덧그리지 않았다.

전달은6PNG(아이콘3·대표1·전후판2), 계약JSON1, README·QA2로9파일이다. 기존 Release14개를 보존하고 고유 r2 이름만 추가한다. 게임 코드·데이터와 원본 atlas를 수정하지 않는다. 이 문서 PR은 대표 C r3 사용자 승인 대기 상태로 미병합 유지한다.

- [아이콘 실제 크기와 마스크 전후](https://github.com/hyunlord/bs-mobile/releases/download/store-art-534-20261029/store-icon-a-r1-r2-rounded-preview-960x480.png)
- [대표 전후](https://github.com/hyunlord/bs-mobile/releases/download/store-art-534-20261029/store-poster-c-r1-r2-860x932.png)

제작 도구는 imagegen이다. 아이콘 생성 원본1254×1254에서1024·60·40을 균등 리샘플했다. 대표 원본853×1844를1.51626898배 균등 확대하고 가로 양끝 각1.68872px를 중앙 크롭해1290×2796으로 정규화했다. Root 실제크기 아이콘 PASS94·대표 전후판 PASS93이며 최종 그림 승인은 사용자 담당이다.

## 대표 C r3 후속

이슈: https://github.com/hyunlord/bs-mobile/issues/538

사용자는 아이콘 A r2를 승인했다. 대표 C r2는 인물 축척과 제목 주변 혼잡으로 불합격 판정했으며 기존 원본과 root 이전 PASS93 검토 기록을 보존한다. r3의 주제는 빛이 돌아온 경계선이다. C r1 기반으로 우상단 숲에서 나오는 원근에 맞는 작은 적 무리와 다리 길목의 영주·병사를 배치하고 제목 주변 하늘·어둠 여백을 확보했다.

imagegen 원본852×1846을 균등1.51462622배 확대하고 좌우각0.23077px 중앙 크롭하여1290×2796으로 정규화했다. 기계 내용 재도색은 없으며 하부 구도 보존을 픽셀 동일로 표현하지 않는다. 새 대표·r2/r3 전후판·README·계약4파일만 기존 Release에 추가한다. 기존23개와 게임 코드·데이터 불변. 대표 C r3는 사용자 승인 대기, 게임 적용·스토어 등록·기기 설치 NOT_RUN이다.
