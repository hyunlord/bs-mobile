# 전투 UI r2 검토 반영

관문: 내부 검토 통과91 — 최종 그림 승인은 사용자 대기입니다. 승인된 일시정지r1은 원본과 파일을 그대로 동결했습니다. 게임 코드·데이터·atlas 변경, Unity 실행·실기 터치는 없습니다.

| 항목 | 검토한 r1 | r2 | 검증 |
|---|---|---|---|
| HUD 전체 높이 |102px·12.09% |84px·9.95% |배경 복원·그림·hit·배지를 모두 포함; 저장 alpha의 마지막 y83,84이하0픽셀 |
| 실제 HUD 전경 |11.37% |32088픽셀·9.748% |예약 띠 면적과 alpha union을 구분 |
| 체력 |낮은 대비의 얇은 레일 |기존 붉은 그림170×20,숫자13 |1800/1800 원문 유지 |
| 경험치 |빈 베이지 레일 |별도 짙은 파랑 바탕170×12 |빈 트랙 색상이며 진행 채움0; 실시간 상태 판독은 미검증 |
| 멈춤 |크림판48×48 |기존 파란 원형48×48 |실제 PortraitV0 원본 사용,논리hit48 |
| HUD 장비 |그림28·배지13 |동일,13칸을 y56..84에 배치 |2원본아이콘 반복·레벨12 합성 시험; 실제 빌드 아님 |
| 카드 글자 |제목20·설명15·부가13 |유지 |줄바꿈과 원문 효과 유지 |
| 카드 분류 |분류색이 약함 |특허장 보라·도구 초록·무기 파랑 띠와 테두리 |현재 분류 RGB 토큰; 원본 카드판 위 같은 색 테두리. 저장색 변환값은 JSON에 별도 |

| 레벨 배너 |크림판 |기존 파랑 배너 |가로52px 소스 분할로 결 유지,제목22/안내14 |
| 일시정지 |사용자 승인 |변경 없음 |기존 공개 파일SHA 및decodedRGBA 동일 |

주 비교판의 왼쪽은 사용자가 검토한r1, 오른쪽은r2 오프라인 시안입니다. HUD가 줄어든 y84..102는 원래 역사 Editor 화면에서 복원했습니다. 새로운 세계 원화를 만든 것이 아닙니다. 기존 역사 화면과 비교하면 명시된 UI영역 밖 RGBA 변화는2화면 모두0입니다.

본 카드 제안은 기존2특허장+1도구를 유지합니다. 별도 분류색 확인판만 첫 카드를 현재 원문의 철날 검으로 바꿔 파랑 무기판을 보여 줍니다. 원문: `앞에 적이 오면→짧은 호로 벤다`. 모든 광택 아이콘 원본은 재생성하지 않았으며 원본RGBA 검증과 표시 리샘플링·숫자배지 덮임을 구분합니다.

84/844=9.9526%입니다. 390 논리단위의48×48 hit는 [Apple44×44pt 권고](https://developer.apple.com/design/tips/)를 참고한 설계 proxy이며 물리pt·레이캐스트·실기 터치를 증명하지 않습니다. 폰트는 오프라인 AppleSDGothicNeo,기기 유효 폰트와 다양한safeArea는 NOT_RUN입니다.

이전15Release파일은 보존하며 r2만 추가합니다. 원본·실패c1·기계적배지상자축소(20→17,PNG SHA 동일) 증거는 로컬에 보존합니다.01–06 병합·자동병합·가지삭제를 실행하지 않습니다.

## 검증 경계

독립 시각 검토 PASS91,8개 PortraitV0원본RGBA 동일,2화면 UI영역 밖 변화0,두 HUD투명층32088픽셀·y0..83 확인. 선언한 논리hit는48 이상입니다. 문서 범위 정적검사와 원격CI만 사용하며 게임코드/데이터 변경과 야간Unity/로컬게임빌드는 없습니다. 최종 r2 그림 승인은 사용자 대기입니다.
