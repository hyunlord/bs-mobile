관문: 부분 — 새 들판의 6분 실제 입력 실행에서 영주 경계 막힘·카메라 클램프가 모두0이었다. 한 방향60초 이동은 완료했으나 녹화25슬롯 누락을 보존하며, 집으로 귀환하는 최종 영상은 검증 중이다.

출발 영지는 남고, 영주가 간 곳에 작업과 복원색이 남는다. 정수 seed/구역으로 회색 지형·소품을 만들며 형식4만 새 지도 규칙을 선택한다. 기존 형식1~3은 옛 직사각형을 유지한다. 스폰량·체력·경제 수치를 바꾸지 않았다. 집·작업대의 고정 그림은 영지 표식이며 가짜 생산·보상·완성 작업을 추가하지 않는다.

두 실행은 동일한 a5b4bf4 Release/Metal 빌드에서 `old`/`field`만 선택했다. 1920×1080·120Hz 화면의 일반 vSync, 촬영·오디오 녹화·Development Profiler 없음, 모든 체감 규칙OFF, 정상 마우스 입력과 카드 선택이다. 정책은 reward-ripe-building-circle-v1로 같지만 상태가 달라진 뒤 명령과 카드까지 동일하다는 뜻은 아니다. 생존을 강제하지 않았다. 양쪽 실제 재생은 검증됐다. 이 정책은 옛 지도에서도 영주가 벽까지 가지 않아 영주0→0만으로 경계 제거를 입증하지 않으며, 직선 영상·음수 좌표 검사와 함께 읽는다.

화면 안 적은 카메라 영역 안의 **적 중심** 수다. HUD에 가린 적은 포함하고 중심이 밖인 일부 보이는 스프라이트는 제외한다. 프레임 p95는 nearest-rank이며 카드 일시정지·비전경을 제외한 틱9900~10800을 사용했다. 적이 줄어서 빨라졌다고 주장하지 않는다. 이는 강한 자동 선택의 자연 플레이이며 #209의 약한 빌드411마리 고정 재생을 대신하지 않는다.

전체 구간의 긴 프레임도 보존한다. old는 틱1780/1795/1803에서189.845/427.926/678.496ms, field는 틱4804에서265.665ms였다. field의 해당 Core 계측 구간은252.834ms, GC 증가0이었다. 재현·원인을 확인하지 않았으므로 환경 지연으로 면책하거나 '끊김 없음'으로 판정하지 않는다. 이 표본의 Core 시간은 카드·조준 등 모든 명령을 포함한 이전 계측이므로 순수 Advance 틱 비용으로 보고하지 않는다. 이후 계측 형식2는 Advance만 센다. 좌표 열에서 카메라는 Unity 단위, 영주는 Core 단위다.
