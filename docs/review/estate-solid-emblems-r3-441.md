# 기록소·병영 단색 새싹 문장 r3 #441

관문: 제작·픽셀 보존 검사 완료, 사용자 그림 승인 대기. 제철소 r2는 사용자 승인되었으며 이번 변경 대상이 아니다. 문장 r2는 가장자리가 흐리고 끊겨 보인다는 사용자 불합격 판정을 보존한다.

[추적 #441](https://github.com/hyunlord/bs-mobile/issues/441) · [동일 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-estate-completion-icons-review-435-20261027)

## 수정 결과

기록소와 병영 s1~s3의 원본 256×320 crop 6장, 문장 9곳을 수정했다. 기존 문양의 따뜻한 색 542픽셀에서 추출한 중앙값 RGB(239,209,169)을 불투명 단색으로 사용한다. 기준 새싹을 생성 도구로 단순화한 뒤 씨앗·휜 줄기·높이가 다른 잎 두 장을 이진 픽셀 마스크로 내보냈다. 새싹 내부에는 그라데이션, 반투명 가장자리, 구멍이나 분리된 조각이 없다.

- [건물 전체 실제 1배 판](https://github.com/hyunlord/bs-mobile/releases/download/m3-estate-completion-icons-review-435-20261027/heraldry-six-buildings-native-1x-r3.png): 원본 크기 256×320 셀 6개를 축소 없이 배치했다. 브라우저의 화면 맞춤 축소 대신 이미지 원본 크기로 확인한다.
- [문장 9곳 전/후 접사](https://github.com/hyunlord/bs-mobile/releases/download/m3-estate-completion-icons-review-435-20261027/heraldry-nine-patches-before-after-r3.png).
- 각 건물별 전/후 비교판은 원본과 후보의 전체 1배 및 nearest-neighbor 4배를 포함한다.

## 검증

| 검사 | 결과 |
|---|---|
| 문장 9곳 색상 / 알파 | 각각 단색 1개 / 255 |
| 4방향 연결 성분 / 내부 구멍 | 각각 1개 / 0개 |
| 마스크 밖 RGBA 변경 | 6장 모두 0바이트 |
| 전체 알파 변경 / PNG 재읽기 차이 | 6장 모두 0 |
| 캔버스 / 기준점 | 256×320 / (128,280) 유지 |

원본 atlas SHA-256은 `7c05718d8666074188a49fe309b9f78378e2caf757f20d6ecf9969a66bab71ee`로 유지된다. 새싹과 옛 문양 제거에 필요한 파란 천 복원은 기존 9곳 마스크 내부로 제한했다. 확대판에서는 주변 천 복원 픽셀의 색 차이가 보일 수 있으며 새싹 자체는 혼합하지 않은 단색이다. 실제 1배 전체판과 9개 접사에서 씨앗과 두 잎의 판독성을 직접 검수했으며 최종 판정은 사용자에게 남긴다.

Swift exporter 타입 검사, PNG 픽셀 대조 및 연결성 검사를 수행했다. 게임 코드·데이터·원본 atlas는 수정하지 않았으며 런타임 설치·실제 게임 화면 검증은 포함하지 않는다. 이전 #435 전체 검사에서 800통과·1실패였던 메모리 할당 테스트 기록은 보존한다. 이번 문서 CI를 해당 실패의 해결 증거로 표현하지 않는다.

기존 r1/r2와 아이콘 잉크 시안은 보존하고 r3 파일만 같은 Release에 추가한다. 현재 광택 아이콘 유지 결정도 그대로다. 작은 개별 접사와 생성 원본은 로컬 제작 기록으로 보존하며, Release에는 요청된 6개 crop·6개 전/후 전체판·9문장 통합 접사·실제 1배 전체판 및 설명을 제공한다.
