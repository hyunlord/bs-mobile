# r8 강·밭 변형 그림 r3 — #497

사용자가 승인한 dense r2의 배치·건물·75px 기본 카메라를 보존하고 강과 밭 조각의 반복을 줄이는 오프라인 그림 검토다. 최소 확대폭은 집 기준50px로 승인되었다. 이번 비교판은 같은 세 장면의75px 화면만 사용한다. 게임 코드·데이터·카메라 구현은 수정하지 않는다.

## 기준본

- 승인 r2 기록: `c649c0a9cd4964666fc6c1ada85b377314c64e9a`, PR #494.
- 13구역1664셀, 시작 건물10채의 위치와 기존다리3곳 유지.
- 집 원화 폭141px × 기존 표현배율0.7 =98.7nativepx. 비교 카메라 배율75/98.7; 모든 건물 폭을75px로 강제하는 뜻이 아니다.
- 세 중심(native projected): 시작·마을(-32,912), 강변(352,1264), 숲·언덕(160,592).
- 새 조립 도구가 승인75px 세 PNG를 파일해시까지 동일하게 재현했음을 먼저 확인했다.

## 변경 범위와 검증 상태

밭 사이 조각6실루엣을 S/M/L 세 크기, 밝음/어둠,1/2배로 내보낸72PNG다. 크기별 명목 바닥은64×32/96×48/128×64이며 접지점은 원화에서 시각적으로 추정했다. 기존 낮은 장식104개의 접지점만 유지해 교체하고, 고정 경작지 건물·벽·큰나무·건물 출입구는 보존한다. 서로 다른 모양과 크기의 실제 화면 가시 개수는 가림 이후 픽셀로 별도 집계한다.

강은 승인 경로를 기준으로 폭 변화±20% 안에서 조립하며 기존 다리 접속부를 유지한다. 모래톱·여울·섬과 실제 물 점유 마스크를 함께 검토한다. 생성 원본 및 실패 후보는 로컬에 보존하고 최종 Release에는 확정 목록만 추가한다.

전체 `./tools/check.sh`는 기준 c649c0a9의 문서 전용 작업 폴더에서 exit0으로 완료했다. 최종 조립은 독립 시각 검토 PASS91, 밭72PNG 검토 PASS93을 받았다. 최종192파일의 해시·치수·기준점·출처 및 기존366개와 이름 충돌0을 독립 검증했다. 원격 Release558개에서 기존366개 ID·이름·크기·해시·수정시각이 그대로이고, 신규192개가 최종 목록 SHA와 일치함을 독립 검증했다. 문서 PR의 필수 CI 통과 후 정상 병합한다. 사용자 최종 r3 그림 승인은 대기이며, 게임 적용·실기 검증은 NOT_RUN이다.

## 같은75px 화면의 전후 수치

아래는 가림 뒤 알파 기여32/255 이상8픽셀인 인스턴스를 보이는 것으로 집계한 오프라인 결과다. 흙 자체인05는 점유 소품으로 세지 않는다. 바깥 나무의 불투명 수관이 실제 땅을 가린 것은 시각 빈 땅 계산에서만 반영하며, 안개는 포함하지 않는다. 보수적 빈 땅 수치는 Release 메타데이터에 별도로 유지한다.
