## 발견하고 수정한 문제

- 첫 원격 CI는 PR 제목의 Conventional Commits 접두사가 빠져, 다음 실행은 필수 본문 제목이 빠져 각각 차단됐다. 제목과 필수 PR 본문 항목(Gate result / Verification / Screens)을 모두 맞춰 새 실행에서 전체 검증을 통과했다. 정책 우회는 하지 않았다.

- 추가 프로필에도 모든 기준 레코드를 강제로 요구하던 검증을 수정했다. 기준 프로필의 정확한 수량은 유지하면서 구현 상태의 전체 참조는 프로필 선택 합집합으로 검사한다. 새 프로필이 새 공통 규칙 도구를 선택할 수 있고, 선택되지 않은 후보의 허위 구현 표시는 계속 차단한다.
- 성장 조건 JSON의 속성 순서만 바꾼 중복 진화를 검증기가 놓쳤다. 조건의 의미를 정규화한 키로 비교하도록 수정하고 회귀 검사를 추가했다.
- 테스트 레코드의 부가 참조와 잘못된 실행 상태 표시를 전체 검사에 포함했다. 독립 변조 14건은 모두 차단됐다.
- 일부 특허장·가신 문구의 수동 배치 해석 가능성을 제거하고 이동·거리·카드 효과에 따른 자동 조건으로 명시했다.
- 새 영지 순환의 중첩 단계명 `people`을 구체 영주 ID로 오인하던 AG002 오류를 수정했다. 실제 영주 ID가 같은 문자열인 경우와 명시적 중첩 ID 참조는 계속 차단되며, Guard 기본 자체 검사 24개·저장소 회귀 검사 11개와 저장소 위반 0건을 독립 확인했다.
- 기존 도구 설명 문자열도 S2 카탈로그 해시에 포함되므로 원문을 복원했다. 새 한국어 설명은 부가 필드에 두었고, 기본·더미 × A/B/C의 전체 21,600틱 해시 6개가 모두 기존 증거와 일치했다.

## 의미와 한계

후보 고유 효과, 비용과 상호작용은 설계 제안이다. `s2-runtime`은 기존 수치 필드가 실행된다는 표시이며, 새 한국어 고유 능력까지 구현됐다는 뜻이 아니다. 피해 계수는 기획 비교값으로만 보관하고 S2 정수 피해에 추가 적용하지 않는다. 바닥값은 비교할 조건을 제시한 가설이며 실측 DPS 보장이 아니다.

도구 반시너지의 물·열, 잔재 배분, 노동·식량 경쟁은 의미 검토 대상이다. 스키마가 문장의 재미나 제품 성공을 증명하지는 않는다. 기본 영주와 영지의 최종 선택은 [needs-decision #32](https://github.com/hyunlord/bs-mobile/issues/32)에 남기고, S4는 임시 집합과 가정을 명시해 진행한다.

S5 최종 감사 보충(2026-10-08): 원본 로그는 기본 자체 검사 24개와 별도로 출력된 저장소 회귀 검사 11개를 모두 통과했다. 이전 요약의 35는 합계이며, 현재 문구는 두 범주를 명시한다. 원본 로그와 기존 S3 ZIP은 변경하지 않았다.
