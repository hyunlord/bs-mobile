# wave-1a 비인간 적 걷기 16프레임 #449

[작업 이슈](https://github.com/hyunlord/bs-mobile/issues/449). 괭이질 r2 사용자 승인으로 영지 작업 루프3종은 종료했다. 이 문서는 seed_mite → crop_grazer → wine_wasp 아트 제작만 다루며 게임 코드·데이터·원본 atlas를 변경하지 않는다.

## 기준과 방법

기존8프레임은 `tools/art-authoring/enemy-rigs`의 오프라인 분절 리그다. 기존 그림·알파 분리·관절·크기·부품 순서·보행 곡선을 실제 UnitySpriteSkin으로 옮겨16개 위상을 캡처한다. 새 원화 생성이나8프레임 복제는 사용하지 않는다. 256셀/4px inset/248UV와 종별 피벗·worldSize를 유지한다. 제작용 SpriteSkin은 게임 런타임에 추가하지 않는다.

seed_mite의55ms×8=440ms는 정수 frameMs 계약 때문에28ms×16=448ms(+1.818%)로 맞춘다. crop_grazer는40ms×16=640ms, wine_wasp는20ms×16=320ms로 기존 주기를 유지한다. 말벌의 지면 기준점은 고정하고 날갯짓과 함께 몸통에 작은 상하 이동을 더한다.

1배 영상은 기존 감사표의390×844/카메라1.4/휴경확대1.15 표시 계약으로 투영한 오프라인 검토 영상이다. 게임 실행 캡처·기기 성능 증거가 아니다. 새16프레임과 기존8프레임은 각각의 주기로 나란히 재생하며, seed_mite의 주기 차이를 표시한다. 3배는1배 픽셀의 최근접 확대다.

## 통합 계약

#410의2048×3840 atlas 원래 영역을 그대로 보존한3072×3840 후보에 새48셀을 오른쪽4열로 추가한다. seed_mite는(2048,0), crop_grazer는(2048,1024), wine_wasp는(2048,2048)부터4×4셀이다. 기존 픽셀 사각형은 이동하지 않으며 UV는 새 텍스처 폭으로 다시 계산해야 한다. 각 변4096 이하, 같은 텍스처ID·머티리얼·1quad 경로를 유지할 수 있는 구조다. 실제 그리기 호출 수와 성능은 통합 후 검증 대상이다.

무압축 RGBA8/no-mipmap 크기는30→45MiB의 산술 추정이며 기기 측정값이 아니다. 기존 `import-approved-walks.mjs`는2048폭과 연속 버퍼 해시를 가정하므로 그대로 적용하면 안 된다. 통합 담당자는 기존 영역을 새 stride로 행 단위 비교하도록 검증을 갱신해야 한다. 이번 작업에서는 importer도 수정하지 않는다.

## 제작·검수 결과

세 종은 실제SpriteSkin16프레임의 작성자·독립 검수를 통과했다. 각각 전16프레임512px 접사 및1배 MP4에서 디코딩한16프레임을 확인했다. 연속 재생 직접 시청이나 숨겨진 발 접지 검증으로 확대하지 않는다. 사용자 승인은 대기다.

|종|기존 대비 대응8자세|실제변형·반복|상태|
|---|---|---|---|
|seed_mite|bbox8/8동일, 실루엣IoU≥0.999933|관절오차≤0.0001authorpx,root고정,뒤집힘0,closure동일|내부통과|
|crop_grazer|bbox8/8동일, 실루엣IoU≥0.999637|관절오차≤0.0001authorpx,root고정,뒤집힘0,closure동일|내부통과|
|wine_wasp|no-bob대조8 bbox동일, 실루엣IoU≥0.999303|관절오차≤0.000142authorpx,root고정,뒤집힘0,closure동일|내부통과|

각종16개RGBA는 모두고유하고256셀/4px여백 검사를 통과했다. 기존 다리의 고정된 굽힘과 껍질/머리에 가려지는 관절은 원형 보존 범위로 남긴다. crop_grazer 독립검수의 최초88점/PASS는 자연스러움 인상과 원본유지 점수가 섞인 표기라 최초보고를 보존하고, 자연스러움88/원본충실도98로 구분한 보충문서를 추가했다. 새 분리/실루엣 결함은 확인되지 않았으므로 원래 다리 모양을 재생성하지 않았다.

[그림 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-nonhuman-walk16-449-20261027)에 개별256프레임, 전16개별접사와전체판,1배/3배/기존8비교MP4,관절검사표와메타데이터를 순서대로 추가했다. 기존파일을 덮어쓰지 않았다.

말벌 정상16프레임은요청한몸통bob ±12authorpx=±6cellpx(약±1.83표시px)를포함한다. no-bob대조8은이동을뺀리그형상 검증용으로분리했다. 표의bbox/IoU는alpha>16기준이며, 모든알파를포함하면seed와wasp의일부가장자리에서1px차이가있다. 반투명날개RGB평균오차는최대1.359/255였다. 정상bob위치가원래8과동일하다고주장하지않는다.

## 공용 후보 검증

Swift 패킹 검사 후 별도 Node PNG 디코더로 기존2048×3840 영역 전체와 새48개256셀을 행 단위 비교했다. RGBA 차이0, 세 역할 pivot/worldSize 정확히 일치, 원본5파일 SHA-256 보존. 최종 후보는3072×3840이며 SHA-256은 `8e3c46fc0c63d1cff459c09ab9968dd308b4d3432d6a63ce97ebb5b49f2f6a6c`이다. 기준 게임 checkout은 `0537368a143fb7faf4da3698f9b7b5115f1498c9`, 원본 atlas SHA-256은 `b238aa39294bd4b8d1f38ae39c904e4f4c3ba7696ed969ff3524e7226d76240c`이다.

Release에 후보 PNG, 미적용 역할 패치, 패킹 계약과 독립검사 요약을 추가했다. 최초 패킹 실패는 Foundation JSONSerialization의 Double 해석 차이였으며 실패 산출물을 보존했다. JSONDecoder의 정확한 수치 비교로 수정했고 인접 Double/좌표/불리언 변경은 계속 거부됨을 검사했다. 허용오차를 늘리지 않았다. 원본이나 게임 manifest는 수정하지 않았다.
