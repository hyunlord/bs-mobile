# 영지 실루엣 보존·문장 교체 r2 #438

관문: 사용자 검토 대기. #435 신규 건물 r1 8종은 사용자가 불합격으로 판정했다. 당시 내부 검수는 기능별 실루엣 구분을 증명하지 못했다. r1 파일·판정은 역사 기록으로 보존하고 기존 게임 atlas를 유지한다.

[추적 #438](https://github.com/hyunlord/bs-mobile/issues/438) · [동일 검토 Release](https://github.com/hyunlord/bs-mobile/releases/tag/m3-estate-completion-icons-review-435-20261027)

## r2 산출물

- 제철소 전용 완성 PNG1장: 돌 제련로·높은 굴뚝·광석·숯 더미·작은 작업 헛간. 기존 천막형 대장간과 다른 실루엣이다.
- 기록소 scriptorium-s1/s2/s3와 병영 barracks-s1/s2/s3 PNG6장: 총9개 문장만 새싹으로 교체했다. 각각 같은 crop의 전/후 비교판을 제공한다.
- [이름 없는 완성10종 한 줄 비교](https://github.com/hyunlord/bs-mobile/releases/download/m3-estate-completion-icons-review-435-20261027/ten-buildings-unnamed-r2.png). 동일256×320 셀을1:1로 배치하고 글자·번호·범례를 넣지 않았다. 역할 순서는 별도 STRIP-KEY-r2.md에 있다. 이 판 자체를 사용자 식별 성공 증거로 표현하지 않는다.

모든 자산은 기존 atlas와 같은256×320 canvas와 기준점(128,280)을 사용한다. 이는 옛 atlas의 기준점이며 r1의 바닥 마름모 중심과 혼동하지 않는다. 제철소는 키 큰 굴뚝을 포함하므로 기존 대장간과 외곽 크기 자체를 동일하게 맞추지 않았다. 원본 근거는 estate-buildings.png / buildings-30-body-atlas.png, SHA-256 7c05718d8666074188a49fe309b9f78378e2caf757f20d6ecf9969a66bab71ee다.

## 픽셀 보존과 검증

생성 도구로 제철소와9개 국소 문장 패치를 제작했다. 문장 패치는 원본의 파란 천·방패 내부로 제한해 합성했으며, 6종 모두 마스크 밖 RGBA 변경 바이트0, 전체 알파 변경0, PNG 재읽기 차이0을 확인했다. 원본 참조16crop도 atlas의 해당 영역과 모든 straight RGBA 바이트가 동일했다. 생성 이미지 전체로 원본 건물을 대체하지 않는다. 보존 수치는 Release의 PIXEL-PRESERVATION-r2.md에 기록한다.

이 작업은 게임 코드·데이터·atlas를 변경하지 않은 아트 검토 문서다. 소스 코드 변경이 없으므로 아트의 크기·알파·원본 대조·직접 시각 검수 및 문서 CI로 확인한다. 이전 #435의 로컬 전체 검사801개 중 메모리 할당 테스트1개 실패는 기존 기록을 보존하며, 이번 문서 CI를 그 실패 해소로 표현하지 않는다.

## 사용자 결정 유지

아이콘 잉크·과슈 시안은32px 목록에서 읽힘이 떨어졌다는 사용자 판단에 따라 보존만 한다. 사용자 결정 전까지 현재 광택 화풍을 유지한다. 게임 설치와 실제 화면 배치 검증은 이번 작업에 포함하지 않는다. r2 최종 그림 승인은 사용자 담당이다.

제철소 크기 비교,6개 전/후 전체판,9문장 접사와 무명10종 판을 직접 확인했다. 실패한 합성 중간판은 별도 진단 기록으로 보존하고 최종판에서 금테 색 유입과 옛 줄기 잔여를 제거했다.
