# 첫 출시 하단 탭 구성 제안

상태: **제안 — 사용자 결정 대기** (2026-10-31). 추적 [#611](https://github.com/hyunlord/bs-mobile/issues/611). 게임 코드·데이터·그림 변경 없음. 결정 전까지 게임은 기존 탭을 유지한다.

## 왜 지금 정하나

- 현재 구현과 승인 UI의 하단: **영지·가신·도전·상점 4탭 + 출정 단추** (`PortraitMetaPanels.EstateMap.cs`, `PortraitBmPanels.cs`, GDD05 "하단 탭 4개와 작은 출정 단추").
- [#561 SLG 화면 흐름](slg-ui-flow-561.md)(사용자 승인 2026-10-30)은 이 하단을 임의로 바꾸지 않았다. 병영·모집·연구는 영지 건물에서, 월드·행군은 월드 진입과 각 화면 안 버튼에서 들어가는 경로를 제안했다(FLOW-r1 9행).
- Astra 신규 시안 `chat-march-ui-iron-20261031-r1`은 하단을 **영지·월드맵·연맹·행군**으로 그렸다. 월드맵 연결 전에 어느 쪽을 첫 출시 기준으로 할지 결정이 필요하다.

## 선택지

| 안 | 하단 | 가신·도전·상점 위치 | 월드·연맹·행군 위치 | 장점 | 비용·위험 |
|---|---|---|---|---|---|
| A 유지 | 영지·가신·도전·상점 + 출정 | 그대로 | 영지의 월드 진입 단추, 연맹은 영지 건물/월드 상단, 행군은 월드 화면 안 목록 | 승인 UI·구현·캡처를 그대로 사용. #561과 일치 | 월드·연맹이 두 단계 안쪽. SLG 핵심 반복(행군·연맹 도움)의 접근성이 낮음 |
| B 시안 | 영지·월드맵·연맹·행군 | 영지 화면 안 메뉴(가신·도전)와 상단 보석+ (상점) | 하단 직접 | SLG 장르 관례와 일치. 행군 진행 확인이 한 번 터치 | 승인 4탭·캡처·테스트 재작업. 판 전투(출정) 진입이 하단에서 빠짐 — 출정 위치 재설계 필요 |
| C 혼합 | 영지·월드맵·연맹·상점 + 출정 | 가신·도전은 영지 화면 안 | 월드·연맹은 하단, 행군은 월드맵 안 진행 목록(시안 부품 재사용) | 출정·상점 유지, SLG 두 축을 하단에 노출 | 가신·도전 진입이 한 단계 깊어짐. 4탭 순서·아이콘 재배치와 #521 캡처 갱신 필요 |

공통: 5칸을 넘기지 않는다(390pt 폭·48×48 터치). 행군 진행은 어느 안이든 월드맵 안 목록 부품(시안 29종 중 진행 목록)을 쓴다.

## 권고

**C 혼합.** 출정(판 전투)과 상점은 첫 출시 수익·핵심 반복이라 하단에 남기고, SLG의 두 축인 월드맵·연맹을 하단에 올린다. 가신·도전은 영지 성장 화면에 속하므로 영지 안으로 옮겨도 의미가 맞다. 행군은 월드맵 맥락에서만 의미가 있어 별도 탭 대신 월드맵 안 목록으로 둔다.

결정되면 같은 번호로 구현 이슈를 열고 GDD05 하단 탭 절을 갱신한다. A를 고르면 Astra 시안의 하단만 기존 탭으로 바꿔 쓰도록 재요청한다(그림 수정은 Astra 담당).

## 이 문서가 하지 않는 것

화면 구현·캡처, 탭 아이콘 제작, 연맹·월드맵 서버 연결. 자원지 카드 등급 상자 미사용(GDD18 등급은 몬스터·거점만)과 철재 r2·신고/차단 아이콘 배치는 자산 통합 작업에서 따로 다룬다.
