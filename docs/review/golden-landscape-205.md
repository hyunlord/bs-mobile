# #205 가로 화면·약한 빌드 후속 검토

관문: 진행 중 — 2b1afa8 사용자 검토의 1~3 수정 후 PR #205 병합 승인에 따른 후속이다. 이전 움직임 판정과 실패 자료는 보존한다.

## 범위와 검증 경계

- 1920×1080·1440×900·1280×800에서 카드 전체 문구·선택·금지·고정·다시 뽑기와 첫 카드 도움말을 동시에 확인한다.
- 가로 HUD와 장비 막대는 각각 높이 11% 이내, 장비는 한 줄이다. 조이스틱 그림은 1080p 환산 지름 160px 이내·반투명이며 입력 반경은 그대로다.
- 돌진 출발점 대신 경로의 화면 교차를 검사한다. 실제 HUD 영역 아래로 경고를 자르고 어두운 테두리와 방향 화살표를 유지한다. 영주 외곽선을 강화하고 성장 문구는 하나씩 표시한다.
- `--capture-weak-build`는 정상 입력으로 외곽을 이동하며 아이템·기존 장비를 우선한다. 무기 최대 2개·진화 없이 필요한 카드만 선택한다. 경험치·레벨·적 수·시각을 강제로 바꾸지 않는다. 6분 이전 사망은 실패 증거로 보존한다.
- `--normal-gc-probe`는 영상·오디오 캡처 없이 별도 프로필에서 정상 UI 입력으로 6분을 진행한다. 미리 할당한 숫자 행에 GC 세대별 증가와 현재/다음 프레임 시간을 기록한다. 이는 GC 슬라이스의 소요 시간 자체를 측정한 자료는 아니다.

Core·실행 데이터·수치 변경은 없다. #126·#98·1b 및 별도 C05 측정 보류는 유지한다. 전체 .NET 검사는 CI에 맡기며 로컬에서 중복 실행하지 않는다.

## 검증 기록

최초 Unity 컴파일의 `Game.Debug` 이름 충돌과 테스트의 아트 프로필 불일치는 수정했다. 실패 로그는 `artifacts/golden-minute/landscape-205/`에 보존한다. 집중 EditMode 03은 35개 중 34개 통과·실패 0·1개 생략이다. 생략은 Unity Mono가 할당 바이트 카운터를 지원하지 않는 큐 검사이며 무할당 통과로 부르지 않는다. 독립 코드 검토에서 발견한 첫 카드 도움말 null 참조와 가장자리 화살표 누락을 수정하고 재검토했다.

최종 집중 EditMode 04는 60개 중 59개 통과·실패 0·같은 할당 카운터 1개 생략이다. 경험치 알림은 표시 중 문구를 보존하면서 4종 대기를 합치고 XP 합계를 유지한다. 실제 7·8건 연속 수집 회귀를 포함한다. 자동 카드 선택의 컨테이너 의존도 공통 버튼 이름으로 제거했다. 독립 최종 소스 검토에서 추가 차단 결함은 없었다.

네이티브 캡처·약한 빌드 결과·GC 관측과 배포 링크는 실제 실행 후 아래에 추가한다. 정적 검사로 실제 가로 화면을 통과 처리하지 않는다.

첫 네이티브 `a8c2f31/ui-01`은 세 해상도 모두 전경·정확한 크기였으나 실패했다. 1920×1080의 화면 밖/잘린 요소25개, 1440×900의 본문 넘침2개가 있었고 1280×800은 기하 검사상0개였다. 창 크기는 바뀌었지만 Canvas 배율·RectTransform 크기가 늦게 갱신된 것이 원인이다. 생성 전 배율 동기화와 실제 UI 크기 캐시를 추가하고 첫 이동 도움말을 HUD 안으로 옮겼다. 집중 EditMode 05는61개 중60통과·0실패·할당 카운터1생략이며, 지연된 배율 회귀를 포함한다. 첫 실패 캡처는 보존한다.
