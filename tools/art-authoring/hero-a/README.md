# A 기사: 승인된 실시간 영웅 바인딩 (#254)

사용자가 M1-2에서 A 기사와 (c) Unity 2D Animation을 선택했다. 기존 B의 원화·굽기·비교 리소스는 수정하지 않는다. 적은 기존 굽기 방식이다.

`Resources/HeroKnight/parts.png`는 생성 원본을 바이트 그대로 복사했다. 코발트 망토, 금발, 상아 누비옷의 13개 부위를 `rig.json`의 원본 픽셀 사각형·피벗으로 연결한다. 원본은 규칙적인 4×4 셀 경계와 다르므로 실제 부위 경계를 쓴다. 검은 기존 `HeroMotion/sword`를 공유한다. 픽셀 재도색·알파 삭제·새 SDK는 없다. 원본 식별자와 SHA-256은 `generation-provenance.json`에 있다. `generation-prompts.txt`에 초기 요청의 재구성 요약과 후속 수정의 실제 프롬프트를 구분해 기록했다. 요약을 원문으로 취급하지 않는다.

## 재생성

```sh
node tools/art-authoring/hero-a/preview.mjs
```

기존 B 오프라인 합성기를 읽어서 A 입력·독립 출력으로만 실행한다. B 도구와 리소스를 덮어쓰지 않는다. 결과는 `artifacts/m1-254/hero-a-authoring/`의 15자세 실제 크기 표본·관절·발바닥 계측이다. A의 발바닥을 다시 맞춘 관절과 발바닥 좌표를 `Resources/HeroKnight/motion-runtime.json`에 기록한다. 런타임은 거리에 따른 걷기 위상을 유지하고 연속 보간한 A 발바닥 위치를 기존 접촉 목표에 맞춘다.

## 일곱 동작

| 동작 | 표현 |
| --- | --- |
| 서기 | 13번째 서기 관절 표본 |
| 걷기 | 이동 거리 기반 12자세 연속 관절 보간 |
| 이동 중 철날 검 | 하체 걷기 + 상체 swing |
| 진화 큰 휘두름 | 하체 걷기 + 상체 evolved-swing |
| 피격 | 하체 유지 + 우선하는 hit |
| 쓰러짐 | 발바닥 기준 관절 전체를 0.55초에 걸쳐 눕힘 |
| 레벨업 | 공격·피격이 없을 때 0.6초 검 든 팔 경례 |

마지막 두 시간은 화면 표현 값이며 Core 규칙·해시를 바꾸지 않는다. 쓰러짐·레벨업은 프로시저 관절 층이고 별도 원화 프레임으로 과장하지 않는다. 오프라인 15자세 표본은 서기·걷기·단일 공격·피격 바인딩만 확인한다. 일곱 동작의 실제 Unity 실행, 자연스러움·발 미끄러짐·성능은 별도 실행 검증 대상이다.
