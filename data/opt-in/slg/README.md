# SLG 콘텐츠 초안 v1 — [가설]

[작업 #571](https://github.com/hyunlord/bs-mobile/issues/571)의 검토용 단일 팩이다. `content-draft-v1.json`은 병종 3종, 영웅 3명, 연구 Lv1 노드 10개, 월드 조우 5종(몬스터 3·거점 2)을 담는다. `runtimeEnabled:false`이며 실제 게임 로더·기존 콘텐츠 manifest에 등록하지 않는다. 이 파일의 `slg:` ID는 초안 내부 참조이며 런타임 ID 등록을 의미하지 않는다.

## 근거와 새 제안

| 영역 | 유지한 설계 | 이번 초안에서 추가한 [가설] |
|---|---|---|
| 병종 | [GDD15](../../../docs/design/gdd/15-slg-troops-proposal.md)의 징집 창병·방패 수비병 훈련/치료 비용과 시간, 병영 상한 | 세 병종의 전투 계수, 낮은 체력·빠른 이동의 근접 척후 창병. 기존 GDD의 승인된 2병종을 3병종으로 변경한 것으로 보지 않는다. |
| 영웅 | [GDD16](../../../docs/design/gdd/16-slg-heroes-proposal.md)의 농로 길잡이·강가 수호자·폐허 탐구자 ID/등급 | Lv1·승급0 기본 계수, 지속 능력과 자동 발동 스킬. 이동 표식·상비군 엄호·성장 작업 표식이며 새 전투 버튼은 없다. |
| 연구 | [GDD17](../../../docs/design/gdd/17-slg-research-proposal.md)의 기존 9개 ID·이름·Lv1 비용/시간·선행 조건 | 10번째 ‘영주 교련’은 기존 영주 공격 판 상한 안의 +2%. 연구 속도·추가 대기열·병력 상한 증가를 넣지 않는다. |
| 월드 | [GDD18](../../../docs/design/gdd/18-slg-world-map-proposal.md)의 적재·부상·서버 정산·개인 판 대체 경로 | 밭 진드기·숲 말벌·언덕 골렘·폐허 표식·강가 초소의 목표, 시간, 유한 자재 및 지정 실증/구역 연결. 기존 적 ID는 그림·설계 참조만 한다. |

`proposalOrigin:gdd-baseline`은 해당 레코드에 설계 문서의 원형이 있다는 뜻이다. 새로 적은 전투 계수까지 승인되었다는 뜻은 아니다. `new-draft`의 병종·능력·연구·조우는 구현 전에 별도 검토한다. 모든 게임 수치는 상속한 GDD 값도 포함해 **[가설]**이다. 초·미터·정수 자원·백분율 단위는 `units`와 필드명으로 명시한다. `5 percent`는 +5%이며 배수 5가 아니다.

## 판이 지도에 남기는 변화와 상한

가신·영웅 성장·지속/자동 능력·연구는 같은 domain으로 합산한 뒤 `sharedCaps`를 한 번 적용한다. 출정 때 효과·대상·계수·콘텐츠 버전을 고정한다. 자동 스킬의 지속 시간·재사용 대기·대상 제한도 그 스냅샷의 규칙이며 판 중 계정 변경으로 갱신하지 않는다. 임시 소환 병사는 상비군 연구 효과 및 병력 정산에서 제외한다. 속도 효과의 시간은 `ceil(기본초 / (1 + 상한적용보너스% / 100))`이며 같은 비율만큼 시간을 빼지 않는다. 보관시간은 `min(18000, max(지도 기본/분기 보관시간, 기존 효과 E 하한) + 연구 추가초)`로 계산하므로 18,000초는 기본시간까지 포함한 최종 상한이다.

스킬 반경은 영웅 중심의 발동 감지·수혜자 선정 범위다. `maxTargets`는 감지한 적/목표 수가 아니라 효과 수혜자 수다. 길잡이·탐구자는 자신 1명, 수호자는 가까운 상비군 최대 5명이며 동률은 안정된 entityId로 정한다. 발동 시 선정하고, 반경 밖으로 나간 수혜자는 반경 효과를 받지 않으며 지속 중 다른 대상으로 교체하지 않는다.

각 조우는 지정 목표 달성으로 공유 월드 대상의 위협 제거/거점 회복을 기록하고, 지정 r8 구역의 되찾기 자격 또는 이름 있는 연구 실증을 남긴다. **자격은 무료 개방이 아니다.** 인접 구역·건물 조건·비용은 그대로 충족해야 한다. 실증도 해당 목표 달성으로만 기록한다. 서버가 `runId`와 `targetId/generation`을 검증해 결과와 지급 권리를 한 번 확정하고, 귀환 정산도 한 번만 한다. 이미 획득한 구역 자격·실증을 중복 지급하지 않는다.

세계 자재는 출정 병력 N×10 이하의 후보량이며, 승리 후 생존 병력 S×10을 다시 적용한다. S=0이면 0, 적재하지 못한 초과분은 우편으로 보내지 않는다. 기본 기사·병력0·자원0의 개인 판은 연구·수집 영웅 없이 무료로 열리며, 지정 목표의 실증/자격을 얻을 수 있다. 개인 판의 자재 및 보류 자재 상한은 각각 60[가설]이며 공유 월드 대상은 바꾸지 않는다. 판 시작 때 보류 자재의 남은 여유를 예약하고 그 한도 안에서 후보 보상을 표시한다. 기본 기사가 이미 행군/판에 잠겨 있으면 서버가 귀환·잠금 해제를 확정한 뒤 참가하며, 같은 기사를 복제하지 않는다. 이 초안은 연구 선행 실증 때문에 초반 진행이 막히지 않도록 10개 실증 모두에 개인 판 경로를 명시한다.

## 검증 범위

정적 스키마·참조·개수·상한 검사는 구현 가능성/밸런스 검증과 다르다. `contracts.validationStatus.schema:PENDING`은 초안 파일 안에서 검증 통과를 자체 선언하지 않는 고정 표기다. 실제 정적 검증 결과는 검사 명령 출력과 PR 증거에서 확인하며, PENDING이 검사 미실행을 의미하지는 않는다. 서버·Unity·실기·밸런스는 **NOT_RUN**이다. 기존 콘텐츠 트리 해시 및 역사 리플레이는 변경하지 않으며, 향후 구현 시 새 opt-in 스냅샷/리플레이 계약과 서버 검증이 별도로 필요하다. 신규 레코드가 런타임에서 실제 작동한다고 주장하지 않는다.
